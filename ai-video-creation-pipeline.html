AI 做视频全流程：选题·写稿·数字人·生成·剪辑·发布一条龙 + 赚钱案例拆解

📅 2026-06-21 🔍 ~50 次检索 + 6 证据包核查 🎬 逐环节工具 × 三档成本 × 赚钱真相 🌏 场景：马来西亚新山(JB)本地知识科普频道

一句话定调：「全自动 AI 量产视频」不是省钱捷径，而是 YouTube 2025–26 正在系统性清洗的死路；真正能活、能赚钱的配方是「AI 把体力活提速到 1/4，人把住独特观点 / 本地洞察 / 创作判断」。你朋友选的「新山本地知识」方向是对的——JS-SEZ、RTS Link、跨境生活、JB 房产这些恰恰是 AI 复制不了的护城河。

本报告按制作流水线展开：核心判断与 YouTube 政策风险（Ch1）→ 收集选题（Ch2）→ 写稿（Ch3）→ 配音（Ch4）→ 数字人（Ch5）→ 画面生成（Ch6）→ AI 剪辑工具（Ch7）→ 代码驱动剪辑（Ch8，直接回答「Codex / Claude Code 怎么剪视频」）→ 一条龙 workflow（Ch9）→ 成本三档（Ch10）→ 封面 SEO 发布（Ch11）→ 赚钱案例与残酷真相（Ch12）→ 新山本地落地（Ch13）→ 给朋友的路线决策树（Ch14）。所有工具能力与定价标注「截至 2026-06-21」，关键数据标 🟢多源 / 🟡单源存疑 / 🔴高度存疑；收入与成功率类一律标幸存者偏差。

📌 三条最关键发现（先扫这个）：

  • 全自动量产 ≠ 赚钱，反而撞 YouTube 枪口。YouTube 2025-07-15 把「重复性内容」政策升级为「inauthentic content（缺乏真实创作）」[1]；2026-01 一次性清退多个 AI 量产频道（媒体调查统计约 16 个、合计约 47 亿播放 / 3500 万订阅 / 估算约 1000 万美元年广告——此组数字来自单一媒体调查 + 估算，仅说明执行风险 🟡）[2]；约 97% 的 faceless 频道从未达到变现门槛（营销来源的警示性估计、非权威总体统计 🔴）[3]。但「政策升级」本身是官方事实 🟢：YouTube 不禁 AI 辅助（脚本/配音/剪辑），禁的是「没有人类创作判断的自动化流水线」。
  • 马来西亚 RPM 全球垫底，纯本地受众靠 AdSense 不划算。大马 CPM 约 $1.31（东南亚最低），新加坡 $2.08（高约 59%），美国 $5.33（4 倍+）[4]。结论：必须英文主导触达新加坡 + 全球华人，中文辅助大马华人，并把变现多元化（成功频道 AdSense 只占 30–50%，本地房产开发商品牌合作才是真人频道的筹码）。🟢
  • 「Codex / Claude Code 剪视频」= 写并运行脚本做「程序化剪辑」，不是操作 GUI 时间线。底层栈是 ffmpeg / ffmpeg 8.0 内置 Whisper / MoviePy / Auto-Editor / Remotion / Shotstack / mcp-video[5]。能做批量烧字幕、按转写切片、去废话、套品牌模板、数据动画、跨视频批处理；不能做审美精剪、节奏、创意转场、故事弧、视觉质检（mcp-video 官方明确要求人工审、不可全自动发布）[6]。它不「配合」Premiere/FCP，配的是 CLI/API。🟢

01核心判断：全自动量产是死路，AI 提效 + 人把关本地洞察才活▾

开篇必须泼一盆冷水，因为这个领域 90% 的内容是卖课软文，标题永远是「AI 月入 X 万」「5 分钟一条视频」。真相是：纯 AI 全自动量产视频，在 2026 年的 YouTube 上不是低成本捷径，而是结构性死路。把这一点想透，你朋友才不会把钱和时间砸进一个被平台主动清洗的赛道。

YouTube 的政策风向已经转了——而且转得很硬

2025–2026 这一年里，YouTube 对「AI 量产 / 缺乏真实创作」的内容连续出手，这不是猜测，是平台官方 + 多家科技媒体多源确认的事实，必须当成「结构性风险」郑重对待：

⛔ 时间线：YouTube 系统性打压 inauthentic content

  • 2024-03-18 引入披露工具 → 2025-05-21 起强制执行：YouTube 2024 年 3 月在 Creator Studio 引入「真实感合成/AI 内容」披露工具，2025-05-21 起在全平台强制要求披露，持续不披露可能被人工加标、移除内容或暂停 YPP[7]。🟢
  • 2025-07-15：YPP（合作伙伴计划）政策更新，把原本针对「重复性内容（repetitious content）」的措辞升级、明确为打击「inauthentic content」——批量模板克隆、AI 幻灯片、合成无情感语音、每日机械量产都在射程内[1]。🟢
  • 2026-01：媒体调查报道 YouTube 单次清退约 16 个 AI 量产频道，合计约 47 亿次播放、3500 万订阅、估算约 1000 万美元年广告收入被切断[2]。🟡（来自单一媒体调查 + 估算，非平台透明报告；量级方向可信、具体数字存疑）
  • AI 音乐频道 40%+ 被取消变现：纯 AI 生成的音乐合辑类频道是重灾区[2]。🟡

关键不在「YouTube 反 AI」——它不反 AI 辅助。你用 AI 写脚本、AI 配音、AI 剪辑都没问题。它反的是「没有人类创造性判断的自动化流水线」：把一个模板套一万次、把别人的内容用 AI 改写量产、用合成语音念维基百科配幻灯片。存活下来的 faceless（不露脸）频道的共性是：独特观点、动态剪辑、可见的创作判断[3]。

为什么「新山本地知识」这个方向选对了

本地超本地知识（具体街道、商户、政策、跨境生活细节）恰恰是大语言模型的幻觉重灾区——LLM 优先「流利」而非「准确」，超本地话题几乎没有可靠训练数据，极易编造[8]。这是双刃剑：自动化做本地内容会编错（Ch2 详述如何用 RAG 防），但反过来——真人创作者在 JB 生活、真的知道 RTS Link 怎么通勤、真的懂新柔特区政策怎么影响房价，这正是 AI 抄不走的护城河。

✅ 本章结论：务实路线 = AI 辅助 + 真人本地洞察 + 英文主导双语 + 多元变现

别全自动量产（会被 YouTube 清）、别纯靠 AdSense（大马 RPM 垫底）、别押文生视频做主画面（跨镜一致性是硬伤）。把 AI 当「把 4–8 小时压到 1–2 小时」的提效工具，把人留在「观点、本地事实核实、创作判断」上。后面 13 章是这条路线的逐环节施工图。

02信息收集 → 选题：用 RAG 防 AI 编造本地事实▾

视频制作的第一道工序是「收集资料 + 定选题」。这一步决定了天花板——选题错了，后面做得再精也白搭；本地事实错了，频道公信力一夜崩塌。

收集 + 整理的黄金搭档：Perplexity + NotebookLM

Perplexity（找）+ NotebookLM（防编造）。Perplexity Deep Research 做主题扫描，免费层每月 1 次 Deep Research，Pro $20/月给到每天 20 次[9]；NotebookLM 免费，能吃 PDF / Google Doc / YouTube 字幕，把你的资料变成一个「只许从上传文件里答」的问答库[10]。🟢

⚠️ 本地知识是 AI 幻觉重灾区——必须人工 + RAG 双重把关

GPT-4 在一般知识上都还有约 5–10% 错误率（Springer 2025）[8]，到了「JB 某条街哪家店、新柔特区某条具体政策、RTS Link 某个班次」这种超本地话题，模型几乎没有可靠训练数据，编造率飙升。解法是 RAG：把本地可信资料（政府官网 PDF、本地新闻、采访录音、自己实地拍的资料）传进 NotebookLM，强制答案只来自上传文件并附引用。Hoodline 那个用 AI 生成本地新闻、编造事实损毁公信力的教训就在眼前[11]——本地频道一旦被发现编错本地事实，信任很难找回。🟢

03写稿：AI 写稿四阶段法 + 五大通病 + 本地事实核实▾

脚本是知识类视频的灵魂。AI 能帮你写稿，但「一口气让 AI 写完整稿」是最烂的用法——出来的东西平、假、像写的不像说的。最佳实践是分段迭代 + 人收口。

George Blackman 四阶段写稿法

1对话发想角度
先跟 AI 聊，把「角度 / 切入点」吵清楚——这个视频到底要让观众明白什么、为什么是你来讲。不要急着写正文[15]。
2逐段从 payoff 倒推 hook
一段一段写，每段先想清楚「这段给观众什么回报（payoff）」，再倒推开头怎么钩住（hook）。绝不一次生成全稿[15]。
3人改一段 → 粘回让 AI 学风格
你亲手改完一段，把改后的版本粘回去，让 AI 学习你的语气和节奏，再写下一段。这样 AI 越写越像你[15]。
4朗读收口
全稿写完大声朗读一遍——读着别扭的地方就是「像写的不像说的」的地方，当场改顺。这一步是质量分水岭[15]。

AI 脚本五大硬伤（写完自查）

逐条对照，命中就改[15]：

  • 开头宣告而非悬念——「今天我们来聊聊 X」是劝退句，应该用钩子制造好奇。
  • 前 1/3 就把问题解决完——后面没张力，观众划走。
  • 没有 open loop——不埋「待会儿揭晓」的扣子，留不住人。
  • 像写的不像说的——书面长句、从句套从句，口语里没人这么说话。
  • 结尾是总结而非视角转变——好结尾应该给观众一个新的看世界的角度，而不是复述前面讲过的。

Shorts vs 长视频，写法完全不同

Shorts（短视频）要在前 1–2 秒抓人、单一信息点、无废话；长视频靠 open loop 和叙事弧维持留存。同一个选题写两套稿。实操上多数人用 Claude / ChatGPT + 自定义 prompt 就够了，不必另外付费买脚本工具；Claude 在结构化 prompt 跟随上比 GPT 更稳 🟡[16]。

⚠️ 最关键一步——本地事实人工核实：AI 写的本地内容（具体票价、班次、政策条款、地名）必须逐条人工核对来源，这是本地频道的生命线。所谓「89% 创作者说 AI 脚本不真实」这个数字来自单一有商业利益的来源（Scriptzen），定性方向可信、具体数字存疑 🔴[17]——但「人工必做朗读 + 设具体讲述角色 + 本地事实核实」这三件事，无论数字真假都该做。

OpenAI TTS 支持马来语和中文、价格很便宜，自助层主要用预设声音——它确有 custom voice 能力，但属 gated/合规审核功能（需符合资格 + consent 录音），不能当成普通低价克隆替代 ElevenLabs[18]。如果频道不靠「个人声音 IP」（比如纯旁白讲解、不露脸不强调本人），OpenAI TTS 或本地免费的 Kokoro（见 Ch10）够用且省钱。但如果朋友想建立「本人 IP」（露脸 + 自己声音），就值得花 ElevenLabs 的克隆钱。🟢

恐怖谷 trade-off：自己的脸反而更挑剔

08剪辑（二）代码驱动：Codex / Claude Code 到底怎么剪视频▾

这一章直接回答你朋友的核心问题——「Codex / Claude Code 怎么直接剪视频？配合什么剪辑软件？」

📌 一句话本质：Codex/Claude Code 剪视频 = 写并运行脚本做「程序化剪辑」，不是操作 GUI 时间线

它不像人一样去 Premiere 里拖时间线、点剪刀。它做的是：你用自然语言下指令，AI 写出一段调用 ffmpeg / Remotion 等工具的脚本并运行，让命令行/代码去完成裁剪、拼接、烧字幕、套模板。所以它「配合的软件」不是某款 GUI 剪辑软件，而是一套 CLI 工具和 API。🟢

底层栈（AI 实际调用的工具）

① ffmpeg —— 万能命令行瑞士军刀

裁剪、拼接、转码、加字幕、变速、改分辨率全能做，是所有程序化剪辑的地基[5]。AI 最常做的就是帮你写 ffmpeg 命令。

② ffmpeg 8.0 内置 Whisper（2025-08）

ffmpeg 8.0 把语音识别 Whisper 直接内置——一条命令就能转写 + 烧字幕，不用再串第三方工具[5]。对知识类视频的批量上字幕是甜点。🟢

③ MoviePy v2 —— Python 视频合成

用 Python 代码合成视频（叠图层、文字、转场），适合 AI 生成可读可改的剪辑脚本[5]。

④ Auto-Editor —— 按音量自动去静音

检测音量自动剪掉静音段/废话停顿，知识口播去废话神器[5]。

⑤ Remotion —— 用 React 代码渲染视频

React 代码渲染数据驱动动画 / 模板 / 动态字幕 / Shorts 批量。「程序员的视频模板引擎」——做品牌片头、数据可视化、批量套模板的标准答案[5]。

⑥ Shotstack —— JSON → 云渲染 API

把视频描述成 JSON，发给云端渲染，不占本地机器[5]。适合规模化/服务器端 pipeline。

⑦ mcp-video（KyaniteLabs）—— 119 个 MCP 工具包 ffmpeg

把 ffmpeg 的能力封装成 119 个 MCP 工具供 Claude Code 等 agent 直接调用，带预检护栏。但官方明确警告：agent 生成的视频必须经过 video_quality_check + 人工审核，不可直接自动发布[6]。🟢

不配某款 GUI 剪辑软件。Codex / Claude Code 不跟 Premiere / Final Cut「配合」——它们配的是 ffmpeg / Auto-Editor / Remotion（本地运行）+ Shotstack / mcp-video（云 API）这些 CLI 和 API 工具[5]。如果一定要接到 GUI 做后续人工精剪，目前最近的桥是 Gling 的 XML 导出：让 AI 先出粗剪 XML，人再导进 Premiere 精调[33]。🟢

⚠️ Codex 专属案例少：目前公开的「AI 写脚本剪视频」案例几乎全是 Claude Code + ffmpeg，OpenAI Codex 专门的视频剪辑案例很少。两者原理一致（都是「让 LLM 写并运行剪辑脚本」），但如果你朋友要找现成教程/模板，搜 Claude Code 会比搜 Codex 多得多。🟡

一个可复现的 pipeline 案例（MindStudio）

MindStudio 给出过一条 Claude Code 当 orchestrator 的全程 pipeline：ffmpeg 规范化 → VideoUse 检测静音/场景 → Hyperframes 模板叠 intro/字幕/logo → ffmpeg 多格式输出，成本约 $1.5–3.6/视频[36]。🟡（单源，数字仅供量级参考）这条案例说明：对会写代码的人，程序化剪辑能把「重复机械的剪辑动作」自动化到很低边际成本——但它处理的是「规范化 / 检测 / 套模板 / 输出」这类机械活，不是替代人的创意精剪。

变现双轨：本地品牌 + 出海受众

真人频道在变现上比纯 AI 有谈判筹码。本地房产开发商 Sime Darby / IOI / EcoWorld、新加坡跨境服务商、旅游局都是潜在品牌合作方[43]——他们要找的是有本地可信度的真人创作者，不是 AI 量产号。变现双轨：① 本地品牌赞助（房产/服务/旅游）；② 出海受众的 AdSense + 联盟（针对新加坡/全球华人投资者的高 RPM）。🟢

⚠️ 一体两面：JB 本地知识大频道是空缺——机会，也是无验证先例。这个 niche 没有现成的大频道可以参照，意味着没有竞争（机会），但也意味着没人验证过这条路能跑通、本地知识频道真实收入数据缺失、大马品牌赞助具体费率也查不到 🟡。所以策略上要「先窄跑通验证」而不是「一上来重投入」（Ch14）。

15FAQ 常见问题▾

Q1Codex / Claude Code 真能「直接剪视频」吗？还是噱头？＋

能，但要理解它的本质：它不是去 GUI 里拖时间线，而是写并运行调用 ffmpeg / Remotion / Auto-Editor 等工具的脚本来完成程序化剪辑[5]。所以它擅长「批量烧字幕、按转写切片、去废话、套模板、跨视频批处理」这些机械活，做不了「审美精剪、节奏、创意转场、故事弧、视觉质检」。mcp-video 官方都明确要求人工审、不可自动发布[6]。一句话：把它当「自动化机械剪辑动作的工具」，不是「替代剪辑师」。

Q2那 Codex 配合哪个剪辑软件用？Premiere 还是 FCP？＋

都不是。它不跟某款 GUI 剪辑软件配合，配的是 ffmpeg / Auto-Editor / Remotion（本地）+ Shotstack / mcp-video（云 API）这些命令行和 API 工具[5]。如果一定要接到 Premiere 做人工精剪，目前最近的桥是 Gling 的 XML 导出——AI 出粗剪 XML，人导进 Premiere 精调[33]。另外提醒：公开案例几乎全是 Claude Code + ffmpeg，Codex 专门的视频案例很少，找教程搜 Claude Code 更多。

Q3用 AI 做数字人出镜，YouTube 会不会封我？＋

用数字人本身不违规，但有两条线要守：① 必须按 YouTube 规则披露合成内容（2024-03 起要求、2025 执法）[7]；② 别用数字人做「全自动量产」——那才是被清洗的对象[1]。数字人当「真人出镜的补充」（批量次要内容、多语言版本），合规可用；当「无人值守量产工厂」就危险。还有一点反直觉：自己脸的高仿真 clone 反而更易触发恐怖谷[22]，知识口播能过门槛但有信任折扣。

Q4ElevenLabs 克隆我朋友的声音说马来语/中文，自然吗？＋

官网标支持马来语和中文，且能跨语言用同一个克隆声音[18]，但「实际口音自然度」必须自己实测——印尼语和马来语模型可能混、中文可能带腔 🟡。建议：用免费即时克隆录一段，生成马来语和中文各一段，让本地人盲听判断再决定要不要花 $22 上专业克隆。不需要本人声音 IP 的话，OpenAI TTS 更便宜（但不能克隆）。

Q5文生视频（Sora/Kling/Veo）能直接做知识视频的主画面吗？＋

不建议当主画面。跨镜一致性是所有文生视频的硬伤——人物面孔无法跨镜统一，平均要生成 3–5 次才出 1 个可用片段[25]。文生视频最成熟的用例是 B-roll（自然景观、数据动画、抽象概念）。知识类正确打法是「实拍新山街景 + Pexels 通用免费素材 + AI 概念 B-roll」三合一。另外 Sora 消费版 2026-04-26 已停服、API 虽仍可用但 2026-09-24 sunset，别拿它做新 pipeline 的依赖[26]；性价比首选 Kling。

Q6为什么不能纯做大马本地受众？我朋友就在大马啊。＋

因为大马 RPM 全球垫底——CPM 约 $1.31（东南亚最低），而新加坡 $2.08、美国 $5.33[4]。纯大马受众靠 AdSense 收入极薄。但你朋友有独特优势：JB 本地知识的天然受众恰恰是新加坡人和海外华人投资者（JB 外来房产投资 51.8% 来自新加坡）[43]——他们 RPM 高、又真的想了解 JB。所以策略是「人在 JB、内容讲 JB、但用英文主导触达高 RPM 的新加坡/全球受众」。

Q7「AI 视频月入几万」的案例是真的吗？＋

极少数是真的，但全是幸存者偏差 + 卖课扭曲。最常被引的 Noah Morris 自述月入 $3–20 万，但他 2025 初被 YouTube 封号单月损失 $25 万，而且他自己在卖工具[40]。真相是：约 97% 的 faceless 频道从未达变现门槛，变现前累计投入 $5k–26k，起号到有意义收入要 6–24 月[3]。这些「吓人数字」也多来自有卖工具动机的来源，但方向和独立分析吻合 🔴。把「月入 X 万」当个例看，别当预期。

Q8起步该花多少钱？买全套高配工具吗？＋

别。先走务实档 ~$50–100/月（脚本 Claude/ChatGPT $20 + 配音 ElevenLabs $22 + 剪辑 DaVinci/CapCut 免费 + 封面 Canva），先做 10 条验证选题[38]。高配档 $412/月在选题没验证前是纯浪费。注意 HeyGen Avatar IV 是 20 credits/分钟、Creator 600 credits 只够约 30 分钟/月——走数字人要算清产能[20]。验证出方向后再升级。

Q9AI 会不会把 JB 本地事实写错？怎么防？＋

会，而且很容易错——本地超本地知识是 AI 幻觉重灾区，模型几乎没有 JB 具体街道/商户/政策的可靠训练数据[8]。两道防线：① 用 RAG——把政府官网 PDF、本地新闻、采访录音传进 NotebookLM，强制答案只来自上传文件并附引用[10]；② 人工逐条核实票价、班次、政策条款这些硬事实。Hoodline 用 AI 编造本地新闻损公信力的教训就在眼前[11]——本地频道一旦被发现编错，信任很难找回。

Q10真的能「5 分钟出一条视频」吗？＋

不能，那是卖课标题。真实产能：全自动 pipeline 宣传 10–15 分钟、实际约 30–60 分钟/条（含审核迭代）；半自动约 30–50 分钟；带数字人约 1–2 小时[27]。AI 的真实价值是把传统 4–8 小时的制作压到 1–2 小时——这已经很好，但别被「量产神话」误导预期。那句「12 秒 AI magic 实际花了 6 小时 prompt + 20 次失败渲染」是真实写照。

Q11小红书 / 视频号能用 AI 一条龙自动发吗？＋

基本不能自动。主流多平台分发工具（Buffer / Repurpose / Opus Clip）不原生支持小红书和微信视频号[39]，要发这两个平台得手动搬。对要触达中国大陆/全球华人的内容这是个手工活成本，规划产能时要算进去。YouTube / TikTok / IG 这些海外平台的自动分发是支持的。

Q12数字人的开源免费方案值得折腾吗？＋

对商业自媒体不太值。MuseTalk（腾讯，MIT，2026 最佳免费口型同步）、SadTalker、Wav2Lip 这些开源工具需要 NVIDIA GPU、技术门槛高[23]。你朋友的时间应该花在「本地洞察和创作判断」上，不是折腾 GPU 环境。建议直接用 HeyGen（$29 起）省心。想先免费试可以上 MuseTalk 的 HuggingFace Spaces 玩一下，但商业产能还是托管服务靠谱。
