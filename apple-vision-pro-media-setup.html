一句话：这套硬件能组成一个干净闭环——群晖只当仓库，Mac Studio 当转码+coding 发动机，AVP 当呈现端。三件事要分清坐标：① AVP 真正的杀手锏是 Apple Immersive Video（180°/8K/3D 全球独家），但在中国大陆不走 Apple TV，要装免费的咪咕/腾讯视频 app[2]；② 群晖影视库的铁律是「能直连就别转码」，2D/4K 用 Infuse、3D 必须换 Moon Player / SKYBOX（Infuse 到 2026 仍不能真 3D 渲染）[13]；③「边看片边瞄 vibe coding 进度」AVP 原生就支持，用普通 Environment + 窗口化播放，别进 Apple TV 影院模式（那个会藏掉 Mac 窗口）[20]。

01执行摘要：5 条最硬结论▼

4 路并行调研（AVP 资源 / 播放器 + 3D 格式 / 群晖 + 串流 / Mac Studio 联动）收敛出的核心判断，每条独立成块，方便扫。

⚠️ 结论 1：国内看 Apple 官方沉浸片，别在 Apple TV app 里找——它在大陆走咪咕/腾讯 🟢 多源

这是对阿杰最关键的一条。中国大陆不通过 Apple TV app 发布 Apple Immersive Video，而是走免费的「咪咕视频」「腾讯视频」app[2]。想看华语/中国题材沉浸内容还可装 iQIYI XR（2.5 万+ 片源）和「沉浸中国」（16K 北京/上海/西安/桂林，免费+内购，需 visionOS 2.6+）[7]。这条直接决定了你国内的内容入口。

⛔ 结论 2：3D 是硬分叉——Infuse 到 2026 仍不能在 AVP 上真 3D 播放 🟢 多源

Infuse（含 8.4.x，2026-05）在 AVP 上会把 SBS/OU/MVC 当 2D 放，不支持 MV-HEVC/frame-packed/3D 蓝光 ISO 的立体模式，Firecore 官方无 3D 时间表[13]。所以 2D/4K HDR 用 Infuse 当统一前端，真 3D 必须换 Moon Player / SKYBOX / Reality Player。这是全篇最容易踩的坑。

✅ 结论 3：群晖只当仓库，铁律是「能直连就别转码」 🟢 多源

AVP 解码强、群晖转码弱，正确策略是 Direct Play 直连不转码——4K HDR 直连优于转码（Plex 转码会把 4K HDR HEVC 压成 1080p H264 SDR、颜色发灰）[22]。这同时绕开了群晖 2025 新机型（X25 系列）砍掉硬件转码驱动的坑[23]。服务端推荐 Jellyfin（免费开源，Docker 跑在群晖上），比 Plex（2025 起远程要订阅、终身版 2026/7 涨到 750 美元）对只在家看的你更划算[26]。

🎯 结论 4：「边看片边瞄代码」AVP 原生支持，不用买第三方 app 🟢 多源

Mac Virtual Display 本身就是 visionOS 里的一个窗口，其他 visionOS app（Apple TV/Infuse/B 站等）作为独立窗口围绕它共存——这正是「沉浸看片 + 偶尔瞄 vibe coding」的技术基础[32]。唯一的坑：别进 Apple TV 自带的「影院 Cinema」模式，它会临时隐藏其他所有窗口、独占视野[20]。用普通 Environment + 数码表冠半沉浸 + 窗口化播放即可。

🧭 结论 5：Mac Studio 是这条链的发动机——转码 + coding 都靠它 🟢 多源

Apple Silicon Mac Studio 一身二用：① 把 3D 蓝光（MVC）走开源 BD_to_AVP、把已有 SBS/OU 走免费 Spatial 命令行工具转成原生 MV-HEVC（最高 8K，用 Apple 官方框架）[16]；② 同时跑 vibe coding，通过 Mac Virtual Display 投进 AVP。关键判断：你的 3D 片若已是 SBS/OU，其实不用转码，Moon/Reality/SKYBOX 直接播即可；连 3D 蓝光 MVC 都能用 4XVR 直接播、省掉转码（Codex 审查补充）[41]，Mac Studio 只在「想要 MV-HEVC 原生质量上限」时才上场[14]。

一句话路线建议

【存】片子放群晖，开 SMB（必开）+ DLNA（可选）。【转】Mac Studio 跑 BD_to_AVP / Spatial 把蓝光或 SBS 升级成 MV-HEVC。【播】AVP 上 2D 用 Infuse 接 Jellyfin 直连不转码、3D 用 Moon/SKYBOX 走 SMB 直连。【联动】Mac Virtual Display 投 coding 屏，普通 Environment 里大屏放片、侧边缩小放代码窗。先把「群晖+Jellyfin → Infuse 看 2D」这条最窄链路跑通，再加 3D、再加沉浸。详见第 12 章决策树。

⚠️ 最大前置未知：你的群晖型号 + 国内 App Store 可用性 🟡 待确认

本报告两个最影响落地的 gap：① 群晖具体型号未知——Intel 核显（有 Quick Sync 硬转）还是 AMD Ryzen（DS923+ 无核显软转）直接决定转码兜底能力，建议确认型号；但走「直连优先」可基本规避此差异[24]。② 已确认（Codex 实查纠正）：Moon ¥58 / Reality ¥58 / SKYBOX ¥68 都在大陆 App Store 上架[39]，3D 播放器不缺；但 大陆 Apple ID 基本无法购买 Apple TV 3D 租购（Apple 官方可用性页：大陆不含 Apple TV 电影购买，香港才有）[40]，要买只能用非大陆 ID 且自担账号/支付/区域风险。

🔬 跨模型审查说明（这份报告被 Codex 审过一轮）

本报告由 Claude 4 路并行写稿后，经 Codex (GPT-5.5) 四维度对抗审查（事实 / 深度 / 缺失 / 角度）。Codex 实查纠正/补强了几处：① 三个 3D 播放器大陆 App Store 价格已查实（Moon/Reality ¥58、SKYBOX ¥68）[39]；② 大陆 Apple ID 基本买不了 Apple TV 3D（官方可用性页佐证）[40]；③ 漏了 4XVR——它能直接播 MVC 3D 蓝光、推翻了"3D 蓝光必须先转码"的结论[41]；④ 修正了几处事实精度（阿凡达3 尚未上线、"超 IMAX"是体验向说法、Developer Strap 是开发件非观影推荐、M5 120Hz "更不晕"应表述为个体差异）。

Codex 提出、本版有意未展开的"落地前待实测"清单（先跑通最窄链路，别纸上过度细化）：

  1. NAS→AVP 3D golden path——用一部已知 SBS + 一部 MVC，实测 SMB / 各播放器谁能放、字幕音轨是否正常
  2. MV-HEVC 入库识别——转后文件能否被 Plex/Jellyfin 认成 3D 编排进库（本地 3D 库的命门）
  3. 群晖型号矩阵——CPU/核显/硬转状态决定转码兜底（直连优先可大幅规避）
  4. 字幕/音轨兼容——PGS/ASS/SRT + 中文字幕 + DTS-HD/Atmos 回退是否触发转码
  5. 舒适度规则——长片 + 瞄码的佩戴时长、眼疲劳、亮度/沉浸度、电池摆放、停看条件
  6. 远程观看——Plex 远程需 Pass、国内网络 + 家宽上行的实际码率上限，Tailscale 受阻时自建 WireGuard

02AVP 观影能力概览：两层坐标▼

把这层拆清楚是全篇坐标——AVP 上「看东西」分两条完全不同的轨道，混了就会买错 app、找错内容、产生错误预期。

2.1 两层结构定义

① Apple 原生 Immersive Video（独家轨道）

AVP 全球独家的 180°·8K·3D·空间音频沉浸格式，任何其他 VR 设备/电视都无法播放，到 2026-05 累计约 47 部[1]。这是 AVP 真正不可替代的杀手锏，但片量少、单部仅 15-30 分钟。

② 通用 2D/3D 影视巨幕（兼容轨道）

在虚拟影院/环境里把任意 2D 影视（流媒体、自有蓝光转录、Mac 串流）投成巨幕（屏幕可达约 100 英尺宽、micro-OLED 观感号称胜过普通影院投影 🟡 体验向）[6]，外加 200+ 部 3D 电影。非独家，但这是日常观影的主力。

③ 你的自有内容（NAS / Mac 串流）

阿杰这套的核心——群晖里的蓝光转录、3D 片，通过 Infuse / Moon / SKYBOX 串流播放，落在轨道 ② 里但要自己搭。详见第 8-9 章。

4.1 Apple Immersive Video 是什么、有多少

到 2026-05-21 累计约 47 部，分类：探险(5)/音乐(6)/体育(12)/纪录(6)/旅行(6)/剧情(5)等[1]。格式为 180°/8K/3D/空间音频，任何其他设备都播不了，多数在英美澳加港法德日新等地区的 Apple TV app 内免费——但大陆是例外，要经咪咕/腾讯[2]。

4.4 visionOS 26 把第三方拍摄内容拉进来了

visionOS 26（2025-09-15 发布）新增对 Insta360 / GoPro / Canon 的 180°/360°/宽视场内容支持，且可从网页直接播放沉浸视频；还引入「空间场景」（AI 给 2D 照片加深度）、Safari 空间浏览、HTML <model> 内嵌 3D[17]。意味着你自己用这些相机拍的 180/360 内容也能进 AVP。⚠️ 具体导入工作流细节本研究未深挖 🔴 待补研究。

4.5 老实说的短板

⛔ Apple 自家沉浸内容更新极慢、片量少、单部仅 15-30 分钟，被多家媒体批评。Bloomberg 称 Apple 故意「慢放」因制作成本极高；AppleInsider 批某片 5 分钟 54 个剪辑（平均 6 秒一刀）违背沉浸本意；用户难分辨什么是独家/原生/3D/仅兼容[10]。所以独家轨道是「点缀」，主菜还得靠你自己的库 + 流媒体 + YouTube VR180。

063D 格式深挖：MV-HEVC vs SBS/OU vs MVC▼

这章是整个 3D 链路的技术核心。搞懂三种格式的关系，才能判断「哪些片要转码、哪些不用」——这直接省你大量 Mac Studio 算力和时间。

6.1 三种格式的关系

格式来源AVP 能直接播？要不要转码特点
MV-HEVC (spatial)AVP 原生 3D 标准✅ 原生已是终点单 track 多 layer，质量上限最高[14]
SBS / Half-SBS / Full-SBS社区 x264 片源✅ VR 播放器直接播⛔ 不用转码Moon/Reality/SKYBOX 自动识别[14]
Over-Under (OU/TB)社区 x264 片源✅ VR 播放器直接播⛔ 不用转码同上，上下排列
MVC (frame-packed)3D 蓝光⚠️ 多数播放器不支持⚠️ 转码 / 或 4XVR 直读多数要转 MV-HEVC；但 4XVR 可直接播 MVC ISO/MKV，省掉转码[41]

🎯 一句话决策：你的 3D 片是 SBS/OU 吗？那不用转码 🟢 多源

MV-HEVC = 单 track 多 layer 共享帧尺寸（hero eye 主视 + 差异辅视），区别于 SBS。蓝光是 frame-packed MVC，必须转码；而 SBS/OU 的 x264 文件 Moon/Reality/SKYBOX 可自动识别直接播放，无需转码[16]。所以 Mac Studio 只在两种情况上场：(a) 蓝光 MVC，或 (b) 想把已有 SBS/OU 升到 MV-HEVC 的原生质量上限。

6.2 Full-SBS vs MV-HEVC：兼容 or 质量上限

Full-SBS 兼容最广但文件翻倍；MV-HEVC 可在比 SBS/OU 更高分辨率/码率下播放（质量上限更高）[19]。MakeSBS3D 把 FSBS 标为「推荐给多数人」因兼容最多播放器；但 Apple 用 MV-HEVC 把第二路画面以 2D 兼容方式存储，原生播放器实测 MV-HEVC 分辨率/码率上限高于 SBS/OU。即：要兼容选 FSBS，要质量上限选 MV-HEVC。⚠️ Half-SBS vs Full-SBS 在 AVP 上的实测画质损失量化数据缺 🔴 待补研究。

6.3 Mac Studio 转码工具链

✅ Spatial 命令行工具（SBS/OU → MV-HEVC，免费）🟢 多源

Mike Swanson 的免费 macOS 工具，输入 SBS/over-under/分离左右眼，输出 MV-HEVC spatial（AVP+Quest 通用），用 Apple 原生框架、最高 8K，可写 cdist/hfov 等空间元数据；要求 macOS Sonoma 14.0+ + Apple Silicon，Homebrew 安装[16]。命令如 ./spatial make -i over_under.mov -f ou -o out.mov。Mac Studio 算力适合批量。短板：命令行无 GUI、转码耗时占空间、需正确填空间元数据否则 AVP 不识别。

✅ BD_to_AVP（3D 蓝光 MVC → MV-HEVC，开源）🟢 多源

把自有 3D 蓝光/ISO/MKV/MTS（MPEG-4 MVC）转成 MV-HEVC 的开源 pipeline，GPL-3.0；要求 Apple Silicon（M1+）、macOS Sonoma、Python 3.12 + FFmpeg/Wine/MakeMKV/MP4Box/MKVToolNix/spatial-media-kit-tool；默认输出 left-right-bitrate 20Mb/s、MV-HEVC quality 75，可选 AI 升 4K + 字幕 OCR[16]。短板：依赖多、配置复杂（Wine/MakeMKV），可见最新版停在 v0.2.137（2024-07），2025/2026 维护状态未证实 🟡 单源；产物默认走 Files/Screenlit 播放。

⚠️ MakeSBS3D（GUI 化，beta）🟡 单源

GUI 化的 3D 蓝光/MKV 转 Full-SBS 或 MV-HEVC 工具，拖拽操作，可输出 FSBS（给 Moon/SKYBOX 直接播）或 spatial（给 Apple 生态），要求 macOS Sequoia/Tahoe[19]。比命令行友好，但仍 TestFlight beta、价格未定、稳定性待验证。

⛔ Synology 2025 新机型砍掉了硬件转码 🟢 多源

DS225+/DS425+ 等 X25 系列悄悄移除了 Plex/Jellyfin/Emby 用的内核显卡驱动，官方禁用了 H.264/HEVC 硬件转码（硬件 Intel J4125 含 Quick Sync 仍有能力，可 SSH workaround 解锁，但官方默认不支持）[23]。这进一步说明应走直连而非依赖群晖转码。

⚠️ Ryzen 群晖（DS923+）无核显，靠 CPU 软转 🟡 单源

DS923+/DS1522+（2025 改动前机型）技术上能转 4K，但 DS923+ 是 AMD Ryzen 无核显，靠 CPU 软转码而非 Intel Quick Sync 硬转，效率低[24]。阿杰型号未知，方案按直连优先即可规避此差异。

🎯 结论：别让群晖转码 🟢 多源

AVP 上的核心策略是「直连直播不转码」——4K HDR 直连本地/远程客户端优于转码，转码极耗服务器，且 Plex 会把 4K HDR HEVC 转成 1080p H264 SDR 导致颜色发灰[22]。Infuse 在 Apple TV 上能流畅直连播放同样让 Plex 转码卡顿的影片，说明直连 + 千兆网络 = 保画质 + 不压服务器。

09群晖 + AVP 看 3D / 纪录片的完整方案▼

把存储、编排、直连 vs 转码、带宽、远程串起来，给一条端到端可执行链路。

9.1 三层链路

① 存：片子放群晖，开 SMB（必开）+ DLNA/WebDAV（可选）。② 转：Mac Studio 是发动机——蓝光 MVC 走 BD_to_AVP、已有 SBS/OU 想升原生质量走 Spatial 命令行工具转 MV-HEVC[16]。③ 播：AVP 上分两类 app——2D/4K HDR 用 Infuse 接 Jellyfin 直连不转码、3D 用 Moon/SKYBOX 走 SMB 直连群晖[13]。

9.2 普通 2D/4K HDR：Infuse 直连完美

Infuse 当统一前端，连 Jellyfin 直连直播 MKV/MP4/ISO/VIDEO_TS/BDMV 不转码，支持 Dolby Vision(Profile 5&8)/HDR10/HDR10+/HLG、Dolby Atmos(E-AC3) passthrough，与 Plex/Jellyfin 双向同步观看进度[13]。需 visionOS 2.6+。这条线体验最佳。

9.3 3D：硬分叉，必须换播放器 + 蓝光先转码

⛔ Infuse 到 2026（8.4.x）仍不能在 AVP 真 3D 播放——SBS 当 2D 放，不支持 MV-HEVC/frame-packed/3D 蓝光 ISO 的立体模式[13]。3D 流程：3D 蓝光 → Mac Studio 用 BD_to_AVP 转 MV-HEVC（默认 20Mbps 双目码率）→ 存群晖 → AVP 用 Moon Player 或 SKYBOX 通过 SMB 直连播放（这俩才支持立体模式，SKYBOX 的 SBS 稳定性口碑更好）[16]。已是 SBS/OU 的片则跳过转码，直接 Moon/SKYBOX 播。另一条捷径（Codex 审查补充）：用 4XVR 可直接播 MVC 3D 蓝光 ISO/MKV，连转码都省了，改变了"3D 蓝光必须先转码"的结论[41]。

9.4 带宽与远程

✅ 局域网千兆 + 直连，4K HDR 毫无压力 🟢 多源

群晖到 AVP 走千兆局域网 + 直连直播，4K HDR 无压力；关键是别让群晖转码[22]。

💡 远程在外看片用 Tailscale 🟢 多源

基于 WireGuard 的零配置 VPN，免端口转发、能穿 CGNAT，让 AVP 在外网安全访问家里群晖；也是绕开 Plex 远程订阅的途径，Jellyfin 配它全程零订阅。VPN 加延迟但不限带宽，家里上行 50+Mbps 时 4K Direct Play 可用[21]。⚠️ 国内访问 Tailscale 控制面偶有连通性波动，若受阻可自建 WireGuard+VPS 中继（更复杂）🔴 待补研究。

⚠️ 待证实：转换后的 MV-HEVC 3D 文件能否被 Plex/Jellyfin 服务器正确识别为 3D 并编排进媒体库（而非仅 Files/Screenlit 直读），以及 Moon/SKYBOX 能否连 Jellyfin/Plex 服务器（而非仅 SMB/WebDAV），均未证实[16]。8K HDR 在 AVP+群晖链路的实测码率/带宽与 AVP 端解码上限未拿到具体数字 🔴 待补研究。

10.1 Mac Virtual Display 是什么

把 Apple Silicon Mac 桌面无线投到 AVP 成为一个可缩放的曲面窗口，支持 Standard 16:9（到 5K）/ Wide 21:9（到 6720×2880）/ Ultrawide 32:9（到 10240×2880，等效双 5K 并排），Ultrawide 靠注视点渲染（foveation）实现 10K 横向分辨率[32]。它本身是一个 visionOS 窗口，可与其他 visionOS app 窗口共存——这是第 11 章「边看边瞄」的基础。免费内置。

10.2 设置步骤（Mac Studio 无屏台式机版）

  1. Mac Studio 确认 macOS 15.2+（Sequoia 及以上，Ultrawide/Wide 要求），AVP 升到 visionOS 2.2+（最好 visionOS 26）[32]。
  2. 两设备同一 Apple ID + 开双因素 + 开 iCloud 钥匙串 + 开 Handoff，Wi-Fi+蓝牙都开，两机 10 米内[32]。
  3. 戴上 AVP 开控制中心选 Mac Virtual Display 连 Mac Studio（Studio 是台式机没屏幕，从控制中心选即可，不用「看着屏幕点连接」）。⚠️ 此 UI 路径为通用推导，未逐字截图确认 🟡。
  4. 连上后点窗口上方按钮选 Standard / Wide / Ultrawide。

10.3 画质 / 延迟取舍

⚠️ 无线画质强依赖 Wi-Fi，瓶颈在「AVP↔路由器」这段 🟢 多源

Mac Studio 自身走有线网，瓶颈在 AVP↔路由器的无线段——务必 Wi-Fi 6/6E/7 且 AVP 离路由近，否则虚拟屏会卡顿；用户普遍反馈卡顿、降分辨率不解决、Wi-Fi 中继器会更糟[34]。

🛠️ Developer Strap 有线 20Gbps（开发/诊断向，非日常观影推荐）🟡 单源

新版 Developer Strap 通过 USB-C 给 AVP 提供 20Gbps 有线连接（旧版仅 USB2.0 480Mbps），$300——但 Apple 定位是开发/诊断用途，不是消费级观影配件，且对初代 M2 AVP 的实际速率 Apple 未明确[33]。不建议为看片/Mac 投屏专门买，无线 Mac Virtual Display 对绝大多数场景已够用。

🎯 M5 款 120Hz vs M2 款 60Hz 🟢 多源

M5 Vision Pro（2025-10 首次硬件升级）把 Mac Virtual Display 刷新率从 60Hz 翻倍到 120Hz，文字更锐（多渲染约 10% 像素）；M2 老款无论有线无线都锁 60Hz[35]。瞄代码/滚动 M5 更顺；120Hz 据厂商/媒体或可减轻部分人的不适感，但"更不晕"是个体差异、需自己实测，不是确定结论。阿杰若是初代 M2 款则无此刷新率提升。

10.4 多屏限制（澄清易混点）

官方 Mac Virtual Display 同时只投 1 个 Mac 屏（Mac 接多显示器时只显示主屏）；第三方 Splitscreen（$19.99）可补第二个 Mac 屏，但分辨率/帧率（1280×720~2560×1440@60fps）低于官方 Ultrawide[36]。但「不能多窗口」指不能挂多个 Mac 显示器，并非不能与 visionOS 视频 app 共存——两者是不同概念，阿杰「1 个 Mac 编码屏 + 1 个视频 app 窗口」用官方功能即可，无需第三方。

11⭐ 一边看电影一边 vibe coding 的工作流▼

这是阿杰的特殊诉求，重点章。核心结论：完全可行，且就是官方设计的多窗口共享空间玩法，不用买任何第三方 app。

11.1 为什么能共存（技术基础）

✅ Mac 虚拟屏是「窗口」，视频 app 是「另一个窗口」 🟢 多源

官方支持文档明确：可在巨大的 Mac 虚拟屏上工作，同时查看并操作显示 visionOS app（Photos/Notes/Files/视频播放器 等）的独立窗口；可用 Mac 触控板/鼠标跨 Mac 屏和邻近 visionOS 窗口操作[32]。Mac Virtual Display 投进 AVP 后只是 visionOS 里的一个窗口，其他原生 app 作为独立窗口围绕它摆放，二者天然共存。

11.2 唯一的坑：别进 Apple TV 影院模式

⛔ Apple TV 专用 Cinema Environment 会藏掉 Mac 窗口 🟢 多源

标准 Environment + 数码表冠半沉浸时，app 窗口仍漂浮可见且可空间锚定；只有 Apple TV 自带的专用「影院 Cinema」模式会临时隐藏其他所有窗口、独占视野（Apple TV 移到正前方，点最小化才能找回其他 app）[20]。第三方沉浸影院 app 走 Full Space 同理会独占。要边看边瞄，就用普通 Environment + 窗口化播放，别进 Cinema 模式。

11.3 推荐窗口布局

① 把 Mac 虚拟屏摆在前方主位（vibe coding 进度就在这看）；② 单独再开一个 visionOS 视频 app 窗口（Apple TV/Infuse/B 站等）放成大屏当电影幕；③ 拧数码表冠进一个喜欢的 Environment（优胜美地/白沙/木星等）做半沉浸；④ 用 Mac 的鼠标/触控板，光标跨 Mac 屏和 visionOS 窗口使用[32]。开发者社区已验证：侧边放视频窗、前方放 IDE 编码，reference 缩小塞一旁随时瞄是真实在用的工作流[37]。

11.4 取舍与现实预期

⚠️ 「偶尔瞄一眼」OK，别当全天主力编码屏 🟢 多源

开发者报告盯小字编码超 30 分钟易眼疲劳，适合短时段/偶尔瞄，不适合全天主力编码屏[37]。阿杰的需求恰好是「沉浸看片 + 偶尔瞄进度」，完全落在舒适区。

💡 freshness 加分项：visionOS 2.2（2024-12）加了 Wide(21:9)/Ultrawide(32:9，等效双 5K) 曲面虚拟屏 + Mac 音频转入 AVP[38]；M5 Vision Pro（2025-10）把刷新率翻到 120Hz，瞄代码更顺手不晕[35]。群晖 NAS 在这一路不直接参与（它属于片源路线）——这里 Mac Studio 跑 coding，AVP 同屏呈现影片+代码。

⚠️ 待补研究：未找到一篇专门评测「电影大屏窗口 + Mac 编码小窗在普通 Environment 内长期共用」的端到端体验文章（结论由官方机制 + 多篇开发者实践拼合推导，confidence 高但缺单一权威实证）；visionOS 26 是否对「窗口与 Environment 共存」有行为改动未确证 🔴 待补研究。

13风险与坑▼

⛔ 坑 1：拿 Infuse 播 3D 会得到一堆 2D

Infuse 到 2026（8.4.x）仍不能在 AVP 真 3D 播放，SBS/OU/MVC 都当 2D[13]。3D 必须换 Moon/SKYBOX/Reality。这是最高频的认知错误。

⛔ 坑 2：群晖 2025 新机型 / Ryzen 机型转码弱

X25 系列砍硬转[23]、DS923+ 是 Ryzen 无核显软转[24]。解法：别让群晖转码，走直连。

⚠️ 坑 3：区域限制与国内可用性

Apple 沉浸片大陆走咪咕/腾讯非 Apple TV[2]；湖人直播仅限南加州转播区[4]；国区 Apple ID 对 Disney+/Apple TV 3D 租购可能受限、Moon/Reality/SKYBOX 国区上架未核实 🔴 待补研究。

⚠️ 坑 4：晕动症 / 佩戴时长

盯小字编码超 30 分钟易眼疲劳，适合「偶尔瞄」不适合全天主力屏[37]；M2 款锁 60Hz 比 M5 款 120Hz 更易晕[35]；长时间佩戴舒适度/重量是另一议题[6]。

⚠️ 坑 5：带宽与转码瓶颈

无线 Mac Virtual Display 强依赖 Wi-Fi（务必 6/6E/7 + 靠近路由）[34]；Moon Player 高码率有卡顿反馈[25]；BD_to_AVP 转码耗时占空间、依赖复杂（Wine/MakeMKV）[16]。

⛔ 坑 6：版权红线

社区灰色 SBS/OU 片源客观存在但属未授权来源[16]。「能播」不等于「该播」，使用者须自行遵守版权法。合法路径（已购升 3D / Disney+ / 腾讯 / 自有碟转录）足够丰富，无需碰灰色。

14FAQ▼

Q我在国内，AVP 上怎么看 Apple 的独家沉浸片？+

别在 Apple TV app 里找——大陆没有。装免费的「咪咕视频」和「腾讯视频」app，Apple 官方沉浸片走这两个渠道[2]。想看华语/中国题材沉浸内容再装 iQIYI XR（2.5 万+ 片源）和「沉浸中国」（16K 景点）[7]。

Q为什么我的 3D 片用 Infuse 放出来是 2D？+

因为 Infuse 在 AVP 上不能真正渲染 3D，SBS/OU/MVC 都被当 2D 播，Firecore 官方无 3D 时间表[13]。换 Moon Player / SKYBOX / Reality Player，这些才支持立体模式并能自动识别 SBS/OU/180/360[14]。

Q我的 3D 片到底要不要在 Mac Studio 上转码？+

看格式。SBS/OU 的 x264 文件不用转码，Moon/Reality/SKYBOX 直接播[16]。3D 蓝光（MVC）必须转码，用 BD_to_AVP 转 MV-HEVC。另外想把已有 SBS/OU 升到「原生质量上限」时，可用免费 Spatial 命令行工具转 MV-HEVC（MV-HEVC 分辨率/码率上限高于 SBS/OU）[19]。

Q群晖服务端选 Plex 还是 Jellyfin？+

对只在家看的你，选 Jellyfin——免费开源、LAN 不依赖云、配 Tailscale 远程也零订阅[27]。Plex 更省心（一键装、客户端最打磨）但 2025 起远程要订阅、终身版 2026/7 涨到 $749.99[26]，性价比低。

Q群晖能不能扛 4K HDR 串流到 AVP？+

能，前提是直连不转码。千兆局域网 + Direct Play，4K HDR 毫无压力[22]。别让群晖转码——2025 新机型砍了硬转、Ryzen 机型只能软转[23]。Infuse/Moon 直连读群晖的 MKV 就行。

Q能一边看电影一边瞄 vibe coding 进度吗？+

能，AVP 原生支持不用买 app。Mac Virtual Display 是一个 visionOS 窗口，视频 app 是另一个窗口，二者天然共存[32]。关键：用普通 Environment + 数码表冠半沉浸 + 窗口化播放，别进 Apple TV 的「影院 Cinema」模式（那个会藏掉 Mac 窗口）[20]。

QMac Studio 是台式机没屏幕，怎么连 AVP？+

戴上 AVP 从控制中心选 Mac Virtual Display 选中 Mac Studio 即可，不用「看着 Mac 屏幕点连接」[32]。前提：两机同 Apple ID + 双因素 + iCloud 钥匙串 + Handoff，macOS 15.2+、visionOS 2.2+。

Q虚拟屏看代码会卡 / 字糊，怎么办？+

瓶颈在 AVP↔路由器的无线段（Mac Studio 本身有线）。务必 Wi-Fi 6/6E/7 且 AVP 靠近路由[34]。想极致清晰低延迟可上 Developer Strap 走 USB-C 有线 20Gbps（$300）[33]。M5 款 120Hz 比 M2 款 60Hz 滚动更顺更不晕[35]。

Q3D 电影有哪些合法又省事的来源？+

① Apple TV 买/租，已购电影免费升 3D，全平台 200+ 部 3D[8]；② Disney+ 订阅含 42 部 3D（漫威/皮克斯）；③ 国内腾讯视频 3D 巨幕（8K+Dolby）[18]；④ 自有 3D 蓝光合法转录。无需碰灰色资源。

QApple 独家沉浸片值得期待吗？+

惊艳但别指望它撑满观影夜。累计约 47 部、单部仅 15-30 分钟、更新慢、被批剪辑过碎[10]。它是「点缀」，主菜靠你的库 + 流媒体 + YouTube VR180。2026 年它在往现场直播（湖人/皇马）迈进是好信号[4]。

Q在外面（异地）能看家里群晖的片吗？+

能，配 Tailscale（基于 WireGuard，免端口转发、穿 CGNAT），Jellyfin 配它全程零订阅，家里上行 50Mbps+ 时 4K Direct Play 远程可用[21]。⚠️ 国内访问 Tailscale 控制面偶有波动，受阻可自建 WireGuard+VPS 中继。

Q第一步应该先搭什么？+

最窄链路：群晖装 Jellyfin → AVP 用 Infuse 直连看 2D/4K → Mac Studio 走 Mac Virtual Display 投 coding 屏。零转码、零订阅，先验证整套体验，打通后再加 3D（阶段 2）、再加沉浸 + 远程（阶段 3）。见第 12 章决策树。
