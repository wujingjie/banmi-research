01为什么动态能力档案是半米最有价值的功能▾

父报告把「动态档案」定为押对的第五个大方向，但没展开它为什么是最有价值——不是之一。这里把四点理由各拆一个独立 callout，因为每一点都决定了后面 11 章「值不值得这么重投入」的判断基准。

✅ 理由一：它是 V1 里 AI 唯一的主战场

半米 V1 的产品教义是老师驱动、推荐引擎后置——AI 不决定学生学什么（那是老师的活），AI 的活就是把每个学生的当下状态 / 进步估出来、可视化喂给老师调方案。换句话说，V1 里其他所有「AI 功能」（推荐、自适应难度、自动派题）都被刻意降级或后置，唯一留给 AI 全力打的就是「估状态 + 画进步」这一件事。沟通日志原话定调：「动态档案不是附属报表，是 V1 里 AI 的主战场」。一个产品在某阶段把 AI 资源单点压在哪，哪就是这阶段最有价值的功能——逻辑上没有第二个候选。这也意味着档案做不透 = V1 的 AI 叙事就是空的。

✅ 理由二：唯一同时服务三个关键人的产物

它是半米功能里唯一一个同时直接服务学生、老师、家长三方的产物：给学生看的是动力曲线（看得见自己在涨，续命学习动机）；给老师看的是诊断视图（定位薄弱、调方案、分组派任务）；给家长看的是「放心 + 看得见的进步」（家长才是真正掏钱续费的人）。教育产品的留存和口碑，本质由「家长 / 学生看得见的进步」驱动——而档案就是把这份「看得见」做出来的那一层。词汇 LE、听力 LE 再强，家长也看不懂、感受不到；档案是把所有暗处的努力翻译成三方都能读懂的价值的翻译器。一个功能能同时撬动「续费的人 + 决策的人 + 使用的人」，价值密度天然高于任何只服务单一角色的功能。

✅ 理由三：最难被抄，且随数据复利

父报告已点明竞品没有一家把词汇量曲线 + CEFR 曲线 + 目标相关知识图谱三件套凑齐：IXL 有掌握分（SmartScore）但无 CEFR[1]；Duolingo English Test 有 CEFR 对齐但无连续成长曲线；松鼠 AI 有知识图谱但锁在 K12 数学[11]。更关键的是档案随数据复利——它的价值不来自某段聪明代码（那能被抄），而来自学生从入学起持续累积的做题 / 复习 / 测评序列。竞品就算照抄 UI，也补不出半米学生已经躺在 event_log 里的几个月连续数据。功能可复制，数据资产不可复制——这是档案比任何单点 LE 都更难被复制的根本原因。

✅ 理由四：把已建好的一切变现，并通向高 LTV 终局

半米已经在产数据的一切——内容 LE 产生的 event_log、词本位 + FSRS 复习池、0020 taxonomy（subject/stage/goal）——都是隐形的管道，用户和家长感知不到。档案是把这些隐形管道变成「看得见的价值」的那一层：同样的底层数据，没有档案就是后台日志，有了档案就是家长愿意续费的成长报告。更远一步，它是升学陪跑终局的数据资产底座：升学陪跑的核心卖点是「从 10 岁到大学录取的连续能力数据」，而这正是动态档案向前投影的产物——先有连续档案，才谈得上「大学目标 → 倒推路径 → 长期陪跑」。所以档案不只服务 V1，它是通向半米最高 LTV 商业终局的地基。

💡 第二名为什么不是它

最有价值的第二名候选是老师端 AI 助教（它是 GTM 飞轮、是把老师从重复劳动里解放出来的引擎）。但它相对可被复制——MagicSchool、Diffit 这类老师工具市场已经很卷；而且它的「诊断」半边本身就要靠动态档案供数据（没有档案，AI 助教诊断不出该补谁补什么）。两者咬合，但档案是更底层、更值钱的那块：助教是消费档案数据的应用，档案是产出诊断信号的源头。源头比应用更难替代。

02三大决定性结论：定义整个方案的形状▾

在进竞品深挖前，先把三条「决定整个方案形状」的结论摆出来。这三条不是建议，是约束——它们一旦定下，后面架构、数据模型、排期都被钉死了走向。每条单独一个 callout，因为每条都改变方案骨架。

★ 结论一：知识图谱骨架用 CEFR-J，不要自己造、不要用 GSE/EVP

这是最关键的一条，决定性原因是授权而非技术：CEFR-J 的 Wordlist 明文允许商用、只需署名，Grammar Profile 商用口径稍弱、入库前宜邮件确认（详见 Ch6）[29]；它把 CEFR 6 级细分成 12 级，正好贴中国学生主战场 A1–B2；半米已经在用。Pearson GSE 颗粒度最理想（每条 can-do 钉死 GSE 数值 + CEFR + 技能 + 关联语法词汇），但所有权完全封闭、无公开商用 API，要用必须直接谈 Pearson[27]；剑桥 EVP/EGP 默认禁止 bulk 商用下载[30]。自己从零造一套 can-do 体系成本极高且没有学术背书。结论：CEFR-J 是唯一同时满足「可商用 + 颗粒够细 + 对口中国学生 + 已在用」的骨架。

★ 结论二：掌握度先规则版，别一上来 BKT / 深度模型

诱惑是直接上 BKT 或 DKT 显得「有 AI 含量」，但那是工程陷阱。规则版 = EWMA（指数加权移动平均）+ 难度非对称加权 + FSRS stability 当遗忘半衰期 + 定级结果当冷启动种子。优势：① 可解释（每个旋钮有语义，老师 / 阿杰都能读懂为什么这个分）；② 小数据稳（半米早期每个知识点观测稀少，BKT 在小数据下参数不可识别、易退化）；③ 直接复用已有的 FSRS 大脑（srs.py），不另起炉灶。BKT 须约束 P(S)<0.5、P(G)<0.5 才不退化[3]，何时切换建议设一个自定的经验门槛（如每 node 攒够约数千观测、且 BKT 在留出集上的 log loss / 校准优于规则版）再换——这个数字是工程保守取值、需上线后用数据验证，不是文献硬规则；DKT（深度知识追踪）黑箱、家长老师读不懂，后置。Phase A 规则版的完整公式见 Ch9，可直接照写。

★ 结论三：英语不能像松鼠 AI 数学拆「纳米知识点」，要双层粒度

松鼠 AI 在 K12 数学拆出上万个「纳米知识点」+ 前置关联图[11]——那是因为数学知识点结构强、边界清晰、可判定。英语不行：「听力理解」「口语流利度」这类综合技能没有清晰离散边界，盲目拆假知识点只会标注成本爆炸、且估不准。正确做法是双层粒度：① 词汇 / 明确语法点（CEFR-J 262 条）/ 明确题型策略（如雅思 matching headings）→ 走离散知识点，用 event_log + FSRS 估；② 听说读写四大综合技能 → 走「技能 × CEFR 档」连续能力（如「听力 @B1 = 熟练、@B2 = 学习中」），用 IRT/Rasch 连续估计，靠定级 / 测评打点。全图约 200–300 个 can-do 节点，不强拆假离散点。

03掌握度估计机制深挖：六套竞品机制 + 可照写公式▾

动态档案的核心引擎是「掌握度估计」——把一连串做题 / 复习事件压成一个「这个学生这个知识点掌握到什么程度」的数。市面上有六套成熟机制，颗粒、可解释性、数据需求各不同。这一章逐个拆到实施级，公式可直接照写到 banmi。

3.1 IXL SmartScore（IXL Learning，美国自适应练习平台）

SmartScore 不是百分比，是 0–100 的自适应掌握指标。最关键的设计是非对称变动：加 / 扣分随题目难度与当前分段缩放，越往高分段惩罚相对越重，刻意逼学生「稳定连对」而非碰运气[1]。具体力度分段不同：低分段（0–70）单次加分大、答错惩罚小；到 90–100 的 Challenge Zone 则加分仅 1–2、答错重扣 3–8（惩罚比奖励重约 3–4 倍）[1]。（⚠️ 旧表述把「+1–2 / -3–8」当全程通则是过度概括，实际只在 Challenge Zone 这么极端。）配套机制：

  • 难度耦合：连对则题目变难、加分维持；答错降低难度并给分步讲解；加 / 扣分随题目难度缩放。
  • 递减增益：分越高单次加分越小（曲线凸向 100），90→100 远比 0→80 难。
  • Challenge Zone（90 分后）：只出最难题、加分更小、扣分更大，要打穿才能到 100。
  • 一致性 / recency：近期作答权重更高（隐式时间衰减）。

阈值惯例：80 = proficiency 熟练 / 90 = excellence 优秀 / 100 = mastery 掌握（需打穿 Challenge Zone）。为什么不用百分比：百分比里错题永久扣分，而 SmartScore 给无限改进机会、强调成长而非静态记录。🟡

⚠️ 焦虑坑（中国学生敏感）：SmartScore 因焦虑被诟病，Change.org 上有「废除 SmartScore」请愿[2]。根源正是 3–8 分的非对称重罚 + Challenge Zone 加难掉分——眼看分往下掉是强挫败源。banmi 借鉴「难度加权 + 非对称」的思路，但必须把惩罚力度调到远比 IXL 温和（见 Ch9 公式：连错不加速下跌、保留无限重练恢复）。

3.2 BKT 贝叶斯知识追踪（Carnegie Learning / Cognitive Tutor）

每个技能一个隐式二态 HMM（隐马尔可夫，状态 = 已掌握 / 未掌握），4 个参数：P(L₀) 初始掌握先验 · P(T) 单次「学会」转移概率 · P(S) slip（已会但失误）· P(G) guess（不会但猜对）[3][4]。每题后验更新（可直接实现）：

答对:  P(Lt|对) = P(Lt)(1-S) / [ P(Lt)(1-S) + (1-P(Lt))·G ]
答错:  P(Lt|错) = P(Lt)·S   / [ P(Lt)·S    + (1-P(Lt))(1-G) ]
带入学习转移: P(Lt+1) = P(Lt|obs) + (1 - P(Lt|obs))·P(T)

掌握判定惯例 P(L) ≥ 0.95。优点：可解释（4 个语义旋钮）、小数据相对友好、O(1) 在线更新。局限：① 技能独立假设（不建模知识点之间的迁移 / 前置）；② 参数可识别性差（须约束 P(S)<0.5、P(G)<0.5 防止退化到无意义解）；③ 标准 BKT 不建模遗忘（要 BKT-Forget 变体才行）[5]。对 banmi 的意义：这是 Phase B 的目标算法，但要等数据够 + 上约束。

3.3 ALEKS 知识空间理论（KST，McGraw-Hill）

ALEKS 的 Knowledge Check（25–30 题自适应）在所有「可行知识状态」（满足前置闭包）构成的格上做贝叶斯更新：每题缩小候选状态集、选信息增益最大的下一题，最终落到一个具体状态 = {已掌握项集合}[6][7]。最值得 banmi 抄的概念是 Outer Fringe = ready-to-learn：

项 i 在 outer fringe  ⟺  i 未掌握，但把 i 加入当前状态后状态仍合法
                          （即 i 的所有前置都已在当前已掌握集合内）
→ outer fringe = 「前置都满足、就差这一个」的学习入口

banmi 可据此建前置依赖图，只给学生推「前置已掌握的下一个知识点」，避免推太超纲或太基础的。这是 Ch9 ready-to-learn 推荐的理论来源。

3.4 NWEA MAP RIT 等距量表 + Renaissance Star SGP

机制是什么对 banmi 的用法
RIT 量表（NWEA MAP）基于 Rasch / 1PL IRT 的等距、跨年级垂直量表（约 100–350）。等距 = 150→151 的学习量 == 250→251；不随年级重置，可纵向追踪多年；题目难度与学生能力同标尺[8]CEFR 能力曲线的「等距纵轴」范式——别用会重置的相对分，要用可多年追踪的绝对能力刻度
SGP 学生成长百分位（Star，Betebenner 法，1–99）分位数回归：以学生历次前测分为自变量（B-spline 基展开），在 99 个分位点各拟合一条分位回归线，得「给定历史分的当前条件分布」，实际分落点的百分位 = SGP[9][10]SGP=85 ⟺「比相似历史的同伴中 85% 的人长得快」。把起点 condition 掉，比绝对分更说明成长，对分层班尤其鼓励性

SGP 的产品价值：它让「起点低但进步快」的学生也能拿高分（成长百分位 ≠ 绝对成绩），这对中国分层班的差生鼓励性极强——是 Ch4 老师端「成长-熟练四象限」散点的横轴来源。

3.5 Duolingo HLR 半衰期回归（Settles & Meeder 2016 ACL）

HLR 用「记忆半衰期」建模复习时机。召回概率 p = 2^(−Δ/h)，Δ = 距上次复习天数，h = 半衰期。回归预测 h：

h_Θ = 2^(Θ·x)
p_Θ = 2^(−Δ / h_Θ)
loss = (p − p_Θ)²  +  α(h − h_Θ)²  +  λ‖Θ‖²₂

特征 x = 历史「见过 / 答对 / 答错」次数（√ 变换）+ 词级 lexeme tag。相对基线降低预测错误 45%+[12]。Birdbrain（2020）= logistic / IRT，管能力估计与选题，与 HLR（管复习时机）分工。

⚠️ HLR 仅作概念参照，不照搬。HLR 的 45%+ 降错是相对其论文里的基线（leitner / pimsleur 式固定间隔），不是相对 FSRS——本报告未找到 FSRS vs HLR 的公开 head-to-head benchmark，所以「FSRS 已超越 HLR」应理解为社区共识 / 工程选择（FSRS 开源、参数更可解释、已成主流），而非有引用支撑的实测结论🟡。对 banmi 的实操结论不变：banmi 已经在用 FSRS[13]，遗忘 / 复习时机这块直接复用现有 FSRS 大脑即可——HLR 的价值是让你理解「半衰期建模召回概率」这个范式，便于把 FSRS 的 stability 当作掌握度估计里的遗忘衰减参数（Ch9 步骤③）。

3.6 松鼠 AI（Squirrel AI / 乂学）

松鼠 AI 把知识点超细拆分 + 建知识图谱（前置 / 关联），掌握度估计是 BKT + IRT + 贝叶斯网络混合、沿 KST 思路。最值得借鉴的是五维错因（MCM）+ 错因知识图谱重构：不止判对错，而是诊断「为什么错」（概念缺失 / 关联误用 / 干扰项混淆…）并映射回图谱定位真缺口[11]。

💡 对英语的启示：英语错题也分错因——词义混淆 / 语法点错 / 题型策略不会 / 粗心。错因决定推送什么：词义混淆 → 推该词的语境复习；语法点错 → 推该 CEFR-J 语法节点；题型策略 → 推该题型专项。所以错题进复习池时不能只记对错，要标错因类型（呼应父报告 P0-4「错题标错因」）。但 banmi 不能学它拆纳米知识点（见 Ch2 结论三）。

4.4 曲线怎么画才「既准又有动力」

词汇量曲线 = 单调台阶，永不下降

Y = 累计已掌握词数（单调不降，FSRS 标记「待复习」的词不从总数扣、只在明细里标「需巩固」），台阶状（每掌握一批跳一级），永远向右上或持平 → 零打击。这是阻力最小、动力最强的第一条曲线。

CEFR 等级曲线 = 离散等级带 + 进度环

Y = 离散等级带（A1 / A2 / B1…），带状台阶显示「当前 B1、距 B2 还差 X%」+ 进度环；等级只升不降——回退表现为「距下一级 %」回缩，而非等级跌落（绝不让学生看到自己从 B1 掉回 A2）。⚠️ 注意：「只升不降」是学生 / 家长展示层的纪律，不是底层数据造假——底层 CEFR 估计该是真实带误差的（含置信区间），老师诊断视图要能看到真实回退 + regression 预警，否则会瞒着老师把学生的真实退步藏掉、误导教学决策。展示层激励 ≠ 数据层失真。

避免下降挫败的统一原则

波动指标（如本周口语分）用「近 4 次平均」或只显最佳成绩线；真要显波动则用浅色区间 + 深色趋势线，文案归因可控因素（「最近练得少」而非「你退步了」）；下降时 LLM 评语转「巩固期」叙事。总原则：能力 / CEFR 曲线 = 台阶式（只在定级 / 测评 / 周测打点，慢且稳）；词汇量 / 掌握热力图 = 平滑式（日常即时反馈）。两条线不混用。

05LLM 评语生成 + 护栏 pipeline：G-E-RG 两 Agent + 老师批准▾

家长 / 学生报告里那句「本周表现」的评语，是档案最容易出事的一环——直接让 LLM 写会幻觉、过度表扬、过度推断。研究共识（EDM 2024 / IJAIED 2025）：LLM 评语会产生不忠实内容（流畅但捏造、过度推断、过度表扬），人类在「明确改进方向 / 准确性 / 抓重点 / 支持语气」上仍优[37][38]。有效护栏是 G-E-RG 两 / 多 Agent pipeline，能把「评语组件完整度」（即一条评语该包含的成分——具体表现 + 证据 + 可操作建议 + 适当语气——的齐全率，论文自定指标）从 28% 提到 98%[36][39]。⚠️ 这个数字是论文在其自有数据集 / 自定 rubric 下的结果，不等于「幻觉率降到 2%」，banmi 落地仍须自建评测集 + 盯 false-pass（误放行）率。四步：

1Generator 生成
基于该生真实数据（错题 / 掌握度 / event_log）用 RAG + CoT 生成，强制引证据、禁泛泛表扬。绝不让 LLM 凭空夸。
2Critic 对抗审查
用 rubric（正确性 / 是否基于本人作品 / 有无可操作建议 / 语气 / 是否过度表扬）逐条打分，标出「未基于学生作品的句子」并打回；先 step-by-step 定位真错误，再让 Generator 重写。
3自动可靠性测试
做最终自动门（全过才放行进下一步），把明显幻觉 / 不忠实的拦在老师之前。
4老师批准闸（铁律）
进老师待审队列，可改可拒，批准后才对学生 / 家长可见，绝不自动发。这条是不可逾越的边界——呼应父报告「AI 初评 + 老师终审」。

⚠️ 为什么必须老师终审、不能自动发：评语出现在家长面前，是品牌信任的最前线。一句幻觉式夸奖（「Danny 已经能流利讨论时事」而其实还在 A2）会直接砸掉家长信任、甚至引发投诉。LLM pipeline 再强也只能把它当草稿生成器，老师批准是责任归属的最后一道门。父报告 Ch16 也提醒：老师终审不是免费资源，要给老师批量化审阅工具（一键批准 / 批量微调）避免审阅疲劳成为规模瓶颈。

⚠️ Pearson GSE——颗粒度最理想但授权封闭（最关键的坑）

GSE 每条 Learning Objective（can-do）钉死四件事：① GSE 数值刻度 10–90（CEFR 线性扩展，PTE 走这把尺）② CEFR 等级 ③ 技能 R/L/S/W ④ 关联语法 + 词汇。GSE→CEFR：A1=22–29、A2=30–42、B1=43–58、B2=59–75、C1=76–84、C2=85–90。IELTS 7.0 ≈ GSE 65–66、KET ≈ 30–35、PET ≈ 43–50。Teacher Toolkit 免费网页可按 GSE/CEFR/技能/学龄过滤查询，但只是 lookup、无导出、无 bulk data 自助商用 license。Pearson 保留 GSE 全部所有权，免费仅限教师 / 学生非商用规划查询；商用必须联系 Pearson 谈直接授权[27]。🔴 商用费用 / 路径未核实——要用 GSE 数据先谈 Pearson。

⚠️ 剑桥 EGP / EVP——质量高但默认禁商用

EGP（English Grammar Profile）从剑桥学习者语料库（~5500 万词）抽 criterial features，1,200+ 条，按 CEFR A1–C2 × 语法大类，带 can-do 措辞 + 真实例句，免费浏览（非商用）。EVP（English Vocabulary Profile）是词义级（多义词每义项独立定级），~7,000 词头 / ~15,000 义项，BrE/AmE 两版，注册后免费浏览。但 bulk data 默认不可商用下载，EVP Terms of Use 明文禁商用；商用须与 CUP 单独书面协议[30]。🔴 路径 / 费用未核实——这是授权最高风险一环，只做开发期人工校验或运行时外链，绝不入库 bulk data。

✅ CEFR-J——对 banmi 最对口、可商用（福音）

CEFR-J 为东亚学习者校准（日本 80%+ 学习者挤在 A/B 段，原始 can-do 无法区分），把 6 级细分成 12 级：Pre-A1, A1.1/.2/.3, A2.1/.2, B1.1/.2, B2.1/.2, C1, C2，覆盖 5 技能。Wordlist v1.6：7,801 条 / 6,868 词头（A1 1166 / A2 1411 / B1 2445 / B2 2779）；Grammar Profile v20180315：262 条语法项（带 CEFR-J 级 + 频率 + 交叉引用 EGP/GSE）。CVLA（文本 CEFR-J 级分析器，cvla.langedu.jp）可挂在 Lexile 旁边。反方提醒：CEFR-J 是为日本 / 东亚校准的，「对东亚对口」不自动等于「对中国 + 雅思场景最优」——它的 C1/C2 段（升学陪跑后期要用）和口语 / 写作描述符相对薄，高目标学生那段可能要叠 Octanove 扩展或人工补，别假定 12 级一把覆盖到底🟡。授权（banmi 福音，但要逐资产看）：Wordlist 明文「可用于研究 AND 商用、免费、须正确署名（Tono Lab, TUFS）」——这条是最确定的；Grammar Profile 下载页主要给引用 + 免责声明，商用授权没像 Wordlist 写得那么直白，入库前宜与 Tono Lab 邮件确认一次🟡；Octanove 的 C1/C2 扩展是 CC BY-SA 4.0（衍生须同协议开放）；CVLA 是在线分析器（运行时调用，非数据入库）；GitHub openlanguageprofiles/olp-en-cefrj 有清洗版；Can-Do 清单仅需登记 license agreement[29][31]。

09掌握度估计引擎 Phase A 规则版（可照写）+ 双层粒度▾

这是整个方案最可直接动手的一章。Phase A 规则版每个 node 维护一个 M ∈ [0,1]，公式如下，可直接照写。设计原则：借 IXL 的「难度加权 + 非对称」但远比它温和（保留无限重练恢复，不学它 3–8 分重罚）。

9.1 单条作答事件更新（correct, 难度 d ∈ [0,1]）

① 单题表现分 s ∈ [0,1] (难度加权 + 非对称，借 IXL 但温和):
   答对:  s = 0.5 + 0.5·d
   答错:  s = max(0, 0.5·(1−d) − P_pen·d)      (P_pen ≈ 0.6)
   ⚠️ 必须 clamp 到 0 下界——否则 d=1 时 0.5·0 − 0.6 = −0.6，
      会把 M 推到负数(违反 M∈[0,1])。max(0,·) 兜底
   ⚠️ 比 IXL 的 3–8 重罚温和; 连错不加速下跌; 保留无限重练可恢复

② EWMA 更新 (M 天然落在 [0,1]，因 s∈[0,1]):
   M_new = clamp01( (1−η)·M_old + η·s )      (η = 0.2 ~ 0.35)
   连对可让 η 略升; 连错不升 (防过山车焦虑)

③ 遗忘衰减 (复用 FSRS，但注意粒度):
   读取时 M_显示 = M_存储 · 2^(−Δ天 / H)
   H = 该 node 关联卡片的 FSRS stability
   ⚠️ FSRS stability 是「卡片级」(per card/sense)，不是「节点级」。
      一个 node 可能挂多张卡(多义词/多技能)，要先把卡级 stability
      聚合成 node 级 H(取最小 / 加权平均)，且非词汇综合技能没有
      直接的 FSRS card，这块只对「有卡的离散知识点」适用

④ 冷启动 = 定级种子:
   定级 B1 → 该档及以下 node M₀ = 0.6
            高一档 M₀ = 0.25
            再高一档 M₀ = 0.05

9.2 掌握分级（温和、不暴露原始小数给学生）

M 区间分级（给学生看的命名）备注
M ≥ 0.85已掌握三档色块呈现，不给原始小数
0.6 ≤ M < 0.85熟练
M < 0.6学习中
n_obs < 3估计中观测不足不下硬结论

9.3 ready-to-learn 推荐（借 ALEKS outer fringe）

建轻量前置图，只推「前置已熟练（M ≥ 0.6）且本 node 仍学习中（M < 0.6）」的节点 = outer fringe。这给老师 / 学生「下一个该学什么」的可执行入口，而非推太超纲或太基础的。

9.4 演进路径

仅当 KC 迁移明显 + 海量序列才上；黑箱，家长老师读不懂，与「档案给人看」目标冲突，长期后置。

9.5 英语 vs 数学：双层粒度（实施口径）

★ 离散知识点层（能掌握 / 可判定）

词汇（词本位离散）、明确语法点（CEFR-J 262 条）、明确题型策略（如雅思 matching headings）→ 走细知识点，用 event_log + FSRS 估，每个点一个 M。这层是上面 9.1 公式直接作用的对象。

★ 连续能力层（模糊综合技能）

读 / 听 / 说 / 写四大维度 → 不强拆假离散点，用「技能 × CEFR 档」矩阵表达（如「听力 @B1 = 熟练、@B2 = 学习中」），用 IRT/Rasch 连续能力估计，靠定级 / 测评打点 + 日常微调。全图约 200–300 个 can-do 节点（🔴 这是规划期粗估，实际数应由目标考试覆盖面 + 现有内容库可挂载量 + 诊断分辨率需求倒推，不是定数）。口径总结：词汇 + 语法点 + 题型走细知识点（event_log + FSRS）；四技能综合走技能 × CEFR 档连续能力（定级测评打点）。

12.3 红线与坑（四条，各拆）

⚠️ 授权红线

CEFR-J Wordlist / Grammar 入库须署名「Powered by CEFR-J, Tono Lab, TUFS」；Octanove C1/C2 扩展是 CC BY-SA（衍生须同协议开放）；EVP / EGP / GSE 一律不入库 bulk data，只做开发期人工校验或运行时外链。这条踩了是法律风险，不是体验问题。

⚠️ 焦虑坑（中国学生 / 家长敏感）

不暴露可下降的精细分 / 排名给学生家长；掌握度只给三档色块（已掌握 / 熟练 / 学习中），不给原始小数；曲线只升不降，下降归因可控因素。IXL 因 SmartScore 重罚被请愿废除[2]就是前车之鉴。

⚠️ 小数据坑

n_obs < 3 不下硬结论（显「估计中」）；冷启动必用定级种子，别让新生从 0 起跳；BKT 不收敛就回退规则版。早期半米数据稀疏，这条决定了「先规则版」不是保守而是必须。

⚠️ 复杂度坑

别一上来全链路并发开。按 V1 → V2 单点先打透——词汇量曲线是最小可行的「看得见的进步」。呼应父报告 Ch16：把「词汇采词 → FSRS 复习 → 老师诊断 → 知识图谱」最短闭环焊死当 wedge，验证「同一大脑」真能带来留存 / 续费，再向其他簇铺。把全链路当愿景、最短闭环当第一仗，避免摊大饼。

一句话路线：先做 V1 词汇量曲线拿「看得见的进步」（数据现成、零挫败、家长立刻有感），再 V1.5 接定级撑起老师诊断，最后 V2 用 CEFR-J 骨架 + 老师闭环 + LLM 评语兑现护城河、接升学终局。估计层永远先规则版收数据再上 BKT；骨架永远 CEFR-J 主入库、GSE/EVP 只外链。这条路线每一刀都可独立验收、地基都已在产数据。

FAQ常见问题▾

Q1为什么不用 GSE 当骨架？它颗粒度明明最理想。＋

颗粒度确实 GSE 最细（每条 can-do 钉死 GSE 数值 + CEFR + 技能 + 关联语法词汇），但授权是死穴：Pearson 保留 GSE 全部所有权，Teacher Toolkit 只能免费 lookup、无导出、无 bulk data 自助商用 license，商用必须联系 Pearson 谈直接授权（费用 / 路径 🔴 未核实）[27]。banmi 是要做产品卖的，把骨架建在「随时可能要付费谈判、无 API」的封闭框架上风险太高。CEFR-J 明文可商用 + 免费 + 12 级够细 + 已在用，是更稳的选择。要用 GSE 数据先谈 Pearson，别先入库。

Q2掌握度到底先做规则版还是直接上 BKT？＋

先规则版（EWMA + 非对称 + FSRS 衰减 + 定级种子，见 Ch9）。三个理由：① BKT 在小数据下参数不可识别、易退化（须约束 P(S)<0.5、P(G)<0.5），而 banmi 早期每个 node 观测稀少[3]；② 规则版可解释（老师 / 阿杰都能读懂为什么这个分），BKT 的 4 参数对非技术方是黑箱；③ 规则版直接复用已有 FSRS 大脑，不另起炉灶。等每个 node 攒到数千观测、且能上约束，再换 BKT；不收敛就回退规则版。DKT 黑箱、长期后置。

Q3曲线会不会因为下降打击学生？＋

会，所以从设计上杜绝下降：① 词汇量曲线单调不降（FSRS 标「待复习」的词不从总数扣，只在明细标「需巩固」），永远向右上或持平；② CEFR 等级曲线只升不降，回退表现为「距下一级 %」回缩而非等级跌落；③ 波动指标用「近 4 次平均」或只显最佳成绩线，真显波动用浅色区间 + 深色趋势线，文案归因可控因素（「最近练得少」而非「你退步了」），下降时 LLM 评语转「巩固期」叙事。IXL 因 SmartScore 答错重扣被请愿废除[2]是反面教材。

Q4家长报告该给什么、不该给什么？＋

给：一句话 LLM 总结（老师批准后发）+ CEFR 等级 + 一条平滑上升曲线（只给方向）+ 1–2 个本周作品 / 朗读亮点 + 1 条下一步建议。藏：原始错题、逐题正确率、排名、班级对比、复杂雷达、任何可下降的精细分。原则是「证据 + 正向 + 克制」——Seesaw 作品集优先（看真实作品而非分数）值得抄，ClassDojo「积分轰炸 + 显惩罚性」是反面教材[33][34]。家长是掏钱续费的人，报告要让他放心，不是让他焦虑或当监工。

Q5英语知识点该拆多细？像松鼠 AI 那样上万个吗？＋

不要。松鼠 AI 的「纳米知识点」是 K12 数学的产物——数学知识点结构强、边界清晰、可判定[11]。英语综合技能（听力理解、口语流利度）没有清晰离散边界，盲目细拆只会标注成本爆炸且估不准。用双层粒度：词汇 / 明确语法点（CEFR-J 262 条）/ 明确题型策略走离散知识点；四大综合技能走「技能 × CEFR 档」连续能力。全图约 200–300 个 can-do 节点足矣。

Q6LLM 评语能自动发给家长吗？＋

绝对不能自动发。LLM 评语会幻觉、过度表扬、过度推断（研究共识，EDM 2024 / IJAIED 2025）[37][38]。用 G-E-RG pipeline：Generator 基于真实数据生成 → Critic 对抗审查打回未基于作品的句子 → 自动可靠性测试 → 老师待审队列，批准后才可见。一句幻觉式夸奖（说孩子已 B2 实则 A2）会直接砸家长信任。LLM 只是草稿生成器，老师批准是责任归属的最后一道门。给老师批量化审阅工具避免审阅疲劳成瓶颈。

Q7为什么先做词汇量曲线，而不是先做知识图谱？＋

词汇量曲线是「最小可行的看得见的进步」：① 数据现成（student_vocab_item.srs_state 已在产）；② 词汇离散可数，聚合简单，2–3 周可上；③ 单调不降，零挫败，家长立刻有感。知识图谱要建 competency_node + 挂内容 KP + 跑估计引擎，工程量大得多，是 V2 的事。先用最小闭环验证「看得见的进步真能带来留存 / 续费」，再投重资源建图谱。这是 Ch12 复杂度红线的核心——别摊大饼。

Q8SmartScore 那套非对称罚分，banmi 到底抄不抄？＋

抄「难度加权 + 非对称」的思路，但不抄它的力度。IXL 答错扣 3–8 分（比奖励重 3–4 倍）+ Challenge Zone 加难掉分，正是它被请愿废除的焦虑源[1][2]。banmi 的 Phase A 公式（Ch9）保留「答对加分、答错减分、难度缩放」，但 P_pen ≈ 0.6 远比 IXL 温和、连错不加速下跌、保留无限重练可恢复，且给学生只显三档色块不显原始小数。对中国学生焦虑度敏感，温和是硬约束。

Q9SGP（学生成长百分位）值得做吗？它要拿全班数据比。＋

V1.5 值得做，但分受众用。SGP 的价值是「把起点 condition 掉」——起点低但进步快的学生也能拿高分（SGP=85 = 比相似历史的同伴中 85% 长得快）[9]，对分层班的差生鼓励性极强，是老师端「成长-熟练四象限」散点的横轴。但它本质是同伴对比，所以只给老师看（诊断 / 分层），绝不直接给学生 / 家长看排名感。早期样本小时 SGP 不稳，可先用绝对进步量代替，样本够再切 SGP。
