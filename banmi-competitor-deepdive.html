01全局判断：半米已押对的方向 + 独有护城河▾

在逐簇拆解前，先给三个全局结论：半米的几个方向性大赌注已被竞品反向验证为对的；它最大的杠杆是「全链路同一大脑」；以及三个最该立刻补强的能力。这一节不挤一个框——每个押对的方向都值得展开，因为它们决定了后面 14 章「该往哪走」的判断基准。

半米已押对的方向（竞品反向验证）

✅ 押对一：老师驱动 > 纯算法推荐

Knewton 当年鼓吹「读心式自适应机器人」、累计融资约 $1.8 亿，但算法脱离内容与老师工作流，交付不出实际效果，2019 年 5 月技术资产被 Wiley 以远低于融资额（据报约 $17M）收购收场[40]。反过来，行业里最干净、可持续的范式——Century Tech 的 Recommended Path、Carnegie Learning LiveLab——全是「老师设定边界 + AI 在边界内推荐 + 老师可随时覆盖」[33]。半米 V1 故意把推荐算法降级、把「省老师力气 + 把学生状态估给老师看」当主战场，是被反复验证过的正确路线，而不是技术能力不足的妥协。这条判断直接决定了 Ch9 自适应章「先 IRT→BKT、DKT 后置」的演进节奏。

✅ 押对二：Today 永远清爽、逾期挪补做区、不堆 backlog

Duolingo 的连胜（streak）设计有一条关键细节：完成 1 节课就保住连胜，跟当天的学习目标量无关、漏掉的天也不累积成债[34]；而 Anki 公认最大的劝退点，恰恰是停几天回来看到几百张积压卡片的窒息感[6]。逾期复习暴露成原始队列，是这个行业的头号 churn（流失）杀手。半米「Today 只突出今天一个主任务 + 逾期项挪到独立补做区 + 学生自助补做、不混进今天」的设计，从架构层面天然规避了这个坑。这是被低估的方向性正确，Ch3 复习章和 Ch13 Today 章都建立在它之上。

✅ 押对三：词本位 + 采词存原句 + 统一 FSRS 复习池

竞品在词汇/复习这条线上全是单点：Readlang 只做语境查词 + 闪卡[2]、批改网只批作文[19]、剑桥 English Grammar Profile 只给语法 can-do 档案[22]。没有任何一家竞品把「读到的词 / 写错的句 / 学到的语法点 / 做错的题」沿同一条 SRS 闭环回流。半米以词本位为基础、采词时存原句来源（vocab_source_context）、概念/错题/造句各包成卡进同一个 FSRS 大脑（review_item + srs.py），这是结构性独有的护城河，不是可被快速复制的功能点。后面每一簇的建议都在加固这条全链路。

✅ 押对四：AI formative 反馈 + 老师终审

严肃的高风险写作/口语评分产品——Linguaskill、PTE、E2——都把人工复核留在出正式分前的环节；即便定位为「练习反馈工具」的剑桥 Write & Improve（自动反馈），也只敢把 AI 给出的分数称为「估算 band」、明确声明非官方[20]。这里要分清两类：练习反馈工具可以全自动给 formative 反馈，但任何被当成「正式定级/band」用的分数，行业惯例都保留人工终审。半米坚持「AI 给 formative（形成性）反馈 + 老师终评」不是技术不够的退让，而是行业最佳实践本身。Ch6 写作、Ch7 口语、Ch9 测评三章都把这条当作不可逾越的边界。

✅ 押对五：动态档案 = 词汇量曲线 + CEFR 曲线 + 知识图谱三件套

竞品里没有一家三者齐全：IXL 有掌握分（SmartScore）但无 CEFR[28]、Duolingo English Test 有 CEFR 对齐但无连续成长曲线[25]。半米把「词汇量曲线 + CEFR 曲线 + 目标相关知识图谱」三曲线同屏，是 V1 里 AI 真正的主战场，方向对。Ch11 报告章会把它做透。

✅ 押对六：CEFR-J 当分级主轴

CEFR-J 是日本东京外大（TUFS）发起、为日本英语教学语境细分 CEFR 的体系（词表 + 语法档 + EVP English Vocabulary Profile 校准）[9]。它源自东亚教学语境，对中国学习者通常比纯 Oxford 3000/5000 更接近（同属东亚 EFL、起点与教材结构相似），但严格说是「日本语境来源」而非「已为中日韩三国分别校准」。半米以它为分级主轴（词表、语法档、定级口径），方向对——⚠️ 但要注意：对中国用户，KET/PET/雅思/中高考/国际课程大纲的可解释对齐，购买驱动力可能强于 CEFR-J 本身，定级报告应做双轨呈现。

半米最大的、竞品都没有的杠杆：全链路同一大脑

半米最高价值的动作，不是把任何单点做到行业第一，而是把全链路打通。它同时握有 阅读/听力/口语 LE + 词本位 + FSRS 大脑（srs.py）+ CEFR-J 语法库 + annotation/review_item/assignment 契约 + 多技能 event_log。竞品都是单点强（查词、批文、评音、复习各做各的），没有任何一家把读到的生词、看错的发音、写错的语法、做错的题全部沿同一个 FSRS 复习池 + 同一张知识图谱回流。这条全链路是后面每一章建议的共同指向：每个单点功能的改进，最终都要回流到这同一个大脑里。

④ 图记只做可选脚手架，绝不让它替代主判定。

03复习系统 / SRS：统一 FSRS 大脑 + 防堆积▾

功能拆解（半米现状）

  • 统一复习池（review_item，4 池）：vocab / concept / knowledge / mistake，统一 FSRS 大脑 srs.py。
  • FSRS 默认参数起步 → 攒数据自动调参；区分新词「学习期」密集 → 毕业进 FSRS 长周期；「软毕业」（升到目标级 + 间隔>180 天 → 移出活跃池但可召回）。
  • 评分 = 客观对错 + 主观难度感 → 合成 FSRS 4 档（Again/Hard/Good/Easy）。
  • 每日上限（绝不堆 200）；复习 = Today 固定一块 + 独立入口；两个 AI 架构（学生 AI 主持 + 老师 AI 注入约束）。

★ 墨墨背单词 SSP-MMC——防堆积内建于调度器

墨墨用「随机最短路 + 最小化记忆成本」的动态规划（KDD/TKDE 论文 SSP-MMC + DHP 记忆模型），卡每日时间预算（约 10 分钟），超预算的项目推到次日，并把未来负载预分配、使复习曲线平滑[3]。半米已定「每日上限」，但更优做法是按预估复习时间封顶（而非固定条数）+ 调度器主动往后推 + 预铺平未来几天。这是墨墨工程里最值钱的部分，也是半米防劝退的关键升级。

★ Duolingo Birdbrain / RemNote——永不暴露原始逾期队列

底层算出 180 项到期，学生端只呈现「今日 N 张」的有限会话[34]。这是半米防劝退的头号铁律，从根上规避 Anki 招牌坑（停几天回来看到几百张积压而弃用[6]）。半米「Today 不堆 backlog」的方向正确，但要确保复习模块也严格遵守同一纪律。

建议

① 每日负载按时间预算封顶 + 跨天重铺平（墨墨式），不要固定条数（P0）。

② 学生端绝不暴露原始 backlog——只给「今日 N 张」（留存生死线，P0）。

⚠️ 主观难度档别乱映射：FSRS 里只有 Again = lapse（遗忘），Hard 仍算成功。把「答对但觉得难」误判成 lapse 会污染 stability（稳定性）估计[1]。
⚠️ 默认参数别当终点：数据少时先用群体级参数，别过早 per-user 拟合（会过拟合）；数据起来后务必落地「自动调参」，否则退化成半个 SM-2[1]。

💡 老师可见的负载/留存预测仪表盘：把「该生未来 7 天预估复习负载、各项预测留存率、哪些词卡在哪一级」暴露给老师——竞品的调度全是黑箱给学生看，这是「AI 估状态给老师」的直接落地，也是半米双 AI 架构（老师 AI 注入约束）的天然出口。

16护城河综合：半米相对竞品的结构性优势▾

把 14 簇的竞品对标收敛，半米相对竞品的结构性优势集中在七条——它们的共同点是「竞品都是单点强、半米靠打通取胜」：

优势为什么竞品做不到
全链路同一 FSRS 大脑读到的词 / 看错的发音 / 写错的语法 / 做错的题 → 同一复习池 + 同一知识图谱回流。竞品全是单点（Readlang 只查词、批改网只批文、ELSA 只评音、Anki 只复习）。
为每生编排连续周计划Diffit/MagicSchool/Twee 只做单次内容生成，无连续编排；半米老师端是核心引擎。

AI 判自由造句产出评估竞品词汇都停在识别/拼写，无人做自由造句产出评估。

一句话护城河：半米的价值不在任何单点功能做到行业第一，而在「把读到的词、看错的发音、写错的语法、做错的题全部沿同一个 FSRS 大脑 + 同一张知识图谱回流」——这条全链路（就本次竞品样本观察）没有任何竞品打通，也最难被快速复制（复制单点功能易，复制贯穿七簇的数据闭环难）。

⚠️ 反方必须正视：全链路也可能是复杂度陷阱

「全链路同一大脑」是结构性优势，但反过来也是工程与认知复杂度的源头：单点工具（Readlang/ELSA/批改网）更轻、更快形成初始 wedge（楔入点），用户一个场景就能上手；半米要让七簇全部回流到同一个大脑，意味着每个单点都不能太弱、且数据契约要一致，铺开成本远高于做透一个场景。务实路径不是「全链路一次铺开」，而是先用 P0 四件事把「词汇采词 → FSRS 复习 → 老师诊断 → 知识图谱」这一条最短闭环焊死、拿它当 wedge，验证「同一大脑」真能带来留存/续费，再向听说写读语法逐簇接入。把全链路当愿景、把最短闭环当第一仗，才避免摊大饼。另注两个被低估的成本：① 老师终审不是免费资源（human-in-loop 会带来延迟、审阅疲劳、责任归属、规模瓶颈，要给老师批量化工具）；② 「Today 不堆债」对学生端是减压，但老师/家长端可能必须看到真实逾期与补交记录——「不暴露 backlog」应是学生视图纪律，而非全系统隐藏。🟡

17阿杰路线建议：P0 / P1 / P2 决策树▾

把 14 簇的建议按「地基成熟度 × 杠杆」排成三级。决策原则：先把已有地基的临门一脚踢成闭环（P0），再做差异化护城河（P1），最后做需要团队/资源的商业放大（P2）。

P1 · 差异化护城河构筑竞品打不通的全链路优势 → 中期
P2 · 商业放大需团队/资源/数据积累 → 后置

P0（临门一脚，逐条展开）

★ P0-1 采词强制存原句 + 复习放回原句考

这是词本位最大的差异化，也是「全链路同一大脑」在词汇侧最直接的落点。半米的 vocab_source_context 表已为此而生——只差把采词时的 source sentence 强制落库、复习时把词放回原句考（轮换该词在不同来源里的句子，LingQ 式「多处复现」[4]）。Readlang 靠这一条吃下了语境查词市场[2]，但它只做查词单点；半米把同样的机制接到 FSRS 大脑 + 老师诊断，就从「又一个 Readlang」变成结构性独有。工程量小、地基已有、杠杆极高，应是第一件事。

★ P0-2 recommendation_queue 做成 Wayground 式可执行回路

半米 Dashboard 已有 recommendation_queue 字段，但它现在只是「看曲线」。抄 Wayground「Analyze with AI」：某技能准确率低于阈值触发 → 系统标出薄弱技能 → 自动生成补救题 → 老师一键「Assign to X students」派给特定几个学生[36]。这一步把老师诊断从「我知道这班整体弱在哪」升级到「我直接拿到该补谁、补什么、一键派出去」——正是半米「省老师力气 + 把状态估给老师」定位的临门一脚。守住 human-in-loop（老师可改可拒），别做全自动。地基（assignment 链 + agent_operation 审计）已有，是诊断闭环最高 ROI 的一步。

★ P0-3 复习按时间预算封顶 + 永不暴露原始 backlog

这是留存生死线，也是半米「Today 不堆债」方向在复习模块的落实。两件事：① 抄墨墨 SSP-MMC——复习负载按预估时间封顶（而非固定条数），超预算项推到次日，并把未来负载预分配铺平[3]；② 抄 Duolingo Birdbrain——底层算出 N 项到期，学生端只呈现「今日 M 张」，永不暴露原始逾期队列[34]。Anki 最大的劝退点恰恰是回来看到几百张积压[6]，半米一旦在复习模块暴露原始 backlog，就把架构层面规避掉的头号 churn 杀手又请回来了。注意主观难度档别乱映射（FSRS 里只有 Again = lapse，Hard 仍算成功[1]）。

★ P0-4 知识图谱可视化范式 + 错题标错因

半米三曲线动态档案的知识图谱部分缺一套可视化语言。直接抄现成的：ALEKS 饼图（深=已掌握 / 浅=ready-to-learn / 空=未学[29]）/ IXL SmartScore 0–100（难度+准确+一致性加权[28]）/ Khan 命名等级（Familiar→Proficient→Mastered[28]）——三者都是验证过的 UI 语言，不必自己发明。同时，错题进池时标错因类型（不只对错，参考松鼠 AI 五维错因[31]）——这既喂老师诊断，又为后续 BKT 估计提供输入。注意对中国学生用命名等级而非冷数字、慎用非对称罚分（IXL 答错重扣易挫败[28]）。

FAQ常见问题▾

Q1半米该不该自研发音评分引擎（GOP）？＋

不该一上来自研。ELSA 的护城河不是算法、是带口音的 L2 训练数据（能识别中国/越南学生特有错音）[10]。从零训练极易对中国口音误判：过严打击信心、过松毫无意义。正确路径是先接 ELSA API 或开源 GOP（wav2vec2-based）验证口径、跑通跟读评分体验，等有了足够本土录音数据、且单位成本压不下来时再评估自研。这跟半米既定的「先接 Azure mock、V0.2 接真 Azure」节奏一致。

Q2复习算法该选 FSRS 还是 Leitner/SM-2？＋

选 FSRS，半米已经选对了。FSRS-6（2025，约 7 亿条复习训练）用 S/D/R 三态 + 幂律遗忘曲线，同 90% 留存比 SM-2 少约 20–30% 复习量[1]；Leitner 太粗、SM-2 是上一代。但两个工程要点：① FSRS 短期记忆模型薄弱，新词「学习期」要单独密集排（别合进 FSRS）——半米两段设计正好对症；② 数据少时先用群体级参数，数据起来再 per-user 自动调参，别过早拟合。真正值钱的不是「换 FSRS」，而是把墨墨的「按时间预算封顶 + 不暴露 backlog」叠在 FSRS 上（见 Ch3）。

Q3GTM 该走 to-school（卖学校）还是 to-teacher（老师 freemium）？＋

混合双引擎，但早期重心放 to-teacher。MagicSchool 2 年靠 bottom-up 老师免费用做到 6M 教师、近乎零销售成本[41]；自上而下卖学区（IXL/DreamBox）销售周期长、回款慢[28]，早期现金流撑不住。半米四级账号天然支持这条：老师免费用 → 学校为「集中管理 + 合规 + 监管台」付费 seat。关键纪律：核心产出别锁付费墙后（MagicSchool「免费但导出付费」激怒用户），变现点是企业级管理/合规而非功能阉割。

Q4背景提升（升学软实力）怎么产品化？＋

抄 Polygence/Lumiere 的标准 SKU 模式：把「约 10 次 1:1 + PhD/资深导师 + 12 周 → 1 篇论文/作品」打包成可独立售卖、可加价阶梯的产品（Individual → Publication → Fellowship 阶梯定价 $3.2k–9.9k）[47]。这是升学线里最该立刻做的高毛利模块——不需要 Crimson 那种 2400+ 真人导师网络的重投入，单元化即可卖。半米的差异化在于：背景提升产生的数据（论文主题、技能成长）能沉淀进同一个动态档案，喂录取概率分/roadmap，这是纯背景提升公司给不了的全链路。

Q5英语自适应该不该学松鼠 AI 的「1 万纳米知识点」？＋

不该。松鼠 AI 的超细知识点拆分是 K12 数学结构强、前置依赖清晰的产物[31]；英语技能边界模糊（一句话同时考词汇/语法/搭配/语用），盲目细化标注成本会爆炸且无收益。英语适合「技能 × CEFR 档」的中等粒度 + 词汇本位的单点追踪。可以借鉴的是松鼠的五维错因诊断（错题标错因类型而非只对错），但拆分粒度要克制。

Q6知识追踪算法 IRT / BKT / DKT 怎么选？＋

渐进上：IRT（静态能力 θ，适合定级冷启动）→ BKT（每技能 2 态、4 可解释参数，适合给老师看的逐知识点掌握图、小数据友好）→ DKT 后置（RNN/Transformer，精度最高但数据饥渴、不可解释）[30]。别一上来上 DKT：数据不够会过拟合，且它给不出老师能读的单点数值，与半米「动态档案给老师看」的目标直接冲突。注意 FSRS 管复习时机、BKT 管掌握度，两者并存而非替代——它们一起串成「定级种子 → 知识图谱 → BKT 掌握度 → FSRS 复习」的同一大脑链路。

Q7AI 能直接给学生官方雅思 band / CEFR 分吗？＋

不能直接给「官方」分。连剑桥 Write & Improve 都只敢称 AI 给出的是「估算 band」、明确声明非官方，写作/口语保留人工复核[20]。ETS e-rater 更是被 BABEL 生成器实证可刷分（胡话靠长度拿高分）[21]。半米守住「AI 初评 + 老师终审」边界：AI 给 formative 反馈和「估算区间」，正式 band 由老师确认。这不是技术不足，是行业最佳实践。

Q8精听里「先盲听后字幕」真的比「带字幕看」强吗？怎么防退化？＋

强，但必须门控。FluentU/LingQ/Trancy 全行业的通病是：一旦字幕随手可开，「精听」就退化成「带字幕看视频」，主动听的环节被跳过。半米 LE 流程「先盲听 → 后字幕」是优势，但要硬门控：循环 N 遍或盲听一遍才解锁字幕[12]。再叠加听写填空判分（Yabla Scribe / 欧路：词级新手、句级进阶），强制把「听懂」变成「能写出来」，这是半米现有 detail 题多为选择题最该补的环节。

Q9游戏化要不要做？做到什么程度？＋

做克制版。Duolingo 连胜的有效设计可借鉴（完成 1 个主任务就保连胜、漏掉的天不成债、Streak Freeze 当缓冲[34]）+ Khan 的努力/掌握双轨（来了就有 energy，但明确「努力≠学会」[43]）。但坚决不学 Duolingo 暗黑模式：愧疚/羞辱推送、损失厌恶当核心循环、默认公开竞争排行榜（东亚学生焦虑度高，设为可选/私密）——Prodigy 已因操纵性营销遭 FTC 投诉[44]。半米「激励放个人空间、装饰与学习主循环解耦」的方向对，保持即可。

Q10老师端 AI 助教最该先做哪一个功能？＋

把 recommendation_queue 做成 Wayground 式可执行回路（薄弱技能 → 自动补救题 → 一键派给特定学生）[36]。理由：① 地基已有（assignment 链 + agent_operation 审计 + Dashboard 已存 recommendation_queue 字段），是工程量最小的临门一脚；② 它直击半米「省老师力气 + 把状态估给老师」的核心定位，把诊断从「看曲线」升级到「可执行」；③ 守住 human-in-loop（老师可改可拒）即避开全行业共识红线。比「再加一个内容生成工具」（Diffit/Twee 已做透）杠杆高得多。

Q11中式英语检测真能做出差异化吗？＋

能，这是中国学生市场的差异化王牌。批改网是少数明确做中式英语检测的产品——靠语料库「查无此用法即标疑似中式英语」[19]；通用语法工具（Grammarly）只查语法对错，不判「native 不这么说」。半米可建 IELTS 范文 + L1-Chinese 高频误用语料，在写作反馈里标「语法对但 native 不这么说」。配合渐进式反馈（首轮只标最高频错误，防轰炸[20]），既保 formative 不喂答案，又给中国学生最痛的点。

Q12半米要不要追「任意 Netflix 视频注入」做精听？＋

不必追，自有可控语料反而是护城河。Language Reactor 靠注入 Netflix 字幕起家、约 2–3M 用户[11]，但字幕质量与时间戳对齐受制于平台，且它没有移动端。半米的 Crash Course/EnglishPod 是自有语料 + 严格时间戳对齐 + WebCodecs 逐句播放器，精听体验的下限可控，这比「任意注入」更稳。别为追求「任意视频」牺牲对齐质量——逐句精听的核心体验恰恰建立在时间戳精度上。Language Reactor 无移动端，正是半米 Web 端的机会窗口。
