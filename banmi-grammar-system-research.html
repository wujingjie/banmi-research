🎯 5 条核心结论

颠覆 #1 EGP 是 CC BY-NC 许可证，半米直接用要谈授权
很多人以为 EGP「免费可用」。事实是：EGP 论文和数据是 CC BY-NC 4.0，明确禁止商用[8]。半米作为收费产品，把 1,239 条 grammar points 直接灌进数据库 = 违反许可证。正确路径：(1) 把 EGP 当 reference / inspiration（合规）；(2) 自家重写描述符（避抄但可参考分级）；(3) 主动联系 Cambridge English 谈商用授权（参考 EVP 模式，他们对教育产品授权友好）；(4) 同时用 EGP + 旋元佑 + EGP-J + CEFR 教学大纲 多源交叉，自家产出独立的"半米 Grammar Profile"。这是阿杰必须立刻做的合规决策。
结论 #2 旋元佑《语法俱乐部》22 章是半米语法 V0.1 的最佳骨架
《语法俱乐部》22 章分 3 篇（初级 11 章 / 中级 4 章 / 高级 7 章）[9]，覆盖 A1→C1 完整跨度，且每章都是单一概念聚焦（基本句型 / 时态 / 不定词 / 动名词 / 分词 / 介系词 / 各种从句 / 倒装）。豆瓣 9.5 分 / 5200 人评价 / 78% 五星[5]，是中文圈最高口碑的语法书。对半米的价值：22 章 = 22 个 V0.1 课程模块的天然单位，每章配 10-20 grammar points，总共约 ~250 grammar points 覆盖 A1→B2 90% 范围。
结论 #3 张满胜的"思维"路线是产品文案差异化金矿
张满胜《英语语法新思维》三册（初/中/高，2008-2020 多版）做的事 = 把规则后面的认知逻辑讲出来[6]。例如冠词 a/an/the 不是"规则"而是"认识/不认识 + 全集/子集"的思维；现在完成时不是"have + 过去分词"而是"过去事件对现在产生影响"的视角。对半米的价值：每个 grammar point 的"为什么"讲解直接拿张满胜风格的文案做模板（不抄文字，学方法）— 这是和市面所有 grammar app（包括 Murphy / Babbel）的差异化卖点。
结论 #4 9 种题型不要全做 — V0.1 只做 5 种就够
SLA 学界共识题型：选择 / 完形 / 改错 / 句型转换 / 翻译 / 排序 / 角色扮演 / 自由写作 / 诊断题。但 Norris & Ortega 2000 meta-analysis 显示显性 form-focused 教学效应量 1.22[7]，类型多样性比题型数量重要。半米 V0.1 建议：只做 5 种（选择 50% + 完形 20% + 改错 15% + 句型转换 10% + 诊断 5%），把每个做透；翻译题留 V0.2（要 AI 评分）；角色扮演 / 自由写作留 V0.3（要 AI 对话）。
结论 #5 AI 改错精度已经到 93-98%，但中国学员需"双层兜底"
2025 研究 GPT-4 两步 pipeline（fine-tune + structured edits）改错精度德语 93.9% / 中文 98.0%[10]；Grammarly 76% / LanguageTool 略高 / Linguix 72%[11]。但：(1) 仍有 hallucination；(2) 中国学员典型错误（冠词缺失 / 时态混用 / 中式表达）需额外 prompt 偏置；(3) 半米建议 Haiku 4.5 主跑 + GPT-4o-mini 兜底 + 规则引擎（自家维护中式错误库）做最后一层。直接套 Grammarly 风险：错误漏判 + 偶尔乱改用户的对句。

02English Grammar Profile (EGP) · CEFR 语法对标的圣经 ★▼

结论先行：EGP = 半米语法板块的对标圣经，跟 EVP (English Vocabulary Profile) 在词汇板块的角色完全对应。EGP 是 Cambridge 用 5500 万词学员语料（Cambridge Learner Corpus，CLC）实证标定的 1,239 条 grammar competence statements，每条 mapped 到一个 CEFR level (A1-C2)。阿杰之前在 vocab 用了 EVP / Oxford 3000，现在用 EGP 是同款思路、不同维度。

2.1 EGP 是什么 · 怎么建立的

📐 1,239 条 corpus-driven grammar competence 描述符 SLA 学界共识
Anne O'Keeffe (Limerick University) + Geraldine Mark 主编；Ron Carter + Mike McCarthy 学术顾问[1][2]

背景：English Profile (EP) 是 Cambridge University Press + Cambridge English Language Assessment + University of Bedfordshire (CRELLA) + British Council + English UK 等机构 2009 启动的研究项目[12]，目的是给 CEFR 各级语言能力配上英语专用的实证描述（CEFR 本身是 language-agnostic 的，只给"能用语言做什么"的 can-do statements，不给具体语言点）。

方法论 4 步：

  1. 数据源：Cambridge Learner Corpus (CLC) — 5500 万词学员英语，来自 250,000+ 考试作文，跨 200 个国家、140 种母语背景、1993-2012 共 17 年的考试数据[2]
  2. 语料标注：每个 grammatical structure 在每个 CEFR 级别 emerge 的频率被统计
  3. criterial features 提取：找出"该级 emerge 且更低级不 emerge"的特征 — 这就是 criterial features（Hawkins & Filipović 2012 提出的概念[13]）
  4. 描述符撰写：每个 criterial feature 写成"can do" 风格的描述（如 A1: "Can use 'be' as a main verb with a limited range of common adjectives"）

关键洞察：EGP 描述"学员实际能做什么"（descriptive），不是"应该教什么"（prescriptive）。例如某语法点理论上 A2 该会，但实际数据显示 90% 学员 B1 才能稳定用 → EGP 标 B1。这跟传统 syllabus 设计相反。

2.3 怎么访问 · 数据格式 · 字段

访问路径：

  • 🌐 在线搜索：englishprofile.org/english-grammar-profile — 免费 + 不强制注册（注册可订阅 newsletter）[14]
  • 📊 下载：官网不直接提供 CSV / Excel 下载（要求点条目逐个看）；ninja33 GitHub 社区维护的 EGP Excel (1,239 items) 是非官方但完整的备份[1]
  • 🔬 学术使用：可以申请 Cambridge English Profile Corpus 研究访问；论文已开源

搜索功能：分 simple search + advanced search 两种[15]：

  • Simple：按 CEFR level 筛 + 关键词
  • Advanced：按 Super Category + Sub Category + Form/Use + CEFR level + 关键词组合筛

数据字段（每条 grammar point）：

  • guideword — 简短标签（如 FORM: PAST SIMPLE）
  • Super Category — 大类（如 ADJECTIVES / CLAUSES / MODALITY / NEGATION / PASSIVES / TENSES / etc.）
  • Sub Category — 子类
  • Level — A1 / A2 / B1 / B2 / C1 / C2
  • Can-do statement — 描述符全文（如"Can use 'be' to give personal information about themselves and others, with a limited range of common nouns and adjectives."）
  • Example(s) — 真实学员语料里的例句
  • Lexical Range — 涉及的词汇范围（部分条目有）

2.6 EGP B1 / C1 抽样（看难度跨度）

B1 sample（中阶 — 半米核心战场）：

  • Can use present perfect with 'just/already/yet'
  • Can use past perfect to talk about earlier past events
  • Can use first conditional (If + present, will + V)
  • Can use defining relative clauses with who/which/that
  • Can use 'used to' for past habits
  • Can use reported speech with simple statements
  • Can use passive voice in present and past simple
  • Can use modal verbs for advice (should/ought to/had better)
  • Can use comparative + 'than' with adverbs
  • Can use 'enough' + noun / 'enough' after adj

C1 sample（高阶）：

  • Can use inverted conditional 'Had I known...'
  • Can use 'no sooner...than' inversion
  • Can use 'not only...but also' with inversion
  • Can use mixed conditional (If I had... I would be...)
  • Can use cleft sentences for emphasis (It was X that...)
  • Can use nominalisation in academic register (the increase of X)
  • Can use 'lest' / 'unless' in formal context
  • Can use 'as if/though' + past for hypothetical
  • Can use participle clauses to reduce relative clauses
  • Can use 'whatever / whichever / whenever / however' clauses

2.7 ⚠️ 商用许可证警告（阿杰必须看）

关键问题：EGP 论文 (O'Keeffe & Mark 2017, International Journal of Corpus Linguistics) 是 CC BY-NC 4.0 许可证[8]。这意味着：

  • ✅ 可以做：学术研究 / 老师上课 / 非营利项目 / 个人学习
  • ❌ 不能做：直接复制 1,239 条描述符到付费 app / SaaS 产品 / 收费课程
  • ⚠️ 灰色地带：作为 reference 参考、自己重写 / 选取 grammar point 命名（避抄）

半米合规路径（4 选 1 或组合）：

  1. 主动谈授权：联系 Cambridge English Profile 团队（contact form 在官网），询问商用授权 — EVP 已经有合作模式（多数 ELT 出版商付费授权），EGP 应该类似
  2. 自家重写：用 EGP 做分级 reference，描述符自己写（"Can use present perfect..." 改成"用 have/has + 过去分词谈过去对现在影响" — 张满胜思维风格），分级数字可以参考但不能直接说"基于 EGP"
  3. 多源合并：EGP + EGP-J (Tono 2008, Japan)[16] + 中考/高考大纲 + 雅思官方 grammar 范围 + 张满胜分级 → 综合产出"半米 Grammar Profile" v1.0
  4. 退一步：V0.1 不公开宣称"基于 EGP"，只内部参考；V0.2 取得授权后才公开

无忌建议：方案 #1 + #3 并行。Cambridge 谈授权同时自家做合并版（即使授权不下来也能用）。这一点比技术实现重要。

CEFR-J 项目（Tono 启动于 2008[16]）：日本因为整体英语水平偏 A1-A2，把 CEFR A1 进一步细分成 pre-A1 / A1.1 / A1.2 / A1.3 等子级，每个子级配对应的 grammar + vocab。对半米的启示：中国 K12 学员（尤其是公立学校）整体也在 A1-B1 区间，可以效仿 EGP-J 的做法把 A1 / A2 细分成 3-4 个子档（如 A1.1 = be 动词 + 基础名词 / A1.2 = 一般现在时 + can / A1.3 = 简单问句 + 一般过去时基础）。这给 V0.1 课程模块的颗粒度提供了细分依据。

  • 非谓语动词：动名词作主宾 / 动词不定式 to do

9.3 "思维"举例（半米产品文案可直接借鉴）

例 1：冠词 a/an/the（A1 痛点）

传统讲法："不定冠词 a/an 用在可数名词单数前，第一次提到用 a/an，再次提到用 the；the 是定冠词，表示特指。"

张满胜讲法：

  • a/an = 不认识，"某一个"（说话人或听话人不知道是哪个）
  • the = 都认识，"那个特定的"（说话人和听话人共同知道）
  • 无冠词 = 全体 / 抽象（不是某一个也不是特定的，是整个概念）

→ "I want a book"（任何一本）/ "I want the book"（你知道我说的那本）/ "I love books"（书这个东西）。一个思维框架解释 3 种用法。

例 2：现在完成时（中考痛点）

传统讲法："现在完成时由 have/has + 过去分词构成，表示过去发生的动作对现在产生影响或结果。"

张满胜讲法：

  • 过去时 = 镜头切到过去那个时间点，现在已经"结束、远去"
  • 现在完成时 = 镜头停留在现在，但向过去回望，强调"这件过去的事对现在的我有什么 relevance"

→ "I lost my keys"（过去某时点丢了，可能已经找到）vs "I have lost my keys"（丢了，现在还没找到、正困扰我）。用"镜头位置"解释时态选择。

例 3：虚拟语气（高考痛点）

传统讲法："与过去事实相反的 if 虚拟条件句，从句用 had done，主句用 would have done..."

张满胜讲法：

  • 虚拟 = "假装跟事实相反 / 假设"
  • 过去 form 表非现实 — 因为"过去 = 已经远去 = 不是现在的事实"，所以用 was/were/had 来"标记"这是虚拟
  • 跟"时间"无关，只跟"现实距离"有关

→ "If I were rich..."（我不富，假设我富）/ "If I had been rich..."（我那时不富，假设那时富）。用"现实距离"代替"时态规则"。

  • Lakoff & Johnson Metaphors We Live By (1980) — "时间 = 空间"等隐喻 → 张满胜"过去 = 远去 = 镜头远"

  • Goldberg Constructions — 句型本身有意义 → 张满胜的句型分析视角

12.1 选择题 Multiple Choice

① 单选 / 多选 / 多选填空 最基础
SLA 学界证据强 + 易自动化评分[53]

实现：句子配 4 个选项，学员选 1 个正确答案。例 "I ___ to school yesterday." (A) go (B) goes (C) went (D) gone。

学界证据：British Council 列为 grammar 测试 #1 题型；可测语法 / 词汇 / 阅读 / 听力多维度[53]。缺点：学员可能"猜"出来；不能测产出能力。

适合 CEFR：全档（A1-C2 都可用）。

AI 时代升级：多选完形（MCC） 是 2024-2025 SLA 学界研究热点（Bondielli et al. 2024[54]）— 用 GPT-4 自动生成 distractors 是新方向。

12.2 完形填空 Cloze / Gap Fill

② 句子或段落挖空 SLA 学界最爱
Oller 1971 起 50+ 年研究[53]

实现：句子或段落挖 1 个或多个空，学员填正确单词 / 短语。可配选项（multiple-choice cloze）或不配（fill-in）。

学界证据：cloze 测的是"对上下文的整体把握" + "目标语法 / 词汇"双维度，跟"高阶 listening / reading"高度相关（Cai 2013 confirmatory factor analysis[53]）。是高考 / 中考核心题型。

适合 CEFR：A2-C2。

变体：

  • 挖每 N 个词（randomly delete every 7th word）— 经典 C-test
  • 挖目标语法点（只挖动词形态）— focused cloze
  • 挖词类（挖介词 / 冠词）— 中国学员痛点专项

12.3 改错题 Error Correction

③ 短文改错 / 句子改错 高考必考
中国高考核心题型[33]

实现：给一段含错的句子或短文，标出 / 改正错误。两种形式：

  • 标识错误："Find the error"（仅指出哪里错）
  • 改正错误："Correct the error"（指出 + 改对）

学界证据：Lyster & Ranta (1997) corrective feedback 研究显示"指出错误 + 让学员自改"比"直接给正确答案"效果更好。改错触发 Schmidt noticing。

适合 CEFR：B1-C2（A1-A2 学员还不知道什么是错）。

AI 时代升级：AI 改错（GPT-4 / Grammarly）已经成熟，半米可让 AI 出错（故意生成含中式错误的句子让学员改）— 这是中国学员痛点针对性强的题型。

12.4 句型转换 Sentence Transformation

④ 主动→被动 / 直接→间接 / 简单→复合 Cambridge 经典
KET/PET/FCE 经典题型[53]

实现：给一句话 + 提示词 / 句型，学员改写成意思相同但结构不同的句子。例：

  • "He has lived here for 10 years." → 用 "since" 改写：He has lived here since 2014.
  • 主动→被动：They built the house in 1990. → The house was built in 1990.
  • 直接→间接：He said, "I am tired." → He said he was tired.

学界证据：British Council 评价："易评分但不测理解"，学员可能"机械应用公式"。Norris & Ortega 显性教学效应量 1.22 部分来自这种题型[7]。

适合 CEFR：A2-C1。

12.5 翻译题 Translation

⑤ 中→英 / 英→中 中国体系核心
CET-4/6 + 考研 + 高考

实现：给中文 / 英文，学员翻译。可以是句子、段落（CET-4/6 是 ~150 字段落）。

学界证据："翻译法"在国际 SLA 学界争议大（直接教学法反对，认为应"全英文"）；但翻译能 explicit 测语法 + 词汇 + 文化对应，对中国学员有针对性。

适合 CEFR：B1-C2。

AI 时代升级：GPT-4 / 通义千问 / Claude 等翻译质量高，可作"参考答案"。半米 V0.2 加翻译题需要 AI 评分（不能简单 string match，要语义匹配）。

12.6 句子排序 Sentence Scramble

⑥ 单词排序成句 / 句子排序成段 UI 友好
Duolingo 招牌题型[55]

实现：给打乱的单词 / 句子，学员按正确顺序排。Duolingo 的 "Tap the words in order" = 这个题型最广泛的产品化。

学界证据：2025 印尼研究（Naghshbandi et al.）显示scrambled sentence 显著提升写作分数（实验组从 55.96 → 80.96，对照组 56.28 → 66.16）[55]。但SLA 学界研究不多。

适合 CEFR：A1-B1（高级学员太容易）。

对半米：A1-A2 学员入门首选，UI 友好可触屏，是 V0.1 必备题型。

12.7 角色扮演 / Dialogue

⑦ 情境对话 / 完成对话 交际法核心
Communicative Language Teaching (CLT) 标志题型

实现：给情境 + 一方台词，学员填另一方台词。或两人 / AI 对话练习。

学界证据：Swain output hypothesis + Long interaction hypothesis 支持"通过交互产出促进习得"。但纯角色扮演对测语法不够精准（评分困难）。

适合 CEFR：A2-C2。

AI 时代升级：GPT-4 Voice / Claude Voice 可做AI 角色扮演伙伴，半米 V0.3 可加（成本高 / 需 V0.2 后用户量上来再做）。

12.8 自由写作 + AI 语法评分

⑧ 命题作文 / 续写 / 读后写 最高阶产出
IELTS Writing / SAT Essay 核心

实现：给题目（"Write about your weekend in 80-100 words"）→ 学员自由写 → AI 评分 + 改错 + 改写。

学界证据："读后续写"（Wang Chuming 2012）在中文 SLA 圈实证强 — interactive alignment 显著提升写作准确率[56]。Swain output 理论支持。

适合 CEFR：B1-C2。

AI 升级：2025 GPT-4 改错精度 93-98%[10]，可作 V0.2 主打。Grammarly / LanguageTool 是 benchmark。

12.9 诊断题 Adaptive Placement Test

⑨ Adaptive 摸底 入门必备
Cambridge Placement Test / Duolingo DET[57]

实现：10-30 题 adaptive 测试 — 根据学员前一题对错调整下一题难度，最终给 CEFR 等级。Cambridge Placement Test 30 分钟测出 Pre-A1 到 C2[57]。Duolingo DET 用 AI adaptive 算法，2024 70 万+ 考生[42]。

学界证据：CAT (Computerized Adaptive Testing) 在 EFL 测试领域是金标准。10-15 题可达到传统 30-40 题的测量精度。

对半米：新用户首次打开必跑诊断（10-15 题，3-5 分钟），定 CEFR 等级 → 推个性化课程模块。这是半米差异化的关键体验（Duolingo 没有强制 placement，导致学员从 A1 一路点 hours 才到合适难度）。

13AI 时代新练习方式▼

2023+ GPT 普及后，5 种 AI 原生 grammar 练习方式开始成熟。半米要做的不是"加一个 AI 按钮"，而是从根本上把 AI 嵌入到 9 种题型 + 错题诊断 + 反馈环节。

13.1 AI 改错 + 解释（写作纠错）

🤖 Write & Correct 最实用
2025 GPT-4 改错精度 93-98% (German/Chinese L2)[10]

实现：学员写一句 / 一段 → AI 找错 + 改正 + 解释为什么错。

关键：解释比改错重要。Grammarly 早期只标红 + 给出建议，不解释 → 学员学不到。GPT-4 之后才能做"为什么这里要用 the 不用 a"的针对性解释。

2025 学界研究：

  • Wu et al. 2025 (SAGE Open) — AWCF (Automated Written Corrective Feedback) 用 GPT-4 比 Grammarly Commercial + GPT-3.5 fine-tune 都好[10]
  • F1 = 93.4%（动词时态）/ 91.7%（冠词缺失）— 中国学员两大痛点
  • 但仍有 hallucination — 偶尔 AI 改对的句子"以为不对"

半米实现：Haiku 4.5 跑主流（速度 + 成本）+ GPT-4o-mini 兜底 + 规则引擎（自家维护中式错误库 300+ 模式）做最后一层。详见 §14.5。

13.2 对抗性出题 Adversarial Question Generation

🎯 AI 针对学员错题模式出题 个性化王者
GPT-4 自动生成精度 ≈ 人工[58]

实现：

  1. 学员错题 → 标签化（"现在完成时 vs 一般过去时 confusion" / "the/a/an 误用" / "动词时态不一致"）
  2. GPT-4 prompt："给我生成 5 道针对'现在完成时 vs 一般过去时 confusion'的多选题，distractors 要 plausible"
  3. AI 出题 → 半米审核（自动 + 人工抽检）→ 推给学员

学界证据：Bloom et al. 2024 (Springer) — GPT-4 生成的 multiple-choice questions 质量已经超过本科生 / 研究生[58]。但医学考试场景仍有 ~10-15% faulty questions，质量控制必要。

对半米：错题本 + AI 出题闭环 = 半米可以做到"题目永远新鲜 + 总是针对学员盲点"的差异化。Duolingo / Babbel / Murphy 都做不到这一点（题库是 fix 的）。

13.3 语法听写 Dictogloss（AI 增强版）

👂 AI dictogloss 夯实多技能
Wajnryb 1990 经典方法 + AI 评分[59]

传统 dictogloss（Wajnryb 1990）：听一段 → 记关键词 → 小组讨论复原全文 → 对照原文找语法点。证据强但需要小组 / 老师。

AI 增强版：

  1. 学员听一段 30-60 秒短文（半米视频例句库现成材料）
  2. 学员独自复原（输入完整文本）
  3. AI 对比原文 + 学员版本 → 标出"语法差异"（不是"完全错"而是"语法选择不同导致意思差异"）
  4. AI 解释每个差异（"这里你用了一般过去时，原文用了现在完成时，因为强调...")

SLA 学界：dictogloss 综合 40 篇研究显著提升写作连贯性 + 语法准确率[59]。AI 让单人也能做。

对半米：跟半米的 Dictation 子模块无缝接入 — 视频例句 → dictogloss 模式 → AI 对比 + 反馈。这是极少 App 做到的（market gap）。

实现：

  1. 学员选 grammar point（如"第三条件句"）

SLA 学界：Tamai shadowing 30 年研究（已在 #16 报告深扒）+ Schmidt noticing hypothesis 双重支持。"selective shadowing" 是新概念 — 不是全跟读，是"针对性高亮 + 反复跟读目标语法"。

对半米：这是半米独门金矿（其他 grammar app 没有视频例句库，只能用文本 / 静态 audio）。半米已经有视频例句库 + Whisper ASR（V0.2），加 selective shadowing 是最低成本最高 ROI的功能。

Why：这是半米跟所有市面 grammar app 的差异化卖点：

  • Babbel / Murphy 讲"规则 + 例子"（form-focused）
  • Duolingo 不讲，靠输入归纳（implicit）
  • 张满胜讲"为什么"（meaning + use focused）
  • 这是认知语法（Lakoff / Langacker / Larsen-Freeman 学派）的产品化

How（可执行清单）：

  1. 制订"半米 grammar 讲解写作风格指南"（1 页 SOP）：
    • 150-200 字 / point
    • 先讲"为什么"（思维 / 隐喻 / 现实距离），再讲"形式"
    • 必含 1 个中英对比例子
    • 不用"规则" "公式" "always" "never" 字眼
    • 用"镜头位置" "距离" "认识/不认识" 等具象比喻
  2. 每个 grammar point 写 3 版讲解（A1 入门版 / B1 进阶版 / 老师版），学员按 CEFR 等级自动看对应版本
  3. AI 辅助生产：用 Claude / GPT-4 prompt 生成草稿（提示带"张满胜思维风格 + 不抄"），人工 review 改写
  4. 每周 5 篇 / 月 20 篇 / 半年 120 篇 = 覆盖 V0.1 500 grammar points 的 25%（pareto 原则，高频 grammar 优先）

14.5 建议 #5 · AI 改错 Haiku 主跑 + 规则引擎兜底

What：AI 改错 = 三层架构：

  • L1 主跑：Anthropic Claude Haiku 4.5（速度快 / 成本低 / 中英文都行）
  • L2 兜底：OpenAI GPT-4o-mini（Haiku 不确定时 second opinion）
  • L3 规则引擎：自家维护"中式错误库 300+ 模式"（如 "Chinese person → Chinese people" / 缺冠词 / 时态混用），LanguageTool 风格的正则匹配

Why：

  • Haiku 4.5 = $0.25/M input / $1.25/M output，跑 100 字句子 ≈ $0.0001 / 次 → 1000 学员每天 100 改错 = $10/天，月 $300，可承受
  • GPT-4o-mini 比 Haiku 4.5 在英文语法上略好但更贵，做 second opinion
  • 规则引擎抓 AI 不擅长的"中式典型错误"（如 every day / everyday 混用，AI 经常放过）
  • 三层降低 hallucination 风险（AI 偶尔会把对的句子改成"错的"）

How（可执行清单）：

  1. 第 1 周：搭 Haiku 4.5 改错 API + prompt engineering（核心 prompt 含 "学员母语是中文，常见错误如下..." 偏置）
  2. 第 2-3 周：搭中式错误库（手工整理 300+ 模式 + 正则匹配脚本）— 这是 V0.1 的护城河
  3. 第 4 周：内测 — 100 个学员句子，三层都跑，对比 Grammarly / LanguageTool 看哪里好哪里弱
  4. 验收：F1 score ≥ 0.85（参考 2025 GPT-4 研究的 0.934）；hallucination rate < 5%
  5. UI：错的部分标红 + 点开看解释（200 字以内，张满胜风格）+ "是否同意改正？" 反馈按钮（用户反馈反过来训练规则库）
  6. Cost monitoring：Anthropic dashboard 每天看用量，超 $20/天报警

14.6 建议 #6 · 跟视频例句库 / Shadowing / Dictation 联动

What：grammar 板块不是孤岛，要跟词汇库 + Shadowing + Dictation 4 大模块串联。

Why：

  • 语法不是孤立学的，是在真实语境中学的（Krashen i+1 / Larsen-Freeman form-meaning-use）
  • 半米已经有视频例句库（前 3 份研究焊死了的资产）— 不用 = 浪费
  • Shadowing 跟读 + Dictation 听写 = 已经做的练习方法，加 grammar 高亮 = 边际成本几乎为零

How（可执行清单 5 个联动点）：

  1. 语法 → 视频例句：每个 grammar point 配 3-5 个真实视频例句（从 SciShow Kids / VOA / Crash Course Kids 等已抓视频库筛）— 学员看完讲解直接看真实使用
  2. 语法 → Dictation：grammar 学习后 5 道"挖目标语法点"的 cloze 听写（如学完现在完成时，给 5 段含 have/has + V-ed 的音频，挖空让填）
  3. 语法 → Shadowing：grammar 学习后 3 句"selective shadowing"（跟读 + 目标语法点高亮 + Whisper 评分发音）
  4. 词汇 → 语法：学员学某个高级词时（如 "achieve"），跳出"这个词用在哪个语法结构里"按钮（如 "achieve + N / achieve to V / be achieved by"）
  5. 语法 → 词汇：学某个 grammar point 时（如关系从句），自动推 5 个 B1+ 词来用（如 "decision, opportunity, achievement, situation, experience" — 都是关系从句高频先行词）

14.7 建议 #7 · 错题本 + SRS 复习闭环

What：错题不仅记录，还要按FSRS / SM-2 算法自动调度复习。

Why：Norris & Ortega 元分析显示显性 + 多次练习 = 最有效。错题是 noticing 之后必须 procedural 化的关键。Anki / 不背单词等都验证了 SRS 在词汇上的效果，grammar 同样适用（虽然学界研究稍少）。

How（可执行清单）：

  1. 错题数据 schema： 
    error_id | grammar_point_id | original_q | student_ans | correct_ans | error_type | next_review_at | difficulty
  2. SRS 算法：V0.1 用 SM-2（成熟 + 实现简单），V0.2 后台并行 FSRS（学员积累 1000+ review 后自动切，少 20-30% 复习量[61]）
  3. 错题类型自动标签：用 AI 把每次错归到"现在完成时 vs 一般过去时 confusion" / "the/a/an 误用" 等具体标签（用 LLM 分类，简单 prompt 即可）
  4. 每日复习推送：每天 10-15 题（混合"今天错的 + 昨天的 + 前周的 + 上月的"渐进梯度）
  5. "弱点雷达图"：学员个人页显示按 grammar Super Category 的掌握度（如"时态 65% / 冠词 80% / 介词 40% / 从句 70%"）— 让学员看到自己的弱点 + 形成回访动力
  6. "错题集 PDF 导出"（参考 Perfect English Grammar 模式）— 每月给学员发"本月错题精选" PDF，含 50 道错题 + 思维讲解，可打印

14.8 建议 #8 · Placement Test 10-15 题摸底

What：新用户首次打开必跑 10-15 题 adaptive placement test，3-5 分钟，定 CEFR 等级 → 推个性化课程。

Why：

  • Duolingo 的"教训" — 没强制 placement → 学员从 A1 一路点 hours 才到合适难度 → 流失
  • Cambridge Placement Test 验证：10-15 题 adaptive 测量精度 ≈ 30-40 题传统测试[57]
  • 个性化路径 = 半米差异化（Babbel / Murphy 都是固定课程）
  • 3-5 分钟 = 用户愿意付出的最大时间

How（可执行清单）：

  1. 题库设计：30-50 道题，每个 CEFR 级别 5-10 题（A1-C2 6 级），按 super category 平衡（时态 + 从句 + 冠词 + 情态动词 + 非谓语）
  2. Adaptive 算法：V0.1 用简化版 — 答对 → 下一题难度 +1；答错 2 题连续 → 下一题难度 -1；累计 10 题后给等级（A1.1 / A1.2 / A1.3 / A2 / B1 / B2 / C1 / C2，参考 EGP-J 细分）
  3. 结果展示：
    • CEFR 等级 + 描述（"你大概是 B1，相当于雅思 5.5 / Cambridge PET 水平"）
    • 3-5 个最强 super category + 3-5 个最弱（"你的时态强 / 冠词弱"）
    • 推荐第一个学习模块（最弱 category 入门）
    • 预计学完到 B2 所需时间（"按每天 15 分钟计 = 6 个月"）
  4. 重新测：每月 1 次（也可手动触发）— 看进步
  5. 家长仪表盘：placement test 结果 + 进步曲线推给家长 — 国际学校家长极在意"我孩子是什么 CEFR 水平"

16mini demo · 可玩的"语法练习样本"（5 题各题型示范）▼

下面 5 道示范题对应 §12 的 5 种 V0.1 题型 + §14.8 的 placement test 样题。点选项立即看反馈。

🎯 半米 grammar 题型示范（CEFR A2-B1 / 现在完成时）

样题 #1 · 选择题（A2）

I _____ to Paris twice.

A) have gone B) have been C) went D) go

样题 #2 · 完形挖空（A2）

Tom is here. He _____ (arrive) just now.

填：has arrived

样题 #3 · 改错（B1）

原句："I have went to school yesterday."

这句话有两个错。你能找到吗？

have went + yesterday 时态冲突 have went 形式 yesterday + 现在完成

样题 #4 · 句型转换（B1）

原句："They built this bridge in 1990."

用被动语态改写：

This bridge was built in 1990.

中国学员典型错：忘了变 was/were 的单复数；或把动词形式弄错（built / build / building）。

样题 #5 · 排序（A1-A2）

把下面单词排成正确句子：

has / Mary / her / lost / keys

Mary has lost her keys Has Mary lost her keys Mary lost has her keys

placement test 体验样题（A2-B1 探测）

If I _____ enough money, I would buy a car.

A) have B) had C) would have

📊 半米 placement test：10-15 题 adaptive，3-5 分钟，结果 = CEFR 等级 + 弱点雷达图 + 推荐第一模块。

16.2 题型设计要点（半米内部 SOP）

无忌注意事项：

  • 每个错选项必须解释为什么错（不能简单"错"）— 错的也是学习机会
  • 解释用张满胜思维风格（"为什么"不是"规则"）
  • 每题标 CEFR 等级（学员看了就知道这题对应自己等级）
  • 每题标 grammar point ID（错了自动入对应错题本）
  • UI 上错的不要红色刺眼（不是惩罚是学习）— 用橙色 + 温和提示

17FAQ 12 条 + References▼

17.1 FAQ · 阿杰最常问的 12 条

Q1.EGP 是 CC BY-NC，半米能直接用吗？+

答：直接用 = 违反许可证（参见 §2.7）。合规路径 4 选 1：(1) 联系 Cambridge 谈商用授权（推荐）；(2) 自家重写描述符（不抄但参考分级）；(3) 多源合并（EGP + EGP-J + 旋元佑 + 大纲）；(4) 内部参考不公开宣传。无忌建议 #1 + #3 并行。

Q2.旋元佑和张满胜两本都用，会不会内容重复？+

答：不会。两本分工明确（§10.2）：旋元佑做骨架（22 章结构 + 5 大句型），张满胜做文案风格（思维讲解）。不抄两本任何文字，参考结构 + 风格 + 思路。

Q3.中国学员真的不需要 SAT 标点那些东西吗？+

答：分两群。中考 / 高考路径学员不需要（中文教育系统）。国际学校学员 + 出国学员必需 — SAT 26% 是 grammar，其中标点占 25%+。半米 V0.3 加 SAT specific 路径就是为这群学员。

Q4.为什么 V0.1 只做 5 种题型？Babbel / Duolingo 都做更多。+

答：DeKeyser skill acquisition theory + Norris & Ortega 元分析：题型多样性比题型数量重要，5 种基础题型已经覆盖 EGP / Cambridge 考试 80% 题型。V0.1 重点在"把 5 种做透"（错题入 SRS + 思维讲解 + AI 改错），不是"覆盖广"。Babbel / Duolingo 的多题型是 N 年迭代结果，半米 V0.1 不该一上来全做。

Q5.Haiku 4.5 改错够吗？要不要直接用 Grammarly API？+

答：Grammarly 没开放 API（只有 Grammarly Business），而且贵。Haiku 4.5 改错 F1 已经接近 0.85-0.93，对中国学员够用；关键是规则引擎兜底（中式错误库 300+ 模式）抓 AI 漏的。三层架构（§14.5）= 比 Grammarly 单层效果好、成本低 1-2 个数量级。

Q6.国际学校 K12 学员真的会用半米 grammar 吗？他们都用 Khanmigo / IXL 了。+

答：Khanmigo 强在 STEM tutor，不做 grammar 系统。IXL 是美国 K-12 全学科练习题平台，grammar 有但是 native speaker 向 + 没有中文思维讲解。半米的差异化：母语非英语 ESL 学员定制 + EGP / CEFR 严格分级 + 视频例句库 + AI 改错 + 张满胜思维讲解。这 5 点 IXL 一个也不做。

Q7.Murphy 系列卖了 3000 万本，半米凭什么超？+

答：半米不是要替代 Murphy，是"Murphy 内容 + AI + SRS + 视频例句 + 个性化"的产品化。Murphy 是书：固定内容 / 不互动 / 不知学员水平 / 没即时反馈。半米是app：内容大致对标 Murphy 145 单元 + 加上书没有的（视频 / AI 改错 / 适应性练习 / 错题 SRS）。学员可以"先看 Murphy 学完一个 unit，再用半米的同主题模块练 + AI 反馈"— 半米 = Murphy 的练习闭环。

Q8.为什么 placement test 必做？我先让学员选 CEFR 不行吗？+

答：90% 学员不知道自己 CEFR 等级（甚至不知道 CEFR 是啥）。让他们自选 = 60% 选错（绝大多数高估自己）。Duolingo 当年的教训：早期没强 placement，导致学员从 A1 一路点 hours 才到合适难度 → 流失。Cambridge Placement Test 30 分钟 1 千万学员用过，效果验证。半米 10-15 题 3-5 分钟版 = 用户愿意付出的最大时间。

Q9.AI 改错有 hallucination，会不会把对的句子改错？+

答：会。所以三层架构（§14.5）的核心 = "是否同意改正？" 反馈按钮（用户反馈反过来训练规则库）+ 对低置信度改正显示"AI 可能错了"提示。同时 V0.1 monitoring：hallucination rate < 5% 是验收标准。GPT-4 2025 在 grammar correction 上 hallucination 已经显著降低（93-98% accuracy）。

Q10.EGP-J（日本本土化）对中国学员有借鉴吗？+

答：有。EGP-J 把 A1 进一步细分成 pre-A1 / A1.1 / A1.2 / A1.3，因为日本整体英语水平偏 A1-A2。中国 K12 公立学校也是 A1-B1 集中区，可以效仿。而且 EGP-J 是 MIT 许可证（可商用！）—— 阿杰可以直接用 olp-en-cefrj GitHub repo 数据。详见 §2.9。
