半米学习系统：笔记 + 复习系统调研

📅 2026-07-09 🔍 ~60 次检索 + 4 款标杆深扒 🧩 笔记形态 × SRS 打通 × 随时调出 🌏 立场：终端用户是东南亚 K12

一句话定调：「K12 儿童把课堂/阅读笔记自动变成复习卡、再由算法排期」这条管道，是被四款成人标杆和一票 K12 刷题产品共同漏掉的市场真空——半米不该照抄任何一款，而应该把 SuperMemo 的「增量阅读思想」、开源 FSRS 的「省 25–40% 复习」、Capacities 的「温故叙事」、Duolingo 的「streak 行为驱动」四样拆出来重新组装，做成「阅读/看视频时划一下 → 自动生填空卡 → FSRS 调度 → 游戏化催你回来」的儿童向闭环。

本报告按认知顺序展开：先立地基（Ch1 三要求 + 学习科学，Ch2 市场全景与 K12 真空），再逐一深扒四款标杆（Ch3 RemNote / Ch4 SuperMemo / Ch5 Heptabase / Ch6 Capacities），然后横向对比收敛（Ch7 大表），接着钻三个技术决策（Ch8 复习引擎选型 / Ch9 学习科学深化 / Ch10 游戏化），再解两个「怎么落」的机制题（Ch11 笔记⟷复习打通 / Ch12 随时可调出），最后给决策树和 MVP（Ch13）。所有价格标注访问日期 2026-07-09，关键数据标 🟢 多源 / 🟡 单源 / 🔴 估算，市场规模等分歧大的数据额外标 ⚠️。

📌 三条最关键发现（先扫这个）：

  • 「K12 儿童：记笔记 → 自动生复习卡 → SRS 调度」一体化管道是真空，谁补上谁独一份。四款标杆没一款瞄准儿童——RemNote/SuperMemo 面向大学生与自学者、Heptabase/Capacities 明确成人研究者；主流 K12 产品（Quizlet 有闪卡无笔记、Anki 有算法不适合儿童、Duolingo/Khan Kids/Prodigy 偏刷题游戏化）没一个做「笔记即复习单元」的一体闭环[44][51]。早在 2014 年就有人指出「面向孩子的间隔重复市场根本不存在」，2025–2026 仍然空白[51]。Readwise 用「高亮 → 每日复习」这条最朴素的输入闭环做到约 1400 万美元 ARR[49]（⚠️ 单源），证明这条管道有真金白银价值。🟢
  • 复习引擎别自研，直接接开源 FSRS——省 25–40% 复习量，对儿童反而更贴。FSRS 已是事实标准：Anki 自 v23.10（2023-10）内置，同样 90% 保留率下比老 SM-2 少 25–40% 复习、预测误差 ±5.3%（SM-2 是 ±16.2%）[38][39]；有 ts-fsrs（浏览器直跑）、py-fsrs、fsrs-rs 全栈可用[40][42]。儿童遗忘曲线更陡、更个体化，FSRS 的自适应拟合正好比固定间隔更快贴合；遗忘指数用默认 10%（保留率 90%）即可[11]。算法思想去学 SuperMemo 的「稳定性 S + 可提取性 R」双组件[11]，代码用别人写好的。🟢
  • SuperMemo 是「算法学它、体验千万别学」的双面教材——它自己都说不适合儿童。它的增量阅读流水线 Import → Read → Extract → Cloze → Review 是全行业最完整的「阅读→提取→回忆」闭环，思路完全可移植[15][16]；但官方专门写了《SuperMemo does not work for kids》，明说幼儿强记有害、外部激励（积分奖励）会形成「毒性关联」干扰内在动机，且官方正在远离游戏化[21][22]。半米要做的正好相反：让 AI/老师自动把内容切成 cloze，孩子只做题不建卡，再叠上正向反馈 + 可见进度 + 游戏化——把 SuperMemo 的引擎装进一辆孩子愿意开的车。🟢

01半米为什么需要「笔记 + 复习一体」▾

半米是东南亚 K12 行为驱动的 AI 学习操作系统，阿杰单人全栈。要给它建笔记系统，阿杰定了三条硬要求，这三条不是并列的功能清单，而是层层递进的一条产品主线：

要求一
笔记以卡片 Card / 块 Block 形态存在（可拆、可复用的原子单元）
要求二
笔记 ⟷ 复习（SRS）系统打通（记下即可进复习队列）
要求三
随时可调出，尤其是阅读时、看视频时（捕获零摩擦）

三条要求其实是一个问题：怎么让「学过」变成「记住」

K12 学习的真正瓶颈从来不是「看没看过」，而是「看过之后忘得多快」。要求一（卡片/块）解决的是复习单元的粒度——一整页笔记没法复习，一个知识点才能；要求二（打通 SRS）解决的是「复习」这个动作会不会真的发生——靠人自觉翻笔记必然失败，得让系统接管排期；要求三（随时调出）解决的是捕获成本——如果记一条笔记要切走应用、点五下，孩子就不记了。三条连起来是一句话：把「记笔记」这个孩子本来就会做的动作，无摩擦地变成一张会自动回来找他的复习卡。

学习科学地基：这不是产品经理的直觉，是几十年元分析的定论

「间隔 + 提取」是被反复验证过的两个最强学习技术，证据体量之大在教育心理学里少见：

间隔效应（spacing effect）：Cepeda 等 2006 年的元分析覆盖 254 项研究、14000+ 次观察，一致显示分散练习优于集中练习[52]；Donoghue & Hattie 2021 的元分析覆盖 242 项研究、约 169000 名被试，把「分散练习」和「提取练习」列为效应最稳的两类学习技术[53]。🟢 这正是 SRS（间隔重复系统）存在的理论基础——半米做复习系统不是赌一个趋势，是在一个几十年定论上盖房子。

测试效应（testing effect / 主动回忆）：Roediger & Karpicke 2006 的经典实验发现一个反直觉结论——学完仅 5 分钟后测，「重读组」略微领先；但 2 天后、1 周后再测，「提取练习组」显著反超[54][55]。🟢 换句话说：让孩子「再看一遍」感觉很努力、短期也见效，但真正把知识焊进长期记忆的是「合上书自己回忆一遍」。这决定了半米的复习卡必须是提取型（填空、问答）而不是重读型（把笔记再展示一遍）。

把这两块地基和三条要求叠在一起，半米笔记系统的产品定义就清晰了：一个让孩子在阅读/看视频时零摩擦记下原子卡片、由 FSRS 排期、以提取（而非重读）方式定期把卡片送回他面前、并用游戏化让他愿意回来的闭环。后面 12 章都是在回答「这个闭环的每一环，四款标杆各是怎么做的、半米该抄哪段、该躲哪个坑」。

02市场全景：笔记 + 复习品类地图与 K12 儿童向真空▾

先把这个赛道的地图铺开。市面上的产品可以按「有没有笔记层」「有没有 SRS」两个轴切成四象限，一眼就能看出真空在哪：

象限代表产品笔记层SRS 复习层目标人群
纯闪卡Anki / Quizlet / Mochi无（只有卡）有大学生 / 医学生 / 语言学习者
纯笔记Notion / Heptabase / Capacities强无或极弱成人知识工作者 / 研究者
笔记 + SRS 一体RemNote / Logseq / Obsidian+插件有有大学生 / 自学者（成人）
K12 儿童一体空——没有一款做「儿童记笔记 → 自动生卡 → SRS 调度」的一体化产品

三条独立结论，各自说透

① Quizlet 有闪卡但没有笔记，Anki 有最强算法但对儿童是灾难

Quizlet 约 5000 万活跃用户，是闪卡赛道的量级王者[43]，但它的模型是「先有卡片集，再来背」——没有「记笔记」这一层，孩子上课记的东西进不去。Anki 走另一极端：约 200 万活跃用户、美国医学生 86.2% 在用[43]，算法与生态最强，但它的 UI「停留在 2008 年」、上手门槛陡[43][44]，让一个 8 岁孩子自己建卡、自己维护牌组是不现实的。就算是把上手做到极致的 Mochi（$5/月、$40/年、Markdown、分钟级 onboarding）也仍是 SM-2 变体、无 FSRS，且同样是「先有卡、再来背」的成人向工具[48]。赛道王者一个缺笔记、一个缺儿童友好度——半米的机会正好卡在两者之间。🟢

② 「笔记 + SRS 一体」这一格已经有人（RemNote/Logseq/Obsidian），但全是成人向

RemNote 是这一格最完整的产品，每行皆 block、任意 block 一键转卡、可切 FSRS[1][2]；Logseq 内置 SRS，任意 block 加 #card 即成卡、免费开源[47]；Obsidian 生态有 26 个间隔重复插件，obsidian-spaced-repetition 同时支持 FSRS 和 SM-2[45][46]。但它们无一例外面向成人——语法多、需要自己组织知识库、没有家长端、没有游戏化。半米要做的不是再造一个 RemNote，而是把这套一体化能力「儿童化 + 移动化 + 游戏化」。🟢

③ K12 儿童向的「笔记→复习」管道，在本报告抽样范围内是结构性真空

主流 K12 产品——Quizlet（刷卡）、Duolingo（游戏化练习）、Khan Academy Kids（视频+练习）、Prodigy（游戏化刷题）——没有一款做「记笔记 → 自动生复习卡 → SRS 调度」的一体化[44]；早在 2014 年就有开发者撰文指出「面向孩子的间隔重复市场根本不存在」，2025–2026 复盘时这个空白依然在[51]。准确表述应是：在本报告抽样的公开英文成人标杆 + 主流 K12 产品中，未发现成熟的儿童一体化方案——这不是穷举式市场普查（未系统覆盖中国、印度、各国本地学校 LMS 与家教机构工具），所以是「值得验证的强假设」而非「已证实的结论」。🟡

⚠️ 反方必须问：这个真空为什么长期没人填？可能不全是「难」

「真空 = 机会」有确认偏差的风险，诚实地列出真空可能长期存在的原因，比一味乐观更有价值：① 孩子本来就不爱记笔记——需求可能是伪的，得先验证「划词生卡」这个动作孩子愿不愿意做；② 老师不愿审 AI 生成的卡——B 端管道多一道审核成本；③ 家长不愿单独为「复习工具」付费——复习是隐性价值，不如「提分/刷题」直观；④ 学校采购周期长；⑤ AI 卡片质量不可控（见 Ch11 的验证要求）。这五条里任何一条不成立，真空就还是真空。半米该做的不是假设它们都能解，而是把它们变成 MVP 阶段要逐个证伪的假设（Ch13 判停条件）。🟡

市场规模：数据分歧极大，只能当量级参考

闪卡/间隔重复软件的市场规模数据在各报告间差异悬殊：Verified Market Reports 给闪卡 App 市场约 13.2 亿美元（2025，CAGR 约 6.3%），另有报告给到约 25 亿美元（CAGR 约 15%），个别极端估值高达 220 亿美元但可信度低[50]。⚠️ 这类数字口径混乱（是否含教育大盘、是否含企业培训各不相同），只能读作「十亿美元量级、增长为正」，不能用来做任何精确测算。🔴 对半米更有意义的信号不是总盘子，而是 Readwise 用最朴素的「高亮→复习」闭环做到约 1400 万美元 ARR 这个具体点[49]（⚠️ 单源）——它证明「输入 → SRS」这条管道单独就能撑起一门生意。

03RemNote 深扒：最接近半米想要的形态▾

四款里 RemNote 和半米的目标形态最像——它就是「笔记即卡片、卡片即复习单元」这条路走得最远的产品，是半米最该逐帧研究的对象。

核心形态：每行皆 block + 双链

  • Rem = outliner bullet：整个笔记是无限层级嵌套的大纲，每一个 bullet 就是一个「Rem」（block）。父级会自动成为子级复习时的上下文——你复习一张卡时，它所在的层级结构一并给你线索[1]。
  • 双链 [[]]：引用任意 Rem 自动生成反向链接（backlink），沉淀出知识图谱[1]。

杀手锏：任意 block 一键转卡，6 种语法

这是 RemNote 最值得半米学的一点——记笔记和建卡是同一个动作，敲一个符号，这行笔记就变成了记忆任务：

语法卡片类型用途
>> / ==正反卡（双向/单向）问 → 答
::Concept（概念）术语 → 定义
;;Descriptor（描述符）属性 → 值
{{ }}Cloze（填空）句子挖空
多选语法多选题选择题
图片遮盖Image Occlusion图上挖区域

来源：RemNote 官方创建闪卡文档[2]。对半米的启示很直接：孩子（或 AI/老师）在笔记里敲一个符号，系统就把它激活成一张会自动排期的记忆卡——「记」和「学」之间零切换。

复习引擎：默认 SM-2，可切 FSRS

RemNote 复习默认用 SM-2 算法，用户可在设置里切换到 FSRS v6——切换后可减少复习量、且自适应无需手动调参[3][4]，还支持自定义调度器。🟡 减少幅度口径不一：RemNote 官方文档多在「少 20–30%」区间、且标注 FSRS 需手动开启、优化前要积累足够复习历史，第三方 benchmark 则给到 25–40%（见 Ch8）——具体数字宜当量级看，别当通用事实。但方向是确定的：FSRS 已成一体化笔记产品的标配选项。

增量阅读：原生 Reader + 第三方插件

  • 原生 RemNote Reader：支持 PDF 导入、高亮、划选转卡，配 Web Clipper 和 AI 批量转卡[6]。
  • SuperMemo 式增量阅读本身是第三方插件 Incremental Everything（开源，仿 SuperMemo 流程）实现的，不是原生功能[5]。这说明「完整增量阅读」即使对 RemNote 也是进阶能力，半米初期做「划线→转卡」的简化版即可，不必一步到位做全套 IR。

平台与定价

全平台覆盖（Web / Windows / Mac / Linux / iOS / Android）且支持离线[7]。但 iOS 端频繁崩溃卡顿是长期痛点——即便 2026-04 有修复，仍有用户投诉[8]。这对半米是一记警钟（见下方 callout）。定价（2026-07-09）：

✅ 半米该从 RemNote 抄的三样

① 「block 级可激活为记忆任务」的交互内核——记笔记即生卡，一个符号完成，这是把「笔记」和「复习」焊死的关键动作，半米应把它做成对孩子更友好的形态（比如长按选中→弹「变成一道题」）。② 直接采用开源 FSRS——RemNote 都从 SM-2 切过去了，半米没有理由自研。③ 语法要做减法——6 种语法对成人自学者合适，对小学生太多；半米初期只保留「填空」和「问答」两种，其余交给 AI 自动判断类型。

⚠️ 坑：iOS 稳定性。RemNote iOS 端长期崩溃卡顿是公开投诉[8]。东南亚 K12 是移动优先、且中低端安卓/iOS 设备占比高的市场，移动端稳定性对半米是第一优先级，不是「以后优化」——一个上课想快速记一条却卡住闪退的应用，孩子第二次就不打开了。

04SuperMemo 深扒：算法学它，体验千万别学▾

SuperMemo 是间隔重复的鼻祖（1985 年起），它贡献了这个领域几乎所有的核心思想，但也是四款里体验最劝退、且官方明确说不适合儿童的一款。对半米，它是最好的「理论老师」和最好的「反面教材」，两个身份同时成立。

算法演进：从单参数到「稳定性 + 可提取性」双组件

  • SM-2（1987，已开源，Anki 至今在用）：只追踪重复次数、E-Factor（1.1–2.5）、间隔。问题在于单一 E-Factor 混淆了「稳定性」和「可提取性」两件本质不同的事[10]。
  • SM-17（2016）：引入记忆的双组件模型——稳定性 S（回忆概率降到 0.9 所需的间隔天数，衡量记忆有多「牢」）+ 可提取性 R（此刻能回忆起来的概率，随时间负指数衰减，衡量此刻有多「想得起」）[11]。
  • SM-18（2019）：小幅改进（难度计算 + 稳定化函数逼近）[12]；SM-20 内置 5 种算法可选[18]。
  • 遗忘指数：理论最优约 20–30%，实践默认 10%（即保留率 90%）[11][12]。这个「10%」是半米直接可用的默认参数。

FSRS 与 SM-x 谁更强？这是场双方各执一词的自测战。FSRS（2022，Jarrett Ye 发起）在 Anki 社区已全面赶超 SM-2，据 supermemo.guru 引述其覆盖了 99.6% 的相关用户群[13]（🟡 该比例来自单一来源，宜当量级）；但 SuperMemo 官方发文自称 SM-19 仍「远胜 FSRS」[14]。双方都是拿自家数据自测，属未决争议🟡。对半米的实操结论不受影响：FSRS 开源、有全栈库、比 SM-2 明显更好，选它；SM-x 是闭源商业算法，学它的思想即可。

招牌功能：增量阅读（Incremental Reading）

这是 SuperMemo 2000 年（SuperMemo 10）引入、竞品至今无人做全的招牌流水线，也是半米最该「移植思想」的一段：

1Import 导入
把文章/网页导入成一个 Topic（被动阅读单元），系统自动记住你读到的位置[15]。
2Read 阅读
按优先级排期阅读 Topic（优先级 0% = 最高，这个反直觉设定见下方坑），不必一次读完[16]。
3Extract 提取
读到关键段落，选中按 Alt+X，生成一个子 Topic——把长文逐步「熬」成精华[16]。
4Cloze 挖空
在提取出的句子里选关键词按 Alt+Z，挖成填空，生成一个 Item（主动回忆卡）[16]。
5Review 复习
Item 进入 SM 算法排期，按间隔反复回忆[15]。

关键区分：Topic = 被动阅读、Item = 主动回忆卡[16]。整条流水线的美妙在于它把「读一篇文章」和「记住其中知识」变成同一个连续动作，中间没有「另外找时间做卡」这一步。SuperMemo 还有知识树：树形 element 容器，节点颜色区分类型，内含概念图谱[17]。

✅ 半米该从 SuperMemo 抄的（只抄这些）

① 算法思想：用开源 FSRS，或至少参考「稳定性 S + 可提取性 R」双组件模型，遗忘指数默认 10%。② 内容原子化流水线：Topic → Extract → Cloze → Review 完全可移植——但要反过来：让 AI/老师自动完成 Extract 和 Cloze，孩子只做题，不承担建卡的认知负担（这正好绕开 SuperMemo「儿童建卡太难」的死穴）。③ 一切产品设计都要躲开它：算法学它，体验千万别学——半米要正向反馈、可见进度、即时成就，SuperMemo 一样都没有。

05Heptabase 深扒：卡片 + 白板，SRS 还没上线的机会窗口▾

Heptabase 是「视觉化知识管理」的代表，它的形态对半米有借鉴价值，而它至今没上线 SRS这件事，本身就是给半米的一个机会信号。

核心形态：Card + 无限白板

  • Card = Markdown 原子笔记，Whiteboard = 无限 2D 画布，可在空间上排布卡片[23]。
  • 同一张 Card 可同时出现在多个白板上（无副本）——单一来源、多处引用[23]。
  • Card 即 Note，没有独立的「Note 层」——笔记的最小单位天然就是卡片[23]。

⚠️ 关键事实核对：Heptabase 的 SRS 尚未上线

网上有第三方文章误报 Heptabase「已有 SRS」，以官方路线图为准：间隔重复功能仍未上线，官方路线图（2026-04-07）把它列为 Priority 1 待开发，当前需手动配合 Anki[24]。🟡（第三方与官方口径冲突，采信官方路线图）这意味着：连一个成熟的成人向卡片工具，都还没把「卡片 → 复习」这一步接上——半米如果先把这一步做扎实，就领先了一个身位。

杀手功能：PDF/视频 → 高亮卡片（学术圈公认的强项）

  • PDF 拖入生成 PDF Card，选中文字生成 Highlight Card，进 Library 后可拖上白板[25]。
  • 扩展生态成熟：Readwise / Zotero / Web Clipper / YouTube（字幕 + 时间戳） / Podcast（AI 转录）[25]。

这条「来源材料 → 高亮卡片 → 拖上知识地图」的三段式是 Heptabase 被称为「academic killer」的原因[27]。对半米要求三（阅读/看视频时随时调出）极有参考价值——尤其它的 YouTube 字幕+时间戳集成，正是半米「看视频时划一句变成卡」的现成范本。

定价与人群

定价（2026-07-09）无免费层：Pro $8.99/月（年付）、Premium $17.99/月（年付 25% off）、Premium+ $53.99/月；7 天试用；无教育折扣[26]。痛点：无 SRS、无协作、移动端弱、大画布卡顿、对学生偏贵[27][28]。目标用户明确是成人/大学生/研究者，K12 明确不在受众[29]。

✅ 半米该从 Heptabase 抄的三样

① 「笔记即卡片，卡片即复习单元」的一体化方向——Heptabase 把「Card 即 Note」做到了极致，半米应继承这个原子化哲学；而它 SRS 未上线 = 半米的机会窗口。② 「来源 → 高亮 → 知识地图」三段式，但半米做简化版：阅读→划线→自动进「单词/概念卡」→触发复习，少一层白板（无限画布对成人研究者是利器，对 K12 儿童是负担）。③ 同一知识单元跨情境复用——单一来源 + 多引用，一个「光合作用」概念卡可以在科学笔记、英语阅读、复习队列里同时出现，不产生副本。

⚠️ 坑：别抄白板。无限白板是 Heptabase 的招牌，但它服务的是「成人做研究、要在二维空间里理清复杂关联」的场景。K12 儿童的核心动作是「记一条、背一条」，不是「在画布上排布几百张卡」。大画布还会带来卡顿（Heptabase 自己的痛点[28]）。半米要抵住「看起来很酷」的诱惑，把白板砍掉，留下卡片和复习。

06Capacities 深扒：对象化结构 + 温故叙事▾

Capacities 是「object-based（对象化）」笔记的代表，它的两个设计——「有类型的对象」和「Created on This Day 温故」——是半米可以直接借用的骨架和情感设计，尽管它本身没有原生 SRS。

核心形态：一切皆 object，且必有 type

  • 基本单元 = object，每个 object 必有一个 type，type 决定它的结构和 properties[30]。
  • 内置 11 种 type（Page / Tag / Image / Weblink / Audio / PDF / Files / Tweet / AI Chat / Query / Table）+ 可自建 Custom Type[30]。
  • block 是 object 的一个 property——type system 叠在块之上，加了一层「语义」[30]。这和 RemNote「每行皆 block」的纯结构不同：Capacities 让每个块「知道自己是什么」。

组织与温故

  • Daily notes = 每日收件箱：可从 WhatsApp / Telegram / 邮件快速捕获[31]——对东南亚（WhatsApp/Telegram 渗透率极高）尤其有参考价值。
  • backlinks 自动；Related Content（Pro/AI）实时展示最相关的 5 个内容[32]；tags 跨库 + 层级；无文件夹。
  • 「Created on This Day」：按日期触发，展示历史上同一天创建的内容——这是四款里最接近「温故」的机制[31]。

⚠️ Capacities 没有原生 SRS，温故是「弱且被动」的

Capacities 无原生间隔重复：它的「温故」靠 Created on this day、Related Content、以及 Readwise 集成（真正的 SRS 在 Readwise 那一侧）[33]；路线图提过「按时间上下文 resurface（重新浮现）」但未上线[34]。🟢 也就是说它的温故是被动的（等你翻到、等系统推给你看），而不是主动排期的提取练习——它能让你「又看见」，但不保证你「回忆得起」。这正是 Ch1 里 testing effect 强调的差别：半米必须做主动提取，不能只做被动 resurface。

阅读闭环与定价

Web Clipper 只存链接不抓正文，PDF 无原生批注层，阅读闭环靠 Readwise 集成打补丁[35]——这是它相对 Heptabase 的短板。定价（2026-07-09）：Free 5GB / Pro $9.99/月（$119.88/年）/ Believer $12.49/月[36]。人群是成人知识工作者/研究者/读书人，学生页面已 404、面向大学文科生，不面向 K12，无游戏化、无师生工作流[37]。

✅ 半米该从 Capacities 抄的三样

① object-type 作内容语义骨架——给半米的每类学习内容定义结构化 type：单词卡 = {词性 / 例句 / 熟练度}，知识点卡 = {学科 / 前置知识 / 掌握度}，由系统管理结构，孩子只填内容。这比 RemNote 的纯 block 更适合 K12（结构化 = 可自动出题、可自动统计掌握度）。② 「Created on This Day」+ 注入 SRS 权重——优先展示「7 天前 / 30 天前的今天你记了什么」，对 K12 比纯 Anki 冷冰冰的调度更有叙事感和情感钩子（详见 Ch10、Ch12）。③ 快速捕获 → 事后分类——先记后整，Daily notes 当收件箱，降低当场记笔记的门槛，尤其借鉴它从 WhatsApp/Telegram 捕获的思路（东南亚场景高度契合）。

  • Anki v23.10（2023-10）内置 FSRS，如今已是主流选择[39]。同样 90% 保留率下，据第三方 benchmark，FSRS-5 比 SM-2 减少约 25–40% 复习量，预测准确性 ±5.3%（SM-2 ±16.2%）[38]；Anki 官方口径较保守，只说「更高效、少复习」不给精确区间[39]，RemNote 官方文档则多说 20–30%（Ch3）。🟡（区间因来源/数据集而异，取「明显少于 SM-2」这个方向即可）

✅ 儿童场景，FSRS 反而比对成人更划算

儿童的遗忘曲线通常更陡、个体差异更大。FSRS 是自适应的——它会根据每个孩子的实际回忆表现拟合出个人化的记忆参数，理论上比「所有人一套固定间隔」更快贴合一个具体孩子的遗忘节奏[41]。🟡（儿童场景 FSRS 拟合速度无专门实证，属基于算法机制的合理推断）遗忘指数用 FSRS 默认的 10%（保留率 90%）起步[11]，等有了真实数据再按年龄段微调。

算法学 SuperMemo，代码用 FSRS——这不矛盾。SuperMemo 贡献的是思想：把记忆拆成「稳定性 S（有多牢）+ 可提取性 R（此刻多想得起）」两个组件[11]，这个心智模型帮你理解「为什么复习要在快忘时做、而不是天天做」，对你设计 UI 文案（比如「这张卡快忘了，复习一下能记更久」）很有用。FSRS 本身也是站在这套思想上用现代机器学习重新拟合出来的[13]。所以：读 SuperMemo 的 wiki 建立直觉，装 ts-fsrs/py-fsrs 落地实现。

09学习科学地基：可产品化的范式与 K12 特殊性▾

Ch1 铺了间隔 + 提取两块地基，这一章往下钻：哪些学习法可以直接变成半米的功能，以及 K12 儿童和成人到底不一样在哪。

两个最强的可产品化范式

① Cornell 笔记法：cue column 强制自测

Cornell 笔记法的精髓不是「分三栏」，而是左侧的 cue column（线索栏）强制你把笔记转成问题、遮住右侧答案来自测——它天然把「记笔记」和「提取练习」缝在了一起。实证：Evans & Shively 2019，101 名八年级学生，用 Cornell 笔记法的班级通过率 100% vs 对照组 70%[56]。🟢 对半米：这就是「笔记的一部分自动变成问题」的学术依据——记下的知识点，系统自动生成一个 cue（问题面），复习时先问后答。

② Incremental Reading：最完整的「阅读→提取→回忆」闭环

SuperMemo 的增量阅读（Ch4）是目前唯一把「阅读→提取→回忆」做成完整闭环的范式[57]。它证明了一件事：复习不必是「阅读之后的独立任务」，可以是「阅读过程本身的自然延伸」。半米做要求三（阅读/看视频时随时调出）时，Cornell（问题化）+ IR（阅读中提取）是两个最该产品化的原型。

Atomic notes（原子笔记）：Zettelkasten 的「一条笔记只讲一个 idea」原则有两个复习价值——一是笔记粒度天然匹配复习单元的大小（一张卡背一个点），二是写的时候被迫把知识讲清楚（等于 Feynman 自测）[58]。这为半米「笔记必须原子化」提供了依据：不是为了整洁，是为了可复习。

K12 特殊性：儿童不是缩小版的成人

★ 一项值得重视但需谨慎外推的儿童实证（Frontiers 2025）

Frontiers in Psychology 2025 年一项针对意大利小学五年级（n=33，样本小）的研究发现两个结论：① 填空测试组正确率 67.0% vs 重读组 48.6%（差异显著）——testing effect 在儿童身上同样成立；② 该设计下间隔 1 天 vs 4 天无显著差异[59]。🟡 第二条不能读成「儿童普遍对间隔不敏感」——原论文明确讨论：这个无差异可能来自实验操控方式，两个条件本身都不是零间隔，且作者呼吁后续研究确定最佳间隔。准确表述是：在该样本、该材料、1 vs 4 天设计下未观察到间隔主效应。

即便谨慎解读，它给半米的产品优先级提示依然清晰：先把「让孩子真的做一次提取」这件事做到位，别一开始就把精力砸在「把间隔算法调到极致精准」上。成人 SRS 圈痴迷于算法优化，但对起步期的儿童产品，一个「够用的间隔 + 一定会发生的提取」大概率优于「完美的间隔 + 经常被跳过的提取」。这与 Ch8 的判断一致——FSRS 够好，先别自研调参，等有真实数据再按年龄段回校。

✅ 半米从学习科学收敛出的四条设计原则

① 以「提取」替代「重读」：所有复习卡做成填空/问答，系统自动生成复习任务，绝不做「把笔记再展示一遍」。② 笔记粒度 = 一个知识点，系统接管调度：原子化不是洁癖，是可复习性 + 元认知补偿。③ 单次单元 ≤15 分钟 + 即时反馈：贴合儿童注意力。④ 别过度优化间隔精度：对儿童，「测试有没有发生」比「间隔算得多准」重要得多——这条直接为「用现成 FSRS、不自研」背书。

10游戏化与行为驱动：半米的「行为」二字怎么落▾

半米的定位是「行为驱动」——这一章就是把「行为」二字落到复习系统上：怎么让孩子真的回来复习。这既是半米相对四款标杆最大的差异化（它们都不做或反对游戏化），也是一条要小心走的钢丝。

正面证据：Duolingo 把行为设计做成了增长引擎

✅ streak（连续打卡）+ 即时反馈的威力

广为流传的数字是 Duolingo 靠 streak + 社交 + 即时反馈把 30 天流失率从 约 47%（2020）降到约 28%（2024）[61]、streak + 里程碑让 DAU 高出约 40–60%[62]。🟡 但要诚实标注可信度：这些数字来自二手分析（youngurbanproject 偏叙事）与营销供应商博客（Plotline），不是 Duolingo 官方 A/B 实验证据，40–60% 更是泛化陈述——引用时当「量级参考」，最稳的做法是找 Duolingo 年报/股东信复核。核心机制层面是稳的：损失厌恶 > 奖励——「快要失去连续记录」的痛感比「完成后给金币」更能驱动回访[62]。对半米，streak 是一个值得验证的强产品假设，不是已证结论：先在 MVP 上小规模验证它对 K12 复习回访的实际拉动，再决定加多重。

方法论：Fogg 行为模型 B = MAP

BJ Fogg 的行为模型：行为（Behavior）= 动机（Motivation）× 能力（Ability）× 提示（Prompt）三者同时越过阈值才会发生[63]。落到半米复习上：

M 动机
streak 损失厌恶 + 即时庆祝，不靠外部物质奖励
A 能力
把「做一张卡」缩到 30 秒起步，越小越容易发生
P 提示
绑已有日常触发点（放学后、睡前），推送到该复习的卡

习惯回路是 Cue → Routine → Reward（提示 → 行为 → 奖励），且即时奖励对养成习惯远胜延迟奖励[64]——复习答对当场给正反馈（动画/音效/进度条动一下），别攒到周末发。

钢丝的另一头：过度外部奖励会反噬

⛔ SuperMemo 的警告不能无视：外部奖励会损伤内在动机

Ch4 提过，SuperMemo 官方明确反对游戏化，认为积分/奖励会与学习内容形成「毒性关联」，干扰内在动机[21][22]。这不是老古板——它触及一个真问题：当孩子「为了金币而学」，一旦金币停了，学习动机可能比没有金币时更低。同时，游戏化的新奇感会消退，新奇过后必须靠内容本身驱动[61]。🟢

★ 半米的平衡点：用「行为脚手架」而非「物质贿赂」

把 Duolingo 的有效机制和 SuperMemo 的警告合起来，半米的游戏化设计原则是：① 优先用 streak / 进度可视化 / 即时庆祝这类「过程性、非物质」的反馈（它们强化的是「我在坚持」的自我认同，不是「我在换奖品」）；② 损失厌恶 > 奖励发放——快掉 streak 时提醒的权重，高于完成后发奖励；③ 绑日常触发点 + 把起步动作缩到最小（Fogg 的 A 和 P）；④ 游戏化是「把孩子领进门」的脚手架，不是学习的目的——内容有用、进步看得见，才是留住人的地基。金币/徽章可以有，但永远是配角，且要能优雅退场。

11打通机制：笔记 ⟷ 复习到底怎么连▾

这一章回答阿杰的要求二——「笔记 ⟷ 复习系统打通」具体是怎么实现的。四款标杆给了三种不同的打通模式，半米要选对一种。

打通模式代表机制对 K12 的适配
符号激活式RemNote / Logseq笔记里敲符号（{{}}、#card）当场把这行标记为卡[2][47]最优雅，但要孩子学语法
流水线提取式SuperMemo读→Extract→Cloze→Review 逐步把文章熬成卡[16]思路最完整，但操作重
外接集成式Heptabase / Capacities笔记在本体，SRS 靠 Anki/Readwise 外接[24][33]两个 App 来回切，孩子必弃

⛔ 外接集成式对 K12 直接淘汰

Heptabase 和 Capacities 都走「笔记在自己家、复习去 Anki/Readwise」的外接路线[24][33]。对成人研究者这尚可忍受，对 K12 儿童是死路——让一个孩子在两个 App 之间来回导数据、维护两套系统，这个摩擦足以让整个复习习惯崩掉。🟢 半米必须做内生的、一体的打通，笔记和复习在同一个应用、同一份数据里。

✅ 半米的打通设计：符号激活式的「AI 代劳」变体

RemNote 的符号激活式最优雅，但要孩子学 6 种语法（Ch3）。半米的解法是把「建卡」这个动作从孩子身上卸下来，交给 AI/老师：
① 孩子只管记——在阅读/看视频/上课时划一句、记一条，动作和普通记笔记完全一样，不学任何语法。
② AI 自动判断并生卡——后台把这条笔记按 Capacities 式的 type（单词/知识点/概念）结构化，自动挑出可挖空的关键词生成 Cloze、或生成一个问答对（Cornell 式 cue，Ch9）。
③ 生成的卡自动进 FSRS 队列（Ch8），从此系统接管排期。
这样就把 RemNote 的「记即生卡」内核 + SuperMemo 的「Extract→Cloze」流水线 + FSRS 排期，缝成了一条孩子零学习成本的打通链。SuperMemo 卡在「儿童不会建卡」，半米用 AI 把这一步吃掉。

结构化 type 是自动生卡的前提

为什么要借 Capacities 的 object-type（Ch6）？因为只有结构化的笔记，AI 才好自动出题。一条自由文本 AI 也能挖空，但如果笔记本身带 type——「这是一张单词卡，字段有 {词 / 词性 / 例句 / 熟练度}」——AI 就能精准地把「例句」挖成填空、把「词性」做成选择题、按「熟练度」字段回写 FSRS 状态。type 骨架 = 自动生卡的脚手架 + 掌握度统计的抓手，这是半米比纯 block 笔记（RemNote）更适合 K12 的地方。

⚠️ 最大的落地风险：AI 生卡质量必须先验证，不能默认它成立。「AI 自动挖空/出题」是整个方案的核心枢纽，但也是最没被证实的一环——AI 可能挖错关键词、生成不可答的问题、幻觉出错误答案、或生成不适合该年级的卡。这不该在 MVP 之后才管，而是 MVP 的验收前提。建议在 Ch13 的 MVP 里加一项 AI 生卡评测：取 100 条真实视频字幕/阅读段落，让老师打 gold label，测 AI 生成的 Cloze/问答的正确率、可答性、年级适配度、拒绝率、老师平均编辑时长；不过关就先做「AI 生草稿 + 老师一键确认」的半自动形态，别让不可控的卡直接进孩子的复习队列。

12随时可调出：阅读时、看视频时的捕获与调用▾

阿杰的要求三——「随时可调出，尤其阅读 + 看视频时」——是三条要求里最考验工程细节、也最能决定「孩子到底会不会用」的一条。捕获成本每高一点，使用率就掉一截。

四款在「阅读/视频捕获」上的成熟度

  • Heptabase 最成熟：PDF 拖入生 PDF Card、选字生 Highlight Card；尤其 YouTube 集成带字幕 + 时间戳、Podcast 支持 AI 转录[25]——这正是半米「看视频时划一句台词变成卡、点一下能跳回视频那一秒」的现成范本。
  • RemNote 原生 Reader：PDF 导入/高亮/划选转卡 + Web Clipper + AI 批量转卡[6]。
  • Capacities 的快速捕获：Daily notes 当收件箱，可从 WhatsApp/Telegram/邮件快速丢内容进来[31]——「先记后整」降低当场门槛。
  • SuperMemo：桌面版支持 PDF/YouTube 导入进增量阅读，但仅 Windows、操作重[18]。

✅ 半米的捕获设计：三个场景各给一个「一步动作」

① 看视频时（半米的强项场景）：借 Heptabase 的字幕+时间戳模型——播放中划一句台词/字幕，一步生成卡片，卡片记住视频时间戳，复习时点一下能跳回原视频那一秒重看。这是四款里最值得逐帧抄的一段。
② 阅读时：借 RemNote Reader——PDF/文章里划选一段，一步转卡，AI 自动挖空（Ch11）。
③ 随手记时：借 Capacities 的 Daily notes 收件箱 + 东南亚场景——「先记后整」，甚至考虑从 WhatsApp/Telegram 捕获（东南亚渗透率极高）。核心纪律：每个场景的捕获都必须是「一步」——划一下、点一下就完成，任何多出来的一步都会劝退孩子。

调出（温故）不止是「排期推送」，还可以有叙事

把 Capacities 的「Created on This Day」注入 SRS 权重。纯 Anki 式调度是冷冰冰的「今天该复习这 20 张」；Capacities 的「Created on This Day」提供了另一种情感钩子——「7 天前的今天你记下了这个」「一个月前你学会了这个词」[31]。半米可以把两者合起来：FSRS 决定「该复习什么」，Created-on-this-day 式叙事决定「怎么把它呈现得有温度」。对 K12，「回顾你的学习足迹」比「完成今日复习任务」更有拉回来的力量（呼应 Ch10 的非物质激励）。这是半米把「调出」从功能升级成体验的机会。🟡（叙事式温故对 K12 留存的增益无直接实证，属基于 Ch10 行为设计原理的推断）

⚠️ 坑：移动端才是主战场。东南亚 K12「阅读 + 看视频」绝大多数发生在手机上，不是桌面。SuperMemo 把最强的增量阅读锁死在 Windows 桌面（Ch4），是它对这个市场彻底无关的根本原因。半米的捕获与调出必须移动端优先设计，桌面反而是次要——这和绝大多数标杆的桌面优先路线相反，却是半米终端用户的真实场景。

把前 12 章收敛成一套可执行的决策。先决策树，再 MVP，再分阶段路线。

⚠️ 两个先于决策树的前提（军师提醒，不在本报告展开）

本报告聚焦「笔记 + 复习系统」的技术与产品形态，但落地前有两块必须单开研究的前置门槛，别默认它们不存在：
① 「孩子」不是单一人群，路线要按年龄分层。8 岁 / 12 岁 / 17 岁在自控力、阅读能力、设备使用、考试压力上完全不同——小学低年级应偏「老师/家长代建卡、孩子只做题」，小学高年级可半自动，中学才开放更强的笔记结构与自主建卡。下面的 MVP 建议先锁定一个年龄段（如小学高年级）跑通，别一款通吃。
② 儿童数据合规是「能不能做」的门槛，先于「怎么做」。面向东南亚 K12 涉及各国 PDPA、家长同意、学校数据处理、以及「把孩子笔记传给 LLM 生卡」的数据出境与删除策略——这些是硬约束，建议单开一份合规研究，别等产品做出来再补。🟡

QFAQ：11 个最可能被问到的问题▾

Q1半米直接用 RemNote/Logseq 的开源思路二次开发，不是更快吗？＋

思路可以借，代码不建议直接扛。RemNote 是闭源商业产品，Logseq 虽开源但架构是为成人知识库设计的、语法门槛高[47]。半米真正的差异化（AI 自动生卡让孩子零建卡、移动端优先、游戏化、老师/家长端）恰恰是这些成人工具没有、也不好硬改出来的。更务实的路是：算法直接接开源 FSRS 库（这个必须复用，别自研，Ch8），产品形态自己按 K12 重做。

Q2FSRS 和 SuperMemo 的 SM-18 到底哪个强？会不会选错？＋

这是一场双方各拿自家数据自测、至今没有中立定论的争议：Anki 社区认为 FSRS 已全面超越 SM-2[13]，SuperMemo 官方则称 SM-19 仍领先 FSRS[14]（都标 🟡）。但对半米这不构成风险：SM-x 是闭源商业算法、没有开源实现、锁在 Windows 桌面里，你根本用不了；FSRS 开源、有全栈库、明确比 SM-2 好。所以答案是——两者思想都学，能落地的只有 FSRS，选它不会错。

Q3SuperMemo 官方都说间隔重复不适合儿童，半米这条路是不是走错了？＋

它说的是「让幼儿自己按 SuperMemo 那套建卡、强记」不适合，尤其反对强制幼儿双倍练习[21]——这恰恰是半米要绕开的。相反，儿童实证显示测试效应在孩子身上同样强（填空 67% vs 重读 48.6%）[59]，问题从来不是「间隔重复对孩子没用」，而是「让孩子自己维护 SRS 系统太难」。半米用 AI 代劳建卡、系统接管调度、游戏化拉回访，正好把 SuperMemo 指出的三个死穴（建卡难、无正反馈、需自律）逐一填上。

Q4既然 SuperMemo 反对游戏化，半米还堆 streak 和金币，不会重蹈覆辙？＋

关键在区分两类游戏化。SuperMemo 反对的是物质外部奖励（金币换东西），它会与学习形成「毒性关联」、损伤内在动机[21][22]。半米主力用的是过程性、非物质的机制——streak（连续记录）、进度可视化、即时庆祝，它们强化的是「我在坚持」的自我认同，而 Duolingo 证明这类机制能把流失率从 47% 砍到 28%[61]。金币徽章可以有，但永远是配角、能优雅退场（Ch10）。这是有意识地走钢丝，不是无脑堆奖励。

Q5笔记形态到底选 block 还是 object-type？为什么不学 RemNote 的纯 block？＋

选 object-type（Capacities 式）。纯 block（RemNote）灵活、适合成人自由组织知识库，但它的每个块「不知道自己是什么」，AI 不好自动出题、系统不好统计掌握度[1]。object-type 给每类内容定义结构（单词卡 = {词/词性/例句/熟练度}），这层语义是自动生卡的脚手架 + 掌握度统计的抓手[30]——正是 K12「AI 代劳建卡 + 家长看掌握度」这两个核心需求的前提（Ch11）。

Q6增量阅读那么强，半米第一版要不要做全套 Import→Extract→Cloze→Review？＋

不要。全套增量阅读连 RemNote 都是靠第三方插件实现[5]、SuperMemo 的完整版锁在 Windows 桌面且操作极重[18]——它是给硬核成人自学者的重型工具。半米第一版只取它的思想：把「划一段 → 挖成填空 → 进复习队列」这条最短路径做通（且让 AI 完成挖空），把「优先级排期、多层提取、自动记阅读位置」这些进阶能力留到后面。Ch13 的 MVP 就是这个简化版。

Q7Heptabase 的无限白板看起来很酷，半米真的完全不做吗？＋

K12 第一版坚决不做。无限白板服务的是「成人做研究、在二维空间里理清复杂关联」的场景，而 K12 的核心动作是「记一条、背一条」，白板对孩子是认知负担，大画布还会卡顿（Heptabase 自己的痛点[28]）。要抵住「看起来很酷」的诱惑。该抄 Heptabase 的是它的卡片一体化和视频高亮卡（字幕+时间戳）[25]，不是白板。

Q8遗忘指数设多少？间隔要不要按年龄精细调？＋

起步用 FSRS 默认的遗忘指数 10%（保留率 90%）即可[11]，先别精调。因为儿童实证显示间隔 1 天 vs 4 天对孩子无显著差异，「测试有没有发生」远比「间隔多准」重要[59]。把工程精力砸在「让孩子真的做一次提取」（捕获零摩擦、复习不卡顿、streak 拉回访）上，回报远高于调间隔算法。等积累了真实数据，再按年龄段微调遗忘指数不迟。

Q9为什么不能像 Heptabase/Capacities 那样，笔记归笔记、复习外接 Anki？＋

因为对 K12 儿童，「两个 App 来回切、导数据、维护两套系统」的摩擦足以让整个复习习惯崩掉[24][33]。成人研究者能忍，孩子不能。半米必须做内生一体：笔记和复习在同一个 App、同一份数据里，记下即进队列，中间没有任何「导出/导入/切换」（Ch11）。这也正是半米相对这两款成人工具的结构性优势。

Q10市场真空说得挺好，但真空会不会是因为「这事根本做不成」？＋

合理的怀疑。真空的成因更可能是「难做 + 没人认真做」，不是「做不成」：儿童建卡难（半米用 AI 代劳解决）、儿童需要外部驱动（半米用游戏化解决）、需要移动端 + 稳定性（多数标杆桌面优先没覆盖）——这些都是工程和产品难题，不是原理上的不可能。学习科学（测试效应在儿童身上同样成立[59]）和商业验证（Readwise 用最朴素的输入→SRS 闭环做到约 1400 万 ARR[49]）都指向「有效且有价值」。风险在执行难度，不在方向。

Q11这些价格、算法版本以后会变，报告还准吗？＋

价格和版本号会变（都标了访问日期 2026-07-09），但报告的结论骨架是稳的：FSRS 是开源事实标准（趋势只会加强）、K12 一体化真空（存在十多年）、四款标杆各自的形态与人群定位、学习科学地基（元分析定论）——这些不会因为某款涨价或出新版本而翻转。价格类信息用时请以当日官网为准；算法类结论（FSRS vs SM-x 争议）已标 🟡，需要时再复核最新自测数据即可。
