半米 YouTube 英语视频库：选源全景 + 与学习 Steps 结合手册

📅 2026-07-14 🔍 五路搜证 + 多轮核查 🎬 频道矩阵 × step 结合手册 🌏 立场：给半米 Library 建英语视频库（第一批英语学习为主）

一句话定调：给半米建 YouTube 英语视频库，真正的难点不是"频道够不够多"，而是"哪个频道字幕靠得住、哪个视频挂哪种 step、怎么让看视频变成掌握证据（Evidence）而不是看完打勾"。这份报告不是频道清单，是一份可以照着抄的"选源 + 用法"操作手册。

报告按建库顺序展开：先立框架（Ch1 半米模型速览 → Ch2 四维打标签选源框架），再铺频道全景（Ch3 少儿 CLIL → Ch4 青少年内容型 → Ch5 教学型三张频道矩阵表，Ch6 单独把"字幕质量"这道隐形第一门槛讲透），然后落方法论地基（Ch7）与 step 结合手册（Ch8 总览 → Ch9 视频精听 → Ch10 影子跟读/复述/听写 → Ch11 泛听/选级/窄听 → Ch12 精读挖空接 SRS + 工具矩阵 → Ch13 一个视频完整闭环样例），最后是版权接入（Ch14）与给阿杰的建库路线决策树（Ch15）。阅读约定：频道矩阵每行的引用主要落在该频道最核心的一两个事实上（如分级设计、字幕类型、订阅量级）；同一行里的 CEFR、口音、语速、更新频率等字段多为编辑综合判断或经验区间，属"初步假设 / 待视频级实测"，不等于逐字段的强证据。客观可查证特点标 🟢、单源或待实测标 🟡、主观筛选判断正文写明。本报告是"频道级发现 + 用法框架"，真正的准入单位是视频——所有 🟢/CEFR/字幕判断都需在建库时逐视频抽检确认（见 Ch6 与 Ch15）。

📌 四条最关键发现（先扫这个）：

  • 频道分三块、按 CEFR 铺开，不要混着堆。少儿段（A0-A2）以内容型 CLIL 为主（Little Fox / SciShow Kids / Crash Course Kids / Super Simple Songs / Peppa Pig 字幕版）[1][10]；青少年/中学段（B1-C1）走内容型科普与学生新闻（TED-Ed / CNN10 / Kurzgesagt / CGP Grey / Easy English）[16][20]；教学型是"直接教英语"的专门频道（BBC Learning English / Rachel's English / engVid / Learn English With TV Series），负责发音、语法、方法。三块角色不同，用法也不同。
  • 字幕质量是隐形的第一门槛，比内容好坏更早决定"能不能用"。精听要核对字幕、精读要逐字稿、挖空要 transcript——没有可信字幕，一大半 step 直接做不了。官方人工字幕 / 完整文字稿 / 双语字幕 > 自动 CC。TED-Ed、CNN10、Little Fox、Easy English 天然优先，正是因为它们把"字幕"当产品的一部分[16][20][1][27]。凡是标"字幕待实测🟡"的频道，入库前必须在 YouTube 逐个视频确认 CC。
  • step 不用自己发明，成熟方法有可直接抄的步骤。视频精听有 Refold 的"先重听再看字幕"铁律和 6 步嵌套[42]，影子跟读有 4 阶段（有稿→无稿→录音对比）[43]，泛听有 i+1 三重检验选级[44]，挖空有"transcript→AI cloze→FSRS"链路[45]。这些正好对得上半米的 LE Template 清单，把方法翻译成 Learning Experience Step 序列就能上产品。
  • 建库要给每个视频/频道打四维标签，看视频要产出"掌握证据"。四维 = 内容型 vs 教学型 × CEFR 分级 × 适配哪种 step × 字幕可信度[12]。而且要让"影子跟读/复述/答题"这类产出型 step 成为 Evidence 来源，喂给成长路径与 OKR 的 KR，而不是"看完就算学过"——因为看过视频只是"接触"，产出才是"掌握"[12]。

01为什么建 YouTube 视频库 + 半米模型速览▾

半米（banmi）是阿杰在做的东南亚 K12 行为驱动 AI 学习操作系统，面向国际学校学生（A0 少儿到 C1 高中）[12]。第一阶段的 Library（素材层）原计划只做 Twitter，现在要加一个 YouTube 英语视频库：既要给学生优质的英语视听输入，又要让这些视频真正接进半米的学习流程。这一章先把半米几个核心模型讲清楚，因为后面所有的"选源"和"step 结合"都建在这套模型上——脱离模型谈频道，就退化成一份普通的资源清单了。

Library：只存素材事实，引用不复制

Library 回答"半米有什么素材、从哪来、能不能用"。关键设计：Library 只保存素材事实（一个视频的标题、来源、videoId、授权状态等），Plan 里的学习内容引用 Library 素材，而不复制素材本身[12]。落到 YouTube 视频库就是：库里存的是"这个视频存在、是谁的、能不能用、videoId 是多少"，而不是把视频文件搬进半米。这一点直接决定了 Ch14 的版权接入结论——嵌入官方播放器 / 存 videoId，不下载重托管。

Media = Media Sources，是总部筛选管理的高质量媒体来源。学生 Library 展示已授权素材，并可以通过 Subscriptions（订阅）从总部开放的来源里挑自己想持续关注的频道[12]。所以"选源"这件事本质上是在替总部做 Media Sources 的白名单。

LE Template：可复用的"怎么学"

LE Template（Learning Experience Template）是总部维护、可反复使用的学习方法，定义"一种共同的学习方式"，不绑定某本书、某个视频、某个学生[12]。半米的第一批 LE Template包括：泛读、精读、视频泛听、视频精听、影子跟读、朗读、复述、写作与修改、词汇复习、练习与测验[12]。

关键性质：同一素材可以套不同 LE Template。同一个视频可以先做视频泛听 → 再视频精听 → 再影子跟读 → 再复述。Library 只保存素材事实，LE Template 保存"怎样学"，两者不混。这正是本报告"一个视频跑完整闭环"（Ch13）能成立的产品基础。

Learning Experience Step：统一的、可嵌套的 step

半米只用一种统一的 Learning Experience Step，不设"Activity"概念[12]。做作业、复习、视频精听，乃至精听里"关字幕先听 → 核对字幕 → 再试"这些动作，都由同一种 Step 组成——粒度不同，不是两套概念。Step 可嵌套：

完成视频精听（一个大 Step）
└ 关闭字幕先听 → 回答大意 → 逐句重听 → 打开字幕核对 → 再次关字幕听 → 提交结果（嵌套子 Step）

LE Template = 一组可复用的 Learning Experience Steps 及其顺序 / 关系 / 完成逻辑[12]。"视频精听 Template"保存一套标准 Step 结构，应用到具体视频时再定素材范围、要求和结果。本报告 Ch9-Ch11 给出的每一条"可直接抄的 Step 序列"，就是在替半米填这些 Template 的 Step 结构。

主链：一个视频怎么走完学习流程

A学生自主素材路线
学生 Library 素材 → 加入 Learn 并决定怎么学 → Plan → Today 激活执行 → Notes/Evidence → 成长路径[12]。
B持续信息路线
总部 Media 筛选来源 → 学生 Subscriptions 订阅 → 日常轻量浏览 → 值得深入的加入 Learn → Plan → Today 正式学习[12]。轻量刷视频（泛听/磨耳朵）可以停在 Subscriptions，不强制进正式学习。

关键状态分离：有权限看 ≠ 准备学；进 Learn ≠ 有 Plan；进 Plan ≠ 在学；只有 Today 激活后才产生正式进度/时长/笔记/完成记录[12]。对视频库的含义是：泛听可以很轻（订阅里随便刷），但精听/影子跟读这类正式学习要走到 Today 才计入进度。

掌握 vs 接触：视频类学习最容易被忽略的一点

看过视频 / 读过讲解 = 仅"接触"；影子跟读 / 复述 / 无提示回忆 / 写作 / 答题 / 老师判断 = 掌握证据；采词 / 高亮 / 收藏 = 学习背景[12]。这条来自半米的成长路径手册，是整个视频库设计的灵魂：视频库要让"精听/影子跟读/复述"这类产出型 step 成为 Evidence 来源，而不是"看完打勾"。后面 Ch10 会反复强调这一点，Ch15 会把它接到 OKR 的 KR 上。

02选源框架：四维打标签 + 选源 7 标准▾

建库前先立组织逻辑，否则收进来的频道会乱成一锅粥。半米视频库的核心组织方式是给每个频道 / 视频打四个维度的标签，四维一确定，这个素材放哪个板块、给哪些学生、挂哪种 step，就自动清楚了。

四维打标签（视频库的组织骨架）

维度①
内容型 vs 教学型——内容型是"用英语讲别的"（动画/科普/新闻），教学型是"直接教英语"（发音/语法/方法）。决定它在库里属于"输入素材"还是"方法课"。
维度②
CEFR 分级——A0-A2 少儿 / B1-B2 青少年 / B2-C1 高阶。对到年龄和 i+1 选级，决定推给谁。
维度③
适配哪种 step——泛听 / 精听 / 影子跟读 / 复述 / 精读挖空。决定它能套哪几个 LE Template。
维度④
字幕可信度——官方人工字幕 / 完整文字稿 / 双语字幕 > 自动 CC > 无字幕。决定能不能做精听精读（见 Ch6）。

四维是正交的：一个频道可以是"内容型 × B1-B2 × 适合精听+影子跟读 × 字幕🟢"（如 TED-Ed），也可以是"教学型 × B1-C1 × 适合影子跟读 × 字幕🟢"（如 Rachel's English）。后面三张频道矩阵表（Ch3/4/5）就是把这四维摊平成表格。

选源 7 标准（决定一个频道收不收）

1. 内容质量 + 语言真实性

内容本身值不值得看，语言是"真实语速地道表达"还是"为教学放慢"。两种都有用但要标清——真实语料（Easy English、TED）练的是真实听力，放慢的教学语料（Rachel's English、Little Fox）适合起步和跟读。

2. 分级适配（能对到 CEFR / 年龄，i+1）

能不能对到一个明确的 CEFR 区间和年龄段。像 Little Fox 自带 9 级分级[1]，天然适配 i+1；很多频道要靠 WPM 和词汇密度估。

3. 字幕（官方英文 CC？准不准？）

决定能否做精听核对 / 精读 transcript / 挖空。这是隐形第一门槛，Ch6 单独讲。

4. 口音多样性

半米服务国际学校，学生要接触多口音（美/英/澳/多元）。库里要有意识地配英音（BBC Earth、Peppa、Lucy）、美音（多数）、澳音（mmmEnglish）和多元口音（TED、Easy English）[26]。

5. 更新频率 + 库存量

能不能撑起一个板块。CNN10 学年日更适合"每日精听"[20]；有些频道（Vsauce、IELTS Liz）已基本停更，只能当存档精选[19][39]。

6. 适配的 step

内容型 → 泛听/精听/影子跟读；教学型 → 方法学习 + 发音跟读。选源时就想好它主要挂哪个 LE Template。

7. 版权 / 接入

能不能合规接入（官方嵌入/videoId）。见 Ch14。第一批建议全部走"嵌官方播放器"，不碰下载重托管。

03少儿段频道（A0-A2）：以内容型 CLIL 为主▾

少儿段（国际学校 K-G3，A0-A2）以内容型为主——孩子不需要"被教英语"，而是需要大量可理解、可爱、语速慢的英语输入（可理解输入原理见 Ch7）。这一段最看重两件事：字幕可信度（能不能做精听/影子跟读）和 学科英语 CLIL（用英语学科学/自然，一举两得，半米最看重）。

本段结论先给：少儿段种子四选 —— Little Fox（分级+内嵌字幕最理想）、SciShow Kids（NGSS 科学 CLIL）、Super Simple Songs（启蒙+字幕最好）、Peppa Pig 字幕版（英音日常会话/影子跟读入门）。Crash Course Kids 语速偏快、配字幕做精听。其中字幕已能查证到🟢的是 Little Fox（内嵌）、Super Simple Songs、Crash Course Kids；SciShow Kids 和 Peppa Pig 字幕仍是🟡（待实测 / 仅部分播放列表有字幕）——它们凭内容价值入选种子，但精听/挖空前必须逐视频确认 CC。这也是 Ch6 反复强调的：字幕可信度是准入项，不能因为频道大就默认有官方字幕。

✅ 为什么 Little Fox 是少儿分级视频库的头号候选（🟡主观筛选）

它把三件半米最需要的事一次做齐：① 自带 9 级 CEFR 式分级（1-3 级对 A0-A1、4-6 级对 A2、7-9 级对 B1），可以直接按级排课，天然适配 i+1[1]；② 所有故事内嵌英文字幕是它的设计核心，不是靠自动 CC 碰运气，看视频时字幕稳定可见、精听核对/影子跟读友好[1]；③ 美音录音室级清晰，适合初级影子跟读。技术区别提醒（🟡）：内嵌（烧录进画面）字幕不等于机器可提取 transcript——要做自动挖空/制卡，需确认它有独立 CC 字幕轨或官方逐字稿，否则要 OCR/人工转录，引入准确率与版权成本（见 Ch12）。它同时能挂"精读"和"泛听"两种 LE Template，是少儿段唯一能撑起完整闭环的分级频道。这是本报告的主观推荐，客观特点（9 级/内嵌字幕）可查证🟢。

⚠️ 少儿段的两个坑

口音要看清：Peekaboo Kidz（Dr. Binocs）是印度出品，带轻微印度英语口音，虽然科学 CLIL 内容不错，但用作主要跟读素材前要判断口音是否匹配半米的口音策略[28]。字幕别想当然：Blippi、Steve & Maggie、Alphablocks、Numberblocks 都标"字幕待核实"，入库前必须到视频页验证 CC，别默认"大频道就有官方字幕"。此外 Disney/Pixar 短片版权复杂，本报告未查，建议第一批不碰。

半米已有实证：阿杰的少儿词汇管线已经在用 SciShow Kids 和 Crash Course Kids 做词表（plp graph），这两个频道是"内容型 CLIL 频道能落地"的现成案例，可以直接当少儿段种子。相关词汇入库还可交叉参考半米研究中心的 #8 youtube-vocab-channels-research 与 #11 banmi-vocab-channel-standard（本报告是它们的"通用频道 + 视频库 + step"扩展面）。

04青少年 / 中学内容型频道（B1-C1）▾

青少年 / 中学段（B1-C1）是内容型频道的主战场：科普动画、学生新闻、纪录片、真实对话。这一段学生已经能处理有情节、有观点的内容，重点从"听懂"转向"大量优质输入 + 精听精练"。选源关键是字幕质量分层——同样是大科普频道，TED-Ed 有专职字幕+文字稿，Veritasium 只有自动 CC，能挂的 step 完全不同。

06字幕质量：选源的隐形第一门槛▾

如果只能记住这份报告一件事，那就是这一章：字幕质量是选源的隐形第一门槛，它比"内容好不好"更早决定一个频道能挂哪些 step。因为半米最有价值的 step——视频精听、transcript 精读、挖空 cloze——全靠字幕核对。字幕不可信，这些 step 直接做不了，频道再好也只能降级成"泛听素材"。

⚠️ 建库操作纪律：字幕待实测的频道必须逐视频验证

所有标 🟡 的频道（SciShow Kids、Peppa Pig、Blippi、Alphablocks、Numberblocks、Nat Geo Kids 等），官方字幕需在 YouTube 逐个视频确认 CC 的存在与质量，不能默认"大频道就有官方字幕"。建库时给这些频道的默认 step 只开泛听，某个视频经人工验证字幕可信后，再单独把这条视频升级到"可精听"。这是把"频道级标签"下沉到"视频级标签"的关键一步。

07用视频学英语的方法论地基▾

这一章给后面所有 step 设计一个理论底座——不是为了掉书袋，而是因为半米的 LE Template 要站得住脚，产品经理得能回答"为什么这样设计 step"。下面每一条都会在 Ch8-Ch13 变成具体步骤，同时诚实标出学界还没定论的地方。

① 可理解输入 i+1（Krashen）——为什么视频比纯音频好

语言习得靠理解"略高于当前水平"的输入（i+1）[50]。视频比纯音频多了视觉通道：画面提供额外语境，让难度显著下降。实证：视听组合相比纯音频，实验组听力理解 +18.2%、词汇习得 +22.2%[51]。这是"用视频学"整件事的科学起点，也是 Ch11 选级的依据。

② 影子跟读（Shadowing）——三通道同步训练

由 Arguelles（会 50+ 语言）推广，同步调用听觉 / 发音肌肉 / 自我监控三通道[52]。实证：台大研究显示显著改善语调、流利度、发音；2025 年一篇涵盖 44 项研究的系统综述确认跨人群可测进步[53]。做法阶梯：先泛听理解 → 有稿跟读（scripted）→ 纯音频跟读（blind）→ prosody 跟读。Ch10 展开成 4 阶段。

③ 精听 vs 泛听 + 窄听——互补不是二选一

精听=短材料听懂每个词、练精度；泛听=长材料整体理解、练流利度和输入量；两者互补[54]。窄听（Krashen 1996）=同主题多材料反复，词汇场景一致、生词反复出现，加速巩固[55]；Cambridge SSLA 研究显示窄听/窄读对意义识别显著优于拼写和主动产出[56]。这撑起 Ch11 的窄听循环设计。

④ 字幕的 SLA 实证——L2 助词汇、L1 助理解、双语最受欢迎

L2 字幕（目标语）最助词汇形式识别+语音分段；L1 字幕（母语）最助内容理解、适合低级，但高水平者无字幕有时更好（redundancy effect）[57]；双语字幕（Wang & Pellicer-Sánchez 2022 眼动研究）学习者偏好 L1+L2 并排，意义回忆/识别均更好[58]。🟡 争议：L1 vs L2 效果量受水平/难度/测试类型调节，元分析不完全一致——所以 Ch8 里"双语字幕当入门 scaffold、逐步撤到 L2、最终无字幕"是有条件的顺序，不是绝对规则。

⑤ 听写 + 复述——从意义处理转向句法处理

听写（dictogloss，Boers 2022 SAGE）对多词组习得有效，与语言总体水平高相关[59]；复述（Swain 1985 输出假说）迫使学习者从意义处理转向句法处理，暴露语法盲区、触发 noticing，Hong 2012 确认 retelling 触发 hypothesis testing[60]。这正是 Ch1"掌握 vs 接触"的科学解释：产出型 step 才逼出掌握。

⑥ 同一视频多轮循环的理据

一个视频反复看不是浪费：①泛听全速→建整体理解；②精听+字幕→精化词汇 form-meaning；③影子跟读→发音语调肌肉记忆；④听写→注意音素词边界；⑤复述→output 激活句法；同主题重复=词汇窄听[61]。这是 Ch13"同一视频 Day1-4 换侧重"的直接依据。

⚠️ 诚实标注：学界还没定论的地方

不要把这些当铁律卖给用户：① L2 vs L1 字幕的元分析结论不一致，需按学习者水平分档看[57]；② ALG（Automatic Language Growth，尽量不学语言本身、silent period 数百小时）的极端形式缺 RCT、有轻微 cult 色彩，以社区实践为主，不宜作为半米主推方法[62]；③ 视频场景 spaced vs massed 的最优复习间隔无定论；④ 视频专项听写的 SLA 研究偏少。🟡 这些地方半米应留可配置空间，而不是把某一种做法写死。

08step 结合总览：方法 → LE Template 映射▾

Ch7 的方法论，落到半米就是一张"方法 → LE Template"的映射表。半米第一批 LE Template 里和视频直接相关的有：视频泛听、视频精听、影子跟读、复述、词汇复习（可含精读挖空）[12]。下面这张表把成熟方法一一对上，后面 Ch9-Ch12 逐个展开成可抄的 Step 序列。

双语字幕：不是独立 step，是各 Template 的入门脚手架

双语字幕（L1+L2 并排）实证上学习者最偏好、意义回忆/识别更好[58]，但它的正确用法是脚手架，用完要撤：入门时用双语字幕降低门槛 → 水平上来撤到只剩 L2 字幕（练词汇形式识别）→ 最终目标无字幕（练真实听力）[57]。所以半米不该把"双语字幕"做成一个独立 LE Template，而应做成各 Template（尤其视频精听/泛听）可切换的字幕模式，随水平推进逐级撤。

09视频精听 step 详解（呼应半米系统总览那套）▾

视频精听是半米视频库最有价值的 step，也是"看视频=接触 → 精听答题=掌握证据"转化的主力。半米系统总览里已经描述过它的嵌套结构：关闭字幕先听 → 回答大意 → 逐句重听 → 打开字幕核对 → 再次关字幕听 → 提交结果[12]。下面把它和成熟精听方法（Refold + Leonardo English）对齐，给出可直接抄进"视频精听 Template"的 6 步 Step 序列。

视频精听：6 步嵌套 Step 序列（可直接抄）

1预热（设聆听任务）
读标题/描述激活背景，设 1-2 个聆听任务（"这集在讲什么问题？给出 3 个关键词"）[42]。对应半米：Step 的"要求"字段。
2第一遍无字幕抓大意（gist）
关字幕整体听一遍抓大意，听不到某些词是正常的，不要停[42]。听完回答步骤 1 设的任务。对应半米总览的"关字幕先听 → 回答大意"。
3第二遍无字幕定位难点 + 原地重听
Refold 铁律：relisten before checking（先重听，再看字幕）。卡住的地方原地重听 1-3 次，仍听不懂再进下一步[42]。对应半米的"逐句重听"。这一步是精听有没有效的关键——不重听直接看字幕，等于跳过了训练。
4第三遍开英文字幕逐句核对
打开英文字幕逐句核对，看刚才没听出来的是哪些词/连读/弱读（中文字幕仅初学者临时用）[42]。对应半米的"打开字幕核对"。字幕必须可信（Ch6）——这一步用的就是 TED-Ed/CNN10 那类🟢频道。
5专注一遍（发音模式 / 词汇模式二选一）
发音模式：挑 3-5 句做影子跟读（接 Ch10）；词汇模式：标 5-10 个短语搭配、查语境义（不查孤立词，查在句子里的意思）[42]。
6再一遍无字幕验收 + 提交结果
再关字幕听一遍验收；仍卡的入 SRS（接 Ch12）[42]。对应半米的"再次关字幕听 → 提交结果"——提交的答题/复述就是 Evidence（掌握证据），不是"看完打勾"。

选材硬指标（照这个筛，精听才不会翻车）

① 有准确字幕/逐字稿（Ch6 的🟢频道）；② 单段 3-5 分钟（别拿整集 20 分钟做精听）；③ 无字幕状态下 comprehension 60-80%（太简单没训练价值，太难挫败）；④ 心理预期：20 分钟视频做精听花 1 小时是正常的[42]。半米在挂"视频精听"Template 时，应把这几项做成素材范围的自动校验/提示。

把每个 step 写成可判定的产品规格（Depth 补强）

上面的 6 步要真正上产品，每步还得补上"完成条件"，否则学生和系统都无法判断该不该进下一步。建议每个 Step 明确：输入素材范围 · 允许的最大重听次数（如逐句 ≤3 次）· 完成条件（如"回答 2 道 gist 题"或"逐句核对完一段"）· 失败路径（连续听不懂→降级换更简单片段或减速）· 证据格式（答题/时间戳/录音）· 评分 rubric · 耗时上限。影子跟读的"比元音/词尾/语调"也要给可操作 rubric（如"3 个目标音是否清晰、词尾有没有吞"），否则学生自评不稳定。无障碍替代（如听觉处理困难学生用更慢速/更短段）一并留口子。

⚠️ 最容易被砍掉的一步，恰恰最重要

学生（和产品）最容易图省事跳过步骤 3 的"先重听再看字幕"，直接第一遍就开字幕跟着读——那样精听就退化成了"看着字幕听"，训练效果大打折扣[42]。半米可以用交互设计守住这条铁律：第一/二遍字幕默认锁定为关闭，必须完成"重听 N 次"或"回答大意"才解锁字幕核对。这是把方法论"焊进"产品的地方。

10产出型 step：影子跟读 + 复述 + 听写▾

这三个 step 是半米视频库的"掌握证据"发动机。Ch1 讲过：看视频只是接触，影子跟读/复述/答题才是掌握证据（Evidence）[12]。所以这一章的每个 step 产出（录音、复述、听写稿）都应作为 Evidence 入库，而不是"完成就打勾"。

影子跟读：4 阶段 Step 序列（可直接抄）

1Listen only ×2（先纯听不开口）
第 1 遍纯听不出声；第 2 遍跟着逐字稿默读，注意语调/节奏/停顿[43]。
2Scripted shadowing ×2-3（有稿出声跟读）
拿着稿，落后原声 0.5-1 秒出声跟读，先让嘴跟上[43]。适合初学者建"发音蓝图"。
3Delayed 无稿 ×2（收稿靠耳跟读）
收起稿，只靠耳朵跟读，落后 1-2 秒，强迫听觉处理[43]。适合中高级练听觉解码。
4录音对比（产出 Evidence）
录自己 30 秒和原声对比：元音清晰度/词尾/语调[43]。这段录音就是掌握证据，入库喂成长路径。

影子跟读的选材与循环参数

选材：单人清晰发音；comprehension ≥ 80-90%（比精听要求更高，因为要能跟得上）；有准确字幕；120-150 WPM（初级用 0.75x 减速）[43]。分级素材：初级 BBC Learning English、中级 YouTube 对话/新闻、高级 TED/电影独白[43]。循环：每次 10-15 分钟、每次 60-90 秒片段、同段重复 3-4 天、4-6 周见变化[43]。这些参数直接填进半米"影子跟读 Template"的完成逻辑。

复述（Retell）：output 激活句法

R复述 Step
看完/精听完，关掉视频，用 5 句左右口头复述内容；再对照逐字稿看漏了哪些关键表达[63]。原理：复述迫使从意义处理转向句法处理，暴露语法盲区（Swain 输出假说）[60]。产出（复述录音/文字）= Evidence。

听写（Dictation / Dictogloss）：注意音素与词边界

D听写 Step
听一小段（清晰、短），把听到的写下来，再对照字幕核对[43]。dictogloss 对多词组习得有效，且与语言总体水平高相关[59]。强依赖可信字幕（核对用）。写出来的听写稿+错误 = Evidence。

三个产出型 step 的共同产品原则

它们的产出必须进 Notes/Evidence，不是打勾。半米应把影子跟读录音、复述文本、听写稿都作为 Evidence 类型入库，接到成长路径与 OKR 的 KR（Ch15）。这正是半米区别于"看视频打卡"类产品的核心：产出型 step 让"看视频"变成可验证的掌握[12]。但要诚实分清一层（🟡效度提醒）：这些产出是"evidence artifact（可观察产出）"，不自动等于"掌握"——跟读可能只是短时声音模仿、复述可能靠刚看完的工作记忆、听写可能测的是拼写、AI 发音分可能有口音偏差。严谨做法是让 artifact 先经 rubric 评分 + 延迟复测/迁移任务通过，才更新 mastery / 记 KR 达成，而不是"提交录音"直接映射成掌握。可交叉参考半米研究中心的影子跟读深挖报告 english-learning-methods--shadowing-deep-dive 和听写深挖 english-learning-methods--dictation-deep-dive（本章的 step 序列可与那两份的方法细节互补）。

11视频泛听 + i+1 选级 + 窄听▾

泛听是"量的引擎"，也是半米订阅（Subscriptions）里最轻的日常动作——不查词、不暂停、追量。它对字幕依赖最弱，反而是选级最考验产品：给错了级，泛听要么太难劝退、要么太简单没输入价值。

泛听原则

量 > 深度，不停不查词。每次 20 分钟到数小时持续听，不暂停不查词；字幕理想是零字幕，需要辅助则英文 > 母语，最终目标无字幕[44]。泛听可以停在半米的 Subscriptions/轻量浏览层，不强制进 Today 正式学习（Ch1 状态分离）。

i+1 三重检验选级（照这个判素材合不合适）

180% 法则
无字幕能听懂 ~80% 最合适；<60% 太难、>95% 太简单[44]。
2生词类型
缺的是 content words（实义词）超纲；只缺专业术语可接受[44]。
3语境推测
听到新词能靠上下文猜个大概，说明难度合适[44]。

WPM 分级参考（把频道对到级）

CEFRWPM 参考对应素材举例
A1-A2100-125 WPMComprehensible English 频道、Super Simple Songs、Ms Rachel[44]

🟡 CEFR 与 WPM 的精确联动阈值学界无统一标准，以上为常见经验区间，半米应作参考默认值、允许人工微调。

⚠️ "80% 法则"别只靠学生自评（可操作化）

让学生凭感觉判断"听懂约 80%"其实不可靠，词汇/WPM/主观理解三者冲突时也没规矩。更稳的做法：用 3-5 道 gist/detail 题 + 词汇覆盖率 + 完成耗时组合估级，答对率落在合适区间才判"这一级刚好"；连续两条视频表现都过高或过低，再自动升/降一级，避免单条误判。半米可把这套做进"选级"逻辑，而不是让学生手动填百分比。

窄听（Narrow Listening）：同主题多视频巩固词汇

窄听 = 同一主题连着看好几个视频。同主题词汇场景一致，生词反复出现，加速巩固[55]；Cambridge SSLA 研究显示窄听对意义识别显著优于拼写和主动产出[56]。半米可把窄听做成"视频泛听"Template 的一个变体：按主题给学生成组推送视频（例如"太阳系"主题下 Kurzgesagt + SciShow Kids + Nat Geo 各一集），让同一批词在不同视频里反复撞见。这也是同主题频道成组入库的产品价值所在。

12transcript 精读 + 挖空 cloze + 接 SRS + 工具矩阵▾

这一章把视频学习和半米已有的笔记+复习系统接起来：从 transcript 精读 → AI 生成挖空卡（cloze）→ 挂到 FSRS 间隔复习。这条链路把"精听时标下的短语"变成长期留存的词汇，是"词汇复习"LE Template 的视频版实现。

transcript 精读 → 挖空 cloze → SRS：5 步链路

1精读逐字稿，标生词/搭配/句型
优先标 content words 和搭配，不孤立标单词[45]。素材=字幕🟢频道的 transcript（Ch6）。
2AI 生成 Cloze 卡
prompt 示例："从这段 transcript 提取 B1/B2 级 20 个关键短语，做填空卡，每张带完整例句"[45]。半米可内置这条 AI 生成能力。
3挂到 FSRS 间隔复习
导入 Anki/FSRS 自动排间隔[45]。半米这一步直接接已有的笔记+复习系统——见半米研究中心 #38 banmi-note-review-system（FSRS 挂载方案），视频挖空卡挂进去即可复用整套 SRS。⚠️ 防卡片过载（MVP 纪律）：别把"AI 一次生成 20 张卡"当默认。建议每条视频最多留 3-5 个高价值项（先去重已知词、按词频/价值排序、人工/教师确认一遍），并给每日 review load 设预算、处理 leech；AI 生成的卡要过一遍防错卡。K12 场景还要控制音频/截图的权利边界与未成年人数据向第三方模型的传输。
4Sentence mining（句子采集）
挑"只含 1 个生词的完整句"（i+1 句）做带上下文的卡：正面挖空句、反面原词+释义+音频[45]。

TranscriptMagic 下 SRT → ASBplayer/Language Reactor 导出词汇 → Anki（LR Pro 直接 Export to Anki，ASBplayer 导出带音频卡）[45]。

13一个视频跑完整闭环样例▾

把前面所有 step 串起来，就是"一个视频跑完整精学闭环"。下面先给通用的 90 分钟闭环（课堂可精简到 45 分钟），再给两个具体落地样例，最后是"同一视频 Day1-4 换侧重"的复用节奏。

通用闭环：一个 5 分钟视频 ≈ 90 分钟（课堂精简 45 分钟）

A泛听预热（5 分）
无字幕看完抓主题 + 3 个关键词。选材：听懂 ≥ 80%、WPM ≤ 150[46]。
B精听主流程（30 分）
Language Reactor 双语字幕：第 1 遍无字幕记生词时间戳 → 第 2 遍卡住先重听 1-3 次再开字幕（Refold relisten）→ 第 3 遍开英文字幕逐句核对、标 5-10 个核心短语[46]。（= Ch9 六步）
C影子跟读（20 分）
选 2-3 段（每段 60-90 秒）：Auto-Pause 每句 scripted ×2 → 无稿 ×1，最后录自己比节奏语调[46]。（= Ch10 四阶段）录音入 Evidence。
D复述 Retell（10 分）
关视频用 5 句口头复述，对照逐字稿看漏了哪些关键表达[46]。复述入 Evidence。
E词汇复习入库（15 分）
ASBplayer/LR 导出 10-20 个生词带例句 → Anki/FSRS 做 cloze 卡 → 当天复习一遍（首次间隔 1 天）[46]。（= Ch12 链路，接 #38 FSRS）

复用节奏：同一视频 Day1-4 换侧重（窄听式重复）

Day1 精听 + 词汇 → Day2 影子跟读 → Day3 无字幕测留存 → Day4 Anki 复习[46]。同一素材套不同 LE Template，正是 Ch1"一个视频可先泛听→精听→影子跟读→复述"的产品落地，也符合 Ch7 同视频多轮循环的理据。

落地样例①：CNN10 一集做"每日精听"

选一集 CNN10（10 分钟学生新闻，学年日更、有 cnn.com 完整文字稿）[20]。课堂 20 分钟精简版：① 预热 2 分（看标题猜今天几条新闻）；② 精听第一条新闻 3-5 分钟段落（无字幕→重听→开字幕核对，用官方文字稿当标准答案）；③ 复述 3 分（用 3 句说这条新闻讲了啥）；④ 词汇 2 分（标 3 个新闻高频词入 SRS）。因为日更且有文字稿，CNN10 天然适合做"每天一集"的持续精听板块，学生有时效动机，产品有稳定素材供给。

落地样例②：Peppa Pig 一集做"影子跟读入门"

选一集有字幕版的 Peppa Pig（5 分钟、英音 RP、句子短、日常会话）[11]。少儿/初学者 15 分钟版：① 泛听 1 遍看画面理解；② Listen only ×2（第 2 遍看字幕默读）；③ Scripted shadowing 选 2-3 句短对话，落后 0.5 秒跟读 ×2（初级可 0.75x）；④ 录 30 秒和原声比。Peppa 句短、语速慢、情境清晰，是影子跟读入门的经典素材；注意用有字幕的播放列表或 PeppaPigSubtitled，非字幕版做不了有稿阶段（Ch6 字幕待实测提醒）。

14版权 / 接入方式（合规路 vs 深加工路）▾

视频库要合规上线，接入方式比选源更早卡住产品。这一章给半米的接入建议，直接呼应阿杰之前两份报告的结论。先声明：以下是接入方式的工程/产品建议，不是法律意见。

核心建议：Library 存元数据 + videoId，播放走官方嵌入，不下载重托管

半米 Library 应嵌入/引用 YouTube 官方播放器（IFrame Player API）或存 videoId 链接，视频始终留在 YouTube 上。这与 Library 的模型天然契合——Library 本来就"只保存素材事实、引用不复制"（Ch1）[12]。视频留在 YouTube 版权风险显著低于自营点播（规避了成排判例与视听牌照风险）——但"官方嵌入"≠ 自动全合规：YouTube 开发者政策还要求隐私政策、YouTube 来源标识、不干扰播放器完整性（不遮挡广告/控件）、以及处理每条视频的 Made for Kids 状态等[12]。所以路线 A 的准确表述是"较低版权风险，但需完成 API/播放器/隐私/儿童合规评审"（详见下方儿童合规 callout）。🟡（接入建议，非法律意见）

15半米建库路线建议（决策树）▾

把全报告收成一条可执行的建库路线。核心思路：别一上来铺 30 个频道，先用"1 个频道 × 1 种 step"端到端跑通，验证 step 序列和 Evidence 回收，再横向铺开。

少儿段（A0-A2）→ Little Fox（分级+内嵌字幕）+ SciShow Kids（已在用）+ Super Simple Songs + Peppa Pig 字幕版[1][2]

关键升级：频道是"发现单位"，视频才是"准入单位"（Codex 审查采纳）

本报告给的是频道级发现 + 用法框架，真正上库时准入判断要下沉到视频级。落地做法：第一批只审 8-12 个频道，每个抽样约 10 条视频，逐条记录一个准入数据集字段——字幕类型（内嵌/CC轨/官方文字稿/自动）· 字幕抽检 WER · WPM · 词汇难度 · 内容风险标签 · Made-for-Kids/嵌入状态 · 年龄适配。三道强制门槛：① 没有字幕抽检结果不得开精听；② 没有内容风险评级不得推给儿童；③ 没有嵌入/隐私/儿童合规评审不得上线。凡矩阵里没有独立证据的字段（多数 CEFR/口音/语速）当"编辑判断/未测"处理，不当 🟢。

MVP 验收指标（别只看"跑没跑通"，要能判断该不该扩库）

Phase 1 先跑 20-30 分钟的小剂量实验，用可测指标决定是否横向铺：step 完成率 · 次日/隔日保持率（延迟复测）· 教师审核成本（每条视频过审耗时）· 字幕错误率（WER）· Evidence artifact 经 rubric 后的有效率。达标才进 Phase 2 铺频道；不达标先改 step 序列或换素材，而不是先铺 30 个频道再说。

⚠️ 本报告未覆盖、后续要补的（诚实划界）

这份是"选源全景 + step 结合手册"，不是完整的视频库治理规范。以下几块建库到一定规模后需要专项补：① 内容类型缺口——本报告偏高制作科普/ESL 教学/英美主流，还应补 Pre-A1 手势故事/无文字叙事、分级读物朗读、青少年同龄人内容、东南亚本地英语与国际学校场景、更多学科系列（数学/编程/艺术）、世界英语与非母语专家表达。② 分级维度要拆开——不要把年龄/年级/CEFR 混用，建议分成 language_level（语言难度）· cognitive/interest_age（认知与兴趣年龄）· school_grade（年级），避免"年龄合适但语言太难"或"语言简单但内容幼稚"。③ 完整运营流程——候选发现→初审→内容安全审核→字幕抽检→权利/API 审核→教学标注→发布→学生举报→定期复审→下架/字幕变更处理→审计日志。④ 教师/家长工具——预览批准、屏蔽频道/主题、谁能看儿童录音、纠正错误字幕、处理举报。⑤ 风险字段——暴力/死亡/战争、性/药物/危险挑战、政治争议、广告植入、刻板印象、创作者历史风险、评论区/外链风险。🟡（这些是产品/治理工作，非本报告选源范围）

给阿杰的一句话结论

第一批别贪多：三块各挑 2-4 个频道当种子（字幕能查证🟢的优先，🟡的先只开泛听），先拿 CNN10×精听 或 Peppa×影子跟读 一个组合端到端跑通，把 Evidence 回收和 SRS 挂载验证了，再横向铺。字幕可信度是准入项、Evidence 是灵魂、四维标签是骨架——把这三件事焊进产品，半米的视频库就不是"又一个看视频打卡工具"，而是"用视频产出掌握证据的学习操作系统"。

FAQ常见问题▾

Q1第一批该收几个频道？＋

别贪多。三块（少儿/青少年/教学型）各挑 2-4 个"字幕🟢"频道当种子就够，总共约 8-12 个。先把频道质量和 step 跑通比堆数量重要。具体名单见 Ch15 决策树 Q1：少儿选 Little Fox/SciShow Kids/Super Simple Songs/Peppa 字幕版，青少年选 TED-Ed/CNN10/Kurzgesagt/Easy English，教学型选 BBC Learning English/Rachel's English/Learn English With TV Series。

Q2字幕不准的频道能用吗？＋

能用，但要降级用。字幕🟡的频道先只开"视频泛听"（泛听对字幕依赖弱），不要挂精听/精读挖空——那些 step 靠字幕当标准答案，字幕错了越对越乱（Ch6）。某条视频经人工验证字幕可信后，可以单独把这条升级到"可精听"。核心纪律：字幕可信度是准入项，不是加分项。

Q3孩子几岁适合影子跟读？＋

没有硬性年龄线，看的是能否听懂和跟上：影子跟读选材要求 comprehension ≥ 80-90%、单人清晰发音、120-150 WPM（初级用 0.75x 减速）[43]。对低龄/初学者，从 Peppa Pig（句短、语速慢、情境清晰）这类素材的"有稿跟读"阶段起步最稳（Ch13 样例②）。先纯听两遍再开口，别一上来就 blind 跟读。

Q4同一个视频要反复看吗？＋

要，而且这是特性不是浪费。同一视频套不同 step、跨天换侧重（Day1 精听+词汇 / Day2 影子跟读 / Day3 无字幕测留存 / Day4 Anki 复习），每一轮训练不同能力，且同素材重复本身就是"窄听"式词汇巩固[61]（Ch7/Ch13）。半米 LE Template 的设计（同素材可套多 Template）正是为此。

Q5要不要买 Language Reactor Pro？＋

MVP 阶段先用免费版验证。Language Reactor 免费版已能做双语字幕、Auto-Pause 每句暂停、S 键重复，覆盖精听和影子跟读的核心交互；Pro 主要多了"直接导出 Anki"[65]。开源的 ASBplayer 免费就能导出带音频+截图的卡[66]。建议：先免费版跑通 step 序列，等确定要规模化导词入 SRS 再考虑付费，或直接用 ASBplayer 免费替代。

Q6自动字幕（自动 CC）能做精听吗？＋

分情况。旁白录音室级、语速慢的频道，自动 CC 准确率极高，可以做精听（Kurzgesagt、CGP Grey）[17][18]；但真实对话、快语速、多口音的频道，自动 CC 错误多，做精听会被错字幕坑（Veritasium、Vsauce）[30]。最稳还是用有"官方人工字幕/完整文字稿"的频道（TED-Ed/CNN10/BBC），字幕即标准答案（Ch6）。

Q7内容型和教学型，哪个先建？＋

先建内容型。内容型是"输入素材"，是半米视频库的主体，精听/泛听/影子跟读/复述都要靠它；教学型是"方法与技能课"，更像补充和示范（教发音、教怎么听）。第一批把内容型的字幕🟢种子铺好、step 跑通，再用教学型（尤其 Learn English With TV Series）把方法层补上、和内容型形成闭环（Ch5）。

Q8视频要不要下载到半米服务器？＋

绝对不要。把 YouTube 视频下载到自己服务器供点播，是有成排判例的确定侵权（peppa-shadowing 报告结论），还可能需要视听牌照。正确做法：Library 存元数据+videoId，播放走 IFrame 官方嵌入，视频留在 YouTube（Ch14）。要做本地精听/挖空深加工，走"用户本地文件/客户端处理"那条（local-video 报告结论）。这是接入建议，非法律意见。

Q9怎么保证口音多样，不让孩子只听美音？＋

建库时有意识配口音（选源标准 4）。库里要配英音（BBC Earth、Peppa、Kurzgesagt 旁白、English with Lucy）、美音（多数）、澳音（mmmEnglish）和多元口音（TED 全球演讲者、Easy English 区域变体）[26][46]。国际学校学生本来就要接触多口音，这是特性。注意个别口音（如 Peekaboo Kidz 的印度腔）用作主跟读素材前要判断是否匹配（Ch3）。

Q10"看视频"怎么变成能算数的学习进度？＋

靠产出型 step 的 Evidence。半米明确区分：看过=接触，影子跟读/复述/答题=掌握证据[12]。所以泛听可以停在轻量浏览层不计正式进度；一旦进 Today 做精听/影子跟读/复述，产出的答题、录音、复述稿就作为 Evidence 入库，喂成长路径和 OKR 的 KR（Ch1/Ch10/Ch15）。这正是半米区别于"看视频打卡"产品的地方。

Q11泛听和精听，学生该多做哪个？＋

两个都要，互补不是二选一。精听练精度（听懂每个词），泛听练流利度和输入量（追量不查词）[54]。半米可以把泛听做成日常轻量动作（订阅里随便刷、不计正式进度），把精听做成正式学习（进 Today、产出 Evidence）。一个健康的节奏是大量泛听打底 + 少量精听精练 + 影子跟读/复述固化，配合窄听（同主题成组）加速词汇巩固（Ch11）。

Q12MVP 到底先做哪个组合？＋

推荐二选一：CNN10 × 视频精听（青少年，字幕🟢日更、有官方文字稿、Ch9 六步现成）或 Peppa Pig 字幕版 × 影子跟读（少儿，句短语速慢、Ch10 四阶段现成）。选一个频道×一种 step 端到端跑通，重点验证三件事：学生能否走完 step 序列、Evidence 能否回收、词汇能否挂上 SRS。跑通再横向铺（Ch15 Phase 1）。
