颠覆点（这条最反阿杰之前判断）：

2026-05-25 阿杰拍"不用付费 API + 全靠订阅 + Haiku 拆小任务"。但 2026-05-27 数据说明这判断需要部分修正[1][6]：

  • DeepSeek V4 Pro cache hit 已永久降到 $0.003625/M（5月22日永久化）[2] — 跑 1000 万 token cache 命中只要 $0.036（不到 3 毛人民币）
  • Anthropic 2026 年 8 月起加了周限额，Max $100/月 Sonnet 限 140-280 小时 / Opus 限 15-35 小时[7] — 真要 batch 处理 17 家频道字幕 (~1.66M token) 在订阅内能跑但慢且占资源
  • 2026 年 4 月 Anthropic 悄悄把 Claude Code 缓存 TTL 从 1h 降到 5min，许多用户成本暴涨 30-60%[8] — 订阅成本不再像 5 月初想象的那么"稳定免费"

新结论：路线 A（纯订阅）适合小规模 / 实验 / 临时任务；路线 B（纯 DeepSeek 付费）适合大 batch；最优是路线 C 混合 — 订阅 Haiku 做"已经在打字时随手能写的小任务"，DeepSeek V3.2 / V4 Flash 付费做"夜里跑一晚上的 100 万 token 级别 batch"。

1.1 五条核心结论

结论 1 数据清洗 = DeepSeek V3.2 / V4 Flash 主力，Haiku 备胎
半米核心 = 海量字幕 / PDF / 题目 → 结构化 JSON / embedding。这类任务对模型质量要求 "够用就行"（70-80% 准确率 + 重试机制），但对成本极敏感（动辄 1000 万 token 级别）。DeepSeek V3.2 cache miss $0.27/M、cache hit $0.028/M[1]，JSON 输出可靠性 100%[9]，是这类任务的性价比之王。Haiku 4.5 走订阅免费但需要排队跑，做实验 / 小规模 OK。
结论 2 $100 能处理 5000 万 token = 半米 V0.1 完整素材库
按 DeepSeek V3.2 cache miss 算（含 30% cache 节省）：$100 ÷ ($0.27 × 0.7 + $0.41 × 0.3 × output比例) ≈ 5000 万 input token + 1500 万 output token。这相当于把 banmi 字幕实测的 17 家 YouTube 频道 ~1.66M token 跑 30 遍（不同任务多轮：归类 + 句子打分 + CEFR 标签 + embedding 配对 + 错题生成）。详见 §11。
结论 3 Embedding 用 OpenAI 3-small 或本地 BGE-M3 — 不要为 embedding 烧钱
OpenAI text-embedding-3-small $0.02/M tokens[10]（batch 半价 $0.01/M），MTEB 62.26[10] 是 90% 应用的"安全默认"。半米全部资料 embed 一遍（按 5 亿 token 估）只要 $5-10，根本不是成本痛点。中文场景 BGE-M3 或 Qwen3-Embedding-0.6B 本地跑零 API 成本[11]，质量也够。
结论 4 学员侧最终输出（改作文 / 出题）仍需 Sonnet 4.6 或 Opus
"数据清洗"（开发者跑的脚本，错了重试无所谓）用 DeepSeek；"学员看到的最终内容"（错题反馈 / 个性化讲解 / 改作文）需要 Sonnet 4.6 或 Opus[3]，因为这是产品质量底线。半米 V0.1（50 学员）每月学员侧 Sonnet 用量 预估 $20-50，不超预算。
结论 5 DeepSeek 稳定性 = 副 provider 必备（不是单点依赖）
DeepSeek 2026-03-30 单次宕机 7h13min[12]，过去 1 年累计 104+ 次中断[12]。半米 batch 任务必须双 provider（DeepSeek 官方 + SiliconFlow 同模型托管[13] 或火山方舟豆包做 fallback）。OpenRouter 自动路由也行[14]。**学员侧产品**绝对不能依赖 DeepSeek 单点 — 必须 Anthropic 或 OpenAI 做主，DeepSeek 做开发侧 batch。

3.4 API 稳定性 + 限流

稳定性是 DeepSeek 的最大短板。2025 以来重要事件：

  • 2025-01 月底 API 连续天级中断[12]，全球用户骂声一片
  • 2026-03-30 单次宕机 7 小时 13 分[12]，是历史最长
  • 过去一年累计 104+ 次中断[12]，API uptime 99.90% / Web 99.44%
  • 中国境外用户延迟 +2-3x（中国业务高峰时段）

对半米建议：开发期 batch 任务用 DeepSeek 主，但永远准备 fallback（SiliconFlow 同模型托管[13] / 火山方舟豆包 / OpenRouter 自动路由）。学员侧产品别用 DeepSeek 单点。

3.5 限流（RPM/TPM）

DeepSeek 采用动态限流而非固定 RPM/TPM 表[38]。实测约 500 RPM、100K TPM（V3 行为）[38]。但峰值 429/503 错误常见。batch 任务必须实现指数退避重试。

3.6 注册 + 充值流程（海外用户）

  1. 选择微信扫码登录（推荐）→ 自动绑定实名
  2. 或邮箱 / 手机号 → 后传护照照片 → 等待 1-3 工作日审核[39]
  3. 创建 API key（sk- 开头，只显示一次）
  4. 充值预设 50/100/500/1000 元四档 → 微信或支付宝扫码 → 秒到账
  5. 新账号赠 500 万 token 额度，30 天有效[39]
给阿杰的下一步：本周先充 $20（¥140） 试水。先跑 1 家 SciShow Kids 全集字幕分析（约 50 万 token）。算下来 ~$0.07 input + $0.30 output = 不到 $0.5。Cache hit 命中 30% 后更便宜。如果 JSON 输出稳定、质量够用、跑通无报错 → 加充 $80 跑全 17 家。

3.7 数据合规风险（半米需要知道）

14风险 + 注意事项▼

14.1 API 稳定性风险

  • DeepSeek：全年 104+ 次中断[12]。Last major 7h13m outage 2026-03-30
  • OpenAI：偶发中断但 status page 透明，自动恢复
  • Anthropic：uptime ~99.9%。但 cache TTL 2026-04 悄悄缩水案例提醒"政策变化也是风险"[8]
  • Google Gemini：地区 / VPN 限制要小心
  • Qwen / GLM / Doubao / Kimi：国产 MaaS 稳定性差异大，有的 99% 有的 95%

缓解：所有学员侧关键路径必须 2 个 provider；batch 任务任意 1 个；自动 fallback 用 OpenRouter 或自写 router。

14.2 数据合规风险（学员侧重点）

  • 学员个人信息（姓名 / 学校 / 家庭 / 联系）→ 永远只发 Anthropic / OpenAI（HIPAA BAA / SOC 2 可签）。不发 DeepSeek / Qwen / 任何中国 API
  • 学员作业答案（含答错的 / 痛苦的）→ 视情况；纯英文作文走 Anthropic；纯中文作业可走 Qwen（同样不出境）
  • 公开素材（YouTube 字幕 / 出版书 PDF / 公开题库）→ 任何 provider 都行
  • 欧盟学员 → GDPR 复杂，目前建议先服务非欧盟

14.3 模型选错的后果

  • 用 DeepSeek 跑学员侧 chat → 中断 7h，学员体验灾难，差评爆发
  • 用 Haiku 跑大 batch → JSON 偶尔失败，下游数据库错误，要重跑 3 次成本反超
  • 用 Opus 跑数据清洗 → 月度账单失控（Opus 比 DeepSeek 贵 50x）
  • 用本地小模型跑改作文 → 学员看到错误反馈，对产品信任崩塌
  • 过早本地部署 → 维护时间成本 > API 省下的钱（V0.1 / V0.2 阶段）

14.4 隐藏成本

  • 多 provider 账号管理 + 充值 + 发票 + 报销时间
  • 每个 provider 的 SDK / 错误处理 / 重试逻辑写代码
  • Anthropic cache TTL 突变案例（2026-04）[8] — 政策成本
  • OpenRouter / SiliconFlow 这类聚合商有自己的加价（通常 5-20%）
  • 本地部署电费 + 硬件折旧 + 升级时间

14.5 阿杰最该警惕的 3 件事

  1. 不要图便宜把学员数据走 DeepSeek — 数据合规 + 稳定性双坑
  2. 不要过早本地部署 — V0.1 / V0.2 阶段算账不划算，运维拉垮开发节奏
  3. 不要让 Embedding 占注意力 — 全量 $5，月度增量 $1，根本不是成本痛点。盯着 generative 任务（L1 / L2）才对

三个原因：(1) 稳定性 — 全年 104+ 次中断[12]，学员侧不能依赖；(2) 合规 — 无 HIPAA BAA / SOC 2，学员个人数据不能上；(3) EFL 作文评分能力较弱[36]，学员产品体验不到位。DeepSeek 主战场是开发期 batch + 非敏感数据清洗，不是替代整个 Anthropic 生态。
Q3Embedding 用 OpenAI 不出境吗？担心合规+
Embedding 走 OpenAI 出境，但 embedding 的输入是公开素材（YouTube 字幕 / 出版书 PDF / 公开题库），无学员个人信息，合规风险低。如果半米要 100% 数据不出境，用 BGE-M3 本地跑 — 质量也够（C-MTEB #1[48]），M4 Pro 64GB 一晚上跑 5 亿 token。学员个人化 embedding（如错题特征）一律走本地。
Q4cache hit 真的能命中 30%？我怎么验证+
DeepSeek 是 transparent automatic caching — 你不用做任何配置，相同前缀自动 cache（最近 24h 内有人调过同样 prefix 的 token 都算）[1]。验证方法：API response 头里有 prompt_cache_hit_tokens 和 prompt_cache_miss_tokens 字段，跑完 batch 后统计比例。半米这种 system prompt 重复度高的场景（"你是一个英语老师，按以下规范分析句子..."这种）实测 30-50% 是常态。
Q5Sonnet 4.6 batch 50% 折扣怎么用？延迟多少+
Anthropic Message Batches API：异步提交一批请求 → 24h 内返回 → 自动 50% 折扣[3]。Sonnet 4.6 从 $3/$15 砍到 $1.50/$7.50。组合 prompt caching（90% 节省）+ batch（50% 节省）可叠加，最高节省 95%。对半米：学员侧改作文 / 出题这些不是实时的任务，全应该走 batch（学员第二天看反馈完全 OK）。
Q6为什么不推 Kimi K2 / GLM-4.6？也很便宜+
两个都好但对半米不是首选：Kimi K2.6 强项是 SWE-Bench Pro 58.6%[24] 的代码能力，对半米数据清洗任务跟 DeepSeek 同档但 DeepSeek 更便宜（$0.14 vs Kimi $0.60-0.95）。GLM-4.6 强项 LiveCodeBench 82.8%[19]，免费版 GLM-4.7-Flash $0/M 是亮点[20]，可以做半米实验性 fallback。但中文 ESL 综合 Qwen 仍最强，价格 DeepSeek 仍最低 — 这两家排第三第四线。
Q7Doubao Seed 1.6 Flash $0.022/M 看起来更便宜，为什么不推+
字节豆包是个好选择但被低估了。$0.022 input / $0.219 output 是行业地板价[21]，TPOT 10ms 极快。问题在 (1) 火山方舟阶梯计费 32K 以下是基础价，半米 input 多在 8K-32K 区间影响小但要注意；(2) 用户量大但生态略小于 DeepSeek（GitHub / SDK 工具不如 DeepSeek 丰富）。建议：阿杰可以在 V0.1 同时充 DeepSeek $20 + 火山方舟 ¥50 做 A/B 实测，看哪个 JSON 输出更稳。
Q8为什么本地部署不推荐？M4 Max 128GB 都买了+
硬件已有的话本地是好选择，但要注意"机会成本"。半米 V0.1 50 学员阶段 API 月成本 $15-25，本地的边际收益 ≈ $20/月 但要付 (a) 占满电脑 8h batch 运行不能干其他活 (b) 模型升级运维时间 (c) 错误处理代码。更优用法：M4 Max 跑 Qwen3-Embedding 8B 做本地 embedding（API 月 $5-10 → 本地 $0 + 1h 跑完），其他任务仍走 API。这样硬件用于"算得多 + 频繁更新"的场景，发挥最大价值。
Q9SiliconFlow / OpenRouter 这类聚合商靠谱吗+
SiliconFlow 是国内 MaaS 头部[13]，DeepSeek-V3 ¥1/M input + ¥2/M output（约 $0.14/$0.28），定价跟 DeepSeek 官方非常接近，质量也对得上。优势：(1) DeepSeek 宕机时这边可能还能用 (2) 同一账号能调 Qwen / GLM / Yi 多家模型。OpenRouter 是国际版同理。建议：半米 V0.1 阶段先用 DeepSeek 官方，撞过 1-2 次中断后再注册 SiliconFlow 做 fallback。
Q10学员侧 chat 用 Haiku 4.5 够吗？还是必须 Sonnet？+
视任务复杂度：(1) 简单答疑 / 单词解释 / 文法问答 → Haiku 完全够，质量 95%+ 接近 Sonnet（艺术分析公司测[3]）；(2) 多轮对话 / 角色扮演 / 上下文长 → Sonnet 更稳，Haiku 会偶尔丢角色；(3) 作文改错 / 复杂诊断 → Sonnet 必须，Haiku 会漏错。实操：先 Haiku 跑，监控学员满意度 + 错误反馈，质量不到位的子场景升级到 Sonnet。这是渐进式优化。
Q11$20 DeepSeek 真能跑完半米 V0.1 全部？+
能。按 §11.1 表格：17 频道字幕 ($0.55) + 句子打分 ($5.60) + 视频摘要 ($0.32) + 难度评估 ($0.30) + 主题分类 ($0.40) + EGP 例句 ($1.69) + Anki 卡片 ($1.82) + 月度增量 (~$1/月 × 4 月) = ~$15。剩余 $5 余量做模型 A/B 实验。如果 cache hit 命中率超预期到 50%+ 还能省更多。
Q12我现在用 Claude Code，工作流要不要变+
基本不变。Claude Code 仍是开发主入口 — 写代码 / debug / review / 跑实验都不变。新增的只是：当任务规模 > 100 万 token 时，写个 Python 脚本（让 Claude Code 帮你写）调 DeepSeek API 跑 batch，跑完结果回到本地用 Claude Code 分析。不要切到 cline / aider，那些工具不如 Claude Code 顺手且 2026-04 后第三方工具要额外按 token 付费[3]。
