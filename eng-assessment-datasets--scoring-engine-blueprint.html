1.3 5 条核心结论

🟢 结论 #1 — 第一版别训模型：LLM 分项 rubric 评分就是 MVP，几天能跑通

2026 年的现实是：不微调、纯 prompt 的 GPT-4 级模型在 IELTS Task 2 上对官方考官已达 QWK 0.811（用 56 篇 Cambridge 官方范文测）[3]，跟官方 reliability 0.92 已经"competing"。这意味着半米第一版完全不需要 ELLIPSE 训 DeBERTa、不需要 XGBoost——那是阶段 3 的壁垒工程。MVP = 一个 FastAPI 端点 + 一个 LLM + 一份带官方 band descriptors + few-shot 锚例的 prompt。父报告 §11 把"NLP+XGBoost"列为"MVP 性价比最高"是从自建可控/可解释角度说的，本报告从最快上线角度修正：纯 LLM 上线最快，XGBoost 作阶段 3 的校准/集成层更值（两者不矛盾，是阶段问题）。

🟣 结论 #2 — 校准 > 架构，这是本报告最重要的一句话（三份姐妹报告同构印证）

同一篇作文评分研究反复证明：每个分数档只给 2 个 few-shot 例子做锚定，QWK 就提升约 26%，对单模型和多 agent 都有效[1]；另一篇 "Anchor is the key" 实测 zero-shot QWK 0.306 → six-shot 0.531[2]；Reflect-and-Revise 这种 让模型迭代精修 rubric 的方法 QWK 增益高达 +0.47[7]。mirofish 报告的 critic #1、lexile 报告的低端真人锚定、cvla 审查的"先 SetFit 微调再说架构"全是同一结论。含义：半米评分不准时，第一优先级永远是搞校准数据 + 精修 rubric + 锚例，不是堆 agent / 换旗舰模型 / 上微调。本报告第 4 章专章讲怎么做校准。

🔵 结论 #3 — 分项 rubric 评分要"先反馈后打分 + 每项单独打 + 结构化抽证据"，不是丢一篇要 4 个数字

三个落地细节都有实证：(a) 先生成反馈/解释再打分（feedback→scoring）比先打分后解释 QWK 高（.533 vs .517）——因为先打分会让模型"为已给的错分编理由"[8]；(b) 分析型 rubric 下，简洁关键词 prompt 反而比塞一大段详细描述符好（详细描述符会"contextual interference"），但每项分开打分仍优于一次要 4 个分[6]；(c) AutoSCORE 这种先让一个 agent 抽出 rubric 对齐的结构化证据（JSON）、再让另一个 agent 据此打分的"extract-then-score"模式，在 essay 集上把 QWK 从 0.251 拉到 0.344（+37%）[9]。第 7 章给可直接用的 prompt 模板。

🔴 结论 #4 — 最大的坑：离题侦测 + LOC 维度系统性偏严 + 高分作文判不准，必须人工兜底

诚实讲边界：(1) 离题最危险——同能力但答错题，分数从 3.11 掉到 2.38；完全离题掉到 1.69（d=-1.33），35% 离题样本被直接判最低分[5]，所以必须有独立的离题/语种/长度预检；(2) LLM 对 Lower-Order Concerns（语法、拼写、conventions）系统性偏严约 -1.0 分，只需 ~5 篇就能测出这个偏差[6]——这跟 cvla 审查里"GPT 给 grammar/conventions 系统性打低"完全一致，要靠 per-trait 校准修正；(3) AES 在高分段和极端样本最不准（few-shot 增益主要在中高分段）[1]。解法：用 conformal prediction 的 prediction-set 大小当置信度，多标签（不确定）的样本路由人工，可在同等错误率下少 20% 人工量[10]。第 10 章详解。

🟪 结论 #5 — 半米的护城河不在评分模型，在"中国学生真人评分锚定集 + CEFR↔CSE 双轨"

评分能力本身正在商品化（任何人调个 GPT-4 级 API 都能到 QWK 0.8）。真正别人买不到的是：中国学生作文的母语负迁移（冠词缺失、时态错乱、介词误用、主谓不一致、中式语序直译）的典型样本 + 真人评分锚定[11]。通用模型对这些母语特定难点的识别有系统盲区（lexile 报告已指出 Lexile 对中文母语者的语言特定因素完全看不到）。半米从国际学校 K12 真人评分作文起步自建这个锚定集，既是 few-shot 校准的弹药，也是阶段 3 训自有模型的合法数据，更是 Cambridge/ETS/Pearson 没有的东西。第 11 章讲怎么建。

02评分目标拆解：IELTS / TOEFL / 通用作文 rubric▾

第一件工程事不是写代码，是把每种考试的评分目标拆成可计算的 rubric。半米要评三类：IELTS / TOEFL / 平时作文。下面逐一拆，并给出"官方 rubric 公开到什么程度、能不能直接当 prompt 锚定"的实查结论。

2.1 IELTS Writing —— 4 项 rubric，官方 public 描述符可直接用

IELTS Writing 分 Task 1（学术：图表描述 / 培训：书信）和 Task 2（议论文，占比更重）。4 项分析型 rubric，每项 0-9 band（0.5 步进），最终 band 是四项均值再按规则四舍五入[12]：

rubric 项Task 2 评什么Task 1 对应权重
Task Response (TR)是否完整回应所有 part、立场是否清晰且全程一致、论点是否有相关例证支撑Task 1 叫 Task Achievement（是否覆盖关键数据/趋势、是否 overview）25%
Coherence & Cohesion (CC)逻辑推进是否顺、衔接词是否自然多样、分段是否合理同25%
Lexical Resource (LR)词汇范围与精度、是否会用 less common 词与搭配、错误是否影响理解同25%
Grammatical Range & Accuracy (GRA)句式多样性（复杂句）、错误频率与是否影响理解、标点同25%

✅ 官方 public band descriptors 是公开的、可直接当 prompt 锚定。British Council / IDP 发布了 "Writing Band Descriptors (public version)" PDF（Task 1 + Task 2，2023-05 更新）[13]，逐 band 写明每项标准。例如 Task Response：Band 9 "fully addresses all parts of the task; position consistently held and logically supported"；Band 7 "addresses all parts but some more fully than others; position clear but conclusions may be inconsistent"；Band 6 "addresses task but main ideas may be unclear/repetitive; position may be unclear"[12]。这些就是直接塞进 rubric prompt 的锚定文本（第 7 章用）。但注意 结论 #3 的 caveat：分析型评分时，把整段长描述符塞 prompt 反而可能因 "contextual interference" 降准，要测"关键词版 vs 全文版"哪个 QWK 高[6]。

2.2 TOEFL Writing —— Independent + Integrated，0-5 scale

TOEFL iBT Writing 两类任务，各自独立 rubric，均 0-5 分（整数 + ETS 内部小数）[14]：

  • Integrated Writing（综合写作）：读一段 + 听一段 lecture，写两者关系。rubric 核心是 "是否准确选出 lecture 的关键信息并与 reading 正确关联 + 组织是否清晰"——本质考信息抓取与综合，不是观点表达。新版 TOEFL 还有 "Writing for an Academic Discussion"（写论坛回帖，0-5）。
  • Independent Writing（独立写作，老版）：给观点写议论文，评 elaboration & relevance（是否充分回应）+ syntax & vocabulary（句式词汇范围）+ social/discourse conventions（格式语气）。

🔵 ETS 官方 rubric PDF 公开（ets.org 上有 toefl-ibt-writing-rubrics.pdf）[14]，可当 prompt 锚定。工程含义：Integrated 任务需要把 reading 原文 + lecture 转写一起喂进去当上下文，评分逻辑跟 IELTS 完全不同（考"抓没抓到点"而非"写得好不好"）——这是半米要单独建一个 rubric 模板的任务类型。

2.3 通用作文 —— 用 CEFR / 三维分析型 rubric 统一框架兼容

平时作文没有官方 rubric。最务实的做法是用一套统一的分析型 rubric 兼容，让所有作文都落在同一个内部坐标系，再映射到不同输出（CEFR / IELTS band / 学校 rubric）。学界已有现成可借鉴的三维分析型 rubric：

  • DREsS rubric（EFL 写作专用，2024）：Content / Organization / Language 三维，每维 1-5（0.5 步进）[15]。Content + Organization 是 Higher-Order Concerns（HOC），Language 是 Lower-Order Concern（LOC）。这套对中国学生平时作文最合适——比 IELTS 4 项更通用，又比单一 holistic 分更可教学。
  • ELLIPSE 6 维（父报告 Top 1 数据集）：cohesion / syntax / vocabulary / phraseology / grammar / conventions——粒度最细，适合做诊断式反馈，但维度太多对 prompt 评分不友好（结论 #3 的"维度越多越要分开打"）。

🎯 半米的统一框架建议：内部主用 4-6 维分析型分数（连续 0-100 或 0-9）作"母语坐标"，所有作文都打这套；输出层再用映射表转成学员想要的刻度（IELTS band / CEFR / TOEFL 0-5 / 学校百分制）。这呼应父报告 §12 的 KG mapping layer——评分和刻度解耦是关键架构决策（第 6 章展开）。HOC/LOC 分层很重要，因为 LLM 在 LOC 上系统性偏严，需要对 LOC 单独校准（第 4 章）。

3.2 holistic vs analytic 的反直觉发现（影响 prompt 设计）

🔴 一个必须知道的坑：原始 LLM 打分时，holistic（整体一个分）的 QWK（约 0.60）远高于 analytic（分项打分）的 QWK（约 0.32）[6]。在 ELLIPSE 上分析型只有 QWK 0.32，DREsS 也只有 0.41，而 ASAP holistic 能到 0.60。含义：半米要的是 IELTS 4 项分项分（analytic），但分项分天然更难准——这正是为什么校准对 analytic 尤其关键，也是为什么要每项单独打分 + per-trait 锚定 + per-trait 校准（第 4、7 章）。直接丢一篇要 4 个数字，准度会很差。

1

为什么先做这个：上线最快（天级），准度已能到 0.7-0.8，校准（锚例）就是这一阶段的全部胜负手。不训任何模型，没有 license 包袱。先把"评一项 IELTS Task 2 + 拿 50 篇真人评分算 QWK"跑通。

2

04校准是成败关键 ★（few-shot 锚定 + QWK 验证，校准>架构）▾

这是整份报告的核心章。如果阿杰只读一章，读这章。所有姐妹报告都指向同一句话：校准 > 架构。下面给可操作的校准方法。

4.1 few-shot 真人锚定 —— 怎么做（最实操）

原理：在评分 prompt 里，针对每个分数档，放进 1-2 篇真人评分过的锚定样例（anchor essay）+ 它的真人分数 + 简短理由，让模型"看着标尺打分"而不是凭空判。实测每档 2 例带来 ~26% QWK 提升，6-shot 把 ASAP QWK 从 0.306 拉到 0.531[1][2]。

✅ 锚例怎么选（实证规则）：

  • 覆盖所有分数档：每个 band（或每 0.5-1 档）至少 1-2 例，"2 per score level"是验证过的甜点[1]。不要全选中间分。
  • per-trait 各选各的：IELTS 4 项，每项要有自己的锚例集（一篇作文可能 TR 高但 GRA 低，要按维度选）。
  • 检索最相似的（进阶）：dense retrieval 选跟当前作文最相似的锚例，比随机选更准（Contriever 检索法 QWK 0.70-0.79）[21]。MVP 阶段固定锚例即可，量大了再上检索。
  • 增益主要在中高分段：few-shot 让 score-4 准度从 42.7% 升到 61.2%[2]——高分段是 AES 最难的，锚例帮最大。

4.2 rubric 迭代精修 —— Reflect-and-Revise（让模型自己改 rubric）

除了锚例，rubric 措辞本身也能校准。Reflect-and-Revise 方法：让模型在一批样例上打分→对比真人分→反思差异→改写 rubric→只在 QWK 提升时保留。10 轮迭代，ASAP 上 QWK 增益高达 +0.47，TOEFL11 +0.19；即使从一句话的简陋 rubric 起步，精修后也能超过人写的详细 rubric[7]。lexile 报告引用的 rubric 精修 QWK 增益 0.19-0.47 就是这个来源。

# Reflect-and-Revise 校准循环（伪代码，半米可直接照搬）
best_rubric, best_qwk = initial_rubric, eval_qwk(initial_rubric, val_set)
for i in range(10):
    batch = sample(train_set, n=10)                 # 取一小批真人评分样例
    preds = [llm_score(e, best_rubric) for e in batch]  # 当前 rubric 打分+理由
    discrepancies = collect(preds, human_scores)    # 对比真人分、收集差异+理由
    new_rubric = llm_refine(best_rubric, discrepancies)  # 让模型据差异改写 rubric
    new_qwk = eval_qwk(new_rubric, val_set)
    if new_qwk > best_qwk:                           # 只在变好时保留
        best_rubric, best_qwk = new_rubric, new_qwk

4.3 校准映射层 —— 把"连续分"对齐到"band"（修系统性偏差）

LLM/模型输出的连续分往往跟真人 band 有系统性偏移（尤其 LOC 偏严 ~-1.0 分）。isotonic regression（保序回归）是修这个的正确工具：拟合一个单调非降的分段函数，把模型分映射到真人分——它能灵活吃掉偏移、保留序关系、不强加线性假设[22]。每个 trait 单独拟合一条。这就是阶段 3"校准层"的核心，几十行 sklearn.isotonic.IsotonicRegression。

🔵 三层校准叠加（从便宜到工程重）：① prompt 层（few-shot 锚例 + 精修 rubric）→ 几乎免费、阶段 1 就做；② per-trait 偏移修正（对每维加一个学到的 offset/scaling）→ 阶段 2；③ isotonic/XGBoost 映射层（用真人评分集学一条映射曲线）→ 阶段 3。顺序很重要：先把便宜的 ① 做到头，再上后面的。

4.4 QWK 怎么算、目标定多少（验证标准）

QWK（Quadratic Weighted Kappa）是 AES 行业标准指标，衡量预测分与真人分的"加权一致性"（越接近 1 越好，错得越远惩罚越重，平方加权）。sklearn.metrics.cohen_kappa_score(y_true, y_pred, weights='quadratic') 一行算出。

🎯 目标值怎么定（有据，不拍脑袋）：

  • 天花板 = 真考官之间的一致性。IELTS 真考官 G 系数 0.81-0.92[4]；AES 不可能超过√(评分标签可靠度)这个理论上限——ASAP 上限 ≈0.926，ELLIPSE 仅 ≈0.816[23]。
  • "人类水平"基准：人-人 QWK 在 ASAP 是 0.754、在 ELLIPSE 只有 0.501（说明 ELLIPSE 标注本身就更"噪")[23]。现代 BERT 系统在 ASAP 已达 0.752（约等于人-人），在 ELLIPSE 达 0.538（已超过人-人）。
  • 半米可用门槛：MVP QWK ≥ 0.70 即可上线（接近单考官水平）；提稳目标 0.75-0.80；别追 0.9+，那超过了人-人一致性，往往是过拟合或测试集泄漏的信号。

4.5 验证集怎么搭

  • 最小验证集：50-100 篇真人评分的作文（IELTS 用 Cambridge 官方范文 + 已知 band；平时作文用国际学校老师评的）。QWK 在 50 篇上已能给出可用信号（IELTS T2 0.811 那篇就只用了 56 篇[3]）。
  • 校准集与验证集分开：锚例（校准）和算 QWK 的样本（验证）不能重叠，否则 QWK 虚高。conformal prediction 也要求独立 calibration set[10]。
  • 定期重标：模型版本变了、prompt 改了，都要在固定验证集上重跑 QWK（第 10 章 drift 监控）。

⚠️ 说明：下面是说明性 prompt 模板，体现第 3、4 章的实证原则（per-trait 分开打 / feedback-first / extract-then-score / few-shot 锚定 / 官方描述符）。半米要按自己的真人锚例和验证集迭代调（Reflect-and-Revise）。这不是替阿杰写完整生产代码，是给一个能照着改的骨架。

7.1 单项 rubric 评分模板（以 IELTS Task 2 · Grammatical Range & Accuracy 为例）

SYSTEM:
You are a certified IELTS examiner. Score ONLY the criterion
"Grammatical Range and Accuracy (GRA)" of the essay below.
Do NOT score other criteria. Output band 0-9 in 0.5 steps.

# Official public band descriptors for GRA (anchor your judgment):
Band 9: full range of structures used naturally and accurately;
        rare minor errors as slips only.
Band 7: good variety of complex structures; errors occur but
        rarely impede communication; frequent error-free sentences.
Band 6: mix of simple and complex structures; some errors in
        complex forms; punctuation sometimes faulty.
Band 5: limited range; complex sentences less accurate than
        simple ones; errors may cause difficulty for the reader.
# (band 8/6.5/... 略)

# Few-shot anchors (real human-rated, 2 per band — calibration):
 ...真人评分锚例全文... → GRA=7.0
   (rater note: 复杂句多但偶有时态错，不影响理解) 
 ...锚例全文... → GRA=5.0
   (rater note: 主谓不一致+冠词缺失反复出现，影响流畅) 
# ...每个 band 2 例...

USER:
PROMPT: {作文题目}
ESSAY:  {学员作文}

# 步骤（feedback-first，再打分）：
1. evidence: 引用 essay 里 3-5 处具体句子，标出复杂句/错误。
2. analysis: 对照上面描述符，这些证据落在哪个 band。
3. band: 给最终 GRA band（数字）。
返回 JSON: {"evidence":[...], "analysis":"...", "band":n.n}

🎯 这个模板焊进了 4 条实证：① 只评一项（analytic 分开打，避免一次要 4 个数字的低准度）；② 官方 public 描述符当锚（§2.1）；③ 每 band 2 个真人锚例（§4.1，~+26% QWK）；④ 先 evidence/analysis 后 band（feedback-first，QWK 0.533 vs 0.517）。记得 A/B 测：分析型评分时"精简描述符 vs 全文描述符"哪个 QWK 高（§3.2 的反直觉）。

7.2 extract-then-score 进阶模板（AutoSCORE 模式）

对长作文/复杂 rubric，先用一个 agent 把 rubric 对齐的证据抽成结构化 JSON，再用另一个 agent 据此打分，QWK 可再涨 +16~37%[9]：

# Agent A（抽证据）：
"对每条 rubric 子标准，从 essay 中抽出支持/反对证据，
 输出 JSON：{TR:{evidence:[],coverage:?}, CC:{...}, LR:{...}, GRA:{...}}"
# Agent B（打分）：
"给定 essay + 上面的结构化证据 JSON + 官方描述符 + 锚例，
 对每项给 band。" → 比直接打分更稳、更可解释

7.3 防 gaming 要在 prompt + 守门双层做（不能只靠 prompt）

🔴 重要纠偏：2026 的实测发现，现代 LLM 评分对"纯堆长度/复读段落"反而会扣分（doubling length → d=-0.24），不像老 AES 那样奖励长度[5]——这是好消息。但离题仍是大坑（d=-1.33 但需要守门层先 flag），且对"插入权威腔套话"有小幅正偏（d=0.16）。所以防 gaming = prompt 里明确"离题/答非所问直接低分" + 守门层独立做离题检测 + 自重复检测，不能指望 prompt 一层兜住。详见第 10 章。

08反馈生成（actionable）— 评分与反馈同时产出▾

半米给学员的价值不只是一个数字，是能照着改的反馈。好消息：反馈生成和评分可以同时做，而且反馈先行还能提升评分准度。

8.1 先反馈后打分 —— 一举两得（实证）

✅ 实测：feedback→scoring 比 scoring→feedback 的 QWK 更高（0.533 vs 0.517）[8]。原因很直觉：先打分会让模型"为已经给出的（可能错的）分数编理由"；先生成诊断反馈，再据反馈打分，相当于把 Chain-of-Thought 当评分的中间推理。所以反馈不是评分之后的附加品，是评分流程的一部分。第 7 章模板的"evidence→analysis→band"就是这个结构。

8.2 actionable 反馈的结构（四件套）

  • 优点（具体到句，不空泛"写得不错"）：引用做得好的地方 + 为什么好。
  • 缺点 / 失分点：对照 rubric，指出哪一项拖了后腿，引用具体证据。
  • 逐项改进建议：每个失分维度给 1-2 条可执行的改法（"把第 2 段这句被动改主动"，不是"提高语法准确度"）。
  • 同水平 / 高一档范例：给一个 band+1 的改写示例片段，让学员看到"好一点长什么样"。

8.3 评分准 vs 反馈好，是两件事（诚实边界）

⚠️ 别混淆：同一篇研究发现，虽然 joint scoring-feedback 提升了评分指标，但评分指令对反馈质量的提升很有限——反馈好不好主要看反馈那部分的 prompt 设计，不是靠"也让它打分"带出来[8]。学界另一发现：偏好优化（DPO/RLHF）的模型反馈更"像考官"、更连贯，但对精确打分不如 criterion-specific 监督[26]。含义：半米可以评分用一套严格 rubric prompt，反馈用更口语化/鼓励性的 persona prompt，两者拆开调。persona 实测有效（"Educational Researcher"/"Teacher's Assistant" persona 的 QWK 和反馈 helpfulness 都更高）[8]。

8.4 中英双语反馈（半米场景）

半米用户在国内，反馈宜中英双语：评分理由/证据用英文（贴 rubric），改进建议给中文（学生看得懂），范例给英文。用便宜模型（DeepSeek/Qwen）生成反馈，贵模型只用在评分/复评——反馈量大但容错高，评分量小但要准（成本分配见第 13 章）。

09多模型复评 + 分歧检测（mirofish 结论落地）▾

这章把 mirofish 报告的多 agent 评分铁律落地成具体工程。先重申铁律，再给实现。

🎯 mirofish 三条铁律（直接套用，别推翻）：

  1. 校准 > 架构：多 agent 是"已有好单模型之上的增强项"，不是从零起步的捷径。先把单模型 + few-shot 校准做到 QWK 0.7+，再上第二个模型[20]。
  2. 必须不同模型家族（disjoint families）：用同一个 LLM 不同 prompt 生成"一堆 agent"是伪多样性——5 个都偏低的评委投票结果还是偏低。要 Qwen + Claude + Gemini 这种真不同家族[20]。
  3. 独立打分别辩论：让 agent 互相辩论会在第一轮后放大偏差。陪审团必须各自独立打分（互不可见）再聚合[20]。

9.1 阶段 2 的最小实现：双模型复评 + 分歧检测

不要一上来三五个模型。最贴半米现状的第一步是加第二个不同家族模型独立复评：

for trait in traits:
    score_A = model_A.score(essay, trait)   # 如 Qwen3.5
    score_B = model_B.score(essay, trait)   # 如 Claude（不同家族）
    if abs(score_A - score_B) <= 0.5:        # 一致
        final[trait] = mean(score_A, score_B)
        confidence[trait] = "high"
    else:                                     # 分歧大
        final[trait] = None
        confidence[trait] = "low"
        queue_for_human_review(essay, trait, score_A, score_B)

🔵 为什么"分歧大→人工"是黄金信号：两个独立的不同家族模型都同意 → 大概率对（高置信，自动出分）；它们分歧大 → 这篇大概率是难判的边界/极端样本（AES 最不准的地方，结论 #4），正好该人工。这让人工只花在最需要的样本上，不是全量复核。

9.2 聚合方法（量大之后）

  • 中位数 / 去极值平均：3+ 模型时取中位数（抗单模型离群）。
  • PoLL（Panel of LLMs）：用一组便宜的小模型（Qwen Flash + Gemini Flash + DeepSeek Flash）组队，mirofish 报告引用 PoLL 实测比单个 GPT-4 judge 更准、还便宜 7 倍——前提是别全用旗舰[20]。这对半米要批量评几千份作文很关键（第 13 章成本）。
  • 加权：哪个模型在验证集 QWK 高就给更高权重（用真人验证集学权重）。

9.3 什么时候才值得上多模型

⚠️ 别过早：多 agent 在好单模型之上只加几个点，且主要体现在"识别弱作文"上[20]。如果半米单模型 + 校准还没到 QWK 0.7，先回去做校准（第 4 章），别用多模型掩盖校准没做好。多模型的真正价值在"分歧检测→人工兜底"这个置信度信号，不在那几个点的准度。

10可靠性验证 + AES 真实坑（诚实边界 · critic）▾

阿杰要"能直接用"，所以更要诚实讲哪里会翻车、什么情况必须人工。下面每个坑独立 callout（按严重程度配色）。

🔴 坑 #1 — 离题 / 答非所问是最危险的失分点

实测：同能力但答错 item，分数从 3.11 掉到 2.38（d=-0.62）；完全离题掉到 1.69（d=-1.33），35% 离题样本被判最低分[5]。问题是 LLM 评分时未必稳定识别离题，所以必须有独立守门层：作文 vs prompt 的语义相似度低于阈值 → 先 flag 再评。不能指望评分 prompt 自己抓离题。

🔴 坑 #2 — LLM 对语法/拼写（LOC）维度系统性偏严约 -1.0 分

多项研究一致发现：LLM 对 Lower-Order Concerns（grammar / conventions / language）系统性打低约 1.0 分（5 分制），且只需 ~5 篇就能测出这个偏差[6]。这跟 cvla 审查里"GPT 给 grammar/conventions 系统性偏低"完全一致，也跟父报告 §12.3"避免 LLM bias"呼应。解法：per-trait offset 校准（第 4.3）+ 用 LanguageTool 的客观错误计数交叉验证 LOC，别全信 LLM 的语法判断。

🟠 坑 #3 — 高分段 + 极端样本最不准

AES 在高分作文和分布极端处误差最大（few-shot 增益主要在中高分段，说明那里本来最弱）[2]。ELLIPSE 这种"标注本身就噪"的数据，人-人 QWK 才 0.501，AES 天花板 √ρ≈0.816[23]——不是模型不行，是高分段连真人都难一致。所以高分作文（如 IELTS 8+）应优先进人工复核。

🟠 坑 #4 — 模型版本漂移（drift）

调 API 评分的最大隐患：provider 静默换了模型版本，分数就漂了。必须：① 每次评分记录 model version + temperature；② 固定一个验证集，定时（每日/每周）重跑 QWK，跌破阈值告警[27]；③ 用一个更强的 reference 模型当 LLM-as-judge 抽查生产输出[27]；④ 温度设 0降低自我不一致。换模型/改 prompt 必须重测 QWK 才能上线。

🟠 坑 #5 — 过度自信 + 中国学生母语负迁移识别盲区

LLM 倾向给出看起来很确定的分数和理由，但 IELTS 真考官之间 reliability 才 0.81-0.92[4]——给学员单一确定分数是误导，应给 band + 置信区间/不确定提示。另外，通用模型对中文母语特定难点（冠词、时态、语序）的识别有系统盲区（lexile 报告指出 Lexile 完全看不到中文母语者的语言特定因素）[28]——这要靠自建中国学生锚定集补（第 11 章）。

10.1 置信度 + 人工兜底（conformal prediction）

✅ 用 prediction-set 大小当置信度信号：conformal prediction 是分布无关的包装器，给任何评分器形式化的覆盖保证（如 90%——真分落在预测集外的概率 ≤10%）[10]。机制：预测集只有 1 个标签 = 高置信（自动出分）；多个标签 = 不确定（路由人工）。实测能在同等错误率下少 20% 人工量[10]。半米的人工兜底信号 = 双模型分歧大（第 9 章） OR conformal 预测集多标签 OR 离题 flag OR 高分段，命中任一进人工队列。

10.2 什么情况必须人工兜底（清单）

  • 离题 / 语种异常 / 长度异常（守门层 flag）。
  • 双模型分歧 > 1 band。
  • conformal 预测集多标签（低置信）。
  • 高 stakes 高分段（IELTS 7.5+，错一档影响大）。
  • 学员申诉 / 抽审（定期抽 X% 全量人工复核校准）。

11中国学生场景适配 + 护城河▾

11.1 中国学生作文常见问题（AI 怎么识别）

中式英语 = 一种 interlanguage，表现为中文句法 + 英文词，由母语负迁移（L1 transfer）造成[11]。实证最高频的错误类型：

错误类型为什么（L1 负迁移）AI 识别难度怎么帮 AI
冠词 (a/an/the) 缺失或误用中文无冠词系统🟡 通用模型常忽略LanguageTool 规则 + 锚例标注
时态错乱中文无屈折变化、靠时间词🟡 中per-trait GRA 锚例覆盖
介词误用中英介词不对应🟡 中搭配检查 + 锚例
主谓一致中文无数的一致🟢 LLM 较易抓LanguageTool
中式语序 / 直译 (Chinglish)套中文句子结构、词义多义直译🔴 最难（语法对但"不地道"）必须中国学生锚例——通用模型对"语法正确但中式"识别最弱
搭配 / 多词单位错误词汇 L1 polysemy🔴 难锚例 + LR 维度专门标注

🔵 关键洞察：纯语法错误（主谓、明显时态）通用模型 + LanguageTool 能抓；但"语法正确但中式直译"（Chinglish 的核心）是通用模型最大盲区——它们用母语者数据训，对"中文母语者读着别扭"没感觉。这正是半米锚例最该覆盖的，也是护城河所在。

11.2 为什么自建中国学生锚定集是护城河

🟪 三层护城河（按价值排序）：

  1. 中国学生真人评分锚定集：国际学校 K12 学生作文 + 老师/examiner 真人评分 + L1 负迁移典型样本标注。这是 ① few-shot 校准的弹药（校准>架构，第 4 章）② 阶段 3 训自有模型的可商用合法数据（替换 NC-license 数据，解锁商用）③ 别人买不到——Cambridge/ETS/Pearson 没有中国学生数据，国内只有流利说有但不公开（父报告 §1.3 结论 #5）。
  2. CEFR ↔ CSE（中国英语能力等级量表）↔ GSE 双轨/三轨映射：国外公司不做、国内公司没评分能力。半米的输出能同时给"国际刻度 + 中国国家标准刻度"——父报告 §12.4 已列为最值钱资产之一。
  3. 中式英语诊断库：把"语法对但中式"的典型 pattern 沉淀成可复用的诊断规则 + 范例，给学员"这句中国人爱这么写，地道说法是…"的反馈——这是教学价值，也是数据飞轮。

11.3 锚定集怎么建（务实路径）

  • 起点小：先攒 50-100 篇国际学校学生作文 + 1-2 个老师真人评分（够做 MVP 校准 + 验证，呼应 lexile 报告"真人锚定 30-50 篇"）。
  • 数据飞轮：人工兜底队列（第 10 章）里老师复核过的样本，自动回流成新锚例——评得越多，锚例越丰富，校准越准。
  • 标注 L1 负迁移：每篇额外标"这里是冠词/时态/中式语序"，沉淀成中式英语诊断库。
  • 合规：自有数据 + 明确授权，从源头避开 NC-license 雷（cvla 审查的教训）。

Step 0 · 搭最小评分 API 骨架

阶段1⚠️ 0.5-1 天

做什么：FastAPI 起一个 POST /score 端点，接收 {essay, task}，内部调一个 LLM（先用 DeepSeek/Qwen 便宜的），返回一个分。统一 LLM wrapper（记 model version）。

Step 1 · IELTS Task 2 单项 rubric few-shot 评分跑通 + 50 篇算 QWK

阶段1校准是胜负手⚠️ 2-3 天

做什么：先只做 GRA 一项（第 7 章模板）：官方描述符 + 每 band 2 个真人锚例 + feedback-first。拿 50 篇 Cambridge 官方范文（已知 band）算 QWK。
产出物：单项评分 + QWK 报告。

验证标准：单项 QWK ≥ 0.65（接近就继续，差太多回去调锚例/rubric，别急着加维度）。
这步是整个项目的"是否走得通"试金石。

2

Step 2 · 扩到 4 项 rubric + 反馈生成 + 守门层

阶段1⚠️ 3-5 天

做什么：① TR/CC/LR/GRA 各一个独立 prompt（分开打，§3.2）；② 聚合成 overall band（IELTS 四舍五入规则）；③ 反馈四件套（优点/缺点/逐项改进/范例，§8）；④ 守门层：语种 + 长度 + 离题（sentence-transformers 相似度）+ 自重复检测。
产出物：完整 IELTS Task 2 评分 + 中英双语反馈 + 守门。
技术要点：评分 prompt 严格、反馈 prompt 用 persona（§8.3）；离题先 flag 再评。
验证标准：overall QWK ≥ 0.70 + 离题测试集能 flag 出 ≥90% 离题样本。
到这里 MVP 可上线给真学生用了。

Step 3 · 第二个不同家族模型复评 + 分歧检测 + 人工队列

阶段2分歧→人工⚠️ 2-3 天

做什么：加第二个不同家族模型（如阶段1用 Qwen，这里加 Claude）独立复评（§9，别辩论）。分歧 > 0.5-1 band 的 trait 路由人工队列（PG 表 + 简单后台）。
产出物：双模型 + 分歧检测 + 人工复核后台。
技术要点：两模型互不可见各自打分；老师复核结果回写当新锚例（数据飞轮起点）。
验证标准：分歧样本人工复核后，QWK 提升到 0.73-0.78；人工量 < 总量的 15-20%。

4

Step 4 · 校准层（isotonic）+ per-trait 偏移修正 + 中国学生锚定集

阶段2→3解锁商用⚠️ 1-2 周

做什么：① 攒 50-100 篇国际学校学生真人评分作文（中国学生锚定集起点，§11.3）；② per-trait offset 修 LOC 偏严（§4.3）；③ isotonic 把连续分映射到 band；④ 用自建锚例替换部分 NC-license 数据（解锁商用方向）。
产出物：校准映射层 + 中国学生锚定集 v1 + 数据飞轮（人工队列回流）。
技术要点：sklearn IsotonicRegression 每 trait 一条；锚定集标 L1 负迁移类型。
验证标准：中国学生作文上 QWK ≥ 0.75；LOC 维度偏移修正后 < 0.5 分。

5

Step 5 · 防 gaming + conformal 置信度 + drift 监控 + 多刻度输出

阶段3⚠️ 1 周

做什么：① conformal prediction 给置信度（预测集多标签→人工，§10.1）；② 防 gaming 收尾（prompt 明确离题低分 + 守门层自重复/模板检测，§7.3）；③ drift 监控（固定验证集定时跑 QWK + 记 model version，§10）；④ 多刻度 mapping（CEFR/CSE/TOEFL/学校制，§6.1 ④）。
产出物：置信度 + 监控 + 多刻度 + 防 gaming 完整版。
验证标准：gaming 测试集（堆长度/复读/套模板）不被骗高分；drift 告警跑通。

Step 6 · 扩到 TOEFL + 通用作文 + (远期) speech

阶段3+持续

做什么：复用同一评分核心，加 TOEFL（Integrated 要喂 reading+lecture，§2.2）和通用作文（DREsS 三维 rubric）的 prompt 模板 + 锚例。Speech 评分是另一条工程线（Whisper + GOP + speechocean762，父报告 §4/§12，工程最重，最后做）。
验证标准：每个新 task 独立算 QWK ≥ 0.70 才上线。

✅ 路线图心法：Step 0-2 是 MVP（约 1-2 周能上线），重点全在 Step 1 的校准；Step 3-4 提稳 + 起护城河；Step 5-6 是工程化和扩张。每步都能独立验证、独立上线，不用等全做完。如果某步 QWK 上不去，回去做校准（第 4 章），不是往后堆架构。

Q1如果只做一件事，阿杰今天该先做什么？+
Step 1：搭一个最小 FastAPI /score 端点，做 IELTS Task 2 的 GRA 一项评分——官方描述符 + 每 band 2 个真人锚例 + feedback-first，拿 50 篇 Cambridge 官方范文算 QWK。这一步验证整个项目走不走得通（目标单项 QWK ≥ 0.65），且全程不训模型、不到一周。校准（锚例）是这步的全部胜负手。
Q2第一版到底要不要训模型？+
不要。2026 的纯 prompt GPT-4 级模型在 IELTS Task 2 上对官方考官已达 QWK 0.811[3]。训 DeBERTa（QWK 0.85）是阶段 3 的壁垒工程，要大标注集 + 训练工程 + 吃 NC license。MVP = LLM + 好 prompt + 真人锚例，几天能跑通。
Q3QWK 目标定多少算"能用"？+
MVP ≥ 0.70（接近单考官水平），提稳目标 0.75-0.80。天花板是真考官之间一致性：IELTS 考官 G 系数 0.81-0.92[4]，理论上限 √(标签可靠度)（ASAP ≈0.926，ELLIPSE ≈0.816）[23]。别追 0.9+——超过人-人一致性往往是过拟合或测试集泄漏。
Q4few-shot 锚定具体怎么做？+
每个分数档放 1-2 篇真人评分过的锚例 + 真人分 + 简短理由进 prompt。覆盖所有 band（别全选中间分），per-trait 各选各的（一篇可能 TR 高 GRA 低）。实测每档 2 例 ~+26% QWK[1]，6-shot 把 ASAP 从 0.306 拉到 0.531[2]。量大后可上 dense retrieval 选最相似锚例。
Q54 项 rubric 是一个 prompt 一起打，还是分开打？+
分开打。analytic（分项）评分本身比 holistic 难（ELLIPSE analytic QWK 0.32 vs ASAP holistic 0.60）[6]，一次要 4 个数字会更差。每项独立 prompt + 各自锚例 + 先反馈后打分（feedback→scoring QWK 0.533 vs 0.517）[8]。长作文可先用一个 agent 抽结构化证据再打分（AutoSCORE，+16-37% QWK）[9]。
Q6详细的 rubric 描述符塞 prompt 里越多越好吗？+
反直觉：不一定。分析型评分时，简洁关键词 prompt 反而常比塞一大段详细描述符好（长描述符会"contextual interference"，同时引入太多约束降一致性）[6]；holistic 则相反，详细描述符有帮助。所以一定要 A/B 测"关键词版 vs 全文版"哪个 QWK 高。还可以用 Reflect-and-Revise 让模型自己精修 rubric（QWK +0.47）[7]。
Q7多模型陪审团到底要不要做？什么时候做？+
要，但不是第一步。先把单模型 + 校准做到 QWK 0.7+，再加第二个不同家族模型独立复评（mirofish 铁律：避免伪多样性 + 别辩论）。多 agent 在好单模型之上只加几个点，真正价值在"分歧检测→人工兜底"的置信度信号[20]。PoLL（一组小模型）可比单 GPT-4 更准还便宜 7 倍。
Q8学生会不会用堆长度/复读/套模板骗高分？+
2026 的好消息：现代 LLM 对纯堆长度/复读段落反而扣分（doubling length → d=-0.24）[5]，不像老 AES。但离题仍是大坑（要靠守门层独立检测），"插权威腔套话"有小幅正偏。防 gaming = prompt 明确"离题低分" + 守门层做离题/自重复/模板检测，双层兜（§7.3）。
Q9什么样的作文必须转人工？怎么自动判断？+
命中任一转人工：① 离题/语种/长度异常（守门 flag）；② 双模型分歧 > 1 band；③ conformal 预测集多标签（低置信，能在同等错误率下少 20% 人工量[10]）；④ 高分段（IELTS 7.5+）；⑤ 申诉/抽审。目标人工量 < 总量 15-20%。老师复核结果回写当新锚例 = 数据飞轮。
Q10LLM 评分有什么系统性偏差要小心？+
最确定的是 对语法/拼写/conventions（LOC）系统性偏严约 -1.0 分，只需 ~5 篇就能测出[6]（跟 cvla 审查发现一致）。还有高分段最不准、过度自信、对中文母语负迁移（尤其"语法对但中式"）有盲区。解法：per-trait offset 校准 + LanguageTool 交叉验证 LOC + 中国学生锚例。
Q11单篇评分多少钱？月度大概多少？+
单篇低到几乎可忽略：便宜模型（Qwen/DeepSeek Flash）< $0.002/篇，性价比组合 ~$0.012/篇，含旗舰复评 ~$0.07/篇[29]。月 1 万篇便宜组合 ~$30，性价比 ~$120。成本主要由量和"用不用旗舰复评"决定。策略：主评分用性价比模型，反馈用最便宜，旗舰只用在复评第二票和高 stakes 样本（§13.2）。
Q12半米的护城河到底是什么？评分模型吗？+
不是评分模型（那正在商品化，谁都能调 API 到 QWK 0.8）。护城河是 ① 中国学生真人评分锚定集（few-shot 弹药 + 可商用训练数据 + 别人买不到）；② CEFR↔CSE↔GSE 多轨映射；③ 中式英语诊断库（"语法对但中式"是通用模型最大盲区）。从国际学校 K12 真人评分起步，人工兜底队列回流成数据飞轮（§11）。
