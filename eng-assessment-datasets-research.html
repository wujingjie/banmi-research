1.3 5 大核心结论（每条独立 callout）

🔴 结论 #1 — 真正含官方 IELTS examiner 评分的 public dataset 实际上不存在

所有声称包含 "official IELTS scores" 的 Kaggle / HuggingFace 数据集，评分来源都无法独立核实。mazlumi/IELTS Writing Scored Essays（Kaggle，2023-07）— 页面只标 "Sample Essays and Scores"，不写评分人是谁[6]。KevSun/IELTS_essay_scoring HuggingFace — README 自称 "18,000 real IELTS essays with official scores"，但作者同时发的 arxiv 2406.01198 论文里写得很清楚训练数据是 ELLIPSE (6,500) + 一个未公开 IELTS 数据（14,500 train / 2,000 test）[7][8] — 而且这个 IELTS 数据并未公开发布，HuggingFace 上的同名 repo 实际是 ELLIPSE 训练的模型。真正的 IELTS 真人评分语料全部在 Cambridge Learner Corpus / IDP 内部，CLC 仅对学术合作开放，non-commercial only[9]。

🔴 结论 #2 — Kaggle / HuggingFace 上大量 IELTS 数据集疑似含 ChatGPT 生成 label，污染严重

chillies/IELTS-writing-task-2-evaluation（10,324 essays，46.7 MB）— 字段含 prompt / essay / evaluation / band。evaluation 字段格式高度模板化（Markdown 结构 + "Task Achievement: [X]" 风格），极可能是 GPT-3.5/4 生成。某些 essay 字段含明显乱码（"injkdfzbvjkkjNCJKXNVJK..."），无 license 信息，无评分人说明。chillestt/Automated-IELTS-essay-evaluation（GitHub） — 作者明确说 9,000+ samples 来自"web scraping + synthetic data generation via Gemini APIs, GPT-3.5-Turbo, and Groq"[10]。这类数据用来训练评分器等于用 LLM 自己评的"假成绩"训练新 LLM — 准度天花板就是 GPT-3.5 的水平，永远赶不上真人 examiner。

🟠 结论 #3 — 真正可商用的高质量数据集寥寥无几，主要是发音/语音类

过去 5 年学术界发布的"明星"评分数据集（ELLIPSE / PERSUADE 1.0 & 2.0 / Write & Improve / Speak & Improve / TOEFL11 / FCE / CLC）全部是 CC BY-NC-SA 或 LDC academic license。真正开商用的只有少数语音类：speechocean762（OpenSLR，CC BY 4.0，可商用，5K 句 / 250 名 L2 中文母语者）[4]、L2-ARCTIC（注册即用，27.1h，24 人）[11]、NICT JLE Corpus v4.1（CC BY-SA 3.0，1300 日本学习者 2M 词转写，可商用 + share-alike）[12]。词法类只有 CEFR-J wordlist（Tono Lab 明确允许商用）[13]。结论：半米要做商业产品，大概率需要自建评分数据，或者跟 Cambridge / Pearson / ETS 直接谈商业 license。

🟢 结论 #4 — MVP 最佳起点：ELLIPSE + ASAP++ + speechocean762 + EVP/EGP/CEFR-J + LLM 验证

对半米 K12 / IELTS 自动评分 MVP，最务实路线：(a) Writing 维度用 ELLIPSE（6 维度 trait scoring）+ ASAP++（5 维度 trait scoring）训 RoBERTa / DeBERTa 多 head 回归，能复刻 arxiv 2406.01198 论文 QWK 0.8+ 水平[8]；(b) Speaking 用 speechocean762 训 GOP / wav2vec2 phoneme-level 评分；(c) CEFR 词法语法用 EVP + EGP + CEFR-J 三层映射（已被 Text Inspector / Cathoven 验证有效）；(d) 最终输出用 GPT-4o / Claude Sonnet 4.6 / DeepSeek V4 做校验 + 解释生成（学术验证 QWK 0.6-0.8，对 IELTS Task 2 已达 0.811）[14][15]。关键：ELLIPSE NC license 在内部模型训练阶段不阻断，但模型 weights 派生品不能商用（CC BY-NC-SA viral）— 需要后期用自建数据完全替换。

🟣 结论 #5 — 中国学生机会点：本地化 CEFR 校准 + 中文母语 phoneme 模型是壁垒，缺失但最值钱

已有：ICNALE（2800 亚洲学习者，含中文）[16]、CLEC（1M 词中国学生写作）、speechocean762（250 名中文母语者英语）、Pearson GSE 已对齐 China Standards of English[17]。缺失：真正国际学校 K12 真人评分作文 + 口语数据完全空白。商业护城河：半米的真正壁垒应该是自建国际学校 K12 真人评分库（联合 1-2 个国际学校 / 老师 + 中文母语 phoneme 误差大典型样本库 + 中国课标 CSE-CEFR 双轨映射）。这个数据 Cambridge / ETS / Pearson 不会有，国内只有流利说有部分（70M 用户的中国人讲英语数据库，自称世界最大）[18]，但不公开。半米可以从国际学校开始自建。

025 个必查线索逐一核查 ★★（阿杰最想看）▾

阿杰指定的 5 个具体线索，每个单独 WebFetch / 多轮 cross-check + 给 16 维评估。核心铁律：评分来源 🟢 真实人类 / 🟡 trained rater / 🔴 AI generated / ❓ 无法核实，必须严格分类。

2.1 线索 #1 — Kaggle "IELTS Writing Scored Essays Dataset" (mazlumi)

mazlumi/ielts-writing-scored-essays-dataset 评分来源不确定 Kaggle

16 维核查结果：

  • 规模：约 1,200 essays（Kaggle 描述 "Sample Essays and Scores"），上传 2023-07-20[6]
  • 字段：essay / prompt / band（具体列名页面未展示完整），含 band score
  • Task 1/2：根据社区 notebook 推测主要是 Task 2 议论文，Task 1 较少
  • 评分来源：🔴 页面完全没说评分人是谁。上传者 mazlumi 是个人用户，无 IELTS 官方背景。推测来自网站爬取（学员自己发的范文）而非 official examiner
  • License：Kaggle 默认 license（页面未具体注明 CC0 还是其他）
  • 商用：⚠️ 风险高 — 即使 license 允许，评分来源不可证伪的数据训练商业模型存在 audit risk
  • 下载量：被多个 Kaggle notebook 使用（BERT 评分 / IELTS exam writing task results 等）[19]
  • 论文引用：未在主要 arxiv 论文中作为主数据
  • 污染风险：🔴 高 — 来源不明 + 数据小 + 时间在 ChatGPT 发布后（2023-07） + 无评分人可追溯

裁定：🟡 仅适合做 demo / sanity check，绝不作为 production 评分系统的训练主数据。如果非要用，必须人工抽样 100 条请认证 IELTS examiner 重评验证 score 真实性。

2.2 线索 #2 — HuggingFace KevSun/IELTS_essay_scoring

KevSun/IELTS_essay_scoring 实际是模型不是 IELTS 数据 HuggingFace

关键澄清：这是一个模型（RoBERTa fine-tune），不是数据集。HuggingFace 401 阻拦 WebFetch，但通过同作者的另一个 repo KevSun/Engessay_grading_ML 和 arxiv 2406.01198 论文交叉验证[7]：

  • 论文真实数据来源：ELLIPSE Corpus（6,500 essays）+ 一个未公开的 IELTS 数据（14,500 train / 2,000 test）。论文写道 IELTS 数据"sourced from the International English Language Testing System"，但数据本身并未 release
  • 评分维度：ELLIPSE 是 6 维度（cohesion / syntax / vocabulary / phraseology / grammar / conventions），IELTS 论文部分是 5 维度（task achievement / coherence&cohesion / vocab / grammar / overall）
  • 评分来源：🟢 ELLIPSE 是 trained human raters（state-wide standardized testing）。IELTS 数据 — 论文笼统说 "real-world scoring criteria"，无法独立核实是否官方 examiner
  • license：模型 MIT，但训练数据 ELLIPSE 实际是 CC BY-NC-SA 4.0 — viral copyleft，模型可能也受 license 传染（业界尚有争议）
  • 下载量：模型 191 次/月（不高）
  • 论文准度：overall QWK 0.8+（在论文自己的 test set 上）

裁定：🟡 "18,000 IELTS essays with official scores" 是误导性宣传。实际可用的部分只有 ELLIPSE 这 6,500 篇（且 NC license）。IELTS 那部分数据不公开，半米拿不到。不要凭网上截图相信 KevSun/IELTS_essay_scoring 是 IELTS 数据集。

2.3 线索 #3 — GitHub chillestt/Automated-IELTS-essay-evaluation

chillestt/Automated-IELTS-essay-evaluation 合成数据 + AI 生成 label GitHub

16 维核查（GitHub README 直接核实）：

  • 规模：9,000+ samples（SFT 数据集）+ 768 samples（DPO preference dataset）— 9000+ 数字属实
  • 数据来源：作者明确写 "web scraping of online IELTS essays + synthetic data generation via Gemini APIs, GPT-3.5-Turbo, and Groq"[10]
  • 评分来源：🔴 AI 生成（pseudo labels）。作者说 essays 来自 "real IELTS tests 2022/2023"，但没说 scores 是不是真人给的，结合"synthetic generation"语境，大概率是 LLM 自己给的伪标签
  • 模型架构：Mistral-7b / Llama-2-7b / Gemma-7b 用 QLoRA + DPO fine-tune
  • license：未指定（License 字段为空）
  • star 数：9 stars（小项目，社区影响力低）
  • 准度：README 没给具体 metric（QWK / accuracy 全无）— 严重 red flag
  • 数据下载：通过 HuggingFace 公开（chillies/IELTS-fighter 系列）
  • 污染风险：🔴 极高 — synthetic data + 无 metric + 无 license + 个人项目

裁定：🔴 不要用。典型的 "LLM 生成自评数据" 闭环陷阱 — 用 GPT-3.5/Gemini 给 essay 评分，再拿这些分训新模型，准度天花板就是 GPT-3.5 本身（QWK 大约 0.6-0.7）[20]。商业系统用这种数据训出来的模型可能系统性偏低（LOC 维度如 Grammar / Conventions 被 LLM 系统性打低分）[21]。

2.5 线索 #5 — arXiv 2406.01198 "Automatic Essay Multi-dimensional Scoring"

arXiv:2406.01198 (Sun & Wang, 2024) 部分数据未公开 arXiv

16 维核查（论文全文 + HF 模型 cross-check）：

  • 用了哪些 dataset：ELLIPSE（6 维度）+ IELTS（5 维度）双数据集
  • 规模：IELTS 部分 train 14,500 / test 2,000；ELLIPSE 全集 ~6,500
  • 评分来源：🟢 ELLIPSE 是 trained human raters（state-wide standardized annual testing，两位 rater 评每篇）[1]；🟡 IELTS 部分论文说 "real-world scoring criteria used in high-stakes language assessments" — 这话含糊，没明说 examiner ID，但作者机构 Tübingen 大学，不太可能拿到 official IELTS examiner 数据，很可能是从某 IELTS 培训网站爬取的学员真人评分
  • 模型架构：Ro-AEMS (RoBERTa) + Distil-AEMS (DistilBERT)，contrastive learning + regression head
  • 准度：overall QWK > 0.8（自报 in-domain test）— 论文用了 precision / F1 / QWK 三 metric
  • 数据公开：ELLIPSE 是 freely available（GitHub），IELTS 部分论文没明确说 release
  • 模型公开：huggingface.co/Kevintu/Engessay_grading_ML（仅 ELLIPSE 训练版）
  • 可复现：ELLIPSE 部分可复现，IELTS 部分不可复现（数据不公开）
  • 论文 limitations：reliance on smaller ASAP datasets historically, BERT 而非 specialized classifier

裁定：🟢 论文方法学有效，QWK 0.8+ 是真实可靠数字（多源验证）。但 IELTS 部分数据不公开 + 来源含糊是个洞。半米可以复刻论文方法（ELLIPSE 部分），IELTS 部分必须自己解决数据问题。

5 必查线索总结：

  • 线索 #1 (Kaggle mazlumi) — 🟡 评分来源不确定，仅做 demo
  • 线索 #2 (HF KevSun) — 🟡 实际是 ELLIPSE 训练的模型，"18K IELTS official" 是误导性宣传
  • 线索 #3 (chillestt GitHub) — 🔴 合成数据 + AI label，不要用
  • 线索 #4 (chillies HF 10K) — 🔴 同上，仅 prompt 池可用
  • 线索 #5 (arxiv 2406.01198) — 🟢 方法有效 + ELLIPSE 可复现，IELTS 部分不公开

给阿杰：5 个线索里只有 ELLIPSE 是真金。其他 4 个是不同程度的"看起来很多其实质量存疑"的迷雾。这就是为什么本报告 §10 Top 10 把 ELLIPSE 排第 1。

03IELTS Writing 数据集大全（10+ 候选）▾

本章覆盖专门的 IELTS 写作语料，以及虽不是 IELTS 但常被替代使用的 EFL 写作语料。结论先讲：真正含官方 IELTS examiner 评分的免费可下载数据集不存在。Cambridge / IDP 官方持有的全部需要商业 license。

3.1 真 IELTS 写作（官方持有，非公开）

Cambridge Learner Corpus (CLC) 仅学术

规模：180,000+ 学员 / 200 国家 / 138 第一语言 / 涵盖 A1-C2 + Cambridge English / CELS / IELTS / ESOL Skills for Life / Business / Legal[9]。评分来源：🟢 Cambridge ESOL examiners 真人。license：non-exclusive non-transferable，research and educational purposes only，明确禁止商用。access：需要跟 Cambridge English Language Assessment 直接合作。关键：这是世界上最权威的 ESL writing 评分语料，但半米不可能拿到商用授权。

CLC FCE Dataset (Yannakoudakis 2011) 仅学术

规模：1,244 exam scripts / ~531K words，来自 2000-2001 年 Cambridge ESOL FCE 考试真实考生[22]。含 original text + marks + error annotation + L1 + age。评分：🟢 真 Cambridge examiner。License：Cambridge non-commercial research only。access：ilexir.co.uk 注册后下载。引用：被 BEA-2019 shared task 等数百篇论文使用，事实上的 GEC + AES 学术 benchmark。

Cambridge English Write & Improve Corpus 2024 仅学术

规模：5,050 user-prompt sets / 766 L2 学员 / 762K word tokens / 23K essays（含所有版本）[2]。评分：🟢 certified though non-operational examiners 给 CEFR 标签。license：non-exclusive non-transferable，研究教育 only，明确禁止商用（"used for or as part of a product or service which is sold..."）。access：Cambridge ELiT 网站申请 + CAPTCHA。含：grammatical error annotation + 原始/修改版双轨。

3.3 EFL 写作（非 IELTS 但相关）

ELLIPSE Corpus (Crossley et al. 2023) ⭐ Top 1

规模：~6,500 ELL essays (final corpus) / 来自 grade 8-12 美国 ELL 学生 / state-wide standardized testing[1]。29 个 prompts，每篇 2 位 trained human rater 评。评分：🟢 trained human raters。6 维度 + overall：cohesion / syntax / vocabulary / phraseology / grammar / conventions。含 demographic：economic status / gender / grade level / race/ethnicity。License：CC BY-NC-SA 4.0（GitHub README 明确）— 禁止商用。access：GitHub scrosseye/ELLIPSE-Corpus 直接 clone。引用：被 Kaggle Feedback Prize 3 使用（3,911 essays），被 arxiv 2406.01198 等数十篇论文使用。关键：方法学上最严谨的 public 资源，但 NC license 是商用最大障碍。

PERSUADE 2.0 (Crossley et al. 2024)

规模：25,996 argumentative essays / 6-12 grade US 学生 / 15 prompts / independent + source-based writing[3]。评分：🟢 trained raters，含 holistic + argumentation effectiveness rubric。License：CC BY-NC-SA 4.0。access：Zenodo + Kaggle 公开。引用：被引用近 100 次，下载数千次。Kaggle 比赛：Feedback Prize 1/2 用 PERSUADE 1.0（12,871 essays），ASAP 2.0 比赛 2024 用 PERSUADE 2.0 子集。

ASAP (Kaggle 2012) + ASAP++

ASAP：Hewlett Foundation 2012 比赛 / 8 prompts / ~12,900 essays / 7-10 grade / 150-550 词/篇[23]。评分：🟢 human expert graders（QWK 评估）。License：Kaggle 比赛默认（事实上学术界视作公共数据）。ASAP++：1,783 essays / 5 trait scores (content / organization / style / fluency / vocabulary)[24]。注意：ASAP 不是 ESL，是 US K12 母语 essay，所以"评 ESL"会有 domain gap。用法：仍是 AES 学术 benchmark 标杆，迁移用作 baseline 训练完全可行。

ASAP 2.0 (Crossley et al. 2024)

规模：24,278 source-based persuasive essays / 6/8/9/10 grade / 7 prompts / SAT 1-6 量表[25]。2024 Kaggle 比赛主数据。评分：🟢 trained。license：开源（GitHub scrosseye/ASAP_2.0）— 但 PERSUADE 衍生品默认继承 NC？需要细看 LICENSE 文件。用法：long context AES / source-based writing 评估的 SOTA benchmark。

EFCAMDAT (EF + Cambridge)

规模：2nd release 1,180,310 texts / 174,743 学习者 / EF Online School 16 个 proficiency 档对齐 CEFR[26]。评分：🟡 由 EF 教学体系自动评级（不是单独 trained rater 评分），不严谨，但量级大。cleaned 版（Itamar Shatz）406,062 句段。license：academic only / Google Drive 申请。UniversalCEFR 也含 efcamdat-cleaned。用法：大规模 CEFR 预训练数据，不适合作 trait scoring 监督主信号，但适合作 CEFR 6 档分类预训练 + 数据增强。

Lang-8 / NUCLE

Lang-8：在线 peer correction 平台数据，无 proficiency 标签，主要用于 GEC[27]。NUCLE：1,400 篇 NUS 亚洲本科生 essay，专业英语教师做语法纠错。用法：GEC 训练（语法自动纠错），不适合做总体评分。但 GEC 输出可作为 essay 评分系统的 grammar feature 输入。

ICNALE (Asian Learners)

规模：2,800 学习者 / 10 亚洲国家（含中国大陆 / 台湾 / 香港）/ 2.5M 词议论文 + spoken dialogue[16]。CEFR 分档：A2 / B1_1 / B1_2 / B2+。评分：🟢 通过 VST 词汇测验 + TOEFL/TOEIC 自报分数 + 控制写作条件，非每篇人工评分但分档可信。access：language.sakura.ne.jp/icnale/。用法：对中国学生最相关的 public 学习者语料，可作 CEFR 分类训练。

CLEC (Chinese Learner English Corpus)

规模：1,000,000 词 / 中学 + 大学非英语 + 英语专业学生 / 5 子库（ST2-ST6）按 proficiency 分[28]。评分：🟡 子库分级而非单篇评分。access：BFSU + Guangdong Foreign Studies / 需联系机构。用法：中文母语英语学习者权威语料，但分级粗糙，做 CEFR 6 档预训练可。

Feedback Prize ELL (Kaggle 2022)

规模：3,911 essays / 8-12 grade ELL / 6 维度评分（同 ELLIPSE）[29]。这是 ELLIPSE 的 Kaggle 比赛版子集。评分：🟢 2 位 normed human raters。license：competition rules（衍生模型商用受限）。winning solution：DeBERTa + adversarial weights perturbation + metric-specific attention pooling，QWK 0.8+。已被 Google Gemini 等采用。

DREsS (Yoo et al. 2024) — Rubric EFL

规模：48.9K samples / DREsS_New (2.3K real EFL undergrad / 英语教育专家评) + DREsS_Std + DREsS_CASE (40.1K synthetic augmentation)[30]。评分：🟢 English education experts。3 rubrics：content / organization / language，1-5 scale 0.5 step。access：haneul-yoo.github.io/dress / ACL 2025 long paper。用法：rubric-based AES on EFL writing，比较新（2024）+ 比较小心做了 augmentation 分离。

04IELTS Speaking 数据集大全（5+ 候选 + 为啥少）▾

4.1 为什么高质量 Speaking dataset 极难获取

3 大结构性障碍：

  1. NDA + 隐私：考生口音 / 声纹 / 内容可识别身份，GDPR / 个人信息保护法限制 redistribute
  2. IP：speaking prompt 本身是 IELTS / TOEFL / DET 的核心知识产权，泄漏会影响 future 考试 fairness
  3. 标注成本：单条 30s-2min 语音，5 个 expert 各维度评要 10+ 分钟，1 万条 ≈ 8000 人时

结果：真正 IELTS / TOEFL speaking 公开数据集几乎不存在。剩下的全是非 IELTS 的 L2 学习者发音 / 整体口语数据。

07WIDA + DET + AES + ASR 行业研究▾

7.1 WIDA ACCESS (美国 K12 ELL 标准)

WIDA ACCESS：美国 K-12 ELL 学生年度英语水平测试，覆盖 Listening / Reading / Speaking / Writing 4 域[50]。结构：ACCESS Online (1-12 grade computer adaptive) + Alternate ACCESS (有 cognitive disability)。access：测试材料只在 WIDA Secure Portal 给会员州。没有公开 corpus。用法：作为评估 rubric / proficiency level descriptor 参考，半米的 K12 国际学校场景跟 WIDA 高度类似（ELL K12），rubric 可借鉴。

7.3 AES 学术 SOTA 2024-2025 概览

主流模型（按 chronology）[52]：

  • BERT baseline：QWK 0.79 / F1 0.97（vs LR baseline 0.30 / 0.91）
  • Electra-small / Mobile-BERT：QWK ≈ 0.82 / < 25M 参数（边缘部署友好）
  • DeBERTa-v3 + AWP + Metric-specific AttentionPool：Feedback Prize ELL winner，QWK 0.85+[53]
  • SBERT + LSTM + Attention：sentence-level 替代 token-level，长文本好
  • Mamba / TransGAT：linear complexity / GNN for multi-dim AES[54]
  • LLM (GPT-4 / Claude / Gemini)：zero-shot QWK 0.6-0.8 / fine-tune QWK 0.7-0.85 / 对 IELTS Task 2 QWK 0.811[14]
  • Hybrid LLM + linguistic feature：DeBERTa + 14 textstat + LSTM fusion，最稳[55]

7.4 ASR for L2 (语音识别)

  • Whisper：OpenAI / 多语言强 / 但对儿童 SSD 50% PER[56] / L2 spontaneous 18.3% WER（fine-tune 后 10.26%）
  • wav2vec2：Facebook / phoneme-level MDD SOTA / GOP 算法基础[37]
  • Azure Speech SDK：commercial / 32 语言 / accuracy + fluency + completeness + prosody + topic 7 维度 / 短音频 ≤ 30s[38]
  • OpenAI Realtime / Gemini Live：interactive speaking practice 但不专门评分

08真人 vs AI 评分污染甄别 ★（关键警示章节）▾

核心问题：很多 Kaggle / HuggingFace "IELTS 评分数据集" 实际是 ChatGPT 套壳给出的伪标签。用这种数据训出来的模型 = 学了 GPT-3.5 的局限性，商业系统准度天花板被锁死。

8.1 5 个污染信号（如何识别）

信号 #1：评分人未注明 — 数据集 README / dataset card 没说"评分人是谁 / 几位 rater / 评分流程"。真数据集（ELLIPSE / PERSUADE / Write&Improve / Speak&Improve）都明确写 "2 trained human raters" / "certified examiners"。没写就是没有。

信号 #2：feedback 格式高度模板化 — evaluation / feedback 字段呈 "Task Achievement: [X] - 解释" 的 Markdown 标准化模板。真人不会写出这么规整的标准报告。GPT 一秒 1 篇出来都是这个格式。chillies HF dataset 就是典型。

信号 #3：分数过度均匀分布在 0.5 步长 — 比如 4.5 / 5.0 / 5.5 / 6.0 / 6.5 全有，且每档样本数差不多平均。真 IELTS 考生分布是正态偏右，5.5-6.5 占大多数，< 4.5 和 > 8.0 极少。过度均匀 = 合成数据 / pseudo label。

信号 #4：上传者是个人 / 上传日期在 2023 年 ChatGPT 发布之后 — 2022 年底 ChatGPT 火之后，Kaggle / HF 上"自动评分数据集"数量爆炸。一个个人账号 (@chillies, @KevSun, @123Harr, ...) 在几个月内发了几个 10K 量级"评分数据集"，99% 是 GPT 跑出来的。

信号 #5：缺乏 inter-rater reliability 报告 — 真评分数据集会报告 Cohen's kappa / QWK 之间 raters 的一致性（0.7+ 才算 acceptable）。没报 IRR = 没真人 rater 评分，单一 LLM 评分自然 IRR = 1.0 不需要报。

8.2 业界已知问题

LLM scoring bias 学术报告[21]：

  • LLM 对 holistic score 有 QWK ≈ 0.6 moderate agreement
  • 但对 analytic trait scoring 有系统性 negative bias on LOC (Lower-Order Concerns) traits，主要是 Grammar / Conventions 维度
  • LLM 倾向把 grammar 评得比人更严厉
  • 2025 综述 65 篇 LLM-human agreement 论文：moderate to good agreement 0.30-0.80[58]

  5. KG：根据 task / 学员目标 (IELTS / CSE / 国际学校) 选择对应 rubric library
  6. Assessment Core：3 个 scorer 并行 → ensemble 投票
  7. Mapping：内部 0-1 score → IELTS 9 档 + CEFR + GSE + CSE 多 axis 输出
  8. LLM feedback：用 GPT-4o / Claude 拿 raw scores + essay → 生成自然语言反馈

12.3 哪些部分最难

3 个最难的：

  1. Speech 评分 pipeline（无现成 SDK 替代）— Whisper L2 fine-tune + GOP 算法 + speechocean762 训练 + 多 L1 适配。需要工程 + 数据双重投入
  2. Knowledge Graph 构建 — CEFR↔GSE↔CSE↔Lexile 多 axis 映射没现成的，需要自建并维护。Rubric library 每个 task 都要写一遍
  3. 避免 LLM bias — GPT-4 在 grammar / conventions 评分系统性偏低 — 需要做 calibration（reference 答案多源 anchor + scaling）

12.4 哪些部分最值钱（壁垒）

3 个最值钱的：

  1. CEFR ↔ CSE ↔ GSE 三轨映射表 + 中国 K12 国际学校 rubric 本地化 — 国外公司不会做，国内公司没数据
  2. 自建中国学生真人评分库（1000-5000 篇学生作品 + 国际学校老师评 + IELTS examiner 校准）— 这是商业模型训练的合法数据
  3. Rubric reverse engineering library — 给一段学员写作，反查 IELTS / TOEFL / 国际学校期末 / GAOKAO 多种 rubric 下的分数预测能力

17FAQ 12 条▾

Q1为什么不能直接用 GPT-4 给学员评分就完事了？＋

可以但有 3 个问题：1) 成本 — 单次评分 ~$0.01-0.05，1000 学员每天评一次月成本 $300-1500；2) 系统性 bias — GPT-4 对 grammar / conventions 系统性偏低（学术验证）[21]；3) 不可解释 — 给学员反馈"为什么是 6.5 不是 7.0"很难追溯到 rubric 哪条。正确路径：GPT-4 作 LLM verifier + 解释生成，主评由 fine-tune 模型 + XGBoost ensemble 做。

Q2真的有"真人 IELTS examiner 评分"的公开数据集吗？＋

基本上没有。Cambridge Learner Corpus (CLC) 含 IELTS exam scripts，但 non-commercial only + 需要跟 Cambridge English Assessment 合作。CLC FCE Dataset 是 1244 篇 FCE 真考（非 IELTS），可学术下载但仍 NC。所有 Kaggle/HF 上自称"IELTS official scores"的都无法独立核实。结论：商业半米要做 IELTS 评分，要么走 Cambridge 商业 license，要么自建 — 没有 free lunch。

Q3用 ELLIPSE 训的模型能商业上线吗？＋

这是法律灰色地带。CC BY-NC-SA 4.0 的 "NC" 条款明确禁止商业用途。"用 NC 数据训出的模型 weights 是不是派生作品" 业界尚无定论 — 保守解释是受传染。建议：内部 R&D 用 ELLIPSE 跑通 baseline；商业产品上线时用自建 + 可商用数据完全替换并重训。或者跟 Crossley lab 联系商业 license。

Q4speechocean762 250 名都是中文母语，这是不是 cherry-pick？＋

不是 cherry-pick，是对半米最大的 stroke of luck。speechocean762 是 SpeechOcean 公司（中国语音数据供应商）发布在 OpenSLR 的，专门收集了 250 名中文母语 L2 英语学习者（125 成人 + 125 儿童），5 位 expert 多粒度标注。CC BY 4.0 可完全商用。对中国学生发音评分场景这是金矿。

Q5XGBoost feature 路线已经过时了吗？现在都用 LLM？＋

不过时 — Hybrid LLM + linguistic feature 是 SOTA[55]。XGBoost on textstat / lexical / syntactic features 的优势在 MVP 阶段无可替代：训练快（分钟级）/ 推理便宜（毫秒级）/ feature importance 可解释 / 低 hallucination。SOTA 系统是 DeBERTa + textstat + XGBoost ensemble。半米 banmi-cvla 已经在这条路上。

Q6Speak & Improve Corpus 2025 这么新，能用吗？＋

能用但有限制。规模：315h L2 English 口语 / Cambridge 评分 / A2-C1 / 含 ASR / SLA / SGEC / SGECF 4 任务。license：non-commercial only。用法：在 Speak & Improve Challenge 2025 框架内提交方案，作内部 R&D；商业产品训练数据必须替换。这跟 ELLIPSE / Write & Improve 是一个套路 — Cambridge 把高质量评分数据放出来，但只允许学术研究。

Q7流利说 70M 中文用户讲英语数据，半米能合作吗？＋

商业上不太可能。流利说这个数据是核心壁垒，不会授权给同业。但学术合作 + 部分匿名化数据合作可能。替代：半米可以从国际学校自建数据切入，规模虽小但领域 fit 更好（国际学校 vs 流利说的成人 ESL 自学者完全不同 segment）。

Q8CSE 中国国家英语标准跟 CEFR 怎么映射？＋

CSE 9 档对应 CEFR 6 档的大致映射（Pearson / British Council 学术研究）：CSE 1-2 ≈ Pre-A1 / A1；CSE 3-4 ≈ A2；CSE 5-6 ≈ B1；CSE 7 ≈ B2；CSE 8 ≈ C1；CSE 9 ≈ C2。但是 CSE 含 interpretation + translation 模块（CEFR 无），不完全对齐。商业产品做映射展示是合规的、有用的、有差异化的功能。

Q9Lexile 跟 CEFR 怎么对齐？＋

MetaMetrics 2018 报告 — Lexile-CEFR alignment 72% 一致性，基于 9 个 CEFR benchmarking studies / 34,477 学生[62]。Lexile 是 reading scale 不是 writing/speaking，所以只对应 receptive skills 一半。Lexile 200L 约 ≈ A1；500L ≈ A2；800L ≈ B1；1100L ≈ B2；1400L ≈ C1。半米 KG 可以做这个 cross-walk 表给学员看。

Q10Pigai (批改网) 国内已经做得很好了，半米还有机会吗？＋

Pigai 偏向 CET-4/6/大学英语应试场景，1000+ 高校 ToB 渠道。半米差异化：1) K12 国际学校 / 双语学校（Pigai 没覆盖）；2) IELTS / TOEFL / SAT 出国考试（Pigai 不专门）；3) ToC 家长 + 学生 app（Pigai 是机构卖给学校），不同 segment。还有 4) AI native experience — Pigai 192 维 corpus 比对是 2010 年代技术，半米可以做 LLM + feedback + multimodal。

Q11自建 1000 篇真人评分作文要多少钱？＋

认证 IELTS examiner 评一篇 essay 大约 $5-15（视市场和资历）。1000 篇 × 2 位 rater (IRR 要求) = 2000 评分次数 × $10 = $20,000。加上学生写作 incentive ($5/篇 × 1000 = $5,000) 总成本 $25,000-30,000。分批做：先 200 篇 cross-check，跑通流程再扩到 1000。1 年累计可到 5000 篇 + 这是合法的商业训练数据。

Q12最重要的 1 步是什么？＋

本周下载并跑通 ELLIPSE 数据 + 复刻 arxiv 2406.01198 RoBERTa baseline。这是验证半米团队能不能复现学术 SOTA 的最小可执行步骤。如果 1 周能跑出 6 维 trait scoring QWK 0.7+，证明数据 + 工程 + 模型链路通了，可以往下加 speechocean762 / XGBoost ensemble / LLM feedback。如果跑不出来，先解决数据预处理 + RoBERTa fine-tune 工程问题，再谈 Assessment Engine 架构。
