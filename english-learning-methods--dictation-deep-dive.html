01摘要 · 3 条核心结论▼

一句话：Dictation 不是 1970s 的"机械训练"标签那样简单。Cai 2013[1]、Kuo 2010[2]、Yu/Boers/Tremblay 2025[3] 系列实证证明 partial dictation 在 confirmatory factor analysis 上跟 higher-order listening 测的是同一个 latent construct，dictogloss 还能在词汇 + 语法两端起效。半米的视频例句库 + CEFR 分级数据 → 做听写是零迁移成本的下一步功能。

🎯 3 条核心结论

结论 #1 Partial / Cloze 听写测的不是"机械拼写"，而是 higher-order listening
Cai 2013 在 367 名中国大学 EFL 学习者上做 confirmatory factor analysis，bi-factor model 最佳拟合，证明 partial dictation 跟 gap-filling、constructed response 同测一个 latent listening competence[1]。这从根上推翻了 Heaton 1975 / Davies 1977 "dictation 太 imprecise 测不到高阶能力"的批评[10]。对半米的意义：cloze 听写不是低档练习，是 B1+ 学员的核心训练模式。
结论 #2 4 种类型按 CEFR 分配，半米的 V0.1 应从 word-level cloze 起步
句子级（A2-C2 全档）/ 词级（A1-A2）/ 段落级（B2-C2）/ Cloze 挖空（A2-C1）[11]。半米首批用户 A2-B1 居多，用现成 6 例句视频做"字幕显示 + 挖目标词"的 cloze 模式，工程量 1-2 天可落地，跟"6 例句"标准无缝接入 — 这就是 V0.1。再叠 V0.2 句级、V0.3 段级、V1.0 dictogloss 形成 4 阶梯。
结论 #3 半米对比竞品的 4 大差异化优势
跟 Lyrics Training（歌词挖空 / 全球 10M+ 用户）[5]、不背单词（中国 50M+ 注册用户 / 听写模式）[12]、扇贝听力（120K+ 真实材料 / 句级精听）[13]、DET Listen-and-Type（高利害考试）[9] 比，半米的差异化是：(1) 词汇 CEFR 等级联动出题（不是孤立 audio）；(2) 真实视频例句（不是 TTS 合成 / 不是歌词 — 跟 narrow listening 学派对齐）；(3) 跟读 + 听写 + AI 对话四件套联动（不是单点功能）；(4) UGC 错题反哺（学员👎过的句子优先出题）。

🚀 给阿杰的直接结论

半米 dictation 模块 V0.1-V1.0 路线：

  1. V0.1（1-2 天）：词级 cloze。复用现成 6 例句 + 字幕 timestamp + 字符匹配评分（Levenshtein）。本周末可上。
  2. V0.2（+1 天）：扩到 1-3 词的句级挖空 + 重听控制（YouTube iframe playbackRate=0.75）[14]。
  3. V0.3（+2-3 天）：段落级听写（30-60s 多句拼接 + working memory 难度）。
  4. V1.0（+3-5 天）：Dictogloss 重建听写 + GPT-4o-mini 评分（Wajnryb 1990 原型 + Yu/Boers 2025 实证[3][15]）。

合计 7-11 天覆盖从 A1 单词到 C1 dictogloss 全谱系，跟 Shadowing 模块（参见姐妹子报告）形成"听·说"闭环。

02学术研究脉络 · 1970s 过气 → 2000s 复兴▼

Dictation 在 SLA 学界经历了三个阶段：1960s-1970s 鼎盛期 → 1975-1985 批评期 → 1990s-至今复兴期。下面按时间线展开。

2.1 1961-1971 起源期 · Sawyer / Lado / Oller 三驾马车

📜 Oller 1971 "Dictation as a Device for Testing Foreign Language Proficiency" 奠基
English Language Teaching, 25, 254-259[16]

Oller 1971 是公认 dictation 进入主流测试理论的奠基论文。他论证 dictation 不是"机械听写"，而是激活学习者internalized grammar of expectancy：学员必须 (1) 区分音素单元；(2) 决定词边界；(3) 解出能成立的词序；(4) 翻译为 graphemic representation[16]。这四步同时调用音系、词汇、语法、语用 — 是 integrative test 的范式标本。

跟随的 Oller 1979 Language Tests at School: A Pragmatic Approach[17] 把整个 integrative testing 派别系统化。学界还有 Sawyer & Silver 1961/1972[18] 早期实证 + Lado 1961 测试理论基础[19]。

🔍 关键数据点：Oller & Streiff 1975 + Oller & Conrad 1971 给出 cloze/dictation 跟 TOEFL 总分的相关系数 .69-.89[4]。Irvine/Atai/Oller 1974 拆细：dictation vs TOEFL Listening r=.69，vs Structure r=.63，vs Vocabulary r=.47，vs Reading r=.53，vs Writing r=.52[4]。结论：dictation 跟 listening 子分关联最紧，但跟其他子分都显著相关 — 即 integrative 性质成立。

2.2 1975-1985 批评期 · Heaton / Davies / discrete-point 学派反扑

Oller 风头过盛后，1975-1985 的批评期开始。代表人物：

  • Heaton 1975：dictation 不是单技能测量工具，因为它同时测了太多东西 — 既测拼写、又测听辨、又测语法、又测词汇 — 这反而是 construct validity 的问题，你说不清它测的是哪个能力[10]
  • Davies 1977：dictation 作为测试方法imprecise，没办法 isolate 出特定能力[10]
  • discrete-point vs integrative 大论战：1976-1980s 学界 split 成两派 — discrete-point 派要求每题测一个独立 micro-skill（典型如 multiple choice 语法题）；integrative 派认为语言是 unitary competence，应该用 cloze / dictation 这种综合任务测[20]

⚠️ 历史误读：很多 ELT 教师以为 "dictation 1970s 后过气了" — 其实是被1980-1990s communicative language teaching (CLT) 浪潮挤出聚光灯，因为 CLT 主推 task-based 真实场景，而 dictation 看起来太"非沟通"。但学术上从未真正被证伪。Buck 2001[21] 在 Assessing Listening 里明确"defends the plausibility of dictation as an integrative test"。

2.3 1990 转折 · Wajnryb 提出 dictogloss

🔄 Wajnryb 1990 Grammar Dictation — 用 dictation 教 grammar 范式重塑
Cambridge University Press[15]

澳大利亚教师 Ruth Wajnryb 1990 出版 Grammar Dictation，提出 dictogloss（"听写重建"）—— 跟传统 dictation 关键差异：学员不立刻写下来，而是听原速 2 遍 → 只做关键词笔记 → 小组协作重建全文 → 跟原文对比[15][22]。

4 步原型：(1) preparation 预热 + 主题词汇；(2) dictation 原速读两遍 + 学员记关键词；(3) reconstruction 小组重建；(4) analysis & correction 跟原文对比 + 师生分析[22]。核心创新：从 input-only 翻到 output-friendly — 学员被迫调用 Swain pushed output。

2.4 2001-2013 复兴期 · Buck / Cai / Kuo / Prince

从 Buck 2001 Assessing Listening[21] 起到 Cai 2013[1]，dictation 重新回到 SLA 主流：

2.5 2016-2025 现代实证 · Hamada / Yu / AI-driven dictation

🟢 最新 5 年实证（高质量）：

  • Hamada 2016：shadowing 的姐妹研究，证明 dictation + shadowing 联动对 bottom-up decoding 增益最大[26]。半米的"听写 + 跟读"组合直接对应这个证据。
  • Yu, Boers, Tremblay 2025（Language Teaching Research Vol 29 Issue 6）[3]：142 名中国 EFL 学员准实验，对比 dictation vs dictogloss vs comprehension questions。结果：(1) dictation 和 dictogloss 在立即测验都显著优于 comprehension questions；(2) 2 周延迟测验差距缩小，且 dictation 的衰减比 dictogloss 更明显 — 说明 dictogloss 的长期保持更好。
  • AI-driven speech recognition RCT 2025（Humanities and Social Sciences Communications）：84 名中国大学生 RCT，AI ASR 组在 listening skill / flow / 焦虑三项都显著优于对照组，3 周 follow-up 仍维持[27]。对半米的意义：Whisper + 评分反馈不只是"工具"，是有学习效果证据的干预手段。
  • Wakitsu et al. 2023 meta-analysis：15 项研究 + 38 effect sizes，ASR 整体 medium 效应（g=0.69）；indirect feedback 如 ASR dictation 中等效应[28]。

2.6 中国本土脉络 · 钟道隆透析法（1980s-至今）

不能跳过 — 中国英语教育里"听写"概念被钟道隆 1980s 提出的逆向英语学习法（透析法）反复塑造。45 岁的通信工程师钟道隆从英语薄弱到能做翻译只用了 18 个月，方法浓缩成"听、写、说、背、想"5 步，材料用 VOA Special English[29]。

透析法 SLA 对照（参见父报告 Ch6）：

  • "逐句听写慢速 VOA" = narrow listening (Krashen) + classical dictation (Oller/Cai)
  • "反对查字典 / 慢速反复" = i+1 + dictogloss 在缺乏母语环境下的中国式落地
  • 记录效果：钟道隆指导过的学校英语四级通过率从 40% → 100%[29] ⚠️ 自报数据需谨慎

对半米的意义：透析法被中文圈贴"伪科学"标签是误读 — 它在 SLA 学界 5 个理论坐标里站得住。半米的 VOA / SciShow Kids 视频例句库 + 听写挖空就是透析法的现代化版本。

3.2 类型 A · Sentence Dictation（句子级听写）

✍️ 一句完整音频 → 学员写下来 经典款

实现：(1) 播一句完整音频；(2) 学员有 X 秒打字；(3) 重听 1-2 次；(4) 提交 → 字符级 diff 显示对错。

难度可调参数：句长（3-30 词）/ 语速（0.75x-1.2x）/ 主题熟悉度 / 重听次数（1 次 / 2 次 / 无限）。

CEFR 适配：A2 → 5-8 词简单句；B1 → 10-15 词复合句；B2 → 含从句的长句；C1+ → 学术演讲单句。

学术证据：Oller 1971 原型；Cai 2013 把它跟 partial dictation 一起做 CFA[1]；Vietnam 2024 study[32] 显示 young learners 也 receptive。

优：测最全面的 listening 能力（音系 + 词汇 + 语法 + 短期记忆）。劣：A1 学员负担过重；评分要容忍同义改写。

3.3 类型 B · Word Dictation（词级听写）

🔤 单个词音频 → 学员写下来 基础

实现：(1) 播放单词音频（带例句重音）；(2) 学员打字；(3) 提交 → 拼写匹配。中国系 App "不背单词" / "百词斩" 标配此模式[12][33]。

CEFR 适配：A1 高频词；A2 学术启蒙词。B1+ 学员单纯背单词意义有限，应升级到 cloze 听写。

学术证据：Quizlet Spell mode（要求每词正确拼 2 次）[34]；Drops 用 audio + 词义图像组合[35]；中国系教材同步类 App 大量做此[36]。

优：低门槛 / 学员爽感强 / 反馈即时。劣：单词脱离语境 → 不到 noticing-in-context（参见父报告 §2.3 Schmidt）；只够到 declarative 阶段，过不去 procedural（DeKeyser）。

半米对此的态度：词级听写不是"竞品做得好我也做"，而是夹在 cloze 听写里做 — 半米的视频例句 + 字幕挖目标词 = 词级 + cloze 二合一，比脱离语境单词听写好。

3.4 类型 C · Passage Dictation（段落级听写）

📜 30-60s 段落 → 学员听 1-2 次写完整段 高阶

实现：(1) 播放完整 30-60s 段落；(2) 学员可重听 1-2 次；(3) 写下完整段落；(4) 句级 token 比对。IELTS Listening Section 4 就是这种 — 学术 lecture + note completion / sentence completion / summary completion[31]。

CEFR 适配：B2 简单学术段；C1 含从句和过渡的演讲段；C2 复杂论证。

认知负载：极重 — working memory 是 bottleneck。SAGE 综述（Sakai）[37] 指出 WM capacity 跟 L2 listening comprehension 正相关，low proficiency 学员 WM 限制更严。

优：训练 working memory + discourse-level inference + 模拟真实学术听力。劣：对 A2-B1 太残忍；改卷复杂（需要忍同义改写 + 标点容错）。

3.5 类型 D · Cloze / Partial Dictation（挖空听写）★ 半米 V0.1 首选

🎯 字幕显示句子 + 挖掉 N 个词 → 学员听 + 填 最佳 ROI

实现：(1) 字幕显示 "I feel ______ in this chair"；(2) 播放完整句音频；(3) 学员填 "comfortable"；(4) 字符匹配评分。

CEFR 适配：A2 挖 1 个目标词；B1 挖 1-3 词；B2 挖 5+ 词或词组；C1 挖关键搭配。

学术证据（强）：

  • Cai 2013（367 名中国 EFL）confirmatory factor analysis 证明 partial dictation 跟"高阶 listening"测的是同一个 construct，不是"低阶机械"[1]
  • Kuo 2010（31 名台湾大一）partial dictation + 英语广播 t-test 显著改善 listening comprehension[2]
  • Lyrics Training（13 种语言 / 10M+ 用户）[5] = cloze dictation 商业化最成功案例 — 证明产品端可行
  • Yu/Boers 2025[3]：dictation 包含 cloze 对 multiword items 学习有用，立即效果显著

优：(1) 难度可调；(2) 工程简单（字符匹配）；(3) 适配现成视频字幕；(4) 学员负担适中；(5) 学术证据最强。劣：太多挖空时变成"猜词练习"，离 listening 远；要平衡挖空密度。

半米现成条件：每个例句已有视频 + timestamp + CEFR 等级 + 学员 UGC 评价。Cloze 听写对应零迁移成本：增一张 dictation_attempts 表存学员答题历史即可。

3.6 类型 E · Dictogloss（重建听写）★ V1.0 高级模式

🔄 听 2 遍 → 不立刻写 → 关键词笔记 → 重建全文 output 训练

实现（Wajnryb 1990 原型）：(1) preparation 主题热身；(2) dictation 原速读 2 遍 + 学员只记关键词；(3) reconstruction 小组用笔记重建全文；(4) analysis 跟原文对比 + 分析差异[15][22]。

App 化适配：去掉"小组"环节 → 学员个人重建 → GPT-4o-mini 用 semantic similarity + grammar check 给分。

CEFR 适配：B1-C1。比 dictation 更偏 output，强 Swain pushed output（参见父报告 §2.4）。

学术证据：

  • Wajnryb 1990 原创[15]。
  • Prince 2013：dictogloss 学生在 task implementation 变量上对产出有显著影响[24]。
  • Yu/Boers/Tremblay 2025（142 名中国 EFL 学员）关键发现：dictogloss 的2 周延迟测验保持率优于传统 dictation[3] — 这是 dictogloss 比 dictation 强的实证差距。
  • 2016-2024 综合 40 篇 dictogloss 研究：显著提升写作连贯性 + 语法准确率（父报告 Ch3 数据点）[22]。

优：跨听·读·写·说四技能；语法 noticing 强；长期保持好。劣：需要 LLM 评分（成本 + 准确性）；A1-A2 学员做不了。

3.7 5 种课堂变体（仅供参考，App 不适合）

  • Running Dictation：墙上贴文，学员跑去看一句 → 跑回来口述 → 同伴写。课堂 only[38]。
  • Picture Dictation：教师描述一幅画 → 学员听 + 画。练 prepositions of place（A1-A2 启蒙）[39]。
  • Pair Dictation：双人轮流 reader/writer，文本"分散"在两人手里[38]。
  • Jigsaw Dictation：句子被打乱顺序贴墙上 → 学员重建文本结构[38]。
  • Grammar Dictation：Davis & Rinvolucri 1988 Dictation: New Methods, New Possibilities[40] 给出的若干变体 — 教师 / 学员谁选文本 / 谁纠错 / 怎么纠都开放。

📝 课堂变体不进半米：除非半米做"亲子互动模式"或"线下俱乐部"功能 — 目前优先级低。

4.1 Lyrics Training · 国际旗舰（cloze + 歌曲）

🎵 Lyrics Training · 全球听写挖空学习 cloze 商业化最佳案例

数据点：13 种语言[5]；全球 10M+ 用户[5]；Google Play 评分 4.55 / Apple App Store 评分 4.8。

对半米的启示：Lyrics Training 证明 cloze dictation 是可大规模商业化的产品形态。半米跟它的差异化 = 用"真实对话视频"（SciShow Kids / VOA）替"歌曲歌词"，跟 CEFR 词汇库联动，做"i+1 正中靶心"的挖空。

5.1 Quizlet Spell · 词级听写做到工业级

  • 体量：50M+ MAU[45]；2024 营收 $80M；2025 $139M[45]
  • Spell mode：听音写词，每 round 7 题，每词需正确拼 2 次[34]

  • 跟半米对比：Quizlet Spell 是工业级词级听写，但词都是孤立的 — 没语境。半米的 cloze 挖空 = 把 Quizlet Spell 的词放回原句视频里 = 升级版

5.2 Anki · DIY 听写圣地（addon 生态）

Anki 本身不内置 dictation，但有多个 addon 把它实现：Speech Recognition (411601849) / Test Your Pronunciation (Cloud Speech to Text 673333980) / Speech to Text (319520119)[46]。

典型用法：cloze deletion 卡 + 音频 → 学员听音频 → 写出被挖词。社区有完整 Bulk Generating Cloze Deletions for Language Learning 教程[47]。

对半米的意义：Anki DIY 生态证明 dictation + cloze + audio 是 power users 的刚需 — 但只有 ~1% 学员有耐心搭 DIY workflow。半米的机会 = 把这套体验做成"开箱即用"。

5.3 Duolingo "Type What You Hear" + DET Listen-and-Type ★

🦉 Duolingo · 听写题作为核心题型 最大规模实战

普通课程的 Type What You Hear：(1) 播放完整句音频；(2) 有 turtle button 慢速重听；(3) 学员打字整句[48]。本质就是 standard dictation。

DET (Duolingo English Test) 的 Listen and Type：高利害考试用[9]：

  • 1 题 60 秒；总共 6-9 题
  • 音频可重听 2 次（共 3 次听）
  • 评分 0-1 分；接近正确分越高
  • 漏词的惩罚比拼错重 — "always try to answer"
  • 大小写 + 句末标点必须对（影响分）
  • 美/英拼写都接 — 但同一句不能混用

对半米的关键启示：DET 高利害测试就用这种题型 = industry-validated。半米可以把"听写"包装成"DET 风格练习" → 锚定 IELTS / TOEFL 备考用户。

5.4 FluentU · 视频字幕 + 4 档 dictation

  • 定位：真实视频（电影 / 音乐 / TED / 新闻）+ 互动字幕[49]
  • Dictation 实现：4 档 — L1 单句填空；L2 较长填空；L3 整句；L4 段落[49]

  • 跟半米对比：FluentU 是半米英文界面最直接对标对象。FluentU 缺：中文界面 / K12 教材联动 / 跟读评分。半米三个都做了

5.5 eJOY · 越南起家的 YouTube 学习方案

  • 体量：Chrome extension 200K+ 用户；4.8/5 评分；2019 创立[50]
  • 实现：YouTube → interactive 听 → shadowing → dictation → role play 四件套[50]
  • 启示：eJOY 证明Chrome extension 改造 YouTube是低成本切入路径 — 半米现在路径（自建视频例句库）相对重，但Chrome extension 形态可考虑做学员的"任意 YouTube 视频"听写工具，V2.0 探索方向

5.6 Migaku · immersion 学派的 dictation

  • 定位：immersion learning 工具；Netflix / YouTube / 任意网页 → 双字幕 + 词查询 + 卡片[51]
  • Dictation 说法：官方文档明确说 "dictation exercises push your listening skills hard - you play a short dialogue segment, pause, and try to write down exactly what you heard, then check against the subtitles, which reveals which sounds you're mishearing"[51]
  • 跟半米对比：Migaku 重 immersion + 词卡片，dictation 是次要功能；半米可学其"任意视频 → 字幕互动"理念，但 dictation 要做主线而不是次要

5.7 Drops · 几乎没做 dictation（反面案例）

  • 50+ 种语言 / 5,000+ 词 / 5 分钟/天[35]
  • 有发音 + 听 + 看图，但没有正式 dictation 功能
  • 说明：纯词卡片 + visual mnemonic 路线不需要 dictation — 但这也是 Drops 被批"用户记不住 / 学不到自由表达"的原因之一

5.8 Babbel · 听写嵌在课程里

  • 14 种语言 / 课程内有 fill-in-the-blank + 听写 + 微录音[52]
  • 没有独立"听写模式"，是课程任务的一部分
  • 启示：dictation 不必单独成模块，可以嵌进学员的日常学习流（半米的"看 6 例句"任务里直接掺入 1 道 cloze 听写）

6.1 IELTS Listening Section 4 · academic note completion

🎓 IELTS Section 4 · 学术 lecture + note completion 高利害听写

形式：一个 speaker 一个学术主题（健康 / 动物 / 历史 / 科学），10 题 note completion / sentence completion / summary completion[31]。

评分规则（关键）：

  • 二元评分 — 100% 对或 100% 错。"environment" 拼成 "enviorment" = 0 分[31]
  • word limit 严格 — "NO MORE THAN TWO WORDS" 超出立扣分[31]
  • 词都是 common knowledge，但spelling 是 bottleneck

跟半米的关系：B2+ 学员准备雅思／托福需要这种练习。半米的段落级听写 V0.3可以包装成"IELTS Section 4 模拟"。市面上的 IELTS Liz / FluentDictation / Daily Dictation 都有这类专项[53]。

  • KET (A2)：5 部分 25 题，每题听 2 遍，含 gap-fill 部分需写词或数字，"spelling 可识别即可，除非题目要求精确拼写"[54]

  • 启示：KET/PET 听写题是 partial dictation 的正规考试形态，半米可以按 KET → PET → FCE → CAE 阶梯设计练习

6.3 Duolingo English Test (DET) Listen and Type

已在 §5.3 详述。再加一笔：DET 在 2024-2025 被越来越多大学接受作雅思替代[9] — Listen-and-Type 这种听写题正在被"高利害化"。半米跟着出"DET 模拟"产品形态成立。

6.4 BBC Learning English · 免费泛听 + 转写

  • BBC Learning English 内容免费：6 Minute English / English at Work / News Review[55]
  • BBC 本身不做"dictation 平台"，但 eJOY / Daily Dictation / dailydictation.com 等第三方把 BBC 内容做成 dictation 训练
  • 启示：内容免费 → 第三方做练习层。半米跟 BBC 学的不是产品，是"内容免费 + 练习层付费"的拆分逻辑

  • VOA Learning English 用~1500 词 + 1/3 慢速朗读[56]
  • 专门第三方平台 DictationToday.com 把 VOA 段子拆成"句听写"练习[57]
  • 钟道隆透析法的核心材料就是 VOA Special English — 中国学员"听慢速 VOA 写下来"的传统 30+ 年了[29]

6.6 IELTS Liz / FluentDictation / engNovate · 第三方雅思练习

  • IELTS Liz：B1+ 学员熟知，免费 IELTS Listening 练习 + 听写专项[53]
  • FluentDictation：YouTube 频道 + 网站，IELTS / TOEFL / Cambridge 真题听写[53]
  • 都证明："考试导向听写"是有付费意愿的细分市场 — 半米可以做半米学员升 B2 后专项的"考试听写"模块

7.1 美国 Scripps National Spelling Bee

  • 历史：spelling bee 短语最早 1850 见诸印刷；Benjamin Franklin 1750 就提议作为学校固定环节[58]
  • National 始于 1925，Courier Journal of Louisville 主办；目前 The E.W. Scripps Company 运营，291 个赞助商，覆盖美国 + 欧洲 + 加拿大 + 新西兰 + 关岛 + 牙买加 + 巴哈马 + 加纳 + 波多黎各 + 美属维京群岛 + 美属萨摩亚[58]
  • 2024 数据：第 96 届 245 名参赛者；Bruhat Soma (12 岁) 夺冠，spell-off 新纪录 — 30 词拼对 29 个[59]
  • 奖励：$50,000 现金 + Scripps Cup + Merriam-Webster 词典套装 + Britannica 全集 + 学校 $1,000 奖学金[59]
  • 跟语言习得的关系：spelling bee 偏 "rare word + 词源 + 拼写规则"，跟 EFL 学员的 listening + 词汇 needs 关系不大。但它建立了"听写 = 严肃学术"的文化认知

  • "全民焐热冰冻汉字行动" 60 亿浏览量

意义：在中国文化里，"听写"自带学术/严肃信号。半米做"听写"模块时文案上可以借这个文化共鸣 — "回到学习的本质"。

7.3 中国 ESL 中考 / 高考听力

  • 中高考英语听力：通常 20 题、25-30 分钟、约占总分 20%。题型含 multiple choice + note completion（partial dictation 性质）[60]

09评分算法 + UI 实现▼

9.1 评分算法 5 层架构

Layer 1: 精确字符匹配 (exact match) ↓ 不通过 Layer 2: Levenshtein 编辑距离 (容忍 1-2 个字符错误) ↓ 不通过 Layer 3: lemma 容忍 (comfortable / comfortably 同分) ↓ 不通过 Layer 4: 同音异形容忍 (their / there / they're 警告但给分) ↓ 不通过 Layer 5: 同义改写容忍 (LLM 评 — V1.0 才上) ↓ 最终给分 + diagnostic tag

9.2 Layer 1+2 · Levenshtein 编辑距离实现

Levenshtein distance（Vladimir Levenshtein 1965）= 把字符串 A 变成字符串 B 所需的最少单字符编辑（增 / 删 / 替）次数[61]。动态规划，O(mn) 时空。NPM fast-levenshtein / Python python-Levenshtein 都是标准库。

用法：

  • distance ≤ 1（10 字以内单词） → 半对（给 0.7 分）+ 提示拼写
  • distance ≥ 2 → 全错
  • 句级用 token-level Levenshtein（每词当一个单位），距离 ≤ 句长 × 0.1 → 接近正确

9.3 Layer 3 · lemma 容忍 (词形容错)

  • 用 spaCy 或 nltk lemmatize 把答案和原文都转词根
  • "comfortable" / "comfortably" / "comfort" 都给分（半米可设"严格模式 / 宽松模式"二档）
  • 对高阶学员可关掉这个 layer — 因为词形错就是 noticing 没到位

9.4 Layer 4 · 同音异形容忍 (homophone)

their / there / they're 这种典型错误[62]：

  • 用预制 homophone 字典（开源的 english-homophones JSON）
  • 命中 → 给 0.5 分 + 警告"这些是 there/their/they're 同音异形 — 注意区分"
  • 累积 3 次同类错 → 触发"同音异形微课"（链接到例句对比）

9.5 Layer 5 · LLM 评分 (V1.0 dictogloss 用)

Dictogloss 学员用自己话重建段落 → 没法字符匹配，要 LLM 评。建议：

  • GPT-4o-mini（便宜 + 中文 prompt 友好）
  • Prompt 模板："原文：[X]。学员重建：[Y]。请评：(1) 信息完整度 0-1；(2) 语法准确度 0-1；(3) 词汇恰当性 0-1。给出 3 项分数 + 1 句反馈。"
  • fallback：embedding cosine similarity 作低成本兜底

9.6 ASR 评分（V0.5 跟读联动）

跟 Shadowing 模块联动：学员听写完后 → 朗读句子 → Whisper ASR 转写 → 比对原文 → 一个练习"听 + 写 + 说"三件套[63]。Whisper 在英语 read speech 上平均 WER ~12.8%（native），non-native 偏高[7]。要做容错 buffer。

Wakitsu 2023 meta-analysis（15 项研究 / 38 effect sizes）[28]：ASR with indirect feedback（如 ASR dictation）moderately effective (medium 效应 g=0.69)。这说明半米的"听写 + ASR 跟读"联动是有学术支撑的。

9.7 错误诊断 (diagnostic tagging)

错的位置告诉你学员真实音系/词汇盲点（参见父报告 §3.4 已列）：

  • 错 thought → /θ/ 音盲点 → tag th-blind
  • 错 have been → reduced form 听不出 → tag connected-speech
  • 错 their / there → noticing 不到位 → tag homophone
  • 错 insurance 拼成 ensurance → 拼写规则 → tag spelling-rule
  • 错 comfortable（多写少写音节）→ 音节切分 → tag syllable

累积 10 次 + 后给出学员弱项报告：「你最常错连读 + th 音；建议练 SciShow Kids 第 N 集 + 跟读"this / that / those" 5 分钟」。这是半米的独特价值 — 别的 App 不做诊断。

9.8 UI 实现要点

5 大 UX 原则：

  1. 实时反馈：边打字边显示对错（字符级即时高亮）— 防焦虑积累
  2. 重听阶梯：默认 1 次；点 🐢 慢速重听（playbackRate=0.75）；3 次错触发"再听一次"按钮；5 次错给完整答案
  3. 显示答案后强化：完整答案给出 → 再听一遍 → 自然 fade 到下一题
  4. 历史 + 错题本：所有听写答题进 SRS 队列，错题加 diagnostic tag
  5. 气氛管理：不计错次（避开多邻国"扣血"机制）；只显示进步曲线

function gradePassage(originalText, userText) {
  // 1. 分句
  const origSents = splitSentences(originalText)
  const userSents = splitSentences(userText)

  // 2. 句对齐 (longest common subsequence)
  const alignment = alignSentences(origSents, userSents)

  // 3. 每对句子做 token-level Levenshtein
  let totalScore = 0
  for (const [orig, user] of alignment) {
    totalScore += tokenLevenshteinScore(orig, user)
  }

  // 4. 漏句惩罚（重要）
  const missingSents = origSents.length - alignment.length
  totalScore *= (1 - 0.1 * missingSents)

  return { score: totalScore, diff_html: renderDiff(alignment) }
}

11半米 Dictation 的 5 大差异化机会▼

市面上的 dictation App 各有各的"独门" — Lyrics Training 占歌曲；扇贝占精听；不背占单词；DET 占考试。半米的差异化必须打在"复合优势"上 — 单点比不过竞品，组合无人能敌。

11.1 差异化 #1 · 跟词汇库 CEFR 等级联动

优势 #1 CEFR-driven dictation 出题

所有竞品都是"内容 driven"（学员选歌选段子选课程），半米可以是"学员等级 driven"：

  • 学员 A2 → 系统出 A2 词例句 cloze（i+1 正中靶心）
  • 学员 B1 → 升级到 B1 词例句 + 部分 B2 词挑战
  • 学员的 weak tag 自动反馈 → 弱项词重复出现

对应 SLA 理论：Krashen i+1 + Nation 95% coverage[65]。市场上没有 dictation App 做到这一层 CEFR 自适应 — 因为他们没半米的词汇分级数据。

11.2 差异化 #2 · 跟视频例句联动（真实场景）

优势 #2 真实视频 i+1 例句

Lyrics Training 用歌曲（artistic 但脱离日常对话）；Quizlet Spell 用 TTS（不真实）；不背单词例句多但碎；扇贝有内容但没视频。

半米的视频例句 = 真实场景 + Krashen comprehensible input + Pellicer-Sánchez narrow listening 三大理论合体[65]：

  • SciShow Kids 例句 → A2-B1 自然科学场景
  • Peppa / Ms Rachel → A1-A2 启蒙日常
  • VOA Special English → B1-B2 新闻段
  • TED / 学术 talk → C1-C2 学术段

所有这些视频已经入库 + 时间戳标记 + CEFR 标注 — 边际成本接近 0。

11.3 差异化 #3 · 听写四阶段闭环（V0.1-V1.0 完整）

优势 #3 4 阶段递进 · 没有竞品做齐

把竞品的"听写功能"梳理一遍：

  • Lyrics Training：只做 cloze（V0.1 类型）
  • 不背单词：词级 + 例句 cloze（V0.1-V0.2）
  • 扇贝：句精听 + 拼写（V0.1-V0.3）
  • Daily Dictation：整句听写（V0.2-V0.3）
  • Parroto：dictation + shadowing 但没 dictogloss
  • 没有任何商业 App 做到 V1.0 dictogloss — 半米先发占位

这就是半米从 A1 词级一路通到 C1 dictogloss 全谱系的护城河。

11.4 差异化 #4 · 学生 UGC 反哺出题（弱项 driven）

优势 #4 UGC + 错题诊断 = 个性化听写

半米独有数据资源：

  • 学员 👎 过的句子 → 优先出听写题（"你说不懂这句，我们听写一下"）
  • 学员错过的词 → 多次复现在新句子里
  • 诊断标签累积 → "你最常错连读" → 推送 connected speech 专题

市场上没有 App 做这种"反向工程学员弱点"。多邻国 + 不背单词都用统计平均，不是学员个性化。

11.5 差异化 #5 · 跟 Shadowing + AI 对话联动（听说闭环）

优势 #5 听 → 写 → 说 三件套

同一句视频例句可以串成3 个练习：

  1. 听写听准 (Dictation) → 学员真听清每个词
  2. 跟读说准 (Shadowing) → 学员能复刻每个音
  3. 对话用准 (AI 对话 V1.0+) → 学员主动产出

这是Schmidt noticing + Swain pushed output + DeKeyser declarative→procedural→automatic 三大理论的工程化合体（参见父报告 Ch2）。

市场上：

  • Lyrics Training 只听写
  • Parroto 听写 + 跟读但没对话
  • 流利说 主跟读 + 对话但没听写
  • 半米三合一

11.6 5 大差异化综合定位陈述

半米 Dictation 一句话定位：

"用真实视频例句做 CEFR 自适应的 cloze 听写，跟单词库 / 跟读 / AI 对话联动 — 从 A1 词级一路通到 C1 dictogloss，没有竞品做齐 5 段。"

给阿杰的话：上面 5 大差异化每一个独立都不强（Lyrics Training 也用真实素材，不背单词也搞 cloze），但5 个组合起来在中国市场没有第二家。这就是护城河。

13FAQ · 12 条阿杰最可能问的▼

Q1为什么先做 V0.1 cloze 听写而不是 V0.3 段落听写？+

3 个理由：

  1. 工程量：V0.1 1-2 天 vs V0.3 2-3 天，边际成本最低。
  2. 学员适配：半米首批学员以 A2-B1 为主，段落听写对他们太残忍，cloze 是i+1 正中靶心。
  3. 学术证据：Cai 2013 CFA 证 partial dictation 测的就是 higher-order listening[1]。不存在"先简单后复杂"的层级 — cloze 本身就够测高阶。
Q2Lyrics Training 已经做了 10M 用户，半米做 cloze 听写还有意义吗？+

有 — 3 个差异：

  • Lyrics Training 用歌词（artistic / 不日常）；半米用真实对话视频（学术 + 启蒙 + 新闻）。歌曲跟日常英语 prosody 差距大。
  • Lyrics Training CEFR 等级弱（按歌曲粗分）；半米按词汇库精确分级到 A1-C2。
  • Lyrics Training 没做 dictogloss / 学员诊断 / 跟读联动；半米一站式 4 阶 + 听说闭环。
Q3不背单词已经有 5000 万注册，半米的 cloze 听写跟它怎么比？+

不背单词的核心是词级，听写只是辅助功能。半米的差异：

  • (1) 不背的"例句听写"挖空只挖目标词；半米可调难度梯度 L0-L5
  • (2) 不背的例句是文字 + 短音频；半米是真实视频片段（场景 + 表情 + 真实 prosody）
  • (3) 不背不做诊断标签；半米做 (th-blind / connected-speech / homophone / spelling-rule)
  • (4) 不背不做 dictogloss；半米 V1.0 占位市场空白

但不背的优势在词包丰富 + 教材同步 + 中国本地化深耕。半米不要正面冲 — 走差异化路线。

Q4Whisper ASR 在 non-native 学员上 WER 多高？跟读评分准不准？+

Whisper 在 native English read speech 上 WER ~12.8%[7]；non-native 偏高（Graham & Roll 2024 测 14 种 L1 背景 mean MER 0.157，Ballier 2024 法国学员 WER 0.132）[63]。对半米的意义：单纯字面匹配 ASR 输出不可靠 — 要做"模糊比对 + 关键词容错 + 不要把"r/l 不分"当严重错"。Wakitsu 2023 meta-analysis 显示 ASR with indirect feedback (像 dictation) 中等效应 g=0.69[28]，跟读评分作"参考反馈"是 OK 的，作"严格打分"会伤学员。

Q5V1.0 Dictogloss 用 LLM 评分，准确性和成本怎么权衡？+

成本：GPT-4o-mini ~$0.005/次 dictogloss 评分，1000 个学员每天 1 次 = ~$150/月。完全可承受。

准确性：LLM 评分有 ±5-10% 噪声。3 个对策：

  • (1) 用 few-shot examples 稳定评分 prompt
  • (2) 同句缓存 hash → 重评取平均
  • (3) 不显示精确分数（"83.7 分"），显示档位（"良好" / "优秀" / "需努力"）

底线：dictogloss 评分主要是给学员反馈方向，不是计分。这跟 SAT 不一样。

Q6钟道隆透析法是不是伪科学？半米对接他的方法靠谱吗？+

透析法被中文圈贴"伪科学"标签是片面的（参见父报告 §6 详解）。学术对应：

  • "逐句听写慢速 VOA" = classical dictation (Oller 1971)[16] + narrow listening (Krashen)[65]
  • "反对查字典 / 慢速反复" = i+1 + dictogloss 在缺乏母语环境下的实践版
  • "再听再说" = 轻量 shadowing (Tamai 1992)

批评点不在方法本身，在"零基础就能学会"的过度承诺。半米的"听写 + 跟读"模块就是透析法的现代化版本 — 砍掉过度承诺 + 加 AI 反馈 + 视频例句多样化。

Q7Dictation 1970s 不是被批过气吗？现在做不是落后？+

这是个流传广的误读。Dictation 学术上从未被证伪：

  • 1975-1985 Heaton/Davies 批它 imprecise[10] — 主要是"测试用途"的批评（测不出独立 micro-skill），不是"教学用途"的批评。
  • 同期 communicative language teaching (CLT) 浪潮挤压 dictation 的曝光度，因为它"看起来不沟通"。
  • 2001 起 Buck[21]、Cai 2013[1]、Kuo 2010[2]、Yu/Boers 2025[3] 一系列实证把它焊回主流。
  • 市场端：Lyrics Training 10M+ 用户 / Quizlet 50M+ MAU 都做 dictation 类—— 商业端验证。
Q8半米要不要做"DET 听写考试模拟"细分？+

建议：V0.3 后再考虑。DET (Duolingo English Test) Listen-and-Type 是高利害考试题型[9]，市场需求强但已经有 GoArno / TST Prep / DETPractice 等专门玩家。半米单独做这个细分会陷入红海。可考虑的侧面切入：

  • (1) 在通用听写模块里加一个"DET 模拟"主题包（给已是半米用户的考试需求者）
  • (2) 不单独做 DET 营销，作为"听写功能"的次级 use case
Q9儿童学员（Danny 这种）做听写合适吗？+

合适但要适配：

  • 5-8 岁：不做正式 dictation，用 picture dictation（听 → 画 / 选图）[39]
  • 8-10 岁 (A1-A2)：V0.1 单词 cloze，从 SciShow Kids / Peppa 短句开始
  • 10+ (A2-B1)：V0.1-V0.2 全套

2024 Vietnam 研究[32] 显示 young learners 对 dictation 接受度高，但要 adapt speech rate + 用 engaging content。半米的 SciShow Kids / Peppa 例句视频是天然适配。

Q10听写做完后，学员立刻"看完整字幕 + 再听一次"对学习有用吗？+

有 — 这是Schmidt noticing 的高质量实施[64]：

  • 学员先没字幕听 → 发现自己听不清 → noticing the gap
  • 给完整字幕 → 学员看到"正确"对照
  • 再听一遍 → 这次能匹配上音和字 → 把听不清的部分"焊"进 implicit knowledge

这就是 Oller 1971 说的 "active process of analysis"[16]。半米一定要保留"提交后立即给完整字幕 + 自动重播一次"流程。

Q11半米的 dictation 如果不收费，怎么变现？+

三个变现路径：

  • (1) 跟整体会员绑定：dictation 是会员权益之一（跟跟读 / AI 对话同档）— 不单卖，提升整体留存。
  • (2) 内容主题包付费：免费学员用基础视频例句；高考听力专项 / IELTS 真题段 / 大学英语听写 = 主题付费包（参考扇贝）。
  • (3) B2B 教材同步：跟出版社合作，做"人教版小学英语听写 App"，按学校采购付费（参考"英语朗读宝" 1000 万用户路径[36]）。

不要用 streak / 焦虑机制变现（参见父报告 Ch9 多邻国质疑）。

Q12如果阿杰只看一句结论，是什么？+

"V0.1 单词级 cloze 听写本周末就能上 — 用现成 6 例句视频 + 字幕挖目标词 + Levenshtein 评分，1-2 天工程量。学术证据强 (Cai 2013[1])，竞品空白（不背做词级 / 扇贝做句精听 / Lyrics 用歌词都不踩半米的 niche），跟现有词汇库零迁移。后续 V0.2-V1.0 用 7-11 人天补齐 4 阶段，做完没有第二家。"
