🎯 3 条核心结论

结论 #1 Shadowing 起效是科学公认事实，但变种比"做不做"重要 100 倍
2025 年 tandfonline 系统综述纳入 44 篇 shadowing 研究，结论：shadowing 对 comprehensibility / intelligibility / accentedness（Derwing & Munro 三维框架[22]）+ 流利度 + prosody 有显著增益；但对 segmental（单音素）证据不一致[2]。Hamada-Suzuki 2024 把 16 种变种按"phonological focus"和"meaning focus"两轴归类[5]，低水平学员（A1-A2）用 mumbling + prosody shadowing 受益最大，中高水平（B1+）才进 content + selective shadowing[6][7]。

意思是：半米做 shadowing 不能只做"录音打分"那一种 — 要按 CEFR 分阶段推不同变种。第 3 章给出 7 种变种 + 推荐 CEFR 对应表。
结论 #2 ASR 技术选型：V0.1 别上 Azure，先用 Web Speech / Whisper 跑通业务
4 个 ASR 选项的 ROI 对比清晰：
  • Web Speech API：成本 ¥0，仅 Chrome/Edge/Safari 支持，转文本准确率对母语者 OK 但没有音素 / prosody 评分 — 只能算字面 accuracy[16]。V0.1 最佳选择。
  • OpenAI Whisper / whisper.cpp 本地：M2 Pro 上 large-v3-turbo 10x 实时[17]；准确率 LibriSpeech 2.7% WER，但中国学习者 ASR 错误率显著高于母语者[23]。V0.2 转写 + 自建字面 diff 评分。
  • Azure Speech Pronunciation Assessment：5 维度（accuracy / fluency / completeness / prosody / 整体）[14]，$0.36/h 批处理（最便宜路径）但 real-time 加 prosody 维度要更贵。V0.3 升级专业版。
  • Speechace API：音素 + 音节级评分，与 IELTS Pearson 相关 0.9[15]，$0.008/15 秒。V0.3 备选。
意思是：阿杰别一上来就接 Azure / Speechace（每月几百到几千刀，没必要）。先用 Web Speech 跑通流程，把"视频例句 → 录音按钮 → 对比反馈"这个 UX 跑顺，再决定 V0.2 上 Whisper / V0.3 上 Azure。
结论 #3 市场空白：跟"词汇库"联动的 shadowing 没人做过
扒了 20+ shadowing app 后，所有产品都把 shadowing 做成独立的"听句子→跟读→打分"循环：
  • Migaku / shadowing.app / Speak Pro：从影视剪辑选句子跟读，没有词汇路径
  • 趣配音（1.78亿用户 [20]）：动画配音游戏化，没有 SRS 词汇
  • 流利说（70M 用户峰值[24]）：跟读评分用自己的 309 亿句 ASR[24]，但跟读是"AI 老师课程"内嵌，不可单点
  • 百词斩：词例句"真人发音 + 跟读"[25]，但没有评分 + 没有同步度判定，更像 read-aloud
半米独门机会：把 shadowing 焊到词汇库 + 6 例句上 — "跟读了 6 例句 = 这个 B1 词的 mastery +50%"，让 shadowing 不是独立循环、是词汇深度习得的产物。这是别人没法快速复制的差异化（第 11 章详述）。

🚀 给阿杰的直接结论（今晚就动手）

今晚先做 V0.1（1-2 天工程量，¥0 成本）：

  1. 选半米已有的 6 例句视频中的 1 句（B1 难度）
  2. 视频下加 🎤 录音按钮 → MediaRecorder API（注意 Safari 是 mp4，Chrome 是 webm[26]）
  3. 录完调 Web Speech API 转文本

  5. 显示「你说：X / 原句：Y / 准确率 87%」

1 周内完成 V0.2（whisper.cpp + 字面 diff，仍 ¥0 服务器 CPU）；V0.3 再决定要不要上 Azure（每学员每天 5 句 × $0.01 ≈ ¥0.05/学员/天，规模化后可控）。详细 4 阶段路径见第 10 章。

02Shadowing 学术研究 30 年脉络 · Tamai 1992 → 2024▼

Shadowing 不是日本人发明的（其源头是 1950s 口译训练，Lambert 等用于同声传译预备[1]），但把它系统化引入 EFL 课堂、做出 30 年累积研究的是日本学界。本章把核心人物 + 关键论文 + 实证数字按时间线讲清楚。

2.1 Tamai Ken — 学派开山者（1992-2017）

📖 Tamai (1992) 开山之作
"Follow-up no chokairyoku kojo ni oyobosu koka oyobi 'follow-up' noryoku to chokairyoku no kankei" — STEP Bulletin, 4, pp. 48-62[1]

原研究：神户市外国语大学 Tamai Ken 在 1992 年的硕论（School for International Training, Brattleboro Vermont）+ STEP Bulletin 期刊发表的日文版本，首次在日本 EFL 情境下系统对比 shadowing 与 dictation 的效果。统计显著结论：shadowing 在听力提升上优于 dictation[1]。

定义（Tamai 1997 改写）："Shadowing is a training technique of listening in which the learner attempts to repeat the incoming information simultaneously as exactly as possible while listening attentively to the heard speech."[1] 延迟 ~0.5 秒，几乎同步。

意义：从此日本 EFL 圈大量后续研究跟进，Shadowing 作为 L2 教学技术在日本进入主流。

📖 Tamai 1997 / 2002 / 2005 学派固化
三篇关键节点 — 从硕论扩成完整研究路线[1]
  • Tamai (1997)："Shadowing no koka to chokai process niokeru ichizuke"（影子练习的效果及其在听力过程中的定位）— Current English Studies, 36, 105-116。把 shadowing 在听力认知过程中的位置定下来（bottom-up phoneme perception）。
  • Tamai (2002)：JAIS 第 3 届年会主旨演讲 — Interpretation Studies, 2, 178-192。把 shadowing 与口译训练打通。
  • Tamai (2005)：东京 Kazama 出版社 Listening shidoho to shite no shadowing no koka ni kansuru kenkyu（关于 shadowing 作为听力指导法效果的研究）— 第一本 shadowing 学术专著[1]。

2.2 Kadota Shuhei — 认知派代表（2007-2019）

🧠 Kadota 2007/2012/2015/2019 认知机制理论化
Kwansei Gakuin Univ. — 把 shadowing 焊到工作记忆 + 自动化理论上[8]

核心贡献：在 2019 年的 Shadowing as a Practice in Second Language Acquisition: Connecting Inputs and Outputs（Routledge）中提出 shadowing 的 4 效应模型：

  1. Input 效应 — 提升听力理解
  2. Practice 效应 — 增强 phonological working memory 的 subvocal rehearsal 机制（这是新词 / 公式 / 结构习得的关键）
  3. Output 效应 — 模拟语音产出的某些阶段
  4. Monitoring 效应 — 训练 executive working memory 的元认知监控

Kadota 认为 shadowing 推动 L2 流利度自动化 — 因为它强制学员双任务并行（perception + production），比单词处理认知负荷大得多，恰恰是 DeKeyser proceduralization 所需的[8]。

2.3 Hamada Yo — 当代主推手（2016-2024）

🔬 Hamada 2016/2017/2019/2022/2024 实证 + 理论双推
Akita University — shadowing 学界最高产的现代研究者[3][6][7][9]

Hamada (2016)："Shadowing: Who benefits and how?" 发表在 Language Teaching Research SAGE 期刊[3]。关键发现：

  • 低水平学习者受益最大 — phoneme perception 在低/中两组都提升，但只有低水平组在 high-school 难度听力题上拿到显著增益
  • 剂量：每次 10-15 分钟、每周 3-4 次、持续 6 周即有可测增益
  • 音段感知（phoneme perception）在两组都提升

Hamada (2018)："Shadowing for Pronunciation Development: Haptic-Shadowing and IPA-Shadowing"[10]：

  • haptic shadowing 组（手势 + shadowing）在 comprehensibility、segmental、suprasegmental 三维都显著进步
  • IPA shadowing 组（看 IPA 国际音标跟读）在 comprehensibility 和 segmental 进步

Hamada & Suzuki (2022/2024)："Situating Shadowing in the Framework of Deliberate Practice: A Guide to Using 16 Techniques"[5]：

  • 把 shadowing 焊到 DeKeyser/Suzuki 的Skill Acquisition Theory上
  • 整理出 16 种变种，分两轴：phonological processing 取向 vs intake through meaning-focused processing 取向
  • 低水平学员用 phonological 变种（mumbling, prosody）；高水平学员用 meaning-focused 变种（content, selective）

Hamada (2024)："Developing a new shadowing procedure for listening vocabulary: selective shadowing" — Innovation in Language Learning and Teaching, 19(2)[7]。日本大学 34 + 25 学生 5 节 Zoom 课。结论：selective shadowing（只跟某类目标词）有效提升 productive 和 receptive aural vocabulary。

给半米的洞察：30 年学界共识有5 个铁律：

  1. 近同步 — 延迟 ~0.5 秒，不是"听完再说"（那是 parallel reading / repetition，非 shadowing）
  2. 剂量 — 每天 10-20 分钟，4-8 周才出效果 用户不能期望快
  3. 低水平受益最大 — A1-A2 学员 ROI > B2-C1 学员
  4. 多变种轮换 — 单一变种会重复枯燥（中国研究证实）
  5. 材料必须 i+0 到 i+1 — 听不懂的跟读 = 鹦鹉学舌，无效

03Shadowing 7 种变种 · 定义 / 适用 CEFR / 半米实操优先级▼

Hamada-Suzuki (2022/2024) 把 shadowing 拆成 16 种变种[5]，但其中大多是细微差异。本章选出 7 种核心变种，每种给：定义 / 学术来源 / 适用 CEFR / 难度 / 主要训练目标 / 半米实操优先级。

3.2 每种变种深度展开

1️⃣ Classic Shadowing 经典同步跟读 Tamai 原版
Tamai (1992) 定义的基线[1]

定义："The learner attempts to repeat the incoming information simultaneously as exactly as possible while listening attentively."[1] 延迟 0.3-0.7 秒。不看字幕、不暂停、不缓速。

认知负荷：极高 — 同时做"perception + production + memory retrieval"，是 Kadota 4 效应里 practice + monitoring 效应的最大化[8]。

学界证据：所有早期 Tamai / Hamada 研究都基于这一变种。Foote & McDonough 2017 用的也是这一变种[28]。

半米实操：V0.2 的"L3 终态"模式。前置条件：学员已在该例句完成 L1 (parallel) 和 L2 (chorus)。

2️⃣ Prosody Shadowing 韵律跟读 A2-B1 最受益
Saito, Nagasawa, Ishigawa (2004) 分类[5][31]

定义：学员关注 stress / rhythm / intonation，可以 mumble 或哼出来；不要求每个词都说对。"在 prosody shadowing 中，学员关注 stress、rhythm、intonation，而 classic shadowing 学员严格关注 phonological 信息"[31]。

训练目标：把英语的"stress rhythm + sound linking (liaison)"内化[31]。Mori (2011) 用 acoustic measure 证明这种训练能显著扩大 sentence-final pitch range，并提升 stressed/unstressed 对比度[13]。

难点：中国学员往往字字咬清，不擅长 prosody。这一变种是"放下完美主义"的训练。

半米实操：V0.1 入门 — 不评分"词对不对"，只显示 "你说的整体节奏 ✓"，鼓励 mumble。

3️⃣ Content Shadowing 内容跟读 高阶
Saito et al. (2004)[31]

定义："The learner repeats both the content and intonation exactly as in the original."[31] 同步度 + 词义都要对。

认知负荷：最高 — perception + production + comprehension 三任务并行。Hamada 2016 显示这一变种对高水平学员才显效[3]。

半米实操：V0.3 进阶 — 只对 B2+ 学员开放。需要配 word-level confidence 反馈才有价值。

4️⃣ Mumbling Shadowing 含糊跟读 A1 入门神器
Saito et al. (2004) / Hamada-Suzuki (2022)[5][31]

定义："Mumbling 是 shadowing 时注意力放在 incoming 声音而不是自己产出 — 小声跟、含糊跟、私下跟。"[31][32]

关键价值：

  • 降低社交成本 — 在公共场合也能练（地铁、公交、办公室）
  • 降低声带疲劳 — 长时间练习不累
  • 降低开口焦虑 — A1 学员最大的心理障碍是"怕说错"

争议：Migaku 2026 指出"mumbling 在低声状态下不训练 auditory perception"[32]。即 mumbling 是 entry stage 不是 endpoint。

半米实操：V0.1 第一步 — 给录音按钮一个"小声模式"，识别音量低于阈值时不打分，只显示「✓ 你跟上了节奏」。

5️⃣ Parallel / Text-Presented Shadowing 带字幕跟读 最易入门
Kuramoto et al. (2007) "text-presented shadowing"[12]

定义：看字幕 + 听一句 → 短暂暂停（可选）→ 跟读一句。严格说这是"shadowing 的脚手架"而不是真 shadowing — 真 shadowing 必须无字幕。

价值：把"听懂"和"跟读"两个挑战拆开 — 学员先用字幕保证理解，然后专注模仿发音。是从 read-aloud 到 classic shadowing 的桥。

Kuramoto 2007 证据：text-presented shadowing 比纯 shadowing 在 bottom-up 听力上效果更好[12]（因为低水平学员的字幕脚手架反而提升 noticing）。

半米实操：V0.1 主力 — 学员看视频 + 字幕，按句子级跟读。半米已有视频例句基础设施，这是0 改动就能上的入门变种。

6️⃣ Selective Shadowing 选择性跟读 ★ 半米独门
Hamada (2024) — 最新提出的变种[7]

定义："Listeners select only certain words and phrases to shadow."[31] 学员只在目标词 / 目标句型出现时跟读，其它时候只听。

Hamada 2024 实证：日本大学 34 + 25 学生 × 5 节 Zoom 课，selective shadowing 显著提升 productive 和 receptive aural vocabulary[7]。学界第一个把 shadowing 和 vocabulary 焊起来的研究。

为什么对半米是金矿：

  • 半米的核心数据资产 = 词汇库 + 6 例句 + B1/B2 难度标
  • selective shadowing 天然适配 — "今天的 10 个 B1 目标词，在视频里出现时跟读"
  • 不需要学员蛮力跟完整段，只在"高价值时刻"跟读
  • 跟 SRS 闭环：跟读了 = +1 encounter，朝 10-17 次 mastery 推进[33]

半米实操：V0.2 ★ — 「今日 10 个目标词」+ 配置成视频例句中目标词出现时高亮闪烁 + 自动暂停等学员跟读。这是别人没法快速复制的差异化。

7️⃣ Mirror Shadowing 全身镜像 不做
高级口译训练流派

定义：shadowing + 模仿肢体语言 / 面部表情 / 眼神 / 手势。源自同声传译 / 表演训练。

问题：需要高质量长镜头视频 + 学员摄像头自拍 + 比对算法（视频处理成本极高），ROI 对 K12 学习者极低。

半米实操：不做。如果学员真想要 mirror practice，引导他们去 BoldVoice（专门做accent training，2M 用户）[34]。

5.6 中国系总结

中国系 4 个共性问题：

  1. "跟读 = 录音上传 + 打分"，没有 Tamai 学派要的"近同步 + 多变种"

这 4 个空白正好是半米的 4 个差异化抓手。

8.3 Whisper 详解（自托管核心选项）

Whisper 系列模型选择：

  • large-v3-turbo：M2 Pro 上 10× 实时（60 秒音频 6 秒转完）[17]。Mac M2 都能本地跑实时。
  • large-v3：准确率略高，但慢得多
  • medium / small / base：低端硬件，准确率掉

关键限制：

  • Whisper 原生不支持 word-level timestamp（utterance 级 ±1 秒精度）[53]。要 word-level 必须叠 WhisperX (wav2vec2 forced alignment) 或 whisper-timestamped。
  • Whisper 原生不支持 phoneme confidence / prosody 评分 — 只能算字面 diff。
  • 中国学习者 ASR 错误率显著高于母语者[23]：JASA 2024 研究显示 Whisper 在非母语者口音上 WER 飙升。

部署成本：

  • 本地 Mac M2 / M3：纯电费，每小时音频成本 ~¥0
  • 云端 L40S spot：$0.32/h × 4h = $1.28 转 100 小时音频（vs OpenAI API $36）[59]
  • Docker faster-whisper：现成镜像[59]

微软 Foundry Tools[14]

09评分维度算法 · 5 维度 + 实现方式▼

shadowing 评分不是单一分数，是5 个维度的组合。本章逐一讲每个维度怎么算 + 哪些可以脚本算 / 哪些必须用商业 API。

9.1 5 维度 + 算法清单

维度定义算法脚本可算？商业 API

9.2 维度 1: Accuracy 准确率（半米 V0.1 就上）

✓ Accuracy 算法 最简单

算法：

  1. ASR（Web Speech / Whisper）转写学员录音 → 文本 A
  2. 原句文本 B（已知）
  3. 用 Levenshtein distance 算编辑距离[27]
  4. 归一化：similarity = 1 - distance / max(len(A), len(B))

伪代码：

function accuracyScore(originalText, asrText):
  // 1. 标准化：lowercase + 去标点 + tokenize
  o = normalize(originalText).split(' ')
  a = normalize(asrText).split(' ')
  // 2. 词级 Levenshtein
  dist = levenshtein(o, a)
  // 3. 归一化 0-100
  return max(0, 100 * (1 - dist / max(len(o), len(a))))

词级反馈：用 Levenshtein 的 traceback 找出哪些词错了，标红

工程量：JavaScript 实现 < 50 行

9.3 维度 2: Fluency 流利度

⏱️ Fluency 算法 脚本可算

2 个子指标：

  1. 语速 WPM：
    • 母语会话 ~150 WPM[18]，TED talks ~163 WPM
    • 学员目标：原音 WPM × 80%-120% 算流畅
    • 算法：WPM = wordCount / (audioLength / 60)
  2. Pause 频率：
    • 用 WebRTC VAD 或简单振幅阈值检测停顿
    • 正常 shadowing 应 ≤ 1 pause / 句

需要 WhisperX 或 timestamp-aware ASR得到 word-level 时间戳

9.4 维度 3: Pronunciation 发音（必须商业 API）

🔤 GOP (Goodness of Pronunciation) 自建难度极高
phoneme-level 评分的事实标准[61]

原理：

  1. Forced alignment：把音频和 phonetic transcription 强制对齐
  2. 对每个 phoneme 算log-likelihood ratio
  3. 分数 = 该 phoneme 实际匹配的 log 概率 / 该位置最可能 phoneme 的 log 概率
  4. 比值低 = 发音偏离，比值高 = 发音准

难度：

  • 需要 acoustic model + pronunciation dict + alignment
  • 儿童发音 forced alignment 误差大[62]
  • 新一代 segmentation-free GOP（2025 arxiv）尝试摆脱 forced alignment 依赖[63]

建议：不要自建，直接用 Azure (5 维) 或 Speechace（专注 pronunciation）。

9.5 维度 4: Prosody 韵律（V1.0 半米差异化）

🎵 Prosody 算法 parselmouth 可本地算
Praat 的 Python 接口 — 开源完整[64]

parselmouth 能提取的特征：

  • Pitch contour（F0 曲线）
  • Intensity（响度）
  • Jitter / Shimmer / HNR（声学参数）
  • Stress contrast（重音 vs 非重音 syllable 对比）

对比算法 (DTW)：

  1. 提取原音 pitch contour P_orig 和学员 P_student
  2. 用 Dynamic Time Warping 对齐两条曲线（克服语速差异）
  3. 算对齐后的均方根误差 (RMSE)
  4. 归一化为 0-100 分

UI 呈现：

  • SVG 画两条 pitch 曲线叠加（学员蓝 / 原音绿）
  • 标红学员明显偏离的 syllable
  • 对应 Mori 2011 学派的 acoustic feedback[13]

工程量：3-5 天（含 parselmouth Python 后端 + 前端 SVG 画图）

9.6 维度 5: Intelligibility 可懂度

这是 Derwing & Munro 1995 框架的最高目标[22]：母语者能否听懂学员说的内容。没有客观算法可测 — 唯一方式：让母语者听 + 转写学员录音。

间接代理指标：

  • 用另一个 ASR 模型（与训练用的不同）再转一遍学员录音，看能否还原原文 — 如果能 = 学员说得"够通"被机器理解
  • 2024 arxiv 提出"latent speech representation"做 perception-based intelligibility 评估[65]，但还在研究阶段

半米建议：V1.0+ 才考虑。短期内用"另一个 ASR 转写吻合度"做代理。

什么：今日 10 个 B1 目标词 → 视频例句中目标词出现时自动暂停跟读 → 跟读了 = +1 encounter，朝 10-17 次 mastery 推进。

学术背书：Hamada (2024) selective shadowing 论文 — 第一篇把 shadowing 焊到词汇上的实证研究[7]。

11.2 抓手 2: 听写 → 跟读闭环

🔁 抓手 2 输入输出闭环

什么：同一个 6 例句句子 — 学员先做听写挖空（perception 维度）→ 听准后再做跟读（production 维度）。"听懂 → 说出来"形成完整闭环。

学术依据：

  • Krashen 输入假说[67]：先得 i+1 input
  • Swain 输出假说[68]：input 不够，必须 push output
  • Tamai 1992[1]：shadowing > dictation 在听力上
  • Kadota 2019[8]：shadowing 4 效应中 monitoring 效应靠"先听懂再说"激活

为什么独有：需要听写挖空（半米已有 F1 模块）+ shadowing 评分（V0.2 上）的组合。

UX：

步骤 1: 听写挖空 → "She invented a ___ machine."
步骤 2: 学员填 "new" ✓
步骤 3: 系统弹出："听准了！现在试着说出来 →"
步骤 4: shadowing 模式 → 评分
步骤 5: 该词 mastery +1（听 1 次 + 说 1 次 = 双权重）

11.3 抓手 3: 6 例句多场景 × shadowing 重复

🎬 抓手 3 "6 例句"标准的新价值

什么：同一个 B1 词在 6 个不同场景跟读 → 等于 6 次不同语境的 selective shadowing → 词汇 productive 掌握。

学术依据：

  • Nation (2001)[2] 词汇 stages 演进：varied encounters → varied use
  • Pellicer-Sánchez & Schmitt (2010)[33]: 10-17 次 encounter
  • 同一个词在 6 个不同句子跟读 = 6 次 contextual production retrieval

对比：

  • 百词斩：1 词 + 1-2 例句，无跟读
  • 趣配音：长视频配音，无词汇标
  • Migaku：影视句子，无 6 例句标准
  • 半米：1 词 × 6 例句 × shadowing → 词汇深度习得

营销话术："不是听 6 遍发音，是在 6 个真实场景里说出来。"

11.4 抓手 4: AI 学员路径 + 错题回流

🔄 抓手 4 长期护城河

什么：学员对句子点 👎（"太难"或"听不懂"）→ AI 把这个句子分解：

  • 哪个词不会 → 加入 vocab 复习队列
  • 是 prosody 问题还是 phoneme 问题 → 推不同 shadowing 变种
  • 难度评估有偏差 → 调整 CEFR 标签

独家：需要半米的学员行为数据 + CEFR 词汇库 + 6 例句池三者打通才能做。

长期：积累几万学员的 shadowing 数据后，可训练专属"半米 ESL ASR 模型"（fine-tune Whisper），针对中国学习者口音准确率提升 — 这是流利说当年 309 亿句数据的护城河逻辑[24]。半米从一开始就要采集这类数据。

13FAQ · 阿杰可能问的 12 个问题▼

Q1Shadowing 到底跟 read-aloud / repetition / mimicking 有什么本质区别？+

核心区别在同步度：

  • Read-aloud：看字幕大声朗读（无原音参考）
  • Repetition：听一句、暂停、复述（延迟 5+ 秒，先理解再说）
  • Mimicking / Parallel：听完整段 → 短暂暂停 → 复述（延迟 1-3 秒）
  • Shadowing (Tamai 定义)：边听边说，延迟 ~0.5 秒[1]，几乎同步

Tamai 1992 关键发现就是"同步性"带来认知负荷的飞跃 — perception + production 并行而非串行 — 这是 shadowing 独有的训练效应。

Q2半米学员是 K12 + 入门成人，他们真的能做 shadowing 吗？认知负荷太高吧？+

对 — classic shadowing 确实对 A1-A2 学员认知负荷太高。但 Hamada-Suzuki 2024 整理的 16 变种[5]正是为解决这个问题：

  • A1-A2 学员先做 mumbling + parallel + prosody（低同步要求，可看字幕，可含糊）
  • B1 才进 classic + selective
  • B2+ 才进 content + 移除字幕

Hamada 2016 实证[3]：低水平学员甚至比中水平受益更大（前提是用对变种）。半米按 CEFR 推变种就行（详见第 3.3 节）。

Q3Web Speech API 中式英语识别那么差，V0.1 真的能用吗？+

能用，但要管理预期 — V0.1 是验证 UX + 流程，不是验证评分准确率。

策略：

  • V0.1 给学员讲清楚"AI 还在学，分数仅供参考"
  • 设宽松阈值：分 ≥ 70 都算"良好"，不死扣分
  • 多给 mumbling / prosody 类反馈，少给 accuracy 死磕反馈
  • V0.2 上 Whisper 后准确率显著改善（Whisper 比 Web Speech 在非母语口音上更好）
Q4为什么不一上来就用 Azure Pronunciation Assessment？+

3 个原因：

  1. 成本：real-time + prosody 维度按 $1/h+ 算，没规模时单学员成本占比高
  2. 过度工程：先验证学员愿不愿意按录音按钮、能不能跟上变种、是不是真在学；这些 UX 问题与 ASR 准不准无关
  3. 锁定风险：一上来绑死 Azure，后期想换成 Speechace / 讯飞 / 国产时已写死的代码改不动

V0.1-V0.2 用抽象的 PronunciationProvider 接口包好（accuracy / fluency / phoneme / prosody 四个方法），V0.3 接 Azure 时只换一个 provider 实现就行。

Q510-15 分钟/天 × 6 周才见效，这怎么留住用户？多邻国那种 streak 我们不做了。+

4 个不依赖 streak 的留存机制：

  • 30 天进步图：不是 streak，是真实进步可视化（accuracy 趋势、词汇 mastery 数）。学员看到自己变好 = 内驱
  • 词汇闭环奖励：跟读到 10-17 次 mastery 时 trigger "🎉 你掌握了 invent" 的庆祝
  • Selective Shadowing 的"今日 10 词"：有明确小目标，做完就有完成感
  • Pitch Contour 朋友圈：V1.0 起，学员可截图自己的曲线 + 进步 → 自传播 + 自我激励

父报告第 13 章详细讨论了 streak 的双刃问题[69]。

Q6Mumbling shadowing 学员含糊跟读，怎么判定"算完成了"？+

3 个间接信号：

  1. 录音时长 ≈ 原句时长（80%-120% 区间） → 说明学员真在跟读不是空跟
  2. 录音中段平均振幅 > 阈值（不全是静音）
  3. "含糊检测" — ASR 转写后置信度低（< 0.5）但有声音 → 这正是 mumbling 的特征

满足这 3 个 = 算完成。不判定 accuracy（mumbling 的目的不是字字对）。

Q7移动端怎么办？iOS Safari MediaRecorder 兼容性怎么处理？+

iOS Safari 14.5+ 支持 MediaRecorder，但格式是 mp4/AAC 不是 webm/Opus[26]。

标准做法：

const mimeType = 
  MediaRecorder.isTypeSupported('audio/webm;codecs=opus')
    ? 'audio/webm;codecs=opus'
  : MediaRecorder.isTypeSupported('audio/mp4')
    ? 'audio/mp4'
  : 'audio/wav';

const recorder = new MediaRecorder(stream, { mimeType });

服务端 ffmpeg re-mux 成 16kHz WAV 后给 ASR：

ffmpeg -i input.mp4 -ar 16000 -ac 1 -c:a pcm_s16le output.wav

Web Speech API 在 iOS 上不支持 — iOS 必须走 Whisper 后端（V0.2 起）。

Q8学员如果用普通话发音读英语怎么办？比如 "She" 读成 "西"？+

这是中国 ESL 的典型问题，Web Speech 和 Whisper 都会出现：

  • Whisper 可能识别成中文（或夹杂中英）
  • Web Speech 设 lang='en-US' 后会强制按英语转写，但准确率掉

3 种应对：

  1. V0.2 Whisper 加 prompt：--initial-prompt "She invented a new machine" 提示模型这是英语句子 → 显著提升准确率
  2. V0.3 Azure：用 referenceText 锁定 — Azure 知道原句，对偏离会精确判定为发音错误而不是转写错
  3. V0.3 讯飞 ISE：专为中式英语调优[57]，识别 "西-儿" 这种情况就能给到 phoneme 红黄绿反馈
Q9Selective Shadowing 要做"目标词出现时高亮 + 自动暂停"，技术上怎么实现？需要 word-level timestamp？+

对 — 需要视频例句的字幕带 word-level timestamp。

3 种获取方式：

  1. WhisperX 一次性预处理：所有视频例句库视频用 WhisperX (wav2vec2 forced alignment)[53]跑一遍，存到数据库 — 一次 1-2 美分/视频
  2. 已有 SRT 字幕：YouTube / 字幕组的 SRT 一般有 句级 timestamp，词级需要再细化
  3. 人工标注：6 例句的核心句子人工对齐（成本高但最准）

半米建议：现有视频例句库全量跑一遍 WhisperX，存 word-level JSON，是一次性投资 + 长期复利。

Q10Pitch contour V1.0 真的有学员看吗？会不会太极客？+

合理担忧。3 个设计原则避免太极客：

  1. 默认不展开：只有 prosody 分 < 80 时才弹出（说明有问题才看）
  2. 用通俗语言解释：不说"F0 contour"说"声音上下波动 / 重音命中"
  3. 红点标重音命中位置：学员看到"我重音对了"就有获得感

同时这是营销资产：朋友圈晒"看，我重音对了！"的截图，自带传播。Onsei Anki 用户社区里 pitch contour 截图是热门内容[40]。
