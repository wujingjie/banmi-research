🎯 5 条核心结论

颠覆 #1 多邻国"5 单元 = 4 学期大学课"是真的，但有大前提
Duolingo 官方研究 (Jiang et al. 2021, Foreign Language Annals) 显示完成 5 单元 = 4 学期大学西/法语课的阅读+听力水平[16]。但学界质疑：(1) 只测了识别（recognition），没测产出（recall / production）；(2) 听说读写四技能里说和写几乎没测；(3) 长期保持效果没数据[17]。

意思是：多邻国适合"被动识别 + 基础词汇"；想真用英语开口、写论文、读小说仍需别的方法。半米可以学多邻国的产品形态，但不能学多邻国的学习指标。
结论 #2 词汇习得"6+ 次 encounter"是误传，真实数是 10-17 次
Pellicer-Sánchez & Schmitt (2010) + Webb (2007) 在 SLA 经典研究里测得：5-8 次 encounter 开始有显著进步，10-17 次后形式 + 意义识别率达 ~80%[6]。Nation 本人 2017 综述也指出"完全掌握需 10+ 次重复"[3]。半米的 "6 例句" 标准是识别门槛（够用），但要"真用得出来"必须配合 SRS 让总 encounter 数到 10-17。
结论 #3 Shadowing 是最被低估的高 ROI 方法
Tamai (1992) 起 30 年研究稳定显示：每天 15-20 分钟 shadowing 几周即有显著的流利度、prosody、intelligibility 提升[10]。这是 SLA 学界共识里对成人学习者最 cost-effective 的方法之一。但市面 App 里把它做透的几乎只有日本系（Migaku / shadowing 类工具），中国系 App（流利说除外）大多不做。半米 V0.2 接入 Whisper ASR + 跟读评分是高 ROI 切入点。
结论 #4 "streak 系统"双刃 — 短期粘性强，长期可能伤害学习
Duolingo 内部数据：streak >7 天用户留存是普通用户 3.5 倍[18]。但 2022 用户调查：62% 漏一天会"内疚"，34% 看到通知会"焦虑"[34]，未成年人尤甚。教育心理学界开始警告 streak 制造"为不丢 streak 而学"的外驱动机替代[20][68]。半米若做 streak，必须设"streak 保护卡"和"健康暂停"机制。
结论 #5 钟道隆透析法 = 中国版 narrow listening + dictation，SLA 学界有交集
钟道隆 1980s 提出的"逐句听写慢速 VOA → 跟读 → 再听 → 再说"流派[37]，在 SLA 框架里恰恰是Krashen narrow listening[39] + 经典 dictation[8] + 轻量 shadowing 的组合。被中文圈贴上"伪科学/苦修"标签是片面的 — 它的"反对查字典""慢速反复"等做法本就是 i+1 + dictogloss 在中国 ESL 缺乏母语环境下的务实落地。半米的 VOA / SciShow Kids 视频例句库就是透析法的现代化版本。

🚀 给阿杰的直接结论

半米 V0.1 上线先做的 3 个方法对接（按 ROI 排序）：

  1. 视频例句库 + 6-12 次 encounter SRS（已在做，对应 Krashen narrow listening + Nation 频次理论 + Pellicer-Sánchez 10-17 次实证）
  2. 透析法 / 听写模式（视频例句 → 全字幕 → 部分挖空 → 全挖三阶；Whisper 自动批改；对应 dictation 学界证据 + Schmidt noticing[4]）
  3. Shadowing 跟读（视频例句循环播放 → Whisper ASR 评分 → 慢速→原速三阶；对应 Tamai 30 年研究[10]，是市场空白）

暂不做（坑深、ROI 低）：streak 系统（V0.3 再考虑，必带健康暂停）/ ChatGPT 全自由对话（B2 以下学员效果有限[28]）/ VR 沉浸（成本太高 / 词汇结果混杂[44]）。

02SLA 学界共识方法论 · 5 大理论底座▼

下面 5 大理论是 SLA 学界 1970-2010 间形成的共识底座。所有市面 App 的设计逻辑都能映射到这 5 个理论上 — 多邻国 = 输入 + 游戏化、Anki = 频次 + spacing、流利说 = 输出 + ASR feedback、Cambly = pushed output、shadowing 类 = noticing + procedural。本章把每个理论的核心论点 + 学界质疑 + 半米落地启示讲清楚。

2.1 Krashen 输入假说（Input Hypothesis, 1985）

📥 Comprehensible Input + i+1 + Affective Filter SLA 基石
Stephen Krashen (1985)，整套 Monitor Model 含 5 个 hypothesis[60]

5 个 hypothesis：(1) Acquisition-Learning（无意识"习得" vs 有意识"学习"，前者主，后者只能做监控）；(2) Monitor（有意识知识只能编辑产出，不是产出源）；(3) Natural Order（语法点习得有固定顺序，教学顺序改不了）；(4) Input（i+1，输入需略高于当前水平）；(5) Affective Filter（焦虑 / 低自信 / 低动机会"过滤"输入[60]）。

实证证据：narrow reading + narrow listening 在 Kang (2015) 等研究中显示能显著提升词汇习得[39]；95-98% lexical coverage 阈值（Laufer 1989, Nation 2006）支持 i+1 量化[7]。

学界质疑 ⚠️：Gregg (1984) 起就批 affective filter 缺实证 — 没办法测[1]；2025 Frontiers 神经生态学批评指出"i+1 太模糊，个体差异巨大，one-size-fits-all 不成立"[1][55]；忽略了 output 和 interaction 的作用。

半米启示：i+1 落地 = 用 B1 词例句优先匹配 A2 视频（已在 V1.1 频道标准做）；affective filter 落地 = 不强迫输出、错了不扣血（避开多邻国的内疚机制）。

2.2 Nation 词汇习得理论

📚 频次理论 + 4 stage of word knowledge + 95% coverage 词汇圣经
Paul Nation (Victoria University of Wellington)，Learning Vocabulary in Another Language (2001/2013)[2]

核心数字：

  • 95% lexical coverage（认识 95% 的词）= 阅读能"勉强懂"的下限，需 ~3,000 word families[7]
  • 98% coverage = 真正独立阅读，需 8,000-9,000 word families[7]
  • 10-17 次 encounter 才能可靠习得（Pellicer-Sánchez & Schmitt 2010；Webb 2007）[6]
  • 5-stage 词知识演进：noticing → retrieval → varied encounters → varied use → elaboration（Nation 三阶段 → 五阶段演化）[2]

实证：Pellicer-Sánchez & Schmitt 用真实小说 Things Fall Apart 测，10-17 次 encounter 后形式 + 意义识别率 ~80%[6]。单次 encounter 只对"识别词形"有效，"识别意义"和"recall 意义"都需要多次。

半米启示：(1) "6 例句"不够 — 那只到识别门槛，要让学员真用得出来必须配 SRS 让总暴露次数到 10-17 次；(2) 95% coverage = i+1 的量化下限，半米例句必须保证学员认识 95% 周围词才推（前面 vocab-research / subtitle-volume-estimation 已经做了）；(3) 5-stage 对应半米可设 5 档"词汇掌握度"标签。

2.3 Schmidt Noticing Hypothesis (1990)

👀 Noticing = 学到 / 没 notice 就没学到 主流但有争议
Richard Schmidt (1990, 2001) — 自己学葡萄牙语日记观察发起[4]

核心论点：学习者必须在意识层面 notice 到语言特征（语法、搭配、发音），才能习得它。无意识暴露不够。

实证支持：Leow (1997, 2000)、Izumi (2002)、Mackey (2006) 多项研究支持 noticing 与习得的相关性[4]。被认为是"SLA 主流构念"。

质疑：N. Ellis 等指出 formulaic sequences 可以无意识习得[4][5]；notice 到什么时候算"出现在产出"有时差，难测。

半米启示：(1) 词高亮 + 颜色标记（生词橙色、新词红色）就是 noticing 机制；(2) 听写挖空强制学员 notice 到目标词的拼写 + 发音；(3) 例句配对比（"这里用 since 不是 because"）就是 noticing 的最大化。

2.4 Swain Output Hypothesis (1985)

📤 Comprehensible Output + Pushed Output 输出派核心
Merrill Swain (1985) — 观察加拿大法语 immersion 学生只输入不输出，听懂但不会说[5]

核心反驳 Krashen：纯输入不够 — Swain 观察到加拿大法语 immersion 学生有大量 comprehensible input，但产出仍弱[5]。原因：输入时可以靠语义"猜过去"，输出时必须语法精确。

3 大功能：(1) Noticing — 产出时发现"我不知道怎么说"；(2) Hypothesis testing — 试说看反馈；(3) Metalinguistic — 用语言反思语言。

Pushed Output：让学员说/写稍高于当前水平的内容，逼他们调用 syntactic processing 而非语义 shortcut[5]。Sun 2020 综述显示 pushed output 在准确率和流利度上都有显著提升。

半米启示：(1) 跟读 + Whisper ASR 评分 = 最低成本的 pushed output；(2) 读后续写（中国流派"读后续写"由 Wang Chuming 2012 提出，证据强[64]）可以加入半米写作模块；(3) AI 对话（ChatGPT Voice） = 全自由 pushed output 但成本高 + 效果分化（参见 §13）。

2.5 DeKeyser Skill Acquisition Theory

⚙️ Declarative → Procedural → Automatic 认知派核心
Robert DeKeyser (1997, 2007, 2025 with Suzuki)[12]

3 阶段：(1) Declarative — 知道规则（"现在完成时用 have + 过去分词"）；(2) Procedural — 能在练习中正确用（思考几秒）；(3) Automatic — 用得快又准（不思考也对）。

关键证据：DeKeyser (1997) 显示 proceduralization 在前 16 个练习 block 内基本完成，之后是漫长的 automatization[12]。这就是为什么"懂了规则但说不出口" — 没过 procedural 关。

对教学的颠覆：练习量 + 类型多样性 + 即时反馈比"懂规则"重要得多。光看课文/听讲解只到 declarative，永远到不了 automatic。

半米启示：(1) 词汇不是"背"，是"练到 automatic" — 半米的多次 encounter + 跟读 + 听写 + AI 对话四种 modality = 4 种 procedural practice；(2) 反馈必须即时（多邻国做到了，所以快）；(3) 学员"看 6 例句"≠ 掌握，必须"用 6 例句做听写/挖空/跟读"才算 procedural；这一点对半米 UI 设计是核心。

2.6 Ellis Implicit vs Explicit Learning

🧠 隐性习得 vs 显性学习 两派之争
Rod Ellis (2005, 2009) — 设计了测量两种知识的标准测试[13]

两种知识：(1) Implicit 隐性 — 类似母语者直觉，不能 explain；(2) Explicit 显性 — 能说出"为什么" 的规则知识。

研究结论：多数对比研究显示 explicit learning 短期效果优于 implicit，但 implicit 知识才是真正的语言能力[13]。N. Ellis 用 frequency effect 证明无意识习得是真实的。

半米启示：(1) 半米需要两条并行 — 大量例句（implicit）+ 关键语法点的 explicit 解释（B1+ 学员需要）；(2) 不要把语法做成 Anki 卡（那是 explicit），而要做成"听 5 个例句然后选哪个对"（这才接近 implicit）。

2.7 五大理论的相互关系（综合视图）

输入 ──┐ │ [Krashen i+1] ←── 95% coverage (Nation) 量化 │ ▼ [Schmidt notice] ←── 高亮 / 挖空 / 提示 │ ▼ [DeKeyser declarative→procedural→automatic] │ ▼ 多次 encounter (Nation 10-17) [Swain pushed output] ←── shadowing / 跟读 / AI 对话 │ ▼ [Ellis implicit/explicit 双知识系统] │ ▼ 真实语言能力

怎么读这棵树：从可理解输入开始 → 学员要 notice 到目标 → 通过多次 encounter + 多模态练习把 declarative 推到 automatic → 通过 pushed output 暴露 gap 反哺输入 → 最终形成 implicit + explicit 双重知识。半米的"视频例句 + 听写 + 跟读 + AI 对话"四件套就是这条链路的产品化落地。

03听写 Dictation · 深度方法学▼

听写在欧美 SLA 学界经历了"过气 → 复兴"的轮回。1970s 被批"机械"；2000s 后 Cai (2013)、Kuo (2010)、Prince (2013) 等研究持续证明它是 listening proficiency 最强的测量工具之一[8][9]，也是高效练习手段。

3.2 学界证据

🟢 多源验证：

  • Cai (2013)：partial dictation 在 367 名 EFL 学习者上 confirmatory factor analysis 证明它与"高阶 listening"测的是同一个构念（不是低阶机械能力）[8]
  • Kuo (2010)：partial dictation 配合英语广播持续训练能显著提升 listening comprehension[8]
  • Prince (2013)：dictogloss 学生在语法准确性上显著优于对照组[9]
  • Wajnryb (1990)：dictogloss 原创人，证据强调"reconstructing"比单纯听写更能促 noticing[9]
  • 2016-2024 综合 40 篇 dictogloss 研究显著提升写作连贯性 + 语法准确率[9]

3.3 听写的难度阶梯（半米 V0.2 阶梯设计）

L0：全字幕显示 → 学员只听 + 跟读（不挖） L1：挖目标单词 → "I ____ to school yesterday"（挖 went） L2：挖目标词 + 周边 → "I ____ ____ school yesterday"（挖 went to） L3：挖词组 → "I ____ yesterday"（挖 went to school） L4：挖句首/句尾片段 → "____ school yesterday" L5：全句无字幕 → 标准 → 学员从听到打字一字不差

3.4 错误诊断价值

关键洞察：听写错的位置 ≠ "粗心"，是学员真实音系/词汇盲点的诊断信号：

  • 错 thought → /θ/ 音盲点（中国学员典型）
  • 错 have been → reduced form 听不出（连读）
  • 错 their / there / they're → 词形混淆（noticing 不到位）
  • 错 insurance 拼成 ensurance → 拼写规则盲点

半米可以做错题数据画像 — 学员每错 1 次自动归到对应"诊断标签"下，10 次后给出弱项报告。

3.5 半米对接

V0.1 实施清单（已与视频例句库无缝接入）：

  1. 每个视频例句默认 L0 全字幕模式；点 🎯 切换到 L1 挖目标词
  2. 学员打字框 → 实时比对字幕 → 错字标红，提示再听
  3. 第 3 次错触发"慢速重听"（YouTube iframe playbackRate=0.75）
  4. 第 5 次错给完整答案 + 拆分音节 + 类似词 link
  5. 错题自动加入 SRS 复习队列，并标注"音系/拼写/连读" 3 大诊断标签

04跟读 Shadowing · 深度方法学▼

Shadowing 起源自口译训练（同声传译预备练习），1990s 由日本学者 Tamai 系统化引入 EFL，30 年研究稳定显示是对成人学习者最 cost-effective 的方法之一[10]。

4.2 学界证据（高强度的多项 meta-analysis 支持）

🟢 多源验证 + 30 年累积证据：

  • Tamai (1992) 起：每天 15-20 分钟 shadowing，几周内显著提升听力 + 流利度[10]
  • Hamada (2016) 综述：shadowing 对低水平学习者增益最大[51]
  • Foote & McDonough (2017)、Mori (2011)：mobile shadowing 显著提升发音准确率和 prosody fluency[10]
  • 2025 系统综述（Tandfonline）：shadowing 对 comprehensibility、intelligibility、accentedness 都有积极证据，但对 segmental（音段）改善证据不一致[10][11]
  • 越南、台湾、土耳其多项 quasi-experimental 研究均显示实验组显著优于对照组[11]

4.3 Shadowing 起效门槛

⚠️ Shadowing 需要正确做法 + 持续时间，不是听几遍就行：

  1. 难度匹配：材料必须 i+0 到 i+1 — 听不懂的内容 shadowing = 鹦鹉学舌，无效
  2. 时间：每天 15-20 分钟，连续 4-8 周才有可测增益
  3. 录音回放：自己 shadowing 时录下来，回放比对原音，noticing 自己跟原音的差距（Schmidt 理论焊接）
  4. 分阶段：先 Parallel Reading (看字幕) → Chorus (跟字幕一起) → Shadowing (无字幕同步) → 才进阶到 Mirror

05绘本阅读 · 4 层教学法 (Fountas & Pinnell)▼

Fountas & Pinnell 框架是欧美 K-G2 阅读教学事实标准，全美几乎所有公立小学采用[19]。半米要做 K12 国际学校 + ESL，绘本就要照这套来。

5.1 4 层（实际 5 层）教学法

L1 Interactive Read-Aloud（家长/老师读 — 全包扶持）
难度：可以超过学员独立阅读水平。谁主导：成人完全主导。核心：让孩子接触更高级语言模式（"听懂"上限可比"读懂"高 1-2 年级）。Ms Rachel 的视频本质是 read-aloud[40]。
L2 Shared Reading（共同读 — 高扶持）
难度：略高于独立水平。做法：放大文本（big book / 屏幕），师生齐读，老师指词。核心训练：concept of print（从左到右、词与音对应）。
L3 Guided Reading（引导阅读 — 中扶持）
做法：4-6 人小组，老师选与组水平匹配的 leveled book。学员先独立读，遇到困难老师引导（不直接给答案）。Fountas & Pinnell 把"小组"是这一层的灵魂[19]。
L4 Independent Reading（独立阅读 — 低扶持）
做法：学员自选 just-right 书独立读。五指法则：开页读，每页不认识 2-3 个词 = 刚好；0-1 个 = 太易；4+ = 太难[21]。配合 Day & Bamford extensive reading 10 principles（读得多、自选、为乐趣读、读快不读慢）[14]。
+ Book Clubs（书友会 — 同伴互动）
F&P 完整框架还有第 5 层 — 学员小组讨论某本书。这一层最难数字化，但Discord/IM 群组 + AI 主持可以模拟。

06原点 / 透析法 · 钟道隆系深度解读 + SLA 对照▼

"透析法" / "逆向法" 是 1980s 中国少将钟道隆（45 岁零基础自学英语成同声传译）原创的中国 ESL 流派[37]。中文圈毁誉参半：被赞"务实有效"，也被批"机械苦修"。本章用 SLA 学界框架重新审视。

6.1 透析法核心做法

第 1 步：选材料 — VOA Special English 慢速（1500 词控制写法[37][66]） 第 2 步：听 — 一句一句听，每句反复听 5-10 次直到听懂 第 3 步：写 — 听懂之后逐字写下来（即 dictation） 第 4 步：对照 — 跟原文对，找出错处 第 5 步：背 — 把全文背下来 第 6 步：跟读 — 跟原音读 第 7 步：想 — 反思错处的原因（音系？词汇？连读？） + 关键纪律：不查字典（强迫上下文推断 / Krashen 风格）

6.2 SLA 学界框架对照

透析法做法SLA 学界对应证据等级
慢速 VOA = i+0 to i+1Krashen 输入假说[1]🟢 经典理论

🟢 反共识结论：透析法 = Krashen narrow listening + classical dictation + Tamai shadowing + Schmidt noticing 的"中国式 7 步组合"。把它当"伪科学"是不读 SLA 文献的偏见。批评点不在方法本身，而在"零基础就能学会"的过度承诺 + 单一材料过久造成兴趣丢失。

6.3 透析法局限 + 修正

⚠️ 3 大局限：

  • 儿童不适用 — 透析法需要高自律 + 抽象推理能力，钟道隆原版是给 45 岁中年男人设计的。给 K12 学生硬套会激发逆反。
  • 纯输入不够 — Swain output 假说 (1985) 证明 immersion 学生光听不说也练不出来。透析法应 + AI 对话 / 跟读评分。
  • "不查字典"门槛高 — Laufer (1989) 显示需要 95%+ coverage 才能 incidental 学到生词[7]。零基础学员 VOA 1500 词都不到，"不查字典"等于猜。修正：A2 以下应该查，B1+ 才执行"不查"。

6.4 透析法的现代化版本 = 半米

半米对接：半米已经在做"透析法 2.0"：

  1. VOA Special English 视频例句库（V0.1 5 家中已选）+ SciShow Kids + Crash Course Kids — 比 1980s 的录音带丰富 100 倍
  2. iframe 跳秒 — 学员可以反复听同一句（钟道隆要倒带，半米一键）
  3. 挖空听写（参见 §3.3）— 把"逐句写下来"自动化打分
  4. Whisper 跟读评分（参见 §4.5）— 把"跟读"做客观反馈
  5. AI 上下文推断助手 — 学员遇到生词不直接给翻译，先给"这个词在这里啥语境下出现"（Khanmigo Socratic 模式[59]）→ B1+ 学员 / A2 以下给直接翻译
  6. SRS 节奏（FSRS[22]）替代钟道隆"凭感觉重听"，更高效

定位话术："半米 = 钟道隆透析法的 AI 时代落地"。给中国家长一句话能听懂的卖点。

半米路线：iframe 跳秒已经做了（参见 youglish-tech / clip-pipeline）— 这本质是"自建半米版 Language Reactor"。下一步加双语字幕切换。

Cambly：母语教师，主打 conversation，不要求认证。

08视频库建设 · 3 种方案 + 组合决策树▼

这一章直接回答阿杰的具体问题：半米视频库到底走哪种？前面 youtube-vocab-channels-research + subtitle-volume-estimation + banmi-vocab-channel-standard 三份报告聚焦"频道选什么"，本章聚焦"库的整体形态"。

8.1 3 种库设计对比

方案 A 单 IP 库（如 Peppa Pig 全集 700+ 集）

优势：

  • 词汇重复率超高 — Peppa Pig 一项 EFL 研究测得：前 3000 word families + 专有名词覆盖 95.45%[49]
  • 角色一致性 — Peppa / George / Daddy Pig 等同一组人物 = 学员认知锚点稳定
  • 场景渐进 — 学校 / 公园 / 游泳池等场景有规律出现
  • 同一发音风格 — Peppa = 英音标准、Cocomelon = 美音 — 学员不被多口音淹没
  • Greek EFL 研究：4-5 岁孩童看 4 集 Peppa（80 min）+ 测试 = 识别率 ~33%，4 岁组词汇翻倍，5 岁组三倍[49]

劣势：

  • 词汇范围窄 — Peppa 主要是 family/school/play 主题，缺商业/学术/科技词
  • 易听腻 — 同一组角色看 100 集后多巴胺锐降
  • 缺多样性 — A2-B1 之后基本词覆盖完了边际效用骤降

适用阶段：A1 启蒙（K-G1）— 阿杰在 banmi-vocab-channel-standard P1 已经写了"A1 词例句全 A1 视频，i+0 启蒙不打乱"。

方案 B 分级混合库（半米现在 17 家方案）

优势：

  • 广度 + 多样性 — Sesame / SciShow Kids / Bob the Canadian / VOA 4 家就覆盖了启蒙 / 科普 / 街头 / 新闻 4 种场景
  • i+1 配比可严格控制（参见 banmi-vocab-channel-standard P3 铁律）
  • CEFR 严格分级 — 17 家按 A1-C2 六档分桶
  • 学员"喜欢这家不喜欢那家" — 不会全盘抛弃半米

劣势：

  • 词汇重复不够密集 — 4 家轮换则每词每家平均出现次数减半（vs 单 IP）
  • 角色不一致 — 学员需要适应 Sesame 的 Elmo + SciShow 的 Jessi 等多套角色
  • 口音混杂 — A1-B1 学员对多口音不友好

适用阶段：A2-B1 主力（小学高年级 + 初中）— 这恰是阿杰的目标人群。

方案 C 场景库（厨房 / 学校 / 户外各 300 视频）

优势：

  • 场景化记忆效率高 — 跟 narrow listening 理论一致[39]，相同场景词反复出现
  • 主题词学习集中 — 学"厨房"就把 stove/knife/pan/peel/chop 一次学透
  • 易迁移 — 学员去真实厨房用得上

劣势：

  • 跨场景泛化弱 — 学完厨房还要重新学客厅
  • 工程量大 — 切分 + 打标 5000+ 视频需要大量人力
  • 分级困难 — 同一"厨房"主题里有 A1（kitchen）也有 C1（julienne）

适用阶段：B1+ 进阶 + IELTS/TOEFL 主题词冲刺。

9.2 Hook Model 4 步拆解（Nir Eyal 框架在多邻国的精装落地）

Step 1 Trigger（触发）
推送通知 "You're one lesson away from keeping your 14-day streak"[31]，定时性触发（lunch break / before bed），用 urgency + loss aversion 调起 action。每天平均 4-7 条通知，逐渐升级语气（"Duo misses you" → "Duo is sad" → "This is your last chance"）。
Step 2 Action（行动）
点开通知 = 直接进 lesson；不需要找入口。lesson 设计成 5 分钟 / bite-sized — 这是 Hooked 框架"降低 action 摩擦"的最大化。学员上线即玩，玩完即出。
Step 3 Variable Reward（变动奖赏）
每次 lesson 完成的奖励随机：奖励 XP / 解锁新 skill / 满分庆祝动画 / level up / 宝箱 / 通关后 surprise streak freeze。这是赌博机 / 老虎机原理（Skinner box / variable ratio reinforcement）— Nir Eyal 自己说这是 Hook 4 步里最关键的一步[30]。大脑永远不知道下一次会拿什么 → 多巴胺持续分泌。
Step 4 Investment（投入）
streak 系统 = investment 的极致体现。越长的 streak 越难放弃（loss aversion + sunk cost）。配合 streak freeze（用 gem 买保命）= 把焦虑转化为变现。streak > 7 天用户留存是普通用户 3.5×，这是多邻国内部数据[18]。

9.3 streak 心理学详拆

Kahneman-Tversky prospect theory：人对"失去"的痛感是"得到"同等价值的 ~2 倍[18]。streak 把"已经积累 200 天"从抽象数字变成个人身份资产 — 失去 = 自我形象崩塌（"我不是那种能坚持的人"）。

多邻国进一步加强：

  • 火焰动画 — 当天没完成时火焰逐渐变小（视觉紧迫感）
  • Duo 表情 — 不学习时小猫头鹰悲伤、流泪、抑郁 → 学员对一个虚构动物产生愧疚 = 拟人化欠债关系
  • Streak Freeze (购买物) — 把焦虑直接货币化
  • 10 mil 用户里 1% 有 300+ day streak — 这部分用户是利润核心

9.6 半米能学什么 / 避开什么

✅ 半米可学：

⛔ 半米避开：

  • Streak 系统（V0.1 不上 — V0.3 再考虑，且必带"健康暂停"）— 见 §13
  • Streak Freeze 货币化 — 把焦虑当生意是道德灰色
  • 排行榜 + leaderboards — 制造同伴焦虑 + 攀比，对国际学校敏感家长是 deal-breaker
  • "心数 (hearts)" 错就扣血 — Affective Filter (Krashen[1]) 升高，焦虑学员退课
  • 过度通知 — Duolingo 用户调查 34% 看到通知会焦虑[34]，国际学校家长会投诉
  • 课程"识别"导向（只测 multiple choice）— 必须配 production 任务（跟读 / 听写 / 写作）才到 DeKeyser procedural 关

13.2 学界 + 教育心理学的 3 大警示

警示 1 Motivation crowding out（动机替代）
外部奖励（XP / streak）会逐步替代内在动机（真想学语言）。这是教育心理学经典 finding（Deci & Ryan SDT）。一旦"streak 系统消失"，学员不再因为 streak 来，但也已经丢失"因为想学英语而来"的初心 → 留存崩溃。
警示 2 Engagement ≠ Learning
多个 SLA 学者 2023-2025 公开撰文质疑 von Ahn TED talk[33]："motivation 应该是 learning 的手段而非目的。当 engagement 成主要 KPI，产品就被 metric goal-divergence 拖偏。" 多邻国的 NPV 由 streak 用户撑起，这是上市公司故事；但学员的语言水平 NPV 没人测得清楚。
警示 3 未成年人心理健康风险
2025 多项儿童心理学研究[68] + 家长投诉表明：streak 系统对 12 岁以下儿童引发损失厌恶 + 强迫倾向 + 焦虑。一篇 Substack 父亲贴文"我女儿戒掉 Duolingo 因为 streak 让她哭" 引发广泛共鸣[20]。国际学校家长群对此尤其敏感。

13.3 反对方观点（不能一边倒）

🟡 持平视角：

  • "没有引擎就根本不学" — 一个 Duolingo 用户的 streak 即便不完美，至少他在动。比"完美方法但不动"强 N 倍。
  • gamification 减少 anxiety（部分研究[68]）— 把"应试英语"包装成"打怪升级"，对 K12 应试焦虑学员是正向缓冲。
  • Quizlet vs 纸卡研究[23] — 学习成果相同但 engagement 显著更高，最终决定坚持时长 → 总学习量增加。
  • 多邻国词汇研究 — 学生确实在词汇 test 上比传统方法的对照组好[17]。

13.4 半米的拍板路线

无忌建议：取中间路线 — "软驱动" 不要 "硬绑架"

  • ✅ 真实进度可视化 — 学员能看"30 天学了 N 词 + 完成 M 任务 + IELTS 7 还差多少词"。真进度比 fake gamification（XP / level）更可信。
  • ✅ 软通知（"无忌给你准备好今天的 10 例句了"），不威胁不内疚
  • ✅ 解锁感（"恭喜你解锁了 SciShow Kids 第 30 集" = 真实学习里程碑）
  • ✅ 家长仪表盘 — 让家长看到学员真实成长，转化"我玩 app" → "我学英语"
  • ⛔ 不做硬 streak（V0.1）— V0.3 才考虑加，且必带"健康暂停"（请假 / 度假 / 病假不破 streak）
  • ⛔ 不做 leaderboards — 制造同伴焦虑
  • ⛔ 不做扣血 / 损失 — affective filter 是 Krashen 5 大假说之一
  • ⚠️ 梗化营销 可以做（无忌 / 三丰 mascot 梗），但不能用威胁通知做内容

14.2 详细学员使用流程（按 SLA 方法分组）

F1 听写模块 (Dictation) V0.1 优先

学员流程（具体到点击）：

  1. 学员打开半米 → 进 "今日学习" → 看到 10 个新词 + 30 个复习词
  2. 点击词 congratulations → 看到 6 个视频例句
  3. 点击例句 ▶️ → YouTube iframe 跳到 0:23 开始播放（前一句和当前句字幕显示）
  4. 切换 🎯 听写模式 → 字幕变成 "I want to say ____ to everyone here"
  5. 学员打字 → 实时 diff 反馈：正确字符绿色，错误红色
  6. 第 3 次错 → 自动降为 0.75x 慢速重播
  7. 第 5 次错 → 显示完整答案 + 音节拆分 (con-grat-u-LA-tions) + 类似词 link
  8. 错题自动归类（音系 / 拼写 / 连读）+ 进 SRS 复习队列
  9. 完成 6 例句 → 进度 +1，下一个词

对应 SLA 理论：Schmidt noticing + Cai 2013 partial dictation 学派 + DeKeyser procedural。

F2 跟读评分模块 (Shadowing) V0.2

学员流程：

  1. 从视频例句界面点 🎤 进入跟读模式
  2. 3 阶进度条：L1 Parallel（看字幕，听一句暂停跟）→ L2 Chorus（带字幕同步跟）→ L3 Shadowing（无字幕同步跟）
  3. L1 阶段：学员点录音按钮 → 播放例句 → 暂停 → 学员跟读 → 录音上传
  4. Whisper ASR 转写 + 与原文字符级 diff + Speechace 音素级评分（V0.2 上 Speechace）
  5. 反馈：每词单独 🟢/🟡/🔴 + 整体分数
  6. 错音点击 → 慢速播放 + 口型示意图（V0.2 接 forced alignment）
  7. 5 次后 L1 解锁 L2，10 次后 L2 解锁 L3
  8. 每周 5 个 shadowing 任务 × 15-20 分钟（Tamai 起效门槛[10]）

对应 SLA 理论：Tamai shadowing 30 年研究 + Swain pushed output + DeKeyser automatization。

F3 阅读屏 + 4 层模式 (F&P) V0.2-V0.3

学员流程：

  1. 学员进绘本首页 → 按 Lexile / CEFR / F&P Level 三种分级选书
  2. 开页 → 5 finger test 自评（"不认识的词 N 个" → 1-3 = 刚好，0-1 = 升级，4+ = 降级）
  3. 选 4 种模式：L1 听读（AI 配音家长读）/ L2 共读（指词跟读，词高亮）/ L3 引导（卡词时 AI 用引导问句，参考 Khanmigo 模式[59]）/ L4 独读（自由读 + 词典查询）
  4. 读完 → 拓展任务（4 选 1）：复述 / 词卡 / 写作续写 / 角色扮演
  5. 写作续写 = 中国流派 Wang Chuming 读后续写法[64] + AI 反馈

对应 SLA 理论：Fountas & Pinnell + Day & Bamford extensive reading + Wang Chuming continuation。

F4 透析法模式 (钟道隆 7 步现代版) V0.2

学员流程：

  1. 学员点"透析模式" → 选 VOA Learning English / SciShow Kids / Crash Course Kids 一篇视频
  2. 步骤 1 听：视频先无字幕播放整段（学员有意识"我听到了什么"）
  3. 步骤 2 逐句听写：逐句循环（默认 3 次），学员打字
  4. 步骤 3 对照：每句完成后 diff 字幕（粒度到字符）
  5. 步骤 4 背：错的句子加入"今日背诵列表"
  6. 步骤 5 跟读：背完后跟读评分（接 F2 模块）
  7. 步骤 6 想：错处自动分析（音系/拼写/连读）并提示
  8. 步骤 7 不查字典：B1+ 默认开启"先猜后查"，A2- 默认关闭

对应 SLA 理论：钟道隆 + Krashen narrow listening + Cai dictation + Tamai shadowing 综合套餐[37][39][8][10]。

F5 AI 对话 (限定场景, 不全自由) V0.2-V0.3

3 个限定场景（比 ChatGPT 全自由对话更适合学员）：

  1. 单词测试：AI 用今天学的 10 个词问问题（"Can you describe a time when you felt nervous?"），学员说，AI 评估目标词出现率 + 语法 + 流利度
  2. 故事接龙：AI 给故事开头 → 学员续 1 句 → AI 续 1 句，循环 10 句。结束 AI 给反馈。
  3. 视频 follow-up：看完 Bob the Canadian 视频 → AI 问 5 个 comprehension question，学员说答案

技术：GPT-4o Voice / 国产替代（豆包 / Kimi Voice）。不做全自由 chat — 学员无目标会卡住 + 评分难。

对应 SLA 理论：Swain pushed output + 限定场景 = 半米的 narrow listening 配套。

F6 歌词挖空模块 V0.3

学员流程：

  1. "听歌学英语" tab → 选 A2-B1 难度英文歌 / 儿歌
  2. 挖目标词（半米词库当前学的 10 个词如果在歌里则优先挖）
  3. 歌词随旋律播放，到挖空处暂停，学员打字
  4. 对了 = 继续；错了 = 重听一次副歌
  5. 完整唱完 = streak +1（这里 streak 是合适的 — 听歌本身是娱乐 affective filter 低）

对应 SLA 理论：Wang & Liu 2025 singing 优于 speech[53] + Schmidt noticing + Krashen 低 affective filter。

F7 游戏化（取多邻国精华 / 避开坑） V0.2

学多邻国 ✅：

  • 5 分钟 bite-sized lesson — 降低启动摩擦
  • 即时反馈（每题对错立即看到）
  • Variable reward（完成动画 / 解锁新 chapter / 满分庆祝）
  • Mascot 角色化（无忌 + 三丰）
  • 真实进度可视化（看到"距 IELTS 7 还差 X 词"）

避开多邻国 ⛔：

  • 硬 streak（V0.1 不上，V0.3 再考虑带"健康暂停"）
  • Streak Freeze 货币化
  • 排行榜 / leaderboards
  • 心数 / 扣血
  • 过度威胁通知（"Duo is sad" 式拟人化情感勒索）

对应 SLA 理论：Krashen affective filter（不焦虑）+ DeKeyser procedural（即时反馈）+ Hook Model 软驱动版本。

F8 词汇分级 + i+1 配比铁律 V0.1 ✅

已经在做（参见 banmi-vocab-channel-standard）：

  • CEFR A1-C2 六档分级
  • i+1 配比铁律：B1 词例句优先 A2 视频，绝不超 B1
  • P4 C1/C2 视频价值递减原则

本报告补充：

  • 5-stage 词知识演进（Nation noticing → retrieval → varied → varied use → elaboration）= 半米词卡 5 档掌握度标签
  • 10-17 次 encounter（Pellicer-Sánchez 实证）= SRS 调度目标
  • 95% / 98% coverage 阈值（Laufer / Nation）= 半米推词时"周围词识别率"检查

14.3 半米的"4 模态练习"焊接 DeKeyser proceduralization

每个目标词在半米的 4 模态练习 📖 看（reading） ── 字幕 + 例句 + 释义 ← declarative 👂 听（listening） ── 视频 + 跟读 ← procedural 起步 ✍️ 写（writing） ── 挖空听写 + 续写 ← procedural 🎤 说（speaking） ── 跟读评分 + AI 对话 ← automatic 每词必须经历 4 模态至少 1 次才算"掌握" → SRS 间隔加长 单一模态 = 半米降级为 Duolingo / 不背单词

16FAQ · 14 条阿杰最常问的▼

Q1.多邻国学习效果是不是真有用？我跟孩子家长怎么说？+

答：双视角说。Duolingo 官方 Jiang 2021 论文：5 单元 = 4 学期大学课的识别能力[16]。但学界质疑：(1) 只测识别不测产出；(2) 听说读写四技能里产出技能几乎没测；(3) 长期保持没数据[17]。

对家长话术："多邻国适合零基础启蒙 + 单词识别，但学到能开口能写作必须配跟读 / 听写 / 真人对话。半米是这个组合包。"

Q2.Shadowing 真能改发音吗？还是听起来玄学？+

答：能，证据强。Tamai 1992 起 30 年研究：每天 15-20 分钟连续 4-8 周显著提升 prosody + intelligibility + comprehensibility[10][11]。但前提：(1) 材料难度匹配 i+0 到 i+1；(2) 录音回放 noticing 自己 vs 原音差距；(3) 持续够久。市面 App 把 shadowing 做透的少，半米 V0.2 上这块是高 ROI 切入点。

Q3.透析法适合儿童吗？我女儿 9 岁能用吗？+

答：钟道隆原版不适合儿童（他是 45 岁中年男人发明的，自律 + 抽象推理要求高）。半米的"透析模式 2.0"对 9 岁可以用 — 我们把 7 步流程做成 5-10 分钟一段的视频任务 + 即时反馈，不需要孩子自驱"重听 10 遍"。难度匹配在 A1-A2 SciShow Kids / Crash Course Kids 而非 VOA 1500 词慢速版。

Q4.Streak 设几天合理？要不要做？+

答：V0.1 不做，V0.3 才考虑，且必带"健康暂停"（请假 / 度假 / 病假不破 streak）。Duolingo 内部数据 streak >7 天留存 3.5×[18]，但 62% 用户漏一天会"内疚"[34]，对国际学校家长是 deal-breaker。真正激发的不是 streak 而是"真实进度可视化"（"30 天学了 200 词 + 距 IELTS 7 还差 1500 词"）。

Q5.ChatGPT Voice 能替代 italki / Cambly 吗？+

答：不能完全替代。2025 研究 ChatGPT Voice 显著降低 speaking anxiety + 提升基础发音[41]，但复杂语境、文化暗示、修辞表达 AI 仍弱。半米路线：自家做"限定场景"AI 对话（单词测试 + 故事接龙 + 视频 follow-up），V0.3 接 italki API 给真人实战。

Q6.为什么 6 例句不够？我已经做了 6 例句怎么还要改？+

答：6 例句是 Nation 老版 "识别" 门槛。但 Pellicer-Sánchez & Schmitt 2010、Webb 2007 实证：要达到"recall + production" 需要 10-17 次 encounter[6]。解决方法：6 例句首次学 + SRS 让总 encounter 在 30 天内累积到 10-17（每次 1-2 例句 + 偶尔再加新例句）。半米 V0.1 SRS 默认调度已经焊死这套节奏。

Q7.国际学校学员真的会用半米吗？他们都用 Khanmigo 了。+

答：Khanmigo 强在 STEM tutor（数学 / 科学），早期 2025 在 language arts 仍弱[59]。半米的差异化：母语非英语的 ESL 学员定制 + CEFR 严格分级 + 视频例句库 + 跟读评分 — 这些 Khanmigo 都不做。共存关系：学员用 Khanmigo 学数学 + 半米学英语。

Q8.百词斩 / 不背单词都做了 N 年，半米差异化在哪？+

答：4 大差异（参见 §11.3）：

  • iframe 跳秒 = 真实视频感（不背是音频 / 短切片）
  • CEFR 严格分级（不背仍按四六级 / 考研分）
  • K12 国际学校定位（不背仍国内应试）
  • 跟读 / 听写 / AI 对话联动（不背只做"看例句选词"）
Q9.Anki 那么强 + 免费，半米凭什么收钱？+

答：Anki 是极客工具，不是产品 — 学习者要花 2-4 周才会用，词卡需要自建 / 找牌组。半米是"Anki + 视频例句 + 跟读 + AI + 分级 + 家长仪表盘"all-in-one，10 分钟上手。Anki 用户和半米用户重合度低（Anki 用户是医学生 + 高级语言极客，半米是 K12 国际学校）。半米可以做"Anki 兼容 export"满足重度用户两边同步。

Q10.FSRS 真比 SM-2 强多少？值得 V0.2 升级吗？+

答：同等留存 FSRS 少 20-30% 复习次数[22]。但前提：用户已积累 ~1000 次 review，FSRS 才能拟合个人 model；之前 fallback 跟 SM-2 差不多。建议：V0.1 用 SM-2（简单），V0.2 后台并行 FSRS（无感升级），用户积累 1000+ review 自动切。

Q11.绘本动画化做完了，怎么跟 4 层教学法绑？+

答：参见 §5.4。半米动画绘本 = L1 Read-Aloud 自动化版（AI 配音 + 节奏控制）。下一步加：L2 共读"指词跟读"按钮 + L3 引导"AI 卡词助教"按钮 + L4 独读"5 finger 自评" + L5 Book Club（V0.3 Discord 群）。整套是 F&P 框架的电子化。

Q12.Whisper 对中国学员发音识别准吗？+

答：Whisper 对 native speaker 准确，对非母语者 error rate 显著上升[42]。解决：(1) 用 prompt 提示（"this speaker is a Chinese learner of English"）；(2) 字面 diff + 音素近似度双层判断；(3) V0.2 接 Speechace API（专测非母语者，IELTS/TOEFL 等校 0.9 Pearson[42]）。Whisper 用作低成本 V0.1 baseline，Speechace 给 V0.2 升级。

Q13.读后续写 (Wang Chuming) 适合 K12 国际学校吗？+

答：适合 B1+ 学员（小高到高中）。Wang Chuming 2012 起 10 年+ 中文圈实证：interactive alignment 显著提升写作准确率 + 流利度[64]。半米实施：绘本读完后给"续写"任务 → AI 配关键词提示（learners pay attention to person/tense/vocab/sentence/rhetoric, 续写时模仿原文风格）→ 提交后 AI 反馈（参考原文哪点 align 哪点偏）。
