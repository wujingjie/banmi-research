Agent Harness 是什么 · 模型=大脑、harness=身体 · 小白向 + 怎么用好
Agent 概念 / 架构 L2 · 3 路并行 Workflow 已完成 · 为何比模型重要 / 部件 / 横评 / 怎么用好 / Codex 审查
把"harness"这个热词彻底讲懂（小白向）。三条核心：① Agent = Model + Harness——模型只是会输出文字的大脑，harness 是让它能干活的身体（工具/循环/记忆/权限/重试/编排）；同一个 Claude Opus 换 harness，CORE-Bench 分数从 42% 区间跳到 78%~95%，差出一两个模型代差。② harness 不是越多越好——Vercel 砍 80% 工具、成功率 80%→100%；"为旧模型写的脚手架"会变死重，要随模型迭代做减法（直接对应你审一遍 30+ skill）。③ 做 AI 产品护城河在 harness 不在模型——Claude Code 泄露源码 98.4% 是 harness、1.6% 才是 AI 逻辑；你写 CLAUDE.md/skills/MC 本质就是 harness 工程。🔬 Codex 四维审查：校验收紧 benchmark 口径、标注 OODA 为类比、补国内合规/MC 差距表/安全威胁模型/"何时不值得投" 待深化清单。· 11 章 + 11 FAQ + 35 引用
