🌐 国外知名 K12 学习网站/系统清单

为半米产品调研整理 · 2026年9月

🔍 关键发现

主流三巨头：Google Classroom (免费生态) / Canvas K-12 (功能全) / Schoology (中学强)

自适应趋势：Khan/IXL/DreamBox 都用 AI 实时调整难度，2024 研究显示数学/阅读成绩明显提升

年龄段分化：Seesaw 专攻小学，Schoology 偏中学，Canvas 全覆盖

📚 学习管理系统 (LMS)

Google Classroom 免费最流行
与 Google Workspace 深度集成，K12 最广泛使用的 LMS 平台，支持作业分发、评分、师生协作。
访问官网 →
Canvas K-12
Instructure 出品，功能全面，支持教师/学生/家长/学区管理，移动优先设计，开放 API 易于集成。
访问官网 →
Schoology
PowerSchool 旗下，连接课堂与数字学习，中学使用多，强调协作工具和课程管理。
访问官网 →
Microsoft Teams for Education 免费
微软教育生态，集会议、协作、作业管理于一体，与 Office 365 深度整合。
访问官网 →
Moodle 开源
开源 LMS，全球 10 万+站点使用，支持 140+ 语言，高度可定制化。
访问官网 →
Seesaw
专注小学(elementary)，2500 万+用户，强化家长沟通和学生作品展示，提升学校文化。

DreamBox
K-8 数学自适应学习，结合脚手架式教学和持续形成性评估，个性化每个孩子的学习路径。
