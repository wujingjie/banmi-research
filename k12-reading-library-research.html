1. 结论摘要

半米阅读板块不应该先做“海量图书馆”，而应该先做一个能支撑教学闭环的分级内容库：老师能按学生水平和目标选择材料，AI 能生成学习体验，学生完成后留下证据，系统给出下一步建议。内容来源要分成“可合法全文接入”“只做书单/元数据/外链”“需要采购授权”三类。

首批最值得做

LE 04 绘本：Reading A-Z / Oxford Reading Tree / I Can Read / Step into Reading / Ready-to-Read。适合 K-G3 和英语启蒙，能验证翻页、图像解词、跟读、认词配对。

最能规模化

LE 05 分级读物：Reading A-Z、Newsela 风同源多级、ReadWorks/ CommonLit 风短文、Oxford/Penguin/Macmillan ELT graded readers。适合做 Lexile-like band、CEFR 和题型标签。

最能形成差异化

LE 06 小说章节：Wonder、Holes、The Giver、Charlotte's Web、Matilda、A Wrinkle in Time 等作为书单；全文接入要授权或用公版经典。半米重点做人物图、伏笔、主题、章节 state。

重要判断：Lexile 只能描述文本复杂度，不等于“适合某个学生”。绘本常有 AD Lexile，高中小说可能 Lexile 不高但主题成熟。半米选书必须同时看 文本难度 + 年龄成熟度 + 主题兴趣 + 学习任务 + 版权状态。

4. 半米首批内容包建议

首批不要追求“全世界所有书都导入”，而是做 6 个能覆盖不同 LE pattern 的内容包。每包都有明确学习体验、报告证据和版权策略。

6. 经典绘本清单

绘本不要按 Lexile 机械排序。很多绘本文本复杂度高，但图片、重复结构、朗读支架强。半米应按 book_type 分为 concept、story、rhyme、social-emotional、nonfiction picture book。

10. 半米落地建议

内容库数据字段

  • title、author、series、publisher、publication_year
  • banmi_band、lexile_like_range、cefr、grade_band、interest_age
  • genre、format、book_type、topic_tags、skill_tags
  • license_status：public_domain / licensed / teacher_uploaded / external_link_only
  • le_pattern：picture_book / graded_reader / novel_chapter / nonfiction_article

推荐算法第一版

  1. 先用老师选择 + 学生 band 做硬过滤。
  2. 用兴趣标签、主题、format 做排序。
  3. 同一周混合：1 篇 anchor text + 2 篇短科普 + 1 个 fluency read + 1 个复习任务。
  4. 报告只输出区间、置信度和证据，不输出“官方 Lexile”。
  5. 老师确认后才写入 plan_patch。

V0.1-V0.3 路线

阶段做什么不要做什么
V0.1建立 100-150 条 metadata seed library；支持老师上传一篇/一本材料；做 LE 04/05/06 demo；公版小说接 1-2 本全文；报告 evidence_refs 跑通。不要批量抓取受版权保护全文；不要做开放式学生自选大书城。
V0.2做 level variants、Moodle/CSV/QTI-like import、RAZ/Oxford/ELT reader level 映射、外部书单推荐页、阅读日志。不要把 Lexile-like 伪装成官方认证；不要给学生只按数字锁书。
V0.3做学校/老师内容包、授权内容采购、章节小说 state、主题图谱、跨书推荐、家长可读报告。不要让家长端实时暴露全部错误和低分，避免焦虑。
