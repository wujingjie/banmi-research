下面 5 条是阿杰真正要的答案，每条单独成框（按重要性排）。每条都直接回应"Lexile 买不买 / Pre-A1/A1 怎么测 / 哪些素材能用 / 自建行不行"。

结论 1 ⛔ Lexile 别买——低端映射粗到对 Pre-A1/A1 没有分辨力，且为母语者设计

MetaMetrics 官方 Aligning the Lexile Framework to the CEFR（2021-08）的 concordance 表，最低一档就是 A1 = <535L，是个开口桶，把从 BR（Beginning Reader 负值）一路到 535L 全塞进同一个"A1"里，没有 Pre-A1，也不区分 A1 内部[1]。而 Reading A-Z 的 MetaMetrics 认证表显示，真实的 Pre-A1/A1 阅读区间是 BR70L 到约 310L（幼儿园到一年级初）[7]——这一整段在 Lexile-CEFR 里是一个点都分不出来的。加上 Lexile 衡量的是文本难度（句长 + 词频对数回归），不测 decoding / 识字 / phonics，而这恰恰是 Pre-A1/A1 学生的真实瓶颈[3]。授权还是 custom Order Form 不公开报价[2]。对半米的低端场景，Lexile 投入产出比极低，不买。

结论 2 ✅ 阿杰的直觉对：Pre-A1/A1 测阅读就不该是"短文 + 选择题"，要换题型

CEFR Companion Volume（2020）明确把 Pre-A1 定义为"通往 A1 的半路里程碑"，学习者还没有 generative capacity，只靠"一堆词 + 套话"[4]。这个级别的阅读 reception 高度依赖图片 / 手势 / 重复 / 慢速，评估在此年龄是"隐性 + 替代"的（游戏 / 项目 / portfolio），铁律是"测他们会的，不是测他们不会的"[4]。现成的题型蓝本就是剑桥 Pre-A1 Starters 阅读写作的 5 部分：①图文勾选对错 ②看图判断 yes/no ③字母重组拼词 ④从词库选词填空 ⑤看图故事一词回答[5]。这些全部可自动评分（详见第 6 章）。

结论 3 ⚠️ 现成"可商用素材"有，但"可直接买的 Pre-A1 阅读题库"基本没有——这块只能自建

免费可商用的素材确实存在：NGSL 高频词表（CC BY-SA 4.0，可商用需署名 + copyleft）[13]、CEFR-J 词表（研究 + 商业可用，需 cite）[11]、islCollective 习题（CC 可商用）[14]、Dolch/Fry 高频词表（词本身开放）[12]。但商业分级库（Raz-Kids / Reading Eggs / Oxford Reading Tree / Big Cat）都是订阅授权、内容不可拿出来嵌进自己产品，Newsela 最低只到二年级（不够低）[9]。真正"现成可购买商用的 Pre-A1 阅读题库"——我没查到任何一个。这正是阿杰说"题目比较少"的根因：这个级别的题库本身就稀缺，市场主要是订阅式整套产品，不卖原料。

结论 4 🟢 自建可行，但有诚实边界：生成能做，"自动标级在超低端最不准"要靠真人锚定

好消息：GPT-4 配好 prompt 能产出像样的 A1 文本（ControlError 0.28，已到人类难以分辨的粒度）[16]。坏消息要诚实讲：① 纯 prompt 会"alignment drift"——多轮后慢慢漂回母语级复杂度[15]；② 可读性公式（Flesch-Kincaid）在短文本 / 超低端直接失效（单句能算出 -146 这种荒谬值）[18]，半米自建的 banmi-cvla 用的就是 FK 派生映射，低端误差大（见 cvla 审查）；③ LLM 判"很简单的文本"难度时系统性"挤向偏低 + 缺粒度"，高估学生能力（competence paradox 的 2025/2026 新证据）[17]。解法：受控解码（FUDGE 把可懂度 39.4%→83.3%）+ 受控词表卡死 + 真人小样本锚定校准[15]。

结论 5 🎯 半米最该先做的窄切口：「受控词表生成器 + 剑桥 Starters 式 5 题型 + 高频词认读测」，先把 A1 一档跑通

不要一上来铺 Pre-A1+A1+A2 全谱。先做一个窄的能跑通的：用 NGSL/CEFR-J 词表卡死前 ~500 高频词 + 受控句长生成 A1 小读物，每篇配 剑桥 Starters 那 5 种可自动评分的题型，再加一个 sight words（高频词）认读测当 placement——这三件事都不需要买任何外部授权，素材和词表都用可商用的免费资源，难度标级用"受控词表 + 真人锚定 30-50 篇"而不是赌 LLM 自动标。1-2 周能出一个能给真学生用的 A1 闭环，跑通了再往 Pre-A1（更偏图文 / 听音）和 A2 扩（详见第 12 章决策树）。

📌 一句话总账：Lexile 不买（低端没分辨力 + 不测识字）；体系参考 CEFR-J（低端最细）+ 剑桥 Starters（题型蓝本）；素材用免费可商用的（NGSL/CEFR-J/islCollective），题库自建；自建走"受控词表 + 替代题型 + 真人锚定"，别赌 LLM 自动标级。

02Lexile（蓝思值）体系原理 + BR 低端区间▾

2.1 Lexile 是什么：一把同时量"文本"和"读者"的尺子

Lexile（蓝思值）是 MetaMetrics 公司的商业测量体系，核心创新是用 conjoint measurement（联合测量）把"读者能力"和"文本复杂度"放到同一把尺子上[1]。文本端的难度主要由两个变量的对数回归算出：句子长度（句法复杂度的代理）+ 词频（语义难度的代理，越罕见越难）[3]。当读者的 Lexile 和文本的 Lexile 匹配时，理论上读者处于"challenging but not frustrating（有挑战但不挫败）"的最优发展区[1]。

正因为这个特性，美国 23 个州 + 国际上很多测试机构把自己的考分链接到了 Lexile 体系[1]。出版社也付费用 Lexile Text Analyzer（自动文本分级软件）给自己的书打分。

2.2 Lexile 的范围：从 BR 负值到 2000L+

Lexile 标度从约 BR300L（最低）一直到 2000L 以上[6]。0L 是分界线，低于 0L 的读者/文本用 BR（Beginning Reader，初学读者）代号表示，把负号去掉换成 BR。例如 -100L 写作 BR100L[6]。

2.3 BR（Beginning Reader）区间：一个反直觉的"倒着走"标度 ⚠️

BR 区间的编号方向是反的，这是很多人踩坑的地方：

  • BR 后面的数字越小 = 读者越强 / 文本越难。BR150L 比 BR200L 更高级（更接近 0L）[6]。
  • 孩子识字进步时，分数从 BR 往 0L 靠拢，越过 0L 后进入正常正值区间[6]。
  • 所以 BR300L（最低）→ BR200L → BR100L → 0L → 100L 是难度递增的顺序。

⚠️ 这里就埋下了第一个问题：整个 BR 区间（约 BR300L 到 0L）+ 0L 到 535L，在 Lexile 的 CEFR 映射里全部塌缩成"A1 一档"（见第 3 章）。也就是说，对一个识字刚起步的孩子，Lexile 能告诉你他在 BR 区间的某个点，但一旦换算到 CEFR / 教学语言，分辨力就归零了。这对以 CEFR 为锚的 ESL 教学（半米的场景）是硬伤。

2.4 BR 区间对应什么阅读阶段

结合 Reading A-Z 的 MetaMetrics 认证对照表[7]，BR 区间大致对应：

Lexile 区间阅读阶段典型表现（对应 Pre-A1/A1）
BR300L ~ BR70L萌芽期 emergent认字母、图文强依赖、个别高频词；≈ Pre-A1 偏前
BR70L ~ 10L萌芽期 emergent（Raz aa/A 级）看图 + 一两个高频词成句；≈ Pre-A1 / A1.1
10L ~ 160L早期 early（Raz B/C 级）简单重复句型、sight words；≈ A1.1–A1.2
160L ~ 310L早期 early（Raz D/E 级，一年级）短句、可解码词为主；≈ A1.2–A1.3

注：上表的"≈ Pre-A1/A1"对应是本报告的推演（把 Reading A-Z 阶段 + CEFR Pre-A1 描述符特征对齐），非 MetaMetrics 官方映射——官方根本没有这么细的低端分档（这正是问题所在）。Lexile/F&P/DRA 是母语阅读发展体系，CEFR/CEFR-J 是 ESL/EFL 语言能力体系，两者只能粗略对齐，详见第 5 章。

⚠️ 读表注意：第 2 列「描述符实测 GSE 均值」和第 4 列「CEFR 大档标准区间」不是同一个东西，也不必相等——这正是 Pearson 报告的发现：把 CEFR-J 描述符放到 GSE 上重测，A1.2/A1.3/A2.2 等档的实测均值显著高于、A1.1/A2.1 等档落在或低于其 CEFR 标准区间[10]（即 CEFR-J 的细分和 CEFR/GSE 大档并非完美对齐，存在已知偏差）。半米用时以第 4 列的 CEFR 标准区间为锚（Pre-A1=13-21、A1=22-29、A2=30-42），第 2 列只作"该级描述符实际难到哪"的参考。

这张表才是半米该用的低端锚。GSE 把 Pre-A1 = 13–21、A1 拆成三等份（22–24 / 25–26 / 27–29），CEFR-J 进一步给每档配了 can-do 描述符和词表。对比 Lexile 的"A1 = <535L 一个桶"，GSE/CEFR-J 在低端的分辨力是它的 4-7 倍。半米若要一把低端尺子，应该锚 GSE/CEFR-J，不是 Lexile。

04Lexile 对 ESL 初学者的已知局限（critic 章）▾

阿杰已有判断："Lexile 为母语者设计，两个硬伤——低端映射粗 + 衡量文本难度≠ ESL 初学者真实阅读能力。"本章验证这个判断，并补上学界批评。结论：阿杰的判断成立，且比他说的还要更严重一点。

CRITIC #1 · 致命
Lexile 测的是"文本难度"，不测 decoding / 识字 / phonics——而这才是 Pre-A1/A1 学生的真实瓶颈
Lexile 文本分由句长 + 词频算出[3]，它假设"读者已经会解码（认字），只是文本词句难易不同"。但 Pre-A1/A1 的 ESL 学生恰恰卡在解码本身——他们可能认得字母却读不出词、或能机械解码却完全不懂意思。ELL 研究反复指出："ELL 即便能 decode 也常常不理解词义，因为缺乏口语英语暴露"[3]。Lexile 对"这个孩子认不认得这 50 个高频词"这个 Pre-A1 最核心的问题，完全无能为力。用 Lexile 测 Pre-A1 阅读 = 用体温计量身高。
CRITIC #2 · 致命
低端映射粗到归零——A1 是单一开口桶，BR 到 535L 全一个标签
见第 3.1 节：官方 CEFR 映射最低档 A1 = <535L，把整个 BR 负值区 + 0–535L 全压进一档[1]。这不是"数据不够细"，是体系设计就没打算服务这个区间——Lexile 的精度甜区在 ~400L–1300L（小学高年级到中学），低端本来就是它的盲区。对一个国际学校 K-2 / 中国 ESL 入门学生扎堆的产品（半米），Lexile 在你 80% 的目标用户身上没有分辨力。
CRITIC #3 · 中
为母语阅读发展设计，跨语言迁移有系统性偏差
Lexile 用美国母语者数据校准。研究发现它的跨语言迁移不可靠——例如同一内容的西班牙语版被 Lexile 标成比英语版更高的难度，说明它没有恰当处理"非母语者的语言特定因素"[3]。对中文母语的 ESL 学生，词频/句长这两个母语者代理变量，不能准确反映中文母语者读英语的真实难点（比如英语的冠词、时态、语序对中文母语者的额外负荷，Lexile 完全看不到）。
CRITIC #4 · 文化/语境
词频基于英语母语语料，文化语境偏差
Lexile 的"词频"代理来自英语母语语料库。一个对美国孩子很常见的词（如某个本土食物/节日词）对中国 ESL 学生可能是完全陌生的低频词，反之亦然。Lexile 假设的"词频 = 难度"在跨文化场景不成立。这一点在低端尤其明显，因为 Pre-A1/A1 的词表本应是跨文化通用的核心高频词（家庭、数字、颜色、身体），而非母语语料频率排序。

✅ 公平地说，Lexile 也不是一无是处：① 它是事实标准，跟很多测试/书目库互通，做"分级阅读库"时它是有用的通用货币（半米的 K12 阅读库可以用 Lexile 当书目标签）；② 在中高端（A2 以上、小学三年级以上）它的分辨力和实用性都不错。问题纯粹在低端（Pre-A1/A1）——而这恰恰是阿杰这次要解决的级别。所以结论不是"Lexile 是坏体系"，而是"Lexile 不是 Pre-A1/A1 这个特定问题的解"。

05对标体系总览：CEFR-J / 剑桥 Starters / F&P / DRA / Raz / GSE — 哪个低端最细 ★▾

本章回答：除了 Lexile，市面上哪些分级/测评体系在 Pre-A1/A1 这个最低端做得最细、有现成测评工具。核心要区分两类体系：(A) 母语阅读发展体系（F&P / DRA / Raz / Reading Recovery / Oxford Reading Tree）——锚识字发展，低端很细但不针对 ESL；(B) ESL/EFL 语言能力体系（CEFR / CEFR-J / GSE / 剑桥 YLE）——锚语言能力，半米该用这类。

5.1 一个根本事实：原版 CEFR（2001）下面什么都没有

Pearson 官方报告直说："CEFR 是为瑞士的成人学习者设计的，A1 以下没有任何描述符，描述符高度集中在 A2/B1/B2，A1 和 C 级极少"[10]。这就是 Pre-A1、CEFR-J、GSE 全部诞生的原因——它们都是为了修 CEFR 低端的空白。所以阿杰感觉"Pre-A1/A1 素材和检测匮乏"不是错觉，是整个框架体系历史上就在低端有结构性缺口，最近这十年才陆续补上。

06Pre-A1/A1 该用的阅读测评题型（核心，呼应阿杰痛点）★★▾

6.1 为什么这个级别不能只靠"短文 + 选择题"

阿杰的判断完全正确，而且有 CEFR 一手文档支撑：Pre-A1 学习者"还没有 generative capacity，只靠一堆词 + 套话"[4]。这意味着：

  • 他们读不了"短文"——一段连贯的短文需要的词汇量和句法处理能力，Pre-A1/A1 还不具备。强行给短文 = 全是挫败，测不出真实能力。
  • "选择题选项"本身就是阅读负担——4 个文字选项对认字都费劲的孩子，是额外的解码任务，干扰了你想测的东西。
  • CEFR 铁律："测他们会的，不是测他们不会的"[4]。这个级别的阅读能力 ≈ 识字 / phonics 解码 / 高频词认读，要直接测这些，不是测"读懂段落"。

所以阿杰说的"出不了多少传统阅读理解题"是对的——解法不是去找更多阅读理解题，是换一整套题型。

6.4 cloze / 完形在低端的适用性 ⚠️

开放式 cloze（挖空让学生自己填）在 Pre-A1/A1 基本不适用——学生还没有 generative capacity，填不出来，会全是 floor effect（全错，区分不出谁强谁弱）。但 maze（挖空给 2-3 个选项选）可以，因为它是多选不是生成，难度低得多[20]。对最低端，业界做法是 cloze 加首字母提示降难度[20]。给阿杰的规则：Pre-A1/A1 用 maze（选项式），不用 open cloze（生成式）。

07朗读流利度(ORF) / Running Records / 早期阅读测评（DIBELS）▾

第 6 章的点选题型测"认不认得"，本章的方法测"读得准不准、流不流利"——对低龄/初学者特别有效，因为它直接观察孩子真实朗读行为，绕过了"选择题选项也是阅读负担"的问题。代价是需要语音识别（ASR）+ 发音评测才能自动化。

7.1 Running Records（朗读记录）+ 准确率分级

Running Record 是让学生朗读约 100 词的文本，记录每个朗读行为（错读 miscue、自我纠正、停顿），算出准确率[21]。准确率直接定义文本对该生的难度等级：

准确率难度等级含义
95–100%独立级 independent可自己读，太简单
90–94%教学级 instructional"有挑战但不挫败"的最优区——放学习内容这里
< 90%挫败级 frustration太难，换简单的

这套准确率分级和 Lexile 的"challenging but not frustrating"是同一个概念，但实现方式更适合 ESL 初学者：它不需要任何外部分级体系，直接用"孩子读这篇错了几个词"动态定位难度。对半米：这是一个不依赖 Lexile、不依赖任何商业授权的难度定位法——只要有 ASR 能数出错读词数，就能自动算准确率给文本分级。

7.2 Oral Reading Fluency (ORF) + Miscue Analysis

ORF 在 Running Record 基础上加速度维度（WCPM，每分钟读对词数）+ 韵律/语调。Miscue analysis 既看量（准确率/错误率）也看质（错读的策略类型——是看首字母猜的？还是按语义猜的？）[21]。一项成人 ESL 研究发现：ESL 学习者的 ORF 与默读理解显著相关，且"准确率"维度的相关性略强于"速度"[21]——说明对 ESL，先抓准确率比抓速度更重要。

7.3 DIBELS：母语早期阅读测评能否借鉴给 ESL？

DIBELS 8（Dynamic Indicators of Basic Early Literacy Skills）是美国母语早期阅读筛查的事实标准，6 个分测验，全部是1 分钟计时小任务[19]：

  • LNF 字母命名流利度 — 测字母知识 + 快速命名
  • PSF 音素切分流利度 — 把短词拆成音素
  • NWF 假词流利度 — 测字母-音对应 + 解码（用假词排除"背过这个词"的干扰）
  • WRF 词汇朗读流利度 — 高频词整词识别
  • ORF 朗读流利度 — 连续文本朗读
  • Maze — 理解（多选填空）

✅ 能借鉴，但要改造：DIBELS 的"把阅读拆成可分别测的子技能 + 短计时任务 + 假词测纯解码"这套思路对 ESL 极有价值（半米的诊断式测评就该这么拆，见 6.3）。但不能照搬：① DIBELS 是英语母语的 phonics 假设，对中文母语 ESL 学生，音素意识（PSF）的难点不一样（中文是音节文字，没有英语的音素切分直觉）；② DIBELS 不测词义/句义理解（母语孩子默认懂口语），而这恰恰是 ESL 的核心难点——半米必须在 DIBELS 的解码测之外，加上第 6 章的图文词义/句义题。

7.4 现成的自动化早期测评工具（参考实现）

已经有产品把这些方法自动化了，可作半米的参考：

  • EuLeApp — 用 IRT + 计算机自适应测试（CAT）做早期识字技能测评[22]，证明低端测评完全可以自适应自动化。
  • Amira / Ello / Project Read（2025/2026）— AI 朗读 tutor + ASR 实时纠错，把 ORF/Running Record 自动化[23]。
  • Page Turner — 监测 phonics、sight words、阅读级别的 K-2 进度追踪[22]。

✅ 半米真能拿来商用的三件套：① NGSL/CEFR-J/Dolch-Fry 词表（卡死生成的词汇范围）+ ② islCollective 习题（参考/改编题型）+ ③ 自己用 LLM 生成的原创读物（版权干净）。这三样组合，半米就不需要买任何商业分级库就能搭出 Pre-A1/A1 的素材底座。⚠️ NGSL 的 CC BY-SA copyleft 要注意——用它的词表做衍生物可能被要求同样开放，跟 banmi-cvla 审查里 Octanove 的 CC BY-SA 是同一类风险。最干净的是词表只当"参考清单"圈定词汇范围，不把词表文件本身打包进产品发布。

8.3 国产/中文场景的正面机会 🇨🇳

阿杰的用户在国内，这里特别提：CEFR-J 的词表是基于中日韩等亚洲国家英语教材编制的[11]——比纯欧美语料的 Lexile 词频更贴近中国 ESL 学生的真实词汇暴露。半米用 CEFR-J 词表当低端锚，比用 Lexile 在文化/语境上对中国学生更友好（直接回应第 4 章 critic #4 的文化偏差问题）。这是一个被低估的本地化优势。

9.1 现成的 Pre-A1/A1 阅读题库：基本不存在可商用的 🔴

🔴 诚实结论：我没查到任何一个"可购买 / 可商用授权"的 Pre-A1/A1 阅读题库。市面上的题分两类，都不能直接拿来商用嵌入：

  • 免费练习题（Test-English、islCollective、esleschool、British Council LearnEnglish Kids/Teens）——量大，但授权各异：islCollective 可商用[14]，British Council 仅课堂用[14]，其余多数没明示。且这些是"练习题"不是"测评题库"（没有难度标定、没有 IRT 参数）。

这正是阿杰说"相关阅读题目比较少"的根因：Pre-A1/A1 这个级别的题库本来就稀缺，且商业模式是"卖整套产品"不是"卖题"。半米这块只能自建。

9.2 学术 learner corpora 能不能当题库素材？

学术界有按 CEFR 标注的学习者语料（如 CEFR-J 的 learner corpus、EFCAMDAT 等，详见 数据集报告）。但这些是"学习者写的作文"语料，不是"阅读测评题库"——用途是训练评分模型/分析错误，不是直接当阅读题给学生做。对半米的 Pre-A1/A1 阅读题，learner corpora 帮不上直接的忙。

10自建路线：LLM 生成 + 自动标级 + 受控词表 + critic ★▾

第 8、9 章证明：素材和题库都得自建。本章讲怎么建，以及——更重要的——诚实讲清楚自动标级在超低端为什么最不准（呼应 banmi-cvla 审查 和 MiroFish 报告 的 competence paradox）。

10.1 用 LLM 生成 Pre-A1/A1 素材：能做，但有坑

✅ 好消息：GPT-4 配好 prompt 能产出像样的 A1 文本。"From Tarzan to Tolkien" 研究显示，GPT-4 用包含完整 CEFR 描述 + 例子的 prompt，ControlError 达 0.28——已经到"人类难以分辨"的粒度（人类感知阈约 0.25）[16]。它能产出 "Tom takes Lily's toy truck. Lily loves this truck." 这种地道的 A1 句子[16]。

⚠️ 坏消息要诚实讲（三个真实坑）：

  • 纯 prompt 会 "alignment drift"：多轮交互中模型慢慢漂回母语级复杂度，因为它的默认输出就是 near-native，没有外部约束时会失控[15]。
  • 开源小模型 prompt 几乎控不住：LLaMA-2-7B / Mistral-7B 纯 prompt 的 ControlError 高达 1.30–1.68（基本失控）[16]。半米若用便宜模型生成，必须配额外控制手段。
  • 受控解码是解药：FUDGE（推理时加一个轻量判别器引导解码）把初学者文本可懂度从 39.4% 拉到 83.3%，且不需要 fine-tune，模块化好接[15]。

10.2 自动标级：把生成内容打 CEFR/Lexile 标 — 超低端最不准 🔴

生成出来后要给内容打级。三种自动标级法，在 BR/Pre-A1 超低端全都最不准：

方法原理超低端表现
可读性公式（Flesch-Kincaid 等）句长 + 音节数🔴 短文本直接失效（单句能算出 -146 这种荒谬值）[18]；banmi-cvla 用 FK 派生映射，低端误差大 ±60L（见 cvla 审查）
ML 分类器（RF / DeBERTa 等）语言特征 → CEFR🟡 A1/A2 准度看似高（>90% checklist），但低端"词难度不显著、传统复杂度指标区分力弱"[26]
LLM 直接判难度读文本 → 评 CEFR🔴 系统性偏差（见下方 critic）
CRITIC · competence paradox（核心诚实点）
强 LLM 判"很简单的文本"难度时，预测"挤向偏低 + 缺粒度"，高估学生能力
MiroFish 报告引用的 competence paradox（arXiv 2601.05473）指出：一个能力很强的模型被要求扮演"半懂的学生"时，流畅交互掩盖了不真实的错误模式[17]。2025/2026 的新研究更直接："虽然真实难度跨度很广，模型预测却窄聚集、系统性挤向偏低值，高估了学生能力，缺乏区分人类挣扎程度的粒度"[17]。
👉 对半米的含义：让 LLM 判一篇 Pre-A1 读物"对一个识字刚起步的孩子难不难"——LLM 会觉得"这也太简单了"，倾向都标成最低档，分不出 Pre-A1 内部的细微难度差。而这个细微差恰恰是半米要的。所以：在超低端，绝对不能赌 LLM 自动标级，必须真人锚定。

10.3 正确的自建标级法：受控生成 + 真人锚定校准

既然自动标级在超低端不可靠，就反过来——用"受控生成"把难度"焊死在输入端"，而不是"生成后再猜难度"：

  1. 输入端卡死：生成时强约束只用 CEFR-J A1 词表的前 N 个词 + 句长 ≤ 6 词 + 只用现在时。难度由约束保证，不靠事后标。
  2. 受控解码兜底：用 FUDGE 类方法防止漂移[15]。
  3. 真人锚定校准：找 30–50 篇真人标好级别的 Pre-A1/A1 样本（可用 CEFR-J 词表 + 剑桥 Starters 样题做锚），让生成内容对齐这些锚点，而不是让 LLM 凭空判级。
  4. 小样本真学生验证：哪怕 5-10 个真学生，读一下、做一下题，看实际难度——这是任何自动方法都替代不了的（competence paradox 决定的）。

📌 一句话：Pre-A1/A1 自建的关键不是"更强的标级模型"，而是"把难度约束在生成的输入端 + 真人锚定校准"。这跟 MiroFish 报告的结论同构——"校准 > 架构"，在低端尤其如此。

12.3 最该先做的窄切口：「A1 一档的点选闭环」

窄切口（唯一推荐）：先做 A1 一个级别、只做纯点选可自动评分的题型。

为什么是 A1 不是 Pre-A1：Pre-A1 更偏图文/听音/口语，需要更多素材资产（图库、TTS）和 ASR，启动成本高；A1 的点选题型（图文匹配/看图 yes-no/句子排序/受控填空）前端就能 100% 自动评分，最快出能给真学生用的闭环。

具体第一步（1-2 周能跑通）：

  1. 圈词表：取 CEFR-J A1 词表前 ~500 高频词 + Dolch sight words，作为生成的硬约束。
  2. 受控生成 20-30 篇 A1 微读物：句长 ≤ 6 词、只用现在时、只用词表内词。用 GPT-4 + 完整 CEFR 描述 prompt（必要时加受控解码防漂移）。
  3. 每篇配 4 种点选题：图文匹配、看图 yes/no、句子排序、受控填空（maze 式，给选项）——全部前端自动评分。
  4. 真人锚定：自己或找一个老师，把这 20-30 篇对照剑桥 Starters 样题难度过一遍，标定 A1.1/A1.2/A1.3。
  5. 5-10 个真学生试跑：看实际难度对不对，competence paradox 决定了这步不能省。

这一步最妙的地方：它0 外部授权成本（词表、题型、素材全是可商用免费资源 + 自建），不依赖 ASR（纯点选），1-2 周出闭环。跑通后再向下扩 Pre-A1（加图库/听音/TTS）和向上扩 A2。这比一开始就纠结"要不要买 Lexile / 怎么自动标级"省了几个数量级的决策成本。

13FAQ 12 条▾

Q1一句话，Lexile 到底买不买？+
不买。它的 CEFR 映射在 Pre-A1/A1 是单一开口桶「A1=<535L」，把 BR70L 到 535L 全压一起，零分辨力[1]；它测文本难度不测识字/解码，跟 Pre-A1/A1 真实瓶颈错配；价格还不公开。唯一可考虑的场景是未来给 A2 以上书目做通用难度标签，但那不是现在的问题。
Q2为什么 Lexile 低端这么粗？是数据不够吗？+
不是数据问题，是体系设计。Lexile 的精度甜区在 ~400L–1300L（小学高年级到中学），低端本来就是盲区。官方 CEFR 映射最低档就是 A1=<535L 一个开口桶[1]，A1 箱线图下探到 -500L 以下、跨度极大。这是"没打算服务这个区间"，不是"细分了但数据不够"。
Q3Pre-A1/A1 到底该怎么测阅读？我的直觉对吗？+
你的直觉完全对。CEFR 一手文档说 Pre-A1 学习者"没有 generative capacity，只靠词+套话"[4]，读不了短文、选择题选项本身就是阅读负担。解法是换题型：图文匹配、看图判断 yes/no、高频词认读、句子排序、受控填空（maze）。剑桥 Pre-A1 Starters 的 5 部分就是现成蓝本[5]，且大部分能自动评分。
Q4哪个分级体系在 Pre-A1/A1 低端做得最细，半米该用哪个？+
测能力分级用 CEFR-J（半米已在用）+ GSE——唯二把 Pre-A1 和 A1 都细分、且专为 ESL 的体系，CEFR-J 还可商用[11]。测题型/出题参考剑桥 Pre-A1 Starters。母语体系（F&P/DRA/Raz）低端更细但锚识字发展、全是闭源商业产品，只能借鉴不能用。
Q5CEFR 不是有 A1 吗，为什么还需要 Pre-A1？+
原版 2001 CEFR A1 以下什么都没有，描述符集中在 A2/B1/B2，A1 本身就极少[10]。Pre-A1 是 2020 Companion Volume 才新增的"通往 A1 的半路里程碑"[4]。CEFR-J（2012）和 GSE 也都是为修这个低端空白而生。所以你感觉"Pre-A1/A1 匮乏"是真的——整个框架历史上就在低端有结构性缺口。
Q6有没有现成可商用的 Pre-A1/A1 阅读题库可以买？+
基本没有。免费练习题（islCollective 可商用[14]、British Council 仅课堂用、其余多数没明示）量大但不是标定好的测评题库；商业测评题库（剑桥/Pearson）是整套产品的一部分，不单卖题，只公开样题参考。这块半米只能自建——这也正是阿杰说"题目少"的根因。
Q7那哪些素材是真能拿来商用的？+
三件套：① NGSL/CEFR-J/Dolch-Fry 词表（卡死生成的词汇范围，全可商用）[11][13][12]；② islCollective 习题（CC 可商用，参考/改编）[14]；③ LLM 自建的原创读物（版权干净）。⚠️ NGSL 是 CC BY-SA copyleft，词表当"参考清单"用、别把文件本身打包进产品发布最安全。
Q8LLM 能可靠生成 A1 文本吗？能自动判难度吗？+
生成能（GPT-4 配好 prompt，ControlError 0.28[16]），但纯 prompt 会漂移（多轮后回到母语级），需受控解码兜底（FUDGE 把可懂度 39.4%→83.3%）[15]。自动判难度在超低端不可靠——LLM 判"很简单的文本"时挤向偏低、缺粒度、高估学生能力（competence paradox）[17]。所以：生成可用，标级靠"输入端约束 + 真人锚定"。
Q9为什么 banmi-cvla 这种可读性公式工具在低端也不行？+
Flesch-Kincaid 这类公式靠句长+音节，短文本直接失效（单句能算出 -146 这种荒谬值）[18]。banmi-cvla 用 FK 派生的 Lexile 经验映射，低端误差大（见 cvla 审查，FK 在 CEFR 6 档上只有 34% 准）。Pre-A1/A1 文本又短又简单，正是这类公式最不准的地方。低端要靠受控词表+真人，不靠公式。
Q10朗读测（Running Records / ORF）值得做吗？+
很值得，但放第二阶段。Running Record 用朗读准确率（95-100%独立/90-94%教学/<90%挫败）动态定位难度，不依赖任何商业分级体系也不依赖授权[21]，对 ESL 初学者特别有效。但它需要 ASR + 发音评测才能自动化，建议复用半米已规划的评分引擎时再做，第一阶段先用纯点选题型出闭环。
Q11DIBELS 这种母语早期测评能搬给中国 ESL 学生吗？+
思路能借，不能照搬。DIBELS"把阅读拆成可分别测的子技能+短计时任务+假词测纯解码"很值得学[19]。但：① 它的音素意识(PSF)是英语 phonics 假设，中文母语学生没有英语音素切分直觉；② 它不测词义/句义理解（母语孩子默认懂口语），而这恰恰是 ESL 的核心难点。半米要在 DIBELS 的解码测之外，加上图文词义/句义题。
Q12如果只做一件事，阿杰该先做什么？+
做"A1 一档的纯点选闭环"（第 12 章）：CEFR-J A1 词表前 ~500 词卡死 → LLM 受控生成 20-30 篇 A1 微读物 → 每篇配 4 种自动评分的点选题（图文匹配/看图 yes-no/句子排序/受控填空）→ 真人对照剑桥 Starters 锚定 → 5-10 个真学生试跑。0 授权成本、不依赖 ASR、1-2 周出能给真学生用的闭环。跑通再向下扩 Pre-A1、向上扩 A2。
