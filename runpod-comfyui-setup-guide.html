⚙ banmi · 视频生成指南

RunPod + ComfyUI 视频生成全套指南

用云 GPU 跑开源 image-to-video 模型（SVD / CogVideoX / Wan 2.1），替代 Mac 本地（PyTorch MPS 跑不动）+ 替代 Hailuo API（贵 10-30 倍）。

场景 RAZ 绘本图 → 5-6s 微动画 mp4
首次配置 ~1-2h
单视频 30s-5min
全 A 级 312 视频 $2-18
全 RAZ 5000 视频 $30-290

§ 0前置准备

  • 一张能国际支付的卡（Visa / Master 信用卡 / 海外银行卡 / Stripe 都行）
  • 浏览器（不需要 VPN，RunPod 直接能上）
  • ssh 客户端（macOS 自带 Terminal 够用）
  • 本地 banmi 项目目录已准备好（/Users/jay/Projects/banmi/）

§ 1注册 RunPod + 充值

1

浏览器 → https://runpod.io → 右上 Sign Up（Google / GitHub / 邮箱）

2

登录后右上头像 → Billing → Add Credit → 充 $10 试水（一次能跑很多）

3

Settings → API Keys → Create API Key → 保存这个 key（sync 脚本可能用到，web UI 操作不需要）

💰 $10 能跑多少

4090 价格 $0.69/h → $10 = ~14 小时。能跑完 RAZ A 级 batch 几次。banmi 跑一次试水 $2-20。

§ 2起一个 ComfyUI 实例

1

左侧 Pods → Deploy

2

GPU 选 "RTX 4090"（最便宜中能跑所有视频模型） — 看到 $0.69/h

3

Container Disk 设 50 GB（默认 20 不够 — 模型加起来 ~60GB，但常用 1-2 个就够）

4

Volume Disk 设 50 GB（持久化，关机模型不丢；关 pod 才删）

5

Template → 搜 "ComfyUI" → 选最热门那个（推荐 runpod/comfyui 或社区高 star 的；通常带 v0.x.x 版本号）

6

Deploy On-Demand → 等 1-2 min instance 起来

起好后状态显示 Running，旁边有几个 button：

按钮用途
Connect看 ComfyUI Web UI 入口（HTTP Service 8188 port）
Logs调试用
Stop暂停（不收 GPU 钱，但 Volume 还在）
Terminate完全删（Volume 也删，数据丢）
⚠ 用完一定按 Stop（不是 Terminate）

Stop 保留 Volume → 下次再 Start 模型不用重下。Terminate 会删一切，模型 60GB 又要下一遍。

§ 3进 ComfyUI Web UI

1

Connect → HTTP Service 8188 → 在浏览器开（链接形如 https://xxx-8188.proxy.runpod.net）

2

看到 ComfyUI 节点图界面（默认 workflow 是文生图，先不管）

第一件事：装 ComfyUI-Manager

管理 custom nodes / 模型。如果 template 已带 Manager（右上角有 "Manager" 按钮），跳过。否则：

  • 点右上 Manager → 没有的话，进 RunPod Connect → Start Web Terminal
  • 在终端跑：
cd /workspace/ComfyUI/custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Manager.git
  • 刷新 ComfyUI 页面 → 右上应该出现 "Manager"

§ 4装模型 + workflow

选 1：SVD-XT 最快

4090 上 ~20-30s / 视频。只 image-conditioned，不能 text prompt。

# 进 RunPod web terminal
cd /workspace/ComfyUI/models/checkpoints
wget https://huggingface.co/stabilityai/stable-video-diffusion-img2vid-xt/resolve/main/svd_xt.safetensors

ComfyUI workflow（拖入 .json 或自己搭）：

  • 推荐：ComfyUI 内置 Examples → Video → Stable Video Diffusion（菜单 Examples / Templates 找）
  • 或下载 github.com/comfyanonymous/ComfyUI_examples 的 SVD example

选 2：CogVideoX-5B 中速 · text 控

支持 text prompt。

# 通过 Manager → Install Custom Nodes → 搜 "ComfyUI-CogVideoXWrapper" → install
# 或：
cd /workspace/ComfyUI/custom_nodes
git clone https://github.com/kijai/ComfyUI-CogVideoXWrapper.git

模型下载在 workflow 里自动触发（点 Queue Prompt 第一次会下载 ~22GB）

选 3：Wan 2.1 14B 最强 · 最慢

4090 上 ~3-5min/视频。SOTA 质量。

# Manager → 搜 "ComfyUI-WanVideoWrapper" → install
# 模型同样首次运行自动下载

§ 5跑第一个视频

1

上传图：ComfyUI 主界面 → 左侧 Queue → Browse Files → 上传你的图（比如 bird-p03-clean.jpg）

2

加载对应 workflow（拖 .json 进画布）

3

Load Image 节点 → 选你上传的图

4

Sampler 节点（SVD）：motion_bucket_id = 127（中等动态）/ noise_aug_strength = 0.02

5

Save Animated WEBP / VHS_VideoCombine 节点：output 选 mp4

6

Queue Prompt → 等 30s-3min（看模型）

7

输出在 /workspace/ComfyUI/output/ 目录

§ 6下载 mp4 回本地

方法 A：Web UI 直接下载

ComfyUI 输出区点视频 → 浏览器另存为

方法 B：sync 脚本（批量推荐）

见 tools/sync_runpod.sh — 自动 rsync 所有 output 回到本地 banmi data 目录。

# 第一次配 SSH key（一次性）
# 把 ~/.ssh/id_ed25519.pub 内容贴到 RunPod → Settings → SSH Public Keys

# 推图上去
./tools/sync_runpod.sh push <RUNPOD_SSH_HOST> docs/prototypes/banmi-claude/student/data/raz/A/bird-goes-home/images/

# 拉视频下来
./tools/sync_runpod.sh pull <RUNPOD_SSH_HOST> /workspace/ComfyUI/output/ ./runpod-output/

§ 7成本控制 tips

行为影响
Pod Stop（不是 Terminate）不收 GPU 钱，Volume 按 $0.10/GB/月（50GB → $5/月）
Terminate Pod全删，下次重新装一切
跑 batch 时用 Network Volume 集中存模型，多个 pod 共享
模型重复下慎重：每下一次 22GB CogVideoX 用 30 min × 网速 = 浪费几小时
关 pod 顺手跑完 batch 立刻 Stop，省钱第一原则

§ 8跟 banmi 集成

跑出来的 mp4 文件名乱（ComfyUI_00001_.mp4 之类）。两种归位策略：

策略 A：手动改名 + 拷进 banmi

# 你下载的 mp4 在 ~/Downloads/ComfyUI_00001_.mp4
mv ~/Downloads/ComfyUI_00001_.mp4 \
   /Users/jay/Projects/banmi/docs/prototypes/banmi-claude/student/data/raz/A/bird-goes-home/video/page-04.mp4

策略 B：用 import_videos.py 批量（推荐）

# 单本归位（按 page）
python3 tools/import_videos.py bird-goes-home --level A --page 5 \
  --src ~/Downloads/Hailuo_xxx.mp4

# 批量（按文件名自动判 page）
python3 tools/import_videos.py bird-goes-home --level A \
  --src-dir ./runpod-output/

# 批量（按顺序绑 page 号）
python3 tools/import_videos.py bird-goes-home --level A \
  --src-dir ./runpod-output/ --pages 3 4 5 6 7 8 9 10

脚本会自动 cp 到 banmi data 目录 + 更新 meta.json 的 video_per_page 字段。

§ 9进阶：SSH + tmux 持久化

如果跑 batch（一次几百张图），建议 SSH 进 pod + 用 tmux 跑，断网不影响：

ssh root@<RUNPOD_SSH_HOST> -p <PORT>
tmux new -s batch
# 跑 ComfyUI batch (ComfyUI 自己支持 batch / Queue 模式)
# Ctrl+B + D 退出 tmux （batch 继续后台跑）
# 下次回来：tmux a -t batch

§ 10故障排查

现象解决
Connect 进不去 ComfyUI看 Logs，可能模型还在下；等 1-2 分钟
OOM (out of memory)Manager → Settings → Reduce VRAM → 启用 lowvram 模式
视频生成出来全黑workflow 里 VAE 没接对；用 Examples 里的标准 workflow 重来
一直 "Queued" 不跑RunPod 那个 GPU 实例没启动；看 Pod 状态是不是 Running
下了模型但找不到放错目录了；应该在 /workspace/ComfyUI/models/checkpoints/

§ 12banmi 端配置变化（无需改）

视频接进来后，前端 picture-book-raz-book.html 已经支持 video_per_page 字段，不需要改前端代码。只需要：

  1. mp4 放到 docs/prototypes/banmi-claude/student/data/raz/A/<book_id>/video/page-NN.mp4
  2. 更新 meta.json 加 video_per_page 条目（用 import_videos.py 自动）
  3. 刷新浏览器 → 自动播
✨ 验证

开 http://localhost:8766/banmi-claude/student/reading/picture-book-raz-book.html?id=bird-goes-home&level=A，进 Step 2 翻页，有 video_per_page 的页自动播 mp4 循环。
