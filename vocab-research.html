三句话结论：(1) 词汇市场已经被 Anki+Quizlet+百词斩+多邻国 分走 80% 的注意力，但课程化形态 + AI 个性化仍是空地，半米的"阅读沉淀 + 双形态 + 统一池"路径走通就有差异化。(2) 用户最爱 Top3 永远是 SRS / 真实例句 / 即时反馈，半米总纲已全部覆盖；缺的是游戏化 streak、社群对决、词卡视觉惊喜这几项 retention 杠杆。(3) 视频词典三层方案可以直接落地：Layer 1 YouGlish iframe 今天就能上（教育用途免费），Layer 2 自建用 yt-dlp + Postgres FTS / Elasticsearch（V0.3 启动，约 3 人月）；本报告底部嵌了一个可玩的 YouGlish widget，输入词试试。

01市场总览▼

整体格局：全球词汇学习市场两条主干线 —— "主动背词"（Anki / Quizlet / 百词斩 / 墨墨）和"内容沉淀"（LingQ / Readlang / FluentU / WordUp / Memrise）。两条线技术栈不同、用户画像不同、commercial model 不同，但都在向中间靠拢 —— 主动背词侧加内容（百词斩做 Word TV、WordUp 做电影例句），内容沉淀侧补 SRS（FluentU 做闪卡 + 间隔重复）。

三波核心趋势（2024-2026）

🌊 第一波 · FSRS 成为新一代 SRS 默认引擎
2024 起 Anki / MintDeck / Mochi / StudyGlen 都把默认调度器换成 FSRS（Free Spaced Repetition Scheduler）。相比经典 SM-2，FSRS 减少 20-30% 复习量到达同样 retention，且按用户个人遗忘曲线动态拟合。半米总纲 §8 用的是 phase 9 混合 SRS（当天真实时间 + 跨天学习日），属于经验法则路径 —— 后期可考虑升级到 FSRS 风格的个体拟合。
🤖 第二波 · AI 个性化 + 自动生卡崛起
Quizlet 推 Magic Notes：上传笔记一键转 flashcards + 测试 + AI 导师；Lingvist 用 AI 持续校准每个学习者的遗忘曲线只教最常用 6000 词；Memrise 2025 推 MemBot AI 陪练。2026 的"AI 个性化"已经不是噱头，是中位线。
🎬 第三波 · 视频 / 真实片段成标配
Memrise 的"native speaker videos"是其核心护城河；WordUp 把 25,000 词全部挂电影 / 新闻片段；百词斩有 Word TV；不背单词 150 万+ 原声例句；FluentU 直接在 Netflix / YouTube 字幕上点词。谁能把"真实场景片段"做好，谁就拿到下一代词汇产品的入场券 —— 这正是半米 V0.2 课程化 + 三层视频词典方案要解决的问题。

Anki — 开源 SRS 之王 / 算法护城河

核心定位

极简词卡 + 极强 SRS + 极开放架构。2024 起把默认调度器从 SM-2 换成 FSRS，按用户个人遗忘曲线动态拟合，同等 retention 下减少 20-30% 复习量。

最被夸的功能

  • FSRS 算法 ——"它真的在按我个人遗忘曲线调度"
  • 开放的卡片模板 / HTML / LaTeX 支持，医学生可放分子式

  • UI 1990 风格，新用户上手前要先学怎么用 Anki
  • iOS 25 美金一次性买断（开发者唯一收入来源，社区争议）
  • 社区 deck 质量参差，没有质量背书

半米可以借鉴

  • FSRS 风格的个人遗忘曲线拟合 —— V0.2 之后可以引入，半米 phase 9 当前是经验阈值，升级路径清晰
  • 三档答题按钮（不会 / 模糊 / 会） —— 半米 §8 已采纳
  • 不要抄它的 UI —— 半米 Q-2 已明确选 D banmi 风格，对的

百词斩 — 中国市场 1.7-2 亿用户 / 图背单词原创

"图背单词" 的发明者 —— 每个单词配一张原创插画 + 例句 + Word TV 短视频（情景剧 / 网络梗）。紧扣中国教材（小学 / 初高中 / 四六级 / 考研 / 雅思托福），所有词书都对齐应试场景。

最被夸的功能

  • 原创插画 + 趣味例句（蹭热梗 / 明星 / 网络新词）
  • Word TV 短视频例句 + 单词电台 + 单词 PK 对战
  • 紧扣教材，初高中生最爱
  • 免费可用，性价比之王
百词斩的优点是紧扣教材、巩固复习、稳定增长、快速上手。这种边玩边学的模式能保持用户的学习耐心。— 知乎产品体验报告

  • SRS 弱 / 记忆效果不强 —— 多次错的词不会智能加大复习频次

  • 例句多次重复，娱乐性大于学习性

  • Word TV 短视频 —— 半米的"短视频讲解"对标这个，且半米更结构化（发音 + 词性 + 词源 + 例句 + 易错点 30-60s 模板）
  • 避坑：百词斩的 SRS 弱是其被骂最多的，半米 §8 走 phase 9 统一池 + Anki FSRS 路径，避开这个坑
  • 避坑："缺少运用" —— 半米要在 V0.2 题型 T2/T4（中文选英 + collocation 选择）+ T6（片段听辨）补足

04问题 1：核心功能 List（最小可用词汇系统）▼

从 18 家产品反向归纳，一个最小可用的词汇系统必须有这 8 项核心功能。每项标"为什么核心 / 谁做得好 / 半米总纲覆盖状态"。

1
SRS 间隔重复调度
实现难度：高 半米覆盖：✅ §8 phase 9 统一池

为什么核心：背单词如果没有 SRS，学过就忘是必然。所有 18 家里只有 LingQ / Readlang / YouGlish 没有完整 SRS，其余 15 家都有。这是入场门槛。

谁做得好：Anki（FSRS 个人拟合）／Lingvist（AI 拟合每个学习者）／墨墨背单词（艾宾浩斯曲线 + 词书全）／Brainscape（5 档信心评分）。

半米状态：已锁混合 SRS —— 当天真实时间 + 跨天学习日（day 1 / 2 / 4 / 7 / 15 / 30）。三档答题按钮（不会 / 模糊 / 会）。升级路径：V0.3+ 可考虑 FSRS 风格的个体遗忘曲线拟合。

2
Context-rich 词卡（不是孤立单词 + 中文）
实现难度：中 半米覆盖：✅ §6 schema 强制 context

为什么核心：研究证实"context-rich"是 vocabulary retention 的核心。Nation & Webb 实验对 12 种背词练习排序，cloze（context 补全）排第二，效果远超孤立背中文释义。

谁做得好：不背单词（150 万+ 原声例句）／LingQ（import 任何文本）／WordUp（25,000 词全挂电影例句）／Reverso Context（双语 movie subtitle 例句库）。

半米状态：schema 强制带 sentence_en + sentence_zh + collocation。建议加强：V0.2 阅读联动让"原句即学习材料"，比孤立例句更高价值（半米 §9 已写）。

3
多题型测试（不只是看英选中）
实现难度：中 半米覆盖：✅ §7 5 类题型

为什么核心：单一题型（看英选中）只测识别不测运用，4-5 种题型轮换是中位线产品的最低配置。

谁做得好：Quizlet（Match / Test / Learn / Write 多模式）／Vocabulary.com（10 种题型 + 20 级 mastery）／扇贝单词（拼写 + 例句 + 短语搭配多题型）。

半米状态：§7 已 deepen 5 类（T1 看英选中 / T2 看中选英 / T3 原句 cloze / T4 collocation / T5 听音拼写）+ V0.2 T6 片段听辨。V0.1.5 取 T1+T3。

4
发音 + 跟读 / 听音
实现难度：中 半米覆盖：🟡 IPA 有，跟读 V0.2+

为什么核心：词汇不是 silent vocab —— 听不懂的词等于没学。每个词卡至少要有 IPA + 朗读，进阶要有跟读评分。

谁做得好：百词斩（真人朗读 + 多口音）／Memrise（native videos）／Drops（每词都有 TTS + 重复跟读）／不背单词（150 万原声例句）。

半米状态：§6 schema 有 IPA 字段。建议补：V0.1.5 加 audio_url 字段 + Web Audio TTS（Azure / Forvo），V0.2+ 加跟读评分（接 phase 0E 写作 / 0C 听力同一套语音 API）。

5
收藏 / 生词本 / 错题词联动
实现难度：低 半米覆盖：✅ §3 三大来源 + §9 阅读联动

为什么核心：学习者必须能"把刚遇到的词当场抓住"。这是 Anki / Quizlet / 扇贝 / 墨墨 都默认有的功能，缺它产品没法用。

谁做得好：Readlang（点词即建卡）／LingQ（5 级 known 状态打标）／不背单词（阅读 + 听力词都进生词本）。

半米状态：三大来源（reading_lookup / reading_unknown / wrong_answer / manual / teacher / official / video / writing）已锁。这是半米最大的护城河之一 —— 8 种来源汇入同一个 SRS 池。

6
官方词库 / 应试词表选择
实现难度：低（内容工程） 半米覆盖：✅ §5 5 个官方词库

为什么核心：K12 学员要应试 —— 必须有"中考 / 高考 / 雅思 / 托福" 词表。这是中国市场区别于全球市场的必须项。

谁做得好：墨墨背单词（词书最全 几乎所有教材 + 真题）／百词斩（紧扣教材）／扇贝单词（真题例句）。

半米状态：5 个官方词库 V0.2 上线（小学+小升初 1500 / 中考 1600 / 高考 3500 / 雅思 5500 / 托福 8000）。版本化要求 §5 已锁。

7
每日上限 + 复习负债管理
实现难度：低 半米覆盖：✅ §8 已规划

为什么核心：Anki 的最大教训 —— 不限新词上限导致复习负债压垮学习者（最终弃用率 70%+）。墨墨用"两天不打卡复习量翻倍"被骂同样问题。

谁做得好：FSRS Helper 插件 / Lingvist（AI 强制每日上限） / Brainscape（confidence-based 自然节奏控制）。

半米状态：§8 已写每日新词 / 复习上限 + overdue 自动滚动 + backlog 高时停新词 + 老师端显示"复习负荷"。这是半米 vs 百词斩的关键差异之一。

8
视频 / 真实场景片段
实现难度：高（自建）/ 低（嵌入） 半米覆盖：✅ §4.5.3 三层方案

为什么核心：2024-2026 已经从"加分项"变成"中位线" —— Memrise / WordUp / 百词斩 / FluentU / 不背单词都有，半米必须跟上。

谁做得好：WordUp（25,000 词全挂电影例句）／FluentU（Netflix/YouTube 互动字幕）／YouGlish（数百万 YouTube 字幕索引）／PlayPhrase.me（AI 语音识别影视片段）。

半米状态：Layer 1 YouGlish iframe（V0.2 即上）／ Layer 2 自建 yt-dlp + Postgres FTS（V0.3+）／ Layer 3 影视片段（V0.4+ 谨慎）。详见第六章深挖。

✅ 评估结论：半米总纲已经覆盖 8 个核心功能中的 7.5 项（发音 / 跟读半覆盖）。剩下要补的是 F4 跟读评分 + 建议加 F9（游戏化 streak）+ F10（社群对战，可选）。

6.3 Layer 2：banmi 自建 YouTube 字幕索引（V0.3+）

(1) Pipeline 总览

1. yt-dlp 批量抓字幕（不下视频本体）
   ↓
2. 字幕 .vtt / .srt 解析成结构化 segment
   ↓
3. 写入 Postgres FTS / Elasticsearch
   (video_id + start_ts + end_ts + sentence + word_index + channel + license)
   ↓
4. 学生查词 → query 索引 → 返回片段列表（按相关度 / 频道质量 / 难度排序）
   ↓
5. 前端用 YouTube iframe ?start=120&end=128 自动播放对应片段
   (视频从 YouTube 直接拉流，banmi 不存视频本体)
   ↓
6. Redis 缓存热门查询结果

(2) yt-dlp 命令实战

抓单视频字幕（不下视频）：

yt-dlp --write-subs --sub-lang en --skip-download \
  --convert-subs srt \
  "https://www.youtube.com/watch?v=VIDEO_ID"

批量抓整个 TED 频道：

yt-dlp --write-subs --sub-lang en --skip-download \
  --convert-subs srt \
  --download-archive ted_archive.txt \
  -P "subtitles:./subs/ted/" \
  "https://www.youtube.com/@TED"

抓多语种（含 auto-generated）：

yt-dlp --write-subs --write-auto-subs --sub-langs "en.*" \
  --skip-download --convert-subs srt \
  "URL_OR_CHANNEL"

(3) Postgres FTS schema

CREATE TABLE subtitle_segment (
  id BIGSERIAL PRIMARY KEY,
  video_id TEXT NOT NULL,           -- YouTube video ID
  channel_id TEXT NOT NULL,
  channel_name TEXT NOT NULL,
  license TEXT NOT NULL,            -- 'CC-BY' / 'standard_youtube' / 'banmi_owned'
  start_ts REAL NOT NULL,           -- 秒
  end_ts REAL NOT NULL,
  sentence TEXT NOT NULL,
  lang TEXT NOT NULL DEFAULT 'en',
  cefr_estimated TEXT,              -- 后期可加 CEFR 估算
  search_vector TSVECTOR,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- GIN 索引（百万级行依然亚秒级查询）
CREATE INDEX idx_subseg_fts ON subtitle_segment USING GIN(search_vector);

ON subtitle_segment FOR EACH ROW EXECUTE FUNCTION
tsvector_update_trigger(search_vector, 'pg_catalog.english', sentence);

FROM subtitle_segment
WHERE search_vector @@ plainto_tsquery('english', $1)
  AND license IN ('CC-BY', 'banmi_owned')
ORDER BY ts_rank(search_vector, plainto_tsquery('english', $1)) DESC
LIMIT 20;

10FAQ for 阿杰（14 条）▼

Q1半米学员才 50 人，做这么完整的词汇系统值得吗？＋

值得，但定位要清晰。50 人不够养独立词汇 toC 产品，但作为半米 OS 的核心 vertical必须做完整 —— 词汇是"学语言"最高频的子任务，词汇系统决定了家长对"我把孩子放在半米学到底学什么"的认知。如果只做阅读不做词汇，家长会问"那我为什么不直接用墨墨 + 你们家阅读"。词汇 + 阅读 + 听力 + 写作 + 考试 5 件套绑定才是半米 OS 的价值密度。

Q2市面已经有百词斩 / 墨墨 / Anki，半米为什么不直接接入第三方？＋

同模考报告 Q5 同样的逻辑：数据闭环 + 体验一致 + 付费链路 三个都断了。但词汇系统更特别 —— 半米的核心是"阅读自然沉淀 → 复习池"，这条链路必须在自家闭环。如果学生在百词斩背的词跟在 banmi 阅读里碰到的词不互通，整个"reading-generated + official + unified pool" 架构就崩塌了。词汇必须自建，是半米架构的承重墙。

Q3最该补的 1 个功能是什么？＋

游戏化 streak + 周排行。总纲没明确这块，但所有头部产品（Duolingo / 沪江开心词场 / 百词斩 / Quizlet）都重金投入这个机制。对 K12 学员特别有效（小孩子争胜欲强 + 家长看到打卡数据高兴）。实现成本低（1-2 周）、retention 拉升明显（行业平均 +30%）、对老师 Dashboard 也有数据增量（"本周班级 streak 排行"）。Q-架构二 已锁双形态后，游戏化是下一个低悬果实。

Q4YouGlish 真的能直接嵌吗？版权 / 商业用途怎么算？＋

可以直接嵌，但要看商业属性。非商业教育用途免费（半米内测 / 学校内部用 OK），需保留"Powered by YouGlish.com" + YouTube ToS + Google Privacy 链接。一旦半米开始向家长收费，就进入"商业"档：500 reqs/天以下 €25/月，1 万 reqs/天 €300/月。临界点 €3600/年 ≈ Layer 2 自建 3 人月开发成本，到这个点就该启动 Layer 2 自建。本报告 6.2 节有完整 checklist。

Q55500 雅思词每个都要配精美图 + 短视频，成本扛得住吗？＋

扛得住，但必须模板化批量生产。AI 生图（Flux / Midjourney）单张约 $0.04-0.1，5500 词 ≈ ¥1500-3500；短视频用 TTS（Azure $4/M chars） + 动态字幕 + 简单动效（Remotion / FFmpeg），单条 30-60s 成本 ¥2-5，5500 条 ≈ ¥1.1-2.7 万。总内容生产成本 5 万以内，对内部学员产品完全可承担。关键是人工抽检关键词（每 100 词 Joy/Dong 抽 10 个），避免 AI 翻车。详见总纲 §4.5.1。

Q6FSRS 算法值得现在就上吗？还是 V0.2 用经验法则？＋

V0.1.5 / V0.2 用经验法则混合 SRS（半米 §8 已锁），V0.3+ 再上 FSRS。原因：① FSRS 需要每个学习者 ~1000 条复习记录才能拟合个性化曲线，V0.2 学员积累不到这个量；② 经验法则（day 1/2/4/7/15/30）已经能解决 80% 问题；③ FSRS 自研工程量大，可以等开源库 fsrs4anki 成熟后接入。路径：经验法则 → 收数据 → V0.3 升 FSRS，每步可独立验证。

Q7百词斩 SRS 弱被骂，半米怎么避坑？＋

百词斩被骂主要 2 点：① 反复错的词不会智能加大频次；② "背了不会用"。半米已经在架构层避坑：① §8 走 phase 9 统一池，复习按 SRS 调度而非顺序遍历，反复错的词必然抬升频次；② V0.2 题型 T2-T6 全套（中文选英 + collocation + 听音拼写 + 片段听辨）+ §9 阅读联动让"背的词在文章里真的遇到"，是真实运用。这两条焊死后，"百词斩坑"基本绕开。

Q8Layer 2 自建字幕索引真要做吗？还是永远停在 Layer 1？＋

要做，但触发条件明确。财务触发：YouGlish €300/月商业月费 × 12 ≈ €3600/年，等于 3 人月自建成本，到这个点必须切。内容触发：当半米 5500 雅思词词卡都希望"精挑细选 5-10 个高质量片段"而 YouGlish 排序不可控时，必须切。战略意义：Layer 2 让 banmi 拥有自己的"片段质量评级 + 频道偏好"算法，是真正的护城河。Layer 1 永远是别人的。

Q9影视片段 Layer 3 到底做不做？＋

V0.4+ 之前都不要做。版权风险大于收益。Joy/Dong 在国际学校体系内做生意，被影视版权方告一次就完蛋。替代路径：① 嵌 PlayPhrase iframe（让他们扛版权）；② OpenSubtitles 字幕 + 跳转 Netflix；③ banmi 自购 / 自录教学视频。"影视片段"对词汇学习的边际增益没有想象中大 —— Layer 1 + Layer 2 已经能给学生 80% 真实场景体验。

抄 Quizlet Class + 加 banmi 独门内容。Quizlet 给的：班级学员清单 / 学员完成度 / 错题集中区。banmi 加的：① 每个学员"阅读查词密度 vs 班级平均"；② 每个学员"已掌握 / 学习中 / 阅读已遇到 / 未遇到"分布（§4.5.5）；③ "本周 streak 排行"；④ "本周班级共同薄弱词" Top 10（系统聚合）；⑤ AI 出"教学建议"给老师参考（"3 个学员在 academic 动词反复错，建议精讲"）。第 5 条是 Quizlet 没有的，半米独门。

正面回应：学员只用阅读不背词 = 半米成功，不是失败。这恰恰是 banmi 架构的设计意图 —— context-rich 自然沉淀比孤立背词效率高。学员每天读 1 篇文章自动沉淀 5-10 个词，半年累积 1500-3000 词，已经覆盖中考 / 高考词库 80%。"主动背词库（V0.2 形态 B）"是给那些有明确应试目标的学员加速通道，不是必经路径。半米通过 Today 屏统一复习入口让两条路殊途同归。

Q12Joy / Dong 老师能接受这套词汇系统吗？＋

关键是让老师感觉"我给学生加分而不是被替代"。具体做法：① 老师 Dashboard 第一屏是"班级薄弱词 Top 10 + AI 出的教学建议" → 老师只需 review + 采纳 / 修改；② 老师可以一键标"这周班级重点词" → 自动进所有学员词汇本（teacher_assigned source）；③ 复习负荷可视化 —— 老师能看到"如果我布置 100 个词，下周复习会爆"；④ 第一周让 Joy 当超级用户做 PM，她吐槽什么就改什么。跟模考报告一样的思路。

Q13AI 生例句质量不稳怎么办？＋

Q-4 已锁多源混合（B + C + D）：词典数据库 + 真题语料 + AI 生成。优先级：① 阅读自然沉淀的原句（最高质量，来自 banmi 阅读材料库）；② 词典 collocation 数据库（Oxford / Collins / Cambridge 接 API 或买静态数据）；③ 真题语料（雅思剑桥真题电子版抓取 + 标注）；④ AI 生成（最后兜底）。每个词卡最少 2 个例句，至少 1 个来自前 3 类。AI 生的例句必须人工抽检 5-10% 才放出。
