01执行摘要 · 3 条核心结论 + 数据快照▼

一句话方案：半米词汇视频库选源不要在"哪家最好"里纠结 — 按 授权风险（绿/黄/红）× CEFR 难度（A1/A2/B1） 切两刀，落到 3×3 的九宫格里，每格选 1-2 家就完事。50 学员阶段先用 3 家全绿区频道，跑出 500 个高频词 × 视频例句的最小可用集；500 学员阶段再扩展到 8-10 家、混入黄区 iframe 嵌入；5000 学员阶段才考虑谈版权或自制。

🎯 三条核心结论

结论 1 · "先做哪 3 家"答案非常明确：CC Kids + SciShow Kids + VOA Learning English。前两家阿杰已经在做（scishow-kids-vocab / crashcourse-kids-vocab skill），把已经在做的事做透就是 50 学员阶段的正解，别贪多。VOA 是 PD 公共领域[1][2]，可以放心切片自托管 — 这是"自建视频词典"的安全底座。

结论 2 · Peppa Pig / Cocomelon / Ms Rachel 这种顶流 IP 只能 iframe 嵌入，不要试图下载切片自托管。Hasbro 旗下 Entertainment One 对 Peppa 商标 + 著作权执法非常激进（Wolfoo 案[8]）。商业 ESL 产品做下载剪辑会被 Content ID 自动识别 + 三振下号[13]。iframe 跳秒嵌入是被多个判例认可的合法路径（Seventh Circuit 判例：embed 不构成侵权）[14]。

结论 3 · Crash Course 主频道 / TED / TED-Ed / Veritasium 全部排除。John Green 主讲的 Crash Course 主频道公认"语速极快，需要 0.5-0.75 倍速才能跟"[10][11]，单视频 10-15 分钟塞满 C1+ 学术词汇。TED-Ed 受众 13-21 岁[15]、动画 4-7 分钟但词汇 B2+。这些是给母语者或高阶学习者的，跟半米 K12 ESL 受众完全不在一个频道上。注意：CC Kids（Sabrina Cruz 主讲）是另一回事，必收。

02阿杰需求拆解（4 维度 + 排除清单）▼

正式选频道之前，把"半米要什么"先翻译成可筛选的指标。阿杰原话是 4 条硬约束 — 我把每条都翻译成可量化的阈值。

🔴 明确排除清单（不在频道库里）

不要的频道类型：

  • Crash Course 主频道（John Green 主讲 / 180+ WPM / 学术词汇 / 17M 订阅[20]但受众 13-34 岁）[10][11]
  • TED / TED-Ed（受众 13-21 岁[15] / 平均 150+ WPM / B2-C1）
  • BBC News / CNN / Sky News（母语者向新闻 / 150+ WPM）
  • Veritasium / Vsauce / Kurzgesagt（C1+ 学术 / 复杂逻辑 / 长视频）
  • 纯 podcast 类（无视频，无法做"看口型 + 看场景"的多模态绑定）
  • 母语者向 vlog（如 Casey Neistat / Mr Beast — 非教学语境，俚语多）

💡 注意分清：CC Kids ≠ Crash Course 主频道

容易踩的坑：阿杰说"不要 Crash Course"指的是 John Green 主讲的主频道（@crashcourse，17M+ 订阅[20]）。但 Crash Course Kids（@crashcoursekids，Sabrina Cruz 主讲[5]）是 3-5 年级科学专向频道、语速明显放慢、词汇贴 NGSS 小学课标 — 必须收。阿杰自己的 crashcourse-kids-vocab skill 已经在用[19]。SciShow Kids 同理：SciShow 主频道是 8M+ 订阅[21]的通用科普，SciShow Kids（1.6M 订阅[22]）是低龄分支、Jessi Knudsen Castañeda 主讲[3]。

📐 半米和"通用 ESL 找频道"的差别

同样是给学英语找 YouTube 频道，半米跟"我自己想学英语找 channel"有三个本质区别：

  1. 不是给人看，是给词条建例句：词汇软件做"happy 这个词在视频里怎么说"，要的是 5-15 秒的句子级片段，不是 10 分钟讲一个 topic。所以场景的独立可截性比频道大小重要。
  2. 规模化，要词频覆盖：单个 highly viral 视频不如 500 个普通视频，因为后者能覆盖更多词汇。"频道存量"比"频道流量"重要。
  3. 商业产品身份：阿杰要做付费产品，不是个人学习。Fair Use 教育豁免对非营利 face-to-face课堂适用[23]，但对商业 SaaS 不适用 — 必须靠 iframe embed 或正经授权。

04A1 启蒙级频道深档（preschool / K-1）▼

A1 段都是给 2-6 岁孩子看的，语速最慢、词汇最简。这一段在半米里主要服务"零基础新手村"或"K-1 学员"。合规上几乎全是黄区 — 商业大 IP 主导，必须 iframe 嵌入。

🔍 A1 段总结

A1 段半米能用 3-5 家就够：Sesame Workshop（绿区，2026 内容暴增）+ Peppa Pig（黄区 iframe 嵌入）+ Super Simple Songs（黄区，歌曲补充）+ 可选 Ms Rachel（First Words 段最强）+ 可选 Bluey（家庭对话）。Cocomelon / Pinkfong / 童谣类不优先 — 它们订阅高但词条贡献度不如对话类。

05A2 小学级频道深档（primary K-3 / 半米最重要的一档）▼

这一段是半米词汇库的核心阵地 — 国际学校 K12 主体在 G3-G6，对应 CEFR A2-B1，词汇 1000-2000 词，需要"能讲故事讲科学但说话不复杂"的频道。SciShow Kids + CC Kids 是金牌组合。

🎬 切片可行性评估

切片可行性 = 能否把视频按字幕行切成 5-15 秒的独立可懂片段。三个关键指标：

  1. 句子完整度：一句话能不能在 5-15 秒内说完，且不依赖前一句。教学频道（SciShow Kids / BBC LE / VOA）几乎每句独立；剧情类（Peppa Pig / Bluey）很多句要前一句铺垫。
  2. 视觉独立性：截下来 5-15 秒画面学员能不能理解。教学频道靠主讲人 + 板书，独立性强；剧情类靠场景上下文，独立性弱。
  3. 时间戳精度：YouTube 官方字幕通常精确到秒，但word-level 精度需要 yt-dlp 的 SRV2 格式才有[60]。

切片可行性最佳 5 家（半米词汇库优先抓字幕的频道）：
1. SciShow Kids — 主讲人每句独立、可视化插图、每集 30-50 个可切片
2. VOA Learning English — 慢速 + 教学结构、每句完整
3. BBC Learning English — 每集围绕一个语言点、句句教学独立
4. Easy English Brighton — 每个被采访者 30 秒就是一片
5. English Singsing — 结构化重复，每句明显独立

10版权 + CC 协议状况（绿/黄/红 三区）▼

读这一章先认清两个事实：（1）美国合理使用（Fair Use）的"教育豁免"对非营利 face-to-face 课堂适用[23]，但商业 SaaS 不适用。半米作为付费产品不能直接套教育豁免。（2）iframe 嵌入是被多个判例认可的合法路径[14] — Seventh Circuit 明确 "embedding YouTube videos is not copyright infringement"。所以"半米能不能用 X 频道"99% 的答案是嵌入永远可以，下载切片自托管要看版权区。

🟢 绿区（可下载 + 可切片 + 可自托管）

1. VOA Learning English（PD 公共领域）[1][2]
美国政府作品，17 USC §105 自动 PD。下载、切片、自托管、重新发布、不需要 attribution — 零风险。半米的"自建视频词典"安全底座。

2. PBS Kids（部分） · Sesame Workshop（教育非营利）[6][7]
非营利公共广播 / 非营利教育组织，教育用例宽松。iframe 嵌入完全 OK。下载切片自托管走教育合理使用空间，商业产品引用上下文要谨慎（建议先以 iframe 为主）。

3. SciShow Kids / Crash Course Kids / Free School（教育资助 / 非营利感强）[3][5][24]
Complexly + PBS Digital 等教育资助渠道，频道方明示鼓励教育使用。iframe 嵌入零风险，小规模切片做教学例句业内默认 OK，但半米作为商业 SaaS 要警惕规模化 — 单视频几十帧 OK，下载整集做镜像就不行。

4. YouTube CC BY 滤镜下的视频[61][62]
YouTube 高级搜索可以筛 Creative Commons 标识的视频，全平台 CC BY 视频约 400 万条[62]。下载 + 改 + 商用都行，只需注明来源。但儿童 ESL 主流频道几乎都不标 CC BY（卡通版权宝贵），所以这条对半米实操意义有限。

🟡 黄区（iframe 永远 OK，下载切片有 Content ID 风险）

1. 商业大 IP：Peppa Pig（Hasbro / Entertainment One）[8]、Cocomelon、Pinkfong / Baby Shark、Ms Rachel（已签 Netflix）[26]、Bluey（Disney+/ABC）、Numberblocks（BBC/CBeebies）[34]。
Hasbro/Entertainment One 对未授权使用执法激进（Wolfoo 案[8]）。半米策略：iframe 嵌入 + 时间戳跳秒，绝不下载切片自托管。

2. ESL 教学独立 IP：BBC Learning English（BBC）[37]、Steve & Maggie（Wattsenglish）[30]、English Singsing[9]、English Tree TV、Super Simple Songs、Easy English（Patreon 自营）[38]、Maple Leaf Learning、Smile and Learn、Storyline Online（SAG-AFTRA 非营利）[35]、British Council、Oxford Online English。
正规商业频道，授权流程清晰但严格。iframe 嵌入 OK，部分（特别是 Storyline Online / British Council）通过邮件商讨教育许可有谈成空间。

🔴 红区（不适合半米受众或半米法律身份）

1. 词汇 / 语速 / 受众错位的：Crash Course 主[10][20]、TED-Ed[15]、Veritasium、Vsauce、BBC News、English with Lucy（B2+ 成人）[43]、mmmEnglish[44]。
语速太快、词汇太深、受众错。

2. CC BY-NC-SA 的 NC 条款挡商业：Khan Academy / Khan Academy Kids[55] 的 NC（非商业）条款让半米作为商业 SaaS 嵌入有合规风险。建议仅作个人学习参考、不入产品库。

📚 实操：YouTube Content ID 与 Fair Use 边界

Content ID 机制：YouTube 自动扫描你上传的视频，发现你用了 IP 持有人备案过的素材就自动 claim[13]。三次 strike 在 90 天内 = 频道终结 + 所有视频删除[63]。所以"我下载 Peppa Pig 切片放到自家网站"理论上不会被 YouTube Content ID 立刻干掉（Content ID 只管 YouTube 内的二次上传），但Entertainment One 可以发 DMCA takedown，半米的服务器商会被迫下架。

Fair Use 四要素对半米的实操判断[23][13]：

  1. 使用性质：商业 vs 非营利 — 半米商业，对 Fair Use 不利
  2. 原作性质：事实 vs 创意 — Peppa Pig 是创意作品，对 Fair Use 不利
  3. 使用比例：5-15 秒一句台词 / 4-5 分钟整集 = 极小比例，对 Fair Use 有利
  4. 对原作市场影响：词典查询不替代看动画，对 Fair Use 中性偏利

四要素综合：商业身份是半米合理使用的最大软肋，所以策略只能是"iframe 嵌入避免下载 + 切片小段控制比例 + 黄区慎重 + 绿区主力"。

11词汇匹配可用度评估（A2-B1 高频 3000 词覆盖率）▼

半米词汇库的核心 KPI：A2-B1 3000 高频词 × 每词至少 2-3 个视频例句。前 5 家频道能覆盖多少？

🎯 目标词表锚定

建议用 Oxford 3000 by CEFR Level[16]作为半米词库底版：

  • A1-A2 段：约 1500 词（覆盖大约 70-75% 文本）
  • B1 段：约 2000 词（覆盖约 80% 文本）[16]
  • B2 段：约 3000 词（覆盖约 85% 文本）

具体说："Oxford 3000 + B1 学员词汇约 2000 词"，这是公认基线。语料库统计：3000 高频词足以理解 80-85% 日常英语文本[16]。

⚠️ 另一个视角（第二轮调研）：SciShow Kids / CC Kids 虽然标注 Grades 1-3，但科学概念密度其实比普通 ESL 频道高，常有专有名词（光合作用 / 牛顿三定律 / 火星探测器）和因果解释长句。建议字幕入库时跑 Ch9 末尾的字幕句子级阈值表，筛掉句长 > 16 tokens / 未知词密度 > 1 / 含专有名词的句子。不是说要换频道，而是要在频道内做精选。VOA 因为本身是 ESL 教学定位，句子级过滤后留存率会比 SciShow 高得多。

🔧 全流程（5 步）

  1. 拉字幕：yt-dlp --skip-download --write-subs --sub-langs en --sub-format vtt[60]。优先官方字幕，没有再 auto-sub。
  2. 分级筛选：用 VocabKitchen CEFR Profiler 给每个频道整体打分[64] — 确认是 A2 还是 B1。
  3. 入索引：SQLite FTS5（参考 subtitle-search-engine-research.html），每条 (channel, video_id, start_ms, end_ms, text)。
  4. 视频展示：iframe 嵌入 https://www.youtube.com/embed/{video_id}?start={seconds}&end={seconds+15} 直接跳秒。半米用户不用看广告外挂层，跨设备友好。

15FAQ · 12 个最关键问题▼

Q为什么排除 Crash Course 但包括 Crash Course Kids？+
完全是两个频道。Crash Course 主（@crashcourse，17M 订阅[20]）是 John Green 主讲，公认语速极快（学生要 0.5-0.75 倍速才能跟[11]）、词汇 B2-C1、受众 13-34 岁、10-15 分钟视频塞满学术词。Crash Course Kids（@crashcoursekids，Sabrina Cruz 主讲[5]）是 Complexly 同一公司 2015 年专为 3-5 年级小学生做的科学频道，语速明显放慢，词汇 NGSS 课标对齐，~50 集完结，A2-B1 适配。阿杰说"不要 Crash Course"指的是前者，Kids 版必收且阿杰已有 crashcourse-kids-vocab skill。
QVOA Learning English 慢速到什么程度？+
VOA Learning English 明确比正常 VOA 慢 1/3[1]，估算 90-100 WPM（正常英语对话 130-150 WPM）。核心词汇 1500 词、刻意避免习语。Let's Learn English Level 1 是 A2 段、Level 2 是 B1-B2 段。除了慢速本身，VOA 的最大杀手锏是公共领域 PD（美国政府作品 17 USC §105）[2]：可以下载、切片、自托管、商用、不需注明来源。半米作为商业 SaaS 这是最安全的内容池。
QEasy English 街头采访适合做词汇库吗？+
非常适合 B1 段。Easy English[38]（@EasyEnglishVideos，Mitch + Isi 主持，Brighton 起家）是 Easy Languages 全球项目的英国分支，街头采访 + 实时双语字幕。三个独特价值：(1) 真实自然口语 — 填充词（well, you know, kind of）、犹豫、自我修正这些在教学频道几乎没有；(2) 双语字幕给跨语言对齐近 0 成本（半米可以直接拿到中英对照）；(3) 每段独立性强 — 每个被采访者就是 30 秒一片，切片可行性极佳。缺点：街头噪音环境下自动字幕准确率会降到 75-85%[12]，要校对一遍。
QTED-Ed 的 lesson 部分可以用吗？+
不建议。TED-Ed[15] 受众 13-21 岁、动画做得极好、4-7 分钟一集 — 看起来很像半米想要的。但词汇 B2-C1（一集 4 分钟塞满学术词）+ 语速 ~150 WPM，跟半米核心 K12 ESL 学员（A2-B1）不匹配。例外：如果半米将来开发"高阶 / 出国冲刺 / B2+ 学员"产品线，TED-Ed 是合理选项。但当前阶段（50 学员 / A2-B1 主体）不应入库。
QPeppa Pig 版权能用于商业产品吗？+
iframe 嵌入完全 OK，下载切片有显著风险。Peppa Pig 版权归 Hasbro 旗下 Entertainment One（2019 收购，38 亿美元）[8]，eOne 对未授权使用执法非常激进 — Wolfoo 案是个标志案例。半米策略：用 YouTube 官方 iframe 嵌入 + 时间戳跳秒（Seventh Circuit 判例认可[14]），不下载、不重新发布。如果一定要下载切片，必须邮件联系 Hasbro/eOne 谈正式教育许可（年费起步预估 ¥10-50 万）。半米 5000 学员阶段以前不必碰这条路。
QEnglish Singsing 是韩国制的，用 AmE 没问题吗？+
没问题。English Singsing[9] 虽然是韩国体系（Genki English 延伸），但配音用美式中性英语，听不出韩式口音 — 韩国 ESL 教材出口产业链非常成熟，专业配音员是英美母语者。它的最大优势是"为非母语者设计的英语"：每段视频明确围绕一个语言点，字幕清晰，每句重复至少 2 遍，1710 视频规模够大。对半米国际学校 K12 学员，相比于纯母语者制作的频道，这种"设计感"的内容反而更贴。
QBluey 的澳式口音对半米学员不好吧？+
看半米的产品定位。如果学员主要应对托福 / 美式国际学校 → AusE 是噪音，少用；如果学员主要应对雅思 / 英式国际学校 → AusE 是有益的多样性补充。Bluey[33] 最大价值是家庭日常对话最自然（言语习得研究案例）[50] — Peppa Pig 偏教学化的"标准句"，Bluey 偏"真家庭怎么说"。半米可以把 Bluey 标 accent=AusE 给愿意听的学员一个选项，但不应作为词条默认例句。
QEnglish with Lucy 11.6M 订阅这么大，为啥排除？+
Lucy Earl[43] 是给成人 ESL 学习者的英式英语博主，受众主体是 18-35 岁打算应对剑桥 / 雅思 / 留学的非母语成人。词汇 B2-C1（俚语、商务、抽象表达多）、语速正常 ~135 WPM、内容偏文化解读 + 高级语法。半米核心 K12 受众（小学到初中）撑不住这个难度。如果将来半米开"高阶产品线"或"出国冲刺包"，可以重新考虑她。同理 mmmEnglish (Emma)[44]、engVid 系（Ronnie / Adam / Alex）全是成人 ESL 向，先排除。
QYouTube auto-caption 准确率到底够不够？+
分场景：(1) 清晰录音棚 + 单一英语母语主讲（SciShow Kids / CC Kids / VOA / BBC LE）→ 90-95% 准确率[12]，半米可以直接用；(2) 多人对话 + 口音 + 环境音（Easy English 街头 / Bluey / Peppa Pig 多角色）→ 75-85%，要人工校对一遍；(3) 歌曲（Super Simple Songs / Pinkfong）→ ASR 经常错歌词，建议拉官方歌词字幕。替代方案：本地跑 Whisper.cpp large-v3-turbo（Mac M2 上 10 倍实时[60]），可以把清晰内容打到 95-98%。
Q中国本土做的英语启蒙 YouTube 账号要不要收？+
不优先。原因：(1) 内地"启蒙号"主体在抖音 / 小红书 / 微信视频号，YouTube 镜像账号普遍只有海外华人观看，量级小；(2) 本土 ESL 启蒙号经常有"中式英语口音"问题，对国际学校学员是反向输入；(3) 词汇覆盖与海外大频道高度重合，没有差异化价值。例外：English Singsing[9]（韩国制，AmE 标准发音）和 Smile and Learn[36]（西班牙制，多语言版本）是"非西方但发音中性"的代表，已纳入候选。
QKhan Academy Kids 看着也是非盈利，为啥不优先？+
Khan Academy 内容用 CC BY-NC-SA 协议（非商业 + 同条款共享 + 注明来源），NC 条款挡住了半米作为商业 SaaS 直接引用[55]。半米要用必须先邮件联系 Khan Academy 获取商业使用豁免（理论上可能因半米的"教育"属性获批，但流程不确定）。同样问题：所有 CC BY-NC 协议的视频对商业 SaaS 都不友好。同理：vimeo / archive.org 上很多教育视频是 CC BY-NC，半米要先看协议。安全做法：先邮件谈，落到书面授权再入库。
Q阿杰下周该做的具体下一步是啥？+
3 件事：(1) 把 scishow-kids-vocab + crashcourse-kids-vocab 两个 skill 跑到 90% 完成度（已经在做的事先做透）；(2) 新建 voa-learning-english-vocab skill — VOA Let's Learn English Level 1 一共 30 集左右，一个周末可以全部拉字幕 + 入库 + 切片自托管，这是验证"自建视频词典"自托管路径的关键试点；(3) 给 Mission Control 加个任务"评估前 3 家频道 Oxford 3000 实际覆盖率"，跑 VocabKitchen Profiler[64] 拿真数据。完成后再决定阶段 2 的扩展节奏。
